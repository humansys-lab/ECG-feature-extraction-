# 簡潔な12誘導ECG診断参照

この参照は仮説の立案のみをサポートします。患者固有の結論は、現在の測定で取得されたecgfeat測定値から確立する必要があります。

<a id="systematic-interpretation"></a>
## 体系的解釈

技術的品質、心拍数、リズム、心房活動、房室関連、PR/QRS/QT間隔、軸、伝導、期外収縮、心室/電圧パターン、Q波、R波の進行、ST-T-Uの形態およびペースメーキングをレビューします。心拍数の表現型をリズムのメカニズムから分離してください。

<a id="rhythm-and-atrial-mechanisms"></a>
## リズムと心房メカニズム

洞性メカニズムには、互換性のあるP波の形態とP-QRS関連を持つ組織化された心房の活性化が必要です。徐脈または頻脈のみでは洞性起源は確立されません。心房細動には、不規則な心室応答と一貫した組織化されたP波の欠如が必要です。1つの検出器チェーンからの候補細動波フィールドは、独立した確認ではありません。心房粗動には、クロスリードのサポートと互換性のある房室関係を持つ、繰り返される組織化された心房活動が必要です。候補心房イベントの数は、局所的な心房脱分極なしに房室伝導比に変換されてはいけません。

<a id="av-and-intraventricular-conduction"></a>
## 房室および心室内伝導

第1度房室ブロックには、報告可能な延長したPR間隔と安定した1対1の房室伝導が必要です。高度房室ブロックには、繰り返される信頼性の高い非伝導心房イベントと再現可能な順次伝導パターンが必要です。単一の検出器イベントでは不十分です。束枝ブロックおよび小枝ブロックには、互換性のあるQRSの持続時間と診断的なクロスリードの形態の両方が必要です。広範なQRSのみは、ペースメーキングと前興奮を考慮した後、非特異的な伝導表現型のみをサポートします。

<a id="pre-excitation-and-ectopy"></a>
## 前興奮と期外収縮

心室前興奮には、独立したPR短縮の証拠と、リード間で互換性のあるデルタ/QRS開始の形態が必要です。デルタ候補のみでは不十分です。期外収縮には、ビートタイミングにおける真の早期性、互換性のある期外収縮の形態、および代表的または繰り返されるサポートが必要です。単一の非支配的形態グループは、アーティファクトまたは外れ値である可能性があります。

<a id="voltage-ischemia-and-repolarization"></a>
## 電圧、虚血および再分極

電圧基準は測定されたECG表現型であり、解剖学的肥厚の証明ではありません。心室ペースメーキングまたは顕著なQRSの広がりがある場合、慎重に解釈するか、全く解釈しないでください。STおよびT波の結論には、信頼性の高いクロスリードの分布と、二次的なQRS原因のレビューが必要です。Q波と異常なR波の進行には、連続するリードにわたる固有ビートの確認と、リード配置および伝導の交絡因子のレビューが必要です。

<a id="interval-interpretation"></a>
## 間隔の解釈

定義レベルの間隔結論には、報告可能なQT/QTcおよびPR測定値のみを使用してください。間隔が利用できない場合は、その構成波形をレビューします：PRについてはP波の可視性と房室関連、QTについてはT/Uの形態と終点の信頼性。欠落している間隔は、疾患を確認することも除外することもできません。
