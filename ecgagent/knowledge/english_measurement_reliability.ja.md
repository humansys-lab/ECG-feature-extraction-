# ECG 測定信頼性リファレンス

このリファレンスは、ecgfeat 観測値にどのように重みをつけるかを説明するものであり、患者の証拠ではありません。

<a id="evidence-hierarchy"></a>
## 証拠の階層

報告可能なグローバル値と安定した反復観測値を優先します。次に、独立して裏付けられたクロスリードまたはクロスビートの形態を使用します。検出サマリーと候補イベントストリームは、調査のきっかけとして扱います。利用できない、曖昧な、または検証されていない観測値では診断を確定できません。

<a id="representative-beats-and-morphology-groups"></a>
## Representative beat と形態グループ

representative beat は、必ずしも記録全体ではなく、1つの形態ファミリーを記述します。その形態を記録に適用する前に、グループの有病率、メンバー数、最長ラン、テンプレートの安定性、および外れ値を確認します。1つのビートによって導かれた結論は、別のビートで再現されるか、格下げされるべきです。

<a id="p-wave-boundaries"></a>
## P波境界

承認されたP波抽出でも、T/Aの曖昧さが残る場合があります。開始と終了の信頼度、有効なリードのサポート、反復されたクリーンな境界、および安定した形態クラスターを使用します。複数のソースリードがリストされている場合でも、1つのストリームからの候補心房イベント行は独立した観測値ではありません。

<a id="st-t-u-and-interval-endpoints"></a>
## ST-T-U と間隔の端点

ST変化は、測定が信頼でき、一貫した連続リード分布を形成している場合にのみ解釈します。T波については、極性、振幅、対称性、T波信号の品質、および対向リードを確認します。QT/QTc には信頼できるT波端点が必要です。フォールバック端点は抽出パスであり、平坦、融合、または異常なT波の証明ではありません。

<a id="pacing-and-native-beats"></a>
## ペーシングと自然ビート

スパイク検出、スパイクからQRSへのマッチング、ペーシングビートフラグ、およびペーシング由来の形態は、1つのアルゴリズムチェーンに属する可能性があります。競合のないマーカータイミングと互換性のある反復形態でペーシングを確認します。ペーシングが疑われる場合は、利用可能な限り、梗塞と再分極のレビューに自然な非ペーシングビートを使用します。

<a id="reliability-language"></a>
## 信頼性の言語

信頼性フラグは証拠の重みを下げますが、測定値を消去するものではありません。同じ主張内で制限を明記し、独立した裏付けを求め、結論がその測定に実質的に依存している場合は信頼度を下げます。
