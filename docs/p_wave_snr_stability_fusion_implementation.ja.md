# P 波局所 SNR、境界安定性、および堅牢な融合変換

生成時間: 2026-07-28

<a id="改造范围"></a>
## 変換スコープ

この変換では、既存の P 候補、生/修正/コンセンサスの 3 層境界、およびダウンストリーム出力が維持されます。
互換性があり、次の決定論的な DSP 証拠が追加されました。

1. 最終 P 候補のゼロ位相 `35 Hz` ローパス検出ビューを生成します。振幅、面積、形態
   元の測定信号を引き続き使用します。
2. ビートごとに前のビートの T オフセットによって検証された TP クワイエット ウィンドウからローカル ノイズを推定します。 PR/PQ
   Ta が含まれており、ノイズ ウィンドウとしては使用されません。以前の T 波コンテキストが不明であるため、最初の拍動の P 前のフォールバックが明確にマークされます。
   出力:
   - `p_local_noise_rms_mv`
   - `p_local_noise_source`
   - `p_local_snr`
   - `p_informative`
   - `p_tp_gap_ms`
   - `p_quiet_window_available`
   - `p_on_t_overlap_risk`
   - `p_ta_overlap_risk`
   - `p_baseline_method`
   - `p_baseline_confidence`
3. ローパス P ビューでタンジェントを `4%、6%、8%、10%、12%` しきい値境界と比較します。
   MAD で構築:
   - `p_onset_sigma_ms`
   - `p_offset_sigma_ms`
   - `p_boundary_stability_method`
4. ローカル SNR/安定性の証拠を持つ少なくとも 4 つのリードが有効なクラスターを形成する場合:
   - 開始では 2 番目に古い境界を使用します。
   -offset は 2 番目の夜の境界を使用します。
5. 保護された早期オンセットにより、すべてのオフセットが P-duration の幾何学的制約に違反する場合は、フォールバックします。
   完全な境界カバレッジの減少を避けるため、クラスター中央値を使用します。
6. 候補マーカー `p_isoelectric_uninformative` は `2 sigma` よりも低い。高い信頼性では参加しません
   逐次統計ですが、十分な高品質のリードがない場合は、古い信頼性の低いクラスターのフォールバックに戻る可能性があります。
7. 高心拍数で TP が不十分な場合、スプリアスローカル SNR は計算されません。コードは P 候補の両側にのみ適合します
   診断ビューとしての継続的なロバスト二次トレンド、`0.45` で境界信頼度を制限し、禁止
   2 番目に古い/2 番目に新しい融合。トレンドは元の P 範囲をカバーしません。
8. Ta リスクはオフセットの信頼度のみに基づいて作用します。 P の存在信頼度は、Ta/no TP の影響を受けません。
   「P が見える」ことと「等電位境界が確実に決定できない」ことを直接区別することが明確になります。

<a id="ta-高心率无-tp-防护追加改造"></a>
## Ta / TP 保護追加修正なしの高心拍数

Ta および P-on-T の生理学的識別不可能性に対して、次の保護が追加されました。

1. PR/PQ セグメントは、P ローカル ノイズ候補セットから完全に外れます。後続のショットでは、前のショットの T オフセットのみに到達します。
   マーキング前に、このビートの開始の間のガード後に少なくとも `16 ms` データを残してください
   `p_quiet_window_available=True`。
2. TP が不十分な場合 (`p_local_snr=None`)、低ノイズ証拠を偽造しないでください。両側にP側波帯を使用する
   連続ロバスト二次トレンドをフィッティング、安定性ビューのみ、ベースライン信頼度は `0.25` です。
3. `p_tp_gap_ms <30 ms` マーク `p_on_t_overlap_risk`、オンセット/オフセット信頼度
   上限は`0.45`で、2番目に古い/2番目に新しい極値融合を無効にします。
4. 検証済みの TP ベースラインがある場合にのみ、P の背後の PR 領域をチェックして、P と反対の極性の兆候と少なくとも 100 の振幅を確認します。
   `max(10 uV, 2 sigma_noise)` の Ta 的な小旅行。ヒット時のオフセットを個別に下げる
   自信、クリアされていない P 存在の信頼。
5. 極値融合が無効になった後、異なるリード サブセットが無効なグローバル ジオメトリを形成する場合、同じバッチのみの使用が許可されます。
   有効リードのオンセット/オフセット**ペアごとの中央値**は、極値統計ではなくカバレッジを復元します。
6. QRST 残差の ST-T 減算により、ビート間の時間シフト、ロバストな振幅/バイアス適応、およびコサイン シームが追加されます。
   テーパーおよび二次差動高周波エネルギー ゲート。中央値 RR における残りのパス `<520 ms`
   次回テンプレートがPエリアに侵入するのを避けるために直接使用することはできません。

セキュリティ ゲーティングは、約 `-15 ms` の既存の P-duration の体系的な縮小には対応していません。その利益は主に
Ta/T テールを「静かなベースライン」として使用することを避け、完全な境界カバレッジを向上させます。ビートレベルの開始、
オフセットと持続時間の SD/MAE はわずかに低下しており、新しいペアごとの中央値フォールバックを示しています。
困難なサンプルの対象範囲を拡大。これらの困難なサンプルは、継続的な検証のために独立した高心拍数/Ta アノテーション セットに依存する必要があります。
