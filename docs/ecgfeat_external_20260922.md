# ECG 新增外部数据集评估（2026-09-22）

本轮接入 ISP v2、BUT PDB 1.0.0、NSTDB 1.0.0，评价既有默认算法及传统信号处理候选。没有训练、深度学习、权重下载或根据新数据调整算法阈值。生产提取器未修改；准确性候选仍默认关闭。

## 数据与评估口径

| 数据集 | 本次范围 | 可以回答的问题 |
|---|---|---|
| [ISP v2](https://zenodo.org/records/14679837) | 475 条十二导联、1000 Hz；官方 train 403 / test 72 分开报告 | P/QRS/T 区间检出、分割重叠及起止点定位 |
| [BUT PDB](https://physionet.org/content/but-pdb/1.0.0/) | 50 条双导联、约 120 秒；360/128 Hz | 病理 P 峰检出与定位、误检，QRS 检出 |
| [NSTDB](https://physionet.org/content/nstdb/1.0.0/) | 12 条双导联、每条 650000 样本 / 360 Hz | 电极运动噪声下 QRS 的退化曲线 |

ISP 只发布一套整合区间标注，不能把同一标签重复到十二导联后声称有十二倍独立样本。主指标使用每搏各导联有效 native 起止点的中位数形成评估用共识区间；II 导联作为次级结果，两个口径分别统计。这是评估适配层，不是新增生产融合算法。区间一对一匹配要求 IoU ≥ 0.5，先最大化匹配数，再最大化总 IoU；同时报告全时段逐样本 Dice，未匹配区间保留为 FP/FN。ISP 没有峰值真值，不报告伪造的“峰值误差”。MAE/P95 仅在匹配且边界已知的事件上计算，必须连同覆盖率阅读，不能直接与 LUDB/QTDB 的峰值容差协议比较。

BUT P 峰主容差为 150 ms，同时固定报告更严格的 50 ms；BUT/NSTDB QRS 容差为 75 ms。匹配沿用现有最大匹配数、最小总峰值距离的动态规划，长记录按无可跨越匹配边的独立分量分解，避免全记录平方级内存。完整记录均纳入评分，不按“有标注 P 的时间范围”裁剪，因此无 P 时段的误检不会消失。

所有输入统一在提取器内部以 500 Hz 运行，输出按真实采样率映射回源样本。ISP 工频 50 Hz，来自美国原始数据库的 BUT/NSTDB 为 60 Hz。双导联信号分别放入 II/V2 适配槽，其余槽位为零，不合成导联；槽名不代表已知解剖导联。长记录每 30 秒计分，两侧最多 2 秒上下文，过短尾段并入前窗；每个预测只归属一个核心窗。NSTDB 先整条匹配，再按参考时刻分配 TP/FN、预测时刻分配 FP 到干净/带噪时段。

**双导联结果检验检测内核，不验证十二导联轴、诊断或整份报告。** 空缺的十个导联会影响十二导联完整性门控，严格门控后输出另作补充分析。native P 误检不等同最终临床诊断误报。

## 标注与幅值审计

- ISP：实际 5105 个 P、5948 个 QRS、5652 个有效 T 区间。`train/150`、`train/388` 的最后一个 T 终点为 11000，超过记录长度；可见区间裁剪用于 IoU/Dice，但终点按删失处理，不计 offset MAE。`test/58` 一个零长度 T 区间排除并保留审计记录，其余区间保留。终点等于信号长度按右开区间边界解释。
- ISP 的 `mkv` 按微伏转换为 mV；标准导联按头文件名称重排，没有凭幅值动态调节增益。
- BUT：`.pwave` 实际包含 5431 个条目，其中记录 08、48 的 `-1` 是无 P 哨兵，因此有效峰为 **5429**；网页介绍为 5437，文件与介绍存在差异。评分分母以校验后的文件为准。
- BUT：`.qrs` 共 7638 个条目，其中 66 个 `!` 为心室扑动波标记，本次标准 QRS beat 指标不计这些标记，故分母 **7572**；保留全部排除位置。这一口径不等同于直接将文件全部条目视作 QRS 的比较。
- BUT 头文件含不规范的字面 `\\muV`。WFDB 按 gain/baseline 读取为 mV 后，记录 01 与原始 MIT-BIH 231 对应段最大差约 **0.00002594 mV**、两导联相关系数均 >0.99999999，确认尺度。README 的源截取位置采用一基索引；此次波形核对用零基 30159 对齐，不平移 BUT 自身 WFDB 标注。[核验数据](../ecgfeat_external_20260922/unit_audit.json)
- NSTDB 现成 ECG 加入的是 **电极运动噪声**，不能把成绩称为同时覆盖肌电和基线漂移。12 条只有原始记录 118、119 两个来源，不是十二个独立受试者；BUT 也有重复源记录，且部分与 NSTDB、QTDB 的 MIT-BIH 来源重叠。

每套主实验保存固定记录清单、源码及数据 SHA256、协议、逐记录失败、逐事件误差。下载采用上游 SHA256；ISP 压缩包核对 Zenodo 公布的 MD5，并记录本地 SHA256。提取失败窗口保留标注分母，按无预测评分。

## ISP：官方测试分区 72 条

主表为默认算法的评估用多导联中位数区间；误差单位 ms，匹配条件 IoU ≥ 0.5。

| 波段 | TP / FP / FN | 区间 F1 | 样本 Dice | onset MAE | offset MAE | onset / offset P95 |
|---|---|---:|---:|---:|---:|---:|
| P | 652 / 184 / 141 | 80.049% | 68.468% | 17.917 | 18.104 | 40 / 40 |
| QRS | 865 / 10 / 35 | 97.465% | 82.465% | 17.003 | 13.784 | 28 / 32 |
| T | 810 / 65 / 54 | 93.157% | 85.807% | 19.596 | 15.907 | 52 / 42 |

P 的样本 Dice 明显低于 QRS/T，仍是波段检测与边界覆盖的主要短板。QRS 虽有较高区间 F1，其 Dice 仍只有约 82.5%；命中一个波段不代表完整边界准确。训练分区只作分布补充：403 条默认 P/QRS/T 区间 F1 分别约 80.92%/97.30%/90.06%，没有用这些标注训练或重新调参。

| 测试集 T 终点候选 | 匹配数 | 区间 F1 | offset MAE | offset P95 | 共同事件的记录平均 MAE 差值 95% 区间 |
|---|---:|---:|---:|---:|---|
| 默认 | 810 | 93.157% | 15.907 | 42 | — |
| 仅终点投影 | 808 | 92.927% | 15.623 | 42 | [−0.505, +0.323] ms |
| 仅终点序列选择 | 810 | 93.157% | 15.806 | 42 | [−0.186, −0.009] ms |
| 两项组合 | 808 | 92.927% | 15.610 | 42 | [−0.505, +0.315] ms |

仅终点序列选择的方向较稳定，但实际改善仅约 **0.10 ms**，P95 不变；记录平均改善约 0.091 ms，71 条有共同评分的记录中 11 条改善、7 条变差、53 条不变。置信区间按记录 bootstrap 5000 次，未作多候选校正，也不是患者级独立性的保证。

投影/组合均少匹配两个 T，不能凭较低条件 MAE 判为整体提升。投影在 train 分区还将共同事件的记录平均 MAE 增加约 0.090 ms。相量 P 在 ISP 测试主口径下未改变区间 F1、匹配起止点 MAE，仅样本 Dice 有极小变化。当前没有足够收益支持将这些候选默认打开。

最终异常复核还发现投影的后续影响：`train/324` 第 0 搏 V5 的 native T 起点由内部样本 221 变为 233，峰仍为 226、终点变为空；`train/343` 第 16 搏 III 的缺失终点变为有效。这会改变参与评估共识的导联集合。前者甚至出现起点晚于峰值，说明仅终点候选的局部修改承诺不等于整个后处理链的最终不变量；候选在启用前还需补全边界有效性与传播回归检查。本轮仅记录问题，未根据测试数据改生产算法。[逐导联复核](../ecgfeat_external_20260922/isp_consensus_probe.json)

## BUT PDB：病理 P 波结果

| 输出 / 容差 | TP / FP / FN | 召回率 | 精确率 | F1 | 匹配峰 MAE |
|---|---|---:|---:|---:|---:|
| 默认 native P / 150 ms | 4547 / 1296 / 882 | 83.754% | 77.820% | 80.678% | 33.150 ms |
| 相量候选 P / 150 ms | 4554 / 1289 / 875 | 83.883% | 77.939% | 80.802% | 32.731 ms |
| 默认 native P / 50 ms | 3401 / 2442 / 2028 | 62.645% | 58.206% | 60.344% | 15.708 ms |
| 相量候选 P / 50 ms | 3432 / 2411 / 1997 | 63.216% | 58.737% | 60.894% | 15.613 ms |
| 默认 QRS / 75 ms | 7079 / 203 / 493 | 93.489% | 97.212% | 95.314% | 9.938 ms |

相量候选没有改变 P 输出总数 5843，只改动了 41 个峰的位置；150 ms 下净多匹配 7 个，F1 提高 **0.124 个百分点**，50 ms 下净多匹配 31 个。宽容差下的收益主要来自定位重选，不能称为补出了大量缺失 P。QRS 结果不变。更严格容差下默认 F1 只有 60.34%，说明不能只用 150 ms 容差判断定位质量。

默认 882 个 P 漏检按固定的“后续 450 ms 内是否有参考 QRS”作诊断性分组：

| 错误情形 | 数量 | 含义 |
|---|---:|---|
| 后续参考 QRS 已检测，P 仍漏检 | 611 | 优先检查 P 搜索窗、P/T/QRS 区分及弱 P 候选 |
| 后续参考 QRS 也漏检 | 188 | 需要先改善上游 QRS 或减少对其依赖 |
| 后续 450 ms 内无参考 QRS | 83 | 需要覆盖未下传 P、长 PR 等情况；该时间规则本身不是临床病因诊断 |

完全无 P 标注的记录 08、48，native P 误检分别为 102、33 个，约 51.0、16.5 次/分钟。32 秒窗口抽查显示严格心房评估均为 `AF_LIKE`、accepted P 为零；因此需要同时评价检测输出和拒绝后的覆盖，而不是直接把 native 误检等同报告误报。[门控抽查](../ecgfeat_external_20260922/but_gate_probe.json)

### 已有心房事件与严格门控：补充分析

在看到 native 结果后，固定原算法再次运行全部 50 条默认配置，补充评分现有 `rhythm_analysis.atrial_events` 和 `p_wave_assessments.accepted` 筛选后的通道 0 native P。这是探索性输出口径分析，不是重新选阈值；50 条的 native 预测与第一次逐项完全相同，无执行失败。

| 输出 / 150 ms | TP / FP / FN | 召回率 | 精确率 | F1 |
|---|---|---:|---:|---:|
| native 通道 0 | 4547 / 1296 / 882 | 83.754% | 77.820% | 80.678% |
| 已有独立心房事件 | 4973 / 5369 / 456 | 91.601% | 48.085% | 63.065% |
| 严格 accepted 后 native P | 0 / 0 / 5429 | 0% | 无定义 | 0% |

独立心房事件分支已经有补检能力，但假阳性代价很大：比 native 多匹配 426 个，同时多 4073 个误检。应优先改善它的候选验证与 P/T/QRS 排除，不应把全部候选直接提升为有效 P。严格输出在当前双导联适配下全部拒绝，零误检伴随着零召回；这提示需要独立的少导联质量与可用性协议，不能靠直接放宽十二导联安全约束解决。

两种输出并不共享解剖定位口径：native 是固定通道 0，而心房事件是多通道融合输出。表格比较的是不同现有接口的检出取舍，不是同一检测器的消融。[补充评分](../ecgfeat_external_20260922/but_atrial_audit/summary.json)

## NSTDB：只看带噪时段

| SNR | TP / FP / FN | 召回率 | 精确率 | QRS F1 | 匹配峰 MAE |
|---:|---|---:|---:|---:|---:|
| 24 dB | 1856 / 1 / 0 | 100.000% | 99.946% | 99.973% | 6.028 ms |
| 18 dB | 1855 / 2 / 1 | 99.946% | 99.892% | 99.919% | 6.608 ms |
| 12 dB | 1790 / 136 / 66 | 96.444% | 92.939% | 94.659% | 8.201 ms |
| 6 dB | 1587 / 491 / 269 | 85.506% | 76.372% | 80.681% | 11.664 ms |
| 0 dB | 1179 / 1113 / 677 | 63.524% | 51.440% | 56.847% | 17.147 ms |
| −6 dB | 708 / 1496 / 1148 | 38.147% | 32.123% | 34.877% | 25.133 ms |

12 dB 开始明显退化，6 dB 以下误检、漏检同时上升。−6 dB 的匹配峰 MAE 只有 25.1 ms，但 F1 已跌至 34.9%，是“只看匹配事件定位误差会掩盖严重漏检”的直接例子。

干净时段 F1 在 6–24 dB 版本中为 99.896%，0/−6 dB 版本中约为 99.04%/99.10%。窗口上下文会跨越加噪切换边界，噪声可通过滤波或整窗统计影响邻接干净段，因此这些干净段不是完全独立的无噪基线。本次未用两条原始来源计算不可靠的人群置信区间。

## 下一步改进优先级

1. **P 候选验证与定位**：先改善 P/T/QRS 区分、弱 P 和异常 PR 搜索，按 50/150 ms 双容差以及无 P 记录的 FP/min 同时验收。已有独立心房分支的补检潜力明显，但当前应先控误检，不能单看召回。
2. **低信噪比 QRS**：针对电极运动干扰加入传统的多通道一致性、噪声自适应阈值/搜索回补及形态验证；优先关注 12、6、0 dB 分层，不用大量干净段稀释结果。
3. **少导联模式的可用性与拒绝协议**：两导联输入不能套用完整十二导联的接受条件；应独立校准有效导联数量、可测项目、拒绝率及拒绝后的漏检代价，同时保留十二导联约束。
4. **T 终点长尾**：保留仅终点序列选择作候选，优先研究大误差病例；本轮零点几毫秒的平均改善尚未降低 P95。

这些数据已被本轮查看，今后据此修改算法时它们属于开发/回归集；应另留未查看的人群或数据作最终独立验证。

## 验证、复现与产物

主实验完成 2487 次提取任务（ISP 2375、BUT 100、NSTDB 12），补充心房审计再完成 50 次，均无执行失败。新增协议测试 **13 passed**，涵盖稀疏分量匹配与完整动态规划等价、分窗覆盖、噪声切换边界、P 哨兵、删失标注和幅值适配。全部源码/数据哈希与冻结清单一致，TP+FN、TP+FP 分母恒等式通过。所有候选的 QRS 原始预测不变；仅终点候选的 II 导联 native T onset/peak 不变，但投影及其组合在 `train/324`、`train/343` 的评估共识 onset 分别变化 8、2 ms，不能声称共识起点完全不变。共识区间中点仅为排序键，终点移动时它也会移动，不是一个有真值的 T 峰。[最终核验](../ecgfeat_external_20260922/validation.json)
