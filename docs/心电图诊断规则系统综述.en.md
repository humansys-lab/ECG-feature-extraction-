# Chapter 0 Basic Matters (must be mastered before interpretation)

<a id="01-心电图的原理"></a>
## 0.1 Principle of electrocardiogram

- The potential difference generated by myocardial depolarization/repolarization is recorded as a voltage-time curve through body surface electrodes.
- **Core Rules**: The depolarization wave** moves toward** the positive pole of a certain lead → the lead records an **upward (positive)** wave; **away from** the positive → **downward (negative)** wave; **perpendicular** to the lead axis → bidirectional or isopotential.
- The direction of repolarization in the normal ventricle is **opposite** to the direction of depolarization (epicardium repolarizes first), so the normal T wave is **in the same direction** as the QRS main wave.
- The electrocardiogram reflects the projection of the instantaneous integrated vector (synthetic vector) on each lead axis.

<a id="02-心电计的操作与记录条件"></a>
## 0.2 Operating and recording conditions of the electrocardiograph

| Item | Standard value | Description |
|---|---|---|
| Paper feeding speed | **25 mm/s** | 1 small grid (1 mm) = **0.04 s**; 1 large grid (5 mm) = **0.20 s** |
| Gain (standard voltage) | **10 mm/mV** | 1 division = 0.1 mV; scaled square wave height 10 mm |
| Low frequency cutoff (time constant) | ≥ 3.2 s (0.05 Hz) | Too short will cause false ST offset |
| High frequency cutoff | 100–150 Hz (adults ≥150 Hz) | Too low will reduce the R wave and cover up the notch |
| AC filtering (Hz filtering) | Try not to use it | It will deform QRS and cover up delta waves and J waves |

**Recording conditions must be confirmed first**: If the paper travels at 50 mm/s, the readings at all times need to be ÷2; if the gain is 5 mm/mV (half standard), the voltage needs to be ×2. **Many misjudgments of "LV high voltage" and "low voltage" come from unconfirmed calibration. **

<a id="电极位置必须记忆"></a>
### Electrode position (must be memorized)

- **limb leads**: right wrist (red), left wrist (yellow), left ankle (green), right ankle (black, grounded)
- **Chest Leads**:
  - V1: 4th intercostal space on the right side of the sternum
  - V2: 4th intercostal space on the left side of the sternum
  - V3: The midpoint of the line connecting V2 and V4
  - V4: 5th intercostal space at left midclavicular line
  - V5: V4 level, front axillary line
  - V6: V4 level, mid-axillary line
  - **V7–V9** (posterior wall): Posterior axillary line/subscapular line/paraspinal line at V6 level
  - **V3R–V6R** (right ventricle): right chest symmetrical position of V3–V6 (V4R most commonly used)

<a id="03-波形名称与测量法"></a>
## 0.3 Waveform name and measurement method

| Wave/Interval | Definition | Reflection |
|---|---|---|
| **P wave** | Atrial depolarization | The first half = right atrium, the second half = left atrium |
| **PQ (PR) interval** | P starting point → QRS starting point | Atrioventricular conduction time (including intraatrial, AVN, His-Purkinje) |
| **QRS Group** | Ventricular depolarization | Intraventricular conduction |
| **J point** | QRS end point = ST starting point | ST offset measurement reference point |
| **ST segment** | J point → T wave origin | Early ventricular repolarization (plateau phase) |
| **T wave** | Ventricular repolarization | |
| **QT interval** | QRS start → T wave end | total ventricular electrical activity time |
| **U wave** | Wavelet after T | Purkinje fiber/papillary muscle repolarization (theory is undecided) |

<a id="测量要点"></a>
### Measurement points

- **Baseline (equipotential line)**: based on **TP segment** (use PR segment in tachycardia).
- **ST offset measurement point**: **0.06–0.08 s** after the J point (Japanese textbooks mostly use 0.08 s after the J point; the diagnosis of ST elevation is measured at the **J point**).
- **QT Endpoint**: The intersection point of the tangent line of the descending branch of the T wave and the baseline (tangent method). When there is a U wave, the U wave is not included; when T-U is fused, the T and U valleys are taken.
- **QT interval in lead II or V5, whichever is longest**.
- **Heart rate calculation**:
  - Rule: `HR = 300 ÷ (RR 大格数)` or `1500 ÷ (RR 小格数)`
  - Irregular (such as atrial fibrillation): Count within **6 seconds (30 large divisions) QRS Count × 10**
- **QT Correction (QTc)**:
  - Bazett: `QTc = QT / √RR(s)` - the most commonly used, but the error is large when the heart rate is too fast/too slow
  - Fridericia: `QTc = QT / RR^(1/3)` - more reliable in tachycardia

<a id="04-qrs-波形的命名规则"></a>
## 0.4 QRS Waveform naming rules

- **Q wave**: The **first downward** wave of QRS, with no upward wave before it
- **R wave**: **Any upward** wave (the 2nd upward wave is marked as R')
- **S wave**: The downward** wave after the R wave**
- **QS wave**: The entire QRS group** has only one downward** wave
- **Case**: Use uppercase** (Q, R, S) for amplitude **≥ 5 mm (0.5 mV), use lowercase** (q, r, s) for **< 5 mm

Examples: `rSr'` (incomplete right bundle branch block type of V1), `qR`, `RS`, `QS`, `rsR'` (M type)

<a id="05-各导联的观察方向定位诊断的根本"></a>
## 0.5 "Observation direction" of each lead (the basis of positioning diagnosis)

| Lead group | Observation site | Corresponding to coronary artery |
|---|---|---|
| **II, III, aVF** | **Inferior wall (diaphragmatic surface)** | RCA (most)/LCX |
| **I, aVL** | **High Side Wall** | LCX or LAD Diagonal Branch |
| **V1, V2** | **Anterior septal wall (ventricular septum)**, also toward the right ventricle | LAD proximal septal branch |
| **V3, V4** | **Front Wall** | LAD |
| **V5, V6** | **Lateral wall (inferolateral left ventricular wall)** | LCX/LAD distal |
| **V1–V6 All** | **Extensive Anterior Wall** | LAD Proximal |
| **V7–V9** | **Rear Wall (front wall)** | LCX/RCA |
| **V3R–V6R (V4R)** | **Right ventricle** | RCA proximal |
| **aVR** | Upper right/intracardiac | Elevation indicates left main or three-vessel disease |

**Definition of "adjacent leads"** ("≥2 adjacent leads" necessary for diagnosis of MI):
`V1-V2-V3-V4-V5-V6` is adjacent in sequence; `aVL-I-(-aVR)-II-aVF-III` is adjacent in sequence.

<a id="06-平均电轴qrs-电轴"></a>
## 0.6 average electric axis (QRS electric axis)

**Finding method (visual method)**:
1. Find the lead whose QRS algebra sum is closest to 0 among the limb leads → the electrical axis is **perpendicular** to the lead axis
2. Look at the main wave direction of the perpendicular lead → determine which side of the vertical direction it is
3. Simple judgment: **I and aVF are both positive → 0°～+90° (normal)**

| Electric axis | Range | Common causes |
|---|---|---|
| Normal | **−30°～+90°** (Loose −30°～+110°) | |
| **Left deviation** | −30° ~ −90° | Left anterior fascicular block, inferior wall MI, LVH, transverse cardiomyopathy, obesity, pregnancy |
| **Right deviation** | +110° ~ +180° | RVH, left posterior fascicular block, lateral MI, vertical heart, COPD, pulmonary embolism |
| **Uncertain axis (northwest axis)** | −90° ~ ±180° | Severe heart disease, ventricular tachycardia, hyperkalemia, dextrocardia, incorrect electrode connection |

<a id="07-术语约定"></a>
## 0.7 Terminology Convention

- **"Sex" vs "Similar"**: Morphological description uses "...pattern", such as "RBBB type", which does not mean true bundle branch block.
- **Primary ST-T changes**: QRS normal, ST-T itself abnormal (ischemia, electrolytes, drugs).
- **Secondary ST-T changes**: ST-T changes that occur "incidentally" due to QRS abnormalities (bundle branch block, hypertrophy, pre-excitation, pacing).
- **"suspected/suggested/consistent"**: ECG diagnosis is mostly **probabilistic** expression. Except for a few (atrial fibrillation, complete AVB, pre-excitation, etc.), it is not appropriate to assert pathological diagnosis.

<a id="第-1-章-正常心电图与判读顺序"></a>
# Chapter 1 Normal ECG and Interpretation Sequence

<a id="10-判读的固定顺序务必按此顺序防漏诊"></a>
## 1.0 Fixed order of interpretation (must follow this order to prevent missed diagnosis)

1. **Confirmation of recording conditions** (paper feeding speed, gain, presence of artifacts, and whether the electrodes are connected incorrectly)
2. **Rhythm** - Is it sinus? Rules or not?
3. **Heart rate (rate)**
4. **P wave** - presence, shape, size, whether each P is followed by QRS
5. **PQ interval**
6. **QRS**: Time limit → Electrical axis → Amplitude → Whether there is any abnormality Q → Chest conduction R wave increase
7. **ST segment**: elevation / depression / pattern
8. **T wave**: direction, amplitude, symmetry
9. **QT interval (QTc)**
10. **U wave**
11. **Comparison with previous ECG** (the most important step!)

<a id="11-节律心率p-波pq"></a>
## 1.1 Rhythm, heart rate, P wave, PQ

<a id="窦性心律的诊断标准4-条全部满足"></a>
### Diagnostic criteria for sinus rhythm (all 4 criteria are met)

1. **P wave is upright** in II, III and aVF, **aVR is inverted**
2. Each P wave is followed by a QRS (PQ constant, 0.12–0.20 s)
3. **PP interval rule** (change < 0.16 s；> 0.16 s for sinus arrhythmia)
4. Frequency **50/60–100 times/min**

<a id="正常-p-波"></a>
### Normal P wave

| Project | Normal Value | Best Observed Lead |
|---|---|---|
| Time limit | **< 0.12 s (< 3 cells)** | II |
| Amplitude | **< 0.25 mV (< 2.5 mm)** | II, III, aVF |
| Morphology | Round and blunt single peak; V1 can be positive and negative biphasic | II, V1 |
| V1 terminal negative part (Ptf) | Area > −0.04 mm·s (i.e. depth <1 mm or width <0.04 s) | V1 |

<a id="正常-pqpr间期"></a>
### Normal PQ (PR) interval

- **0.12 – 0.20 s** (slightly shorter in children/tachycardia, up to 0.21 s in the elderly/bradycardia)
- Measurement should be taken from the longest PQ** (at II or V1)

<a id="12-qrs-群的检查点"></a>
## 1.2 Checkpoint of QRS group

| Project | Normal Standard |
|---|---|
| **Time limit** | **< 0.10 s** (0.10–0.11 s is mild extension; **≥ 0.12 s is wide QRS**) |
| **Electric axis** | −30° ~ +90° |
| **Normal q wave (interval q)** | I, aVL, V5, V6 may have small q: **width < 0.04 s and depth < 1/4 of the R wave in the same lead** |
| **aVR** | Normally QS or rS (main wave downward) |
| **V1** | Normal can be QS or rS; **V1 has q wave, which is abnormal** |
| **Chest conduction R wave increases** | V1→V5 gradually increases; **R of V1 < S**，**V6 的 R > S** |
| **Transition Zone (R=S)** | **V3 – V4** (V2 or right = counterclockwise transposition; V5 or left = clockwise transposition) |
| **Ventricular activation time VAT (classic tortuosity)** | V5, V6 **< 0.05 s**; V1, V2 **< 0.03 s** |
| **Amplitude (not too low)** | At least 1 limb lead ≥ 0.5 mV, at least 1 chest lead ≥ 1.0 mV |

<a id="13-st-段的检查点"></a>
## 1.3 Checkpoint of ST segment

- The normal ST segment is **flush** with the baseline (TP segment), which is a **smooth upward concave** curve.
- Allowed range:
  - **Elevated**: Limb leads **< 0.1 mV**; V1–V3 **< 0.2 mV (Male ≥40 years) / < 0.25 mV (Male <40 years) / < 0.15 mV (Female) **
  - **Depression**: **< 0.05 mV** (any lead)
- **Early repolarization (normal variant)**: J-point elevation with J wave (notch/contusion), ST showing **superior concavity**, T wave towering and upright, more common in V2–V5 and inferior wall, young men and athletes. **The key is concave morphology + no dynamic evolution + no corresponding lead depression**.

<a id="14-t-波的检查点"></a>
## 1.4 T-wave checkpoints

- Direction: **Same direction as QRS main wave**
  - I, II, V3–V6: **Upright**
  - aVR: **Inverted**
  - III, aVL, V1, V2: **can be inverted (normal variation)**; V1 inversion is particularly common in women
- Shape: **Asymmetric** (ascending limb is slow, descending limb is steep)
- Amplitude: limb leads < 0.5 mV, chest leads < 1.0–1.5 mV; generally **≥ 1/10** of the R wave in the same lead (too low means T wave is low and flat)
- **persistent juvenile T**: V1–V3 T inversion in young women, normal variation

<a id="15-qt-间期与-u-波"></a>
## 1.5 QT interval and U wave

| Project | Normal Value |
|---|---|
| **QTc (Bazett)** | Male **≤ 0.44 s**, Female **≤ 0.46 s** (≥0.48 s is definitely lengthening; ≤0.34–0.36 s is shortening) |
| **Simple judgment** | **QT < half of RR** (applicable when heart rate is 60–100) |
| **U wave** | In the same direction as T (upright), amplitude **< 1/2** of T wave** (generally < 0.1–0.2 mV), V2–V3 most pronounced |

**U wave inversion is abnormal in any lead** (except aVR).

# Chapter 2 P-QRS Abnormal relationship: Abnormal basic rhythm (non-tachycardia)

> **Entry point**: No normal P wave found, or P does not correspond to QRS.

<a id="21-心房颤动af-af"></a>
## 2.1 Atrial fibrillation〈AF / Af〉

| Diagnostic elements | Specific criteria | Optimal leads |
|---|---|---|
| **P wave disappears** | Replaced by **thin tremor f wave**, frequency **350–600 beats/min**, irregular amplitude shape | **V1** (f wave is the clearest), II |
| **RR intervals are absolutely irregular** | No regularity ("absolutely irregular") | Arbitrary |
| **QRS Morphology** | Usually normal (narrow); widened with bundle branch block or differential conduction | |

**Additional interpretation**:
- **Ventricular rate classification**: < 50 次/分＝慢心室率型（提示 AVN 传导障碍或药物过量）；50–100＝控制良好；> 100 = fast ventricular rate type
- **Coarse AF**: f wave ≥ 0.1 mV, common in mitral stenosis and significant left atrium enlargement
- **Ashman phenomenon**: The short RR after the long RR appears wide QRS (mostly RBBB type), which is **differential conduction** rather than PVC
- **AF + regular slow ventricular rate** → **Complete AV block combined with AF** (Important! Do not miss the diagnosis)
- **AF + regular rapid ventricular rate (>100, regular)** → junctional tachycardia / digitalis intoxication
- **AF + Extremely Fast (>200) Irregular Wide QRS** → **Pre-excitation with AF (pseudo-VT)**, Digitalis/Verapamil disabled

<a id="22-心房扑动afl"></a>
## 2.2 Atrial flutter〈AFL〉

| Diagnostic elements | Specific criteria | Optimal leads |
|---|---|---|
| **F wave (saw-tooth)** | Frequency **250–350 times/min** (typical ~300) | **II, III, aVF** (typical negative sawtooth), **V1** (positive upright P-like) |
| **No equipotential lines** | F wave is continuous and the baseline is continuous wave | II, III, aVF |
| **Atrioventricular conduction ratio** | 2:1 (ventricular rate ~150), 3:1 (~100), 4:1 (~75); if the ratio is fixed, it will be the RR rule, if it is not fixed, it will be irregular | |
| **QRS** | Usually narrow | |

**Key Points**:
- **Narrow rule for constant ventricular rate around 150 beats/min QRS Tachycardia → Suspect first 2:1 AFL** (F wave hidden in QRS and T)
- Exposure method: carotid sinus massage or adenosine → increased atrioventricular conduction ratio, F wave exposure
- **Typical (common/counterclockwise)**: II/III/aVF negative sawtooth, V1 positive
- **Atypical (reverse typical)**: II/III/aVF positive, V1 negative

<a id="23-房室交界区节律-加速性交界区节律"></a>
## 2.3 Atrioventricular junctional rhythm/accelerated junctional rhythm

| Type | Frequency | Definition |
|---|---|---|
| **Junctional escape rhythm** | **40–60 beats/min** | Passive escape beat in sinus node insufficiency or AV block |
| **Accelerated junctional rhythm** | **60–100 beats/min** | Increased junctional automaticity (digital intoxication, inferior wall MI, myocarditis, cardiac surgery) |
| **Junctional Tachycardia** | > 100 beats/min | |

**Diagnostic elements**:
1. **QRS Narrow** (unless combined with bundle branch block)
2. **P wave retrograde**: **II, III, aVF inverted**, **aVR upright**
3. The positional relationship between P and QRS (determined by the relative speed of reverse transmission and forward transmission):
   - **P before QRS**: PR **< 0.12 s** ("Upper Junction Zone")
   - **P buried in QRS**: P cannot be seen (most common)
   - **P after QRS**: RP **< 0.20 s** ("lower junction zone")
4. RR interval rules

<a id="24-心室固有节律-加速性心室固有节律aivr"></a>
## 2.4 Intrinsic ventricular rhythm/Accelerated intrinsic ventricular rhythm〈AIVR〉

| Type | Frequency | Meaning |
|---|---|---|
| **Intrinsic ventricular (escape) rhythm** | **20–40 beats/min** | Complete AVB, near-death rhythm; extremely dangerous |
| **Accelerated intrinsic ventricular rhythm AIVR** | **60–100 (~120) beats/min** | **Sign of acute MI reperfusion**; mostly transient and benign |

**Diagnostic elements**:
1. **Wide deformity QRS ≥ 0.12 s**, the T wave is opposite to the main wave direction of QRS
2. **No relevant P wave** (or presence of atrioventricular dissociation)
3. Rhythm** rules or general rules**
4. **Gradual start and end** ("warm-up / cool-down") - different from the sudden and sudden stop of ventricular tachycardia
5. Fusion beat and capture wave are common because the frequency is close to sinus rhythm

**AIVR vs VT**: AIVR frequency < 120、渐起渐止、血流动力学稳定；VT ≥ 100（通常 >130), sudden stop.

<a id="25-心房静止as-窦室传导"></a>
## 2.5 Atrial Quiet〈AS〉/Sinoventricular Conduction

**atrial standstill**:
- **Complete absence of P waves** (absent in every lead, including V1)
- Regular junctional or ventricular escape rhythm
- Causes: hyperkalemia, digitalis poisoning, atrial myopathy (atrial palsy), end-stage heart disease

**Sino-ventricular conduction - characteristic manifestation of hyperkalemia**:
1. **P wave disappears** (the atrial muscle cannot be depolarized, but the sinoatrial node impulse is transmitted to the ventricle through the internodal bundle)
2. **QRS is significantly broadened** (sinusoidal waveform, unable to distinguish QRS from T)
3. **T wave peak**
4. Rhythm rules
>Normokalemia >8 mEq/L, **emergency** (calcium + glucose insulin + dialysis)

<a id="第-3-章-p-波形态大小异常"></a>
# Chapter 3 Abnormal P wave shape and size

> **P wave looks at lead II (time limit, amplitude) + V1 lead (biphasic component)**, these two leads are the main battlefield for P wave diagnosis.

<a id="31-左房扩大p-mitrale"></a>
## 3.1 Left atrial enlargement (P mitrale)

| Standard | Value | Lead |
|---|---|---|
| **P wave duration extended** | **≥ 0.12 s (≥ 3 divisions)** | **II** (or I, aVL) |
| **Double peak P (notched)** | Distance between two peaks **≥ 0.04 s** | **II** |
| **P wave terminal potential (Ptf-V1)** | **≤ −0.04 mm·s** (that is, the terminal negative wave **depth ≥ 1 mm and width ≥ 0.04 s**) | **V1** |

- Cause: **Mitral stenosis/regurgitation**, left atrial load due to left ventricular hypertrophy/heart failure, hypertension
- Note: Ptf-V1 abnormality is the **most sensitive** indicator and can also be seen in left ventricular diastolic dysfunction (not necessarily true left atrial enlargement)

<a id="32-右房扩大p-pulmonale"></a>
## 3.2 Right atrium enlargement (P pulmonale)

| Standard | Value | Lead |
|---|---|---|
| **P wave peak** | **≥ 0.25 mV (≥ 2.5 mm)** | **II, III, aVF** |
| **V1 initial positive part increases** | **≥ 0.15 mV (≥ 1.5 mm)** | **V1** (or V2) |
| **P wave duration** | **Normal (< 0.12 s)** - the key difference from left atrial enlargement | II |
| Electrical axis | P Electrical axis deflected to the right (> +75°) | |

- Cause: **COPD/cor pulmonale, pulmonary hypertension, tricuspid valve disease, congenital heart disease (PS, ASD, TOF, Ebstein)**
- **Biatrial enlargement**: Lead II P is both high (≥2.5 mm) and wide (≥0.12 s) + V1 increases both positive and negative components of P in both directions

<a id="33-异位心房节律冠状窦节律-左房节律"></a>
## 3.3 Ectopic atrial rhythm (coronary sinus rhythm/left atrial rhythm)

**Common ground**: Abnormal P wave morphology but **PQ ≥ 0.12 s** (key differentiator from junctional rhythm)

| Type | Characteristics | Lead |
|---|---|---|
| **Coronary sinus rhythm** | **P inverted** in II, III, aVF, **PQ ≥ 0.12 s**; P upright in I, V5–V6 | II, III, aVF |
| **Left atrial rhythm** | **P inversion** of I and/or aVL** (key!); V1 is **"dome and dart"** like P | **I, aVL, V1** |
| **Inferior right atrial rhythm** | II, III, aVF P inverted, I upright | |

> **Function**: P inversion + PQ ≥ 0.12 s → ectopic atrial property; P inversion + PQ < 0.12 s → junctional property.

<a id="34-游走性起搏点wandering-pacemaker"></a>
## 3.4 Wandering pacemaker

**Diagnostic elements (same lead, usually looking at II)**:
1. **P wave forms have ≥ 3**, which gradually change beat by beat (upright → low and flat → inverted → upright again)
2. **PQ interval changes accordingly** (above 0.12 s to below 0.12 s)
3. **PP interval mildly irregular**
4. The heart rate is usually normal or slow (**if > 100 beats/min → called "multisource atrial tachycardia MAT"**, more common in severe COPD)

- Mechanism: The pacemaker moves between the sinoatrial node ↔ atrium ↔ junction zone
- Mostly **physiological phenomena** caused by increased vagal tone (athletes, youth, sleeping)

<a id="第-4-章-pqpr间期缩短与延长"></a>
# Chapter 4 PQ (PR) interval shortening and prolonging

<a id="41-wpw-综合征心室预激"></a>
## 4.1 WPW syndrome (ventricular preexcitation)

<a id="诊断三联征"></a>
### Diagnostic triad

| # | Standard | Value |
|---|---|---|
| 1 | **Shortened PQ interval** | **< 0.12 s** |
| 2 | **δ (delta) wave** | The starting part of QRS is rough and blunt; making QRS start slowly for 0.03–0.05 s |
| 3 | **QRS widening** | **≥ 0.12 s** (the sum of PQ + QRS is constant because the PJ interval is normal ≤ 0.26 s) |
| Attached | **Secondary ST-T change** | ST-T direction is opposite to the delta wave/QRS main wave |

<a id="分型依据-v1-的-δ-波qrs-主波极性"></a>
### Type (based on the δ wave of V1/QRS main wave polarity)

Type | QRS main wave of V1 | Bypass position | Easily misdiagnosed as |
|---|---|---|---|
| **Type A** | **Forward (R or Rs)** | **Left Side Wall/Left Posterior** | **RBBB, Posterior Wall MI, RVH** |
| **Type B** | **Negative (rS or QS)** | **Right side wall/right anterior** | **LBBB, anterior septal wall MI** |
| **Type C** | V1–V4 positive, V5–V6 negative | Posterior left septum | Rare |

**IMPORTANT TRAPS**:
- Pre-excitation can produce **pseudo Q waves** (when delta waves are downward), which can be misdiagnosed as old MI (especially inferior wall)
- ST-T changes in pre-excitation are **secondary** and not diagnostic of ischemia
- **WPW + atrial fibrillation = pseudo-VT** (extremely fast, irregular, wide QRS) → **Digitalis, verapamil, beta blockers are prohibited** (can accelerate accessory pathway conduction → VF)
- **Intermittent pre-excitation** (delta wave comes and goes) indicates a long refractory period of the accessory pathway and a low risk of sudden death

<a id="42-lgl-综合征"></a>
## 4.2 LGL syndrome

| Standard | |
|---|---|
| **PQ < 0.12 s** | ✅ |
| **No delta waves** | ✅ |
| **QRS time limit is normal (< 0.10 s)** | ✅ |
| History of episodic supraventricular tachycardia | Necessary for diagnosis of "syndrome" |

- Mechanistic hypothesis: James bundle (atrial-nodal accessory pathway) or fast conduction pathway within AVN
- If there is no tachycardia episode, describe it only as "**short PQ(PR) interval**"

<a id="43-i-度房室阻滞"></a>
## 4.3 I degree atrioventricular block

| Standard | Value |
|---|---|
| **PQ interval prolongation** | **> 0.20 s** (the elderly can be relaxed to > 0.22 s; children > 0.18 s) |
| **QRS after each P wave** | No shedding (this is the difference from II degrees) |
| PQ constant | |

**Inference of blockage site**:
- **QRS Narrow + PQ Prolonged** → Block mostly within **AVN** (benign, improved with atropine)
- **QRS wide (bundle branch block) + PQ prolongation** → block may be below **His bundle** (need to be wary of progression to high AVB)
- PQ **> 0.30 s** is called "significant degree I AVB" and can cause atrioventricular dyssynchrony ("pacemaker syndrome"-like symptoms)
- Causes: increased vagal tone, athletes, digitalis/beta blockers/calcium antagonists, inferior wall MI, myocarditis (especially Lyme disease), degeneration of the conduction system in the elderly

<a id="第-5-章-qrs-增宽与电轴异常"></a>
# Chapter 5 QRS Widening and Electrical Axis Abnormality

> **Entry point**: QRS ≥ 0.12 s, first look at the shape of **V1** (positive direction = RBBB type, negative direction = LBBB type), and then look at the electric axis.

<a id="51-完全性右束支阻滞crbbb"></a>
## 5.1 Complete right bundle branch block〈CRBBB〉

| # | Standard | Lead |
|---|---|---|
| 1 | **QRS ≥ 0.12 s** | Any |
| 2 | **V1 (V2) is rsR', rSR', M type** ("rabbit ears"), R' > r | **V1, V2** |
| 3 | **I, aVL, V5, V6 appear wide and choppy S waves** (S width > R width or > 0.04 s) | **I, aVL, V5, V6** |
| 4 | **VAT (class-based tortuosity) for V1 > 0.05 s** | V1 |
| 5 | **Secondary ST-T changes**: V1–V2 ST depressed, T inverted | V1, V2 |

- **Incomplete RBBB (IRBBB)**: Same morphology but **QRS 0.10–0.12 s**. Common in normal young people, **ASD (IMPORTANT!)**, RV volume overload.
- **RBBB does not hinder MI diagnosis**: Because the QRS start vector (interval depolarization) is normal, the Q wave can still be interpreted.
- **qR** type RBBB in V1 → suggests combined **anteseptal MI** or right ventricular hypertrophy.

<a id="52-完全性左束支阻滞clbbb"></a>
## 5.2 Complete left bundle branch block〈CLBBB〉

| # | Standard | Lead |
|---|---|---|
| 1 | **QRS ≥ 0.12 s** | Any |
| 2 | **V5, V6, I, aVL present wide, depressed or flat-top R waves**, **no q wave** (interval q disappears) | **I, aVL, V5, V6** |
| 3 | **V1, V2 are rS or QS** (r is minimal or absent) | **V1, V2** |
| 4 | **VAT for V5, V6 > 0.06 s** | V5, V6 |
| 5 | **Secondary ST-T changes**: I, aVL, V5, V6 ST depressed + T inverted; V1–V3 ST elevated + T upright | |
| 6 | The electric axis often deviates to the left | |

**Clinical Points**:
- CLBBB is almost always a sign of **organic heart disease** (ischemic cardiomyopathy, hypertension, dilated cardiomyopathy, aortic valve disease), as opposed to RBBB.
- **CLBBB masks MI diagnosis** → Use **Sgarbossa criteria** for acute MI:
  - ST elevation **≥ 1 mm and concordant with QRS main wave** —— 5 points
  - V1–V3 ST depression **≥ 1 mm and in the same direction as QRS main wave** —— 3 points
  - ST elevation **≥ 5 mm and discordant with QRS main wave** —— 2 points
  - (Modified Smith criterion: ST/S ratio ≤ −0.25)
  - **≥3 points** indicates acute MI
- **New LBBB + Chest Pain** Treat as STEMI equivalents.
- LBBB cannot diagnose LV hypertrophy, MI, ischemia** (interference from secondary changes).

<a id="53-非特异性室内传导障碍nonspecific-ivcd"></a>
## 5.3 Nonspecific IVCD

| Standard |
|---|
| **QRS ≥ 0.11–0.12 s** |
| **Does not conform to the pattern of a typical RBBB nor a typical LBBB** |
| Often diffuse QRS widening, thickening, and notching |

- Causes: **Hyperkalemia, Class Ia/Ic antiarrhythmic drugs (flecainide, etc.), tricyclic antidepressant poisoning, severe myocardial disease, myocardial fibrosis, high-grade myocardial ischemia**
- Check **serum potassium** and **medication history** immediately when seeing an IVCD.

<a id="54-左前分支阻滞lah-lafb"></a>
## 5.4 Left anterior fascicular block〈LAH/LAFB〉

| # | Standard | Lead |
|---|---|---|
| 1 | **Significant left deviation of the electrical axis: −45° ~ −90°** (some textbooks use ≤ −30°) | Limb leads |
| 2 | **II, III, aVF are rS-type**, and **S(III) > S(II)** | II, III, aVF |
| 3 | **I, aVL is of qR type**, **R(aVL) > R(I)** | I, aVL |
| 4 | **QRS The time limit is normal or slightly extended (< 0.12 s)** | |
| 5 | VAT of aVL ≥ 0.045 s | aVL |
| 6 | It is necessary to **exclude** other causes of left deviation such as inferior wall MI, LVH, vertebral heart, emphysema, etc. | |

- is the most common branch block. Can result in **Poor V1–V3 R wave progression** (pseudoanterseptal MI) and **aVL pseudo Q waves**.

<a id="55-左后分支阻滞lph-lpfb"></a>
## 5.5 Left posterior fascicular block〈LPH / LPFB〉

| # | Standard | Lead |
|---|---|---|
| 1 | **Right axis deviation: +90° ~ +180°** (most requirements ≥ +110°) | Limb leads |
| 2 | **I, aVL is rS type** | I, aVL |
| 3 | **II, III, aVF are of qR type**, and **R(III) > R(II)** | II, III, aVF |
| 4 | **QRS < 0.12 s** | |
| 5 | **Must be excluded**: RV hypertrophy, vertebral heart (slender body shape), lateral MI, emphysema, pulmonary embolism | |

- The left posterior branch is thick and has dual blood supply → **Isolated LPH is rare**, and when present, it indicates extensive disease and poor prognosis.
- **Diagnosis of LPH is a diagnosis of exclusion**, be sure to rule out RVH first.

<a id="56-双分支阻滞与三分支阻滞"></a>
## 5.6 Bifascicular block and trifascicular block

| Type | ECG combination |
|---|---|
| **bifascicular block** | ① **RBBB + LAH** (most common: V1 rsR' + axis ≤−45°) <br>② **RBBB + LPH** (V1 rsR' + axis ≥+110°, poor prognosis) <br>③ alone CLBBB (considered as left anterior + left posterior involvement simultaneously) |
| **Trifascicular block** | Bifascicular block **+ I degree AVB (PQ prolongation)** ("Incomplete trifascicular") <br> or Bifascicular block **+ Alternating to another trifascicular block **<br> or Bifascicular block **+ Degree II/III AVB** ("Complete trifascicular" = complete AVB) |

- Bifascicular block + syncope → strongly suggestive of intermittent complete AVB, **Pacemaker indication evaluation**.

<a id="57-双侧束支阻滞交替性束支阻滞"></a>
## 5.7 Bilateral bundle branch block, alternating bundle branch block

- **Alternating BBB**: In the same or consecutive records, **RBBB and LBBB appear alternately**, or RBBB+LAH and RBBB+LPH alternate → **Bilateral bundle branch disease, very high risk, permanent pacemaker Class I indication**.
- **Bilateral bundle branch block**: Manifested as **complete atrioventricular block + wide QRS escape beat**, block site below His bundle (escape beat frequency < 40, unresponsive to atropine).

# Chapter 6 Left Ventricular Potential Too High/Low

<a id="61-左室高电压high-voltage"></a>
## 6.1 Left ventricular high voltage (high voltage)

> Only voltage increase, ** no ST-T When ** changes, only "left ventricular high voltage" can be diagnosed, but left ventricular hypertrophy cannot be diagnosed.

| Standard Name | Formula | Lead |
|---|---|---|
| **Sokolow-Lyon (chest conduction)** | **S(V1) + R(V5 or V6) ≥ 3.5 mV (35 mm)** | V1, V5, V6 |
| **R(V5) or R(V6)** | **≥ 2.6 mV (26 mm)** | V5, V6 |
| **Sokolow-Lyon (limb conduction)** | **R(I) + S(III) ≥ 2.5 mV** | I, III |
| **R(aVL)** | **≥ 1.1 mV (1.2 mV)** | aVL |
| **Cornell Voltage** | **R(aVL) + S(V3) > 2.8 mV (male) / > 2.0 mV (female)** | aVL, V3 |
| **Cornell Product** | (Cornell Voltage + Female 0.6 mV) × QRS Time > 2440 mm·ms | |

**Note**: Young people, lean bodies, and athletes often have false positives; obesity, emphysema, and pericardial effusion often have false negatives.

<a id="62-左室肥大lvh"></a>
## 6.2 Left ventricular hypertrophy〈LVH〉

Diagnosis = **Voltage Standard + Supporting Findings**:

| Supporting findings | Specific description | Leads |
|---|---|---|
| **① ST-T strain pattern** | ST segment **descending depression** + **asymmetric inversion T** (descending limb is steep, ascending limb is gentle, in the "fishhook" reverse direction) | **V5, V6, I, aVL** |
| ② Left atrial enlargement | Ptf-V1 ≤ −0.04 mm·s | V1 |
| ③ Left deviation of electrical axis | ≤ −15° ~ −30° | |
| ④ QRS The time limit is slightly extended | 0.09–0.11 s | |
| ⑤ VAT extension | V5, V6 **> 0.05 s** | V5, V6 |
| ⑥ V1–V3 Poor R wave progression | | V1–V3 |

**Romhilt-Estes scoring method (≥5 points = confirmed, 4 points = likely)**

| Project | Points |
|---|---|
| Either limb conductor R or S ≥ 2.0 mV, or S(V1,V2) ≥ 3.0 mV, or R(V5,V6) ≥ 3.0 mV | 3 |
| ST-T Strain type (without digitalis) | 3 (1 when digitalis is used) |
| Left atrial enlargement (Ptf-V1 ≤ −0.04 mm·s) | 3 |
| Electrical axis left deviation ≤ −30° | 2 |
| QRS time limit ≥ 0.09 s | 1 |
| VAT(V5/V6) ≥ 0.05 s | 1 |

- Causes: hypertension, aortic stenosis, hypertrophic cardiomyopathy, aortic coarctation

<a id="63-左室容量舒张期负荷"></a>
## 6.3 Left ventricular volume (diastolic) load

> Opposite of "pressure load (strain type)", morphologically opposite.

| Characteristics | Description | Leads |
|---|---|---|
| **Deep and narrow q-waves** | Increasing spacing q (but width < 0.04 s) | **V5, V6, I, aVL** |
| **High R-wave** | Increased voltage | V5, V6 |
| **ST segment elevation (mild) or flush** | Not depressed | V5, V6 |
| **T wave tall and upright** | Opposite of the strained inverted T | V5, V6 |

- Cause: **Aortic regurgitation, mitral regurgitation, VSD, PDA, arteriovenous fistula, anemia/hyperthyroidism and other high-discharge states**
- Memory: pressure load → ST-T strain (inverted T); volume load → deep q + high T.

<a id="64-肥厚型心肌病hcm"></a>
## 6.4 Hypertrophic cardiomyopathy〈HCM〉

<a id="一般型非对称性室间隔肥厚"></a>
### General type (asymmetric ventricular septal hypertrophy)

| Characteristics | Description | Leads |
|---|---|---|
| **LV High Voltage** | Often significant | V4–V6 |
| **Abnormal Q waves (pseudoinfarct type)** | **Narrow (< 0.04 s) and deep** Q waves due to ventricular septal hypertrophy | **II, III, aVF, V4–V6, I, aVL** |
| ST-T Change | Inverted T, ST depressed | Lateral leads |
| Left atrial enlargement | | V1, II |

- **Key differentiators**: The Q wave of HCM is **narrow and deep** (<0.04 s), and the Q wave of MI is **wide** (≥0.04 s).

<a id="心尖肥厚型aph日本多见"></a>
### Apical hypertrophy type (APH, common in Japan)

| Feature | Value | Lead |
|---|---|---|
| **Giant inverted T wave〈GNT〉** | **Depth > 1.0 mV (10 mm)**, the deepest is usually V4 | **V3–V5** (V4 is the deepest) |
| **Left ventricular high voltage** | R(V4–V5) increased, often ≥ 2.6 mV | V4, V5 |
| ST depressed | Accompanied | V4–V6 |
| **No abnormal Q waves** | Differentiating from MI | |

- Echocardiography/MRI shows an "Ace of Spades"-like left ventricular cavity at the apex.

<a id="65-低电压low-voltage"></a>
## 6.5 low voltage

| Standard | Value |
|---|---|
| **Low voltage in limb leads** | **QRS amplitude (sum of R+S absolute values) < 0.5 mV (5 mm) for all 6 limb leads** |
| **Low Voltage in Chest Leads** | **All 6 Chest Leads QRS Amplitude < 1.0 mV (10 mm)** |
| **Wide range low voltage** | Both |

**Cause identification**:

| Mechanism | Disease |
|---|---|
| Insulation/short circuit between heart and electrode | **Pericardial effusion (+ alternans → cardiac tamponade)**, pleural effusion, **emphysema/COPD**, pneumothorax, obesity, subcutaneous edema |
| Decreased electrical activity of the myocardium itself | **Myocardial amyloidosis (low voltage + pseudo-infarction Q wave, important!)**, extensive myocardial infarction, end-stage dilated cardiomyopathy, **myxedema (hypothyroidism)**, restrictive cardiomyopathy |
| Others | Constrictive pericarditis, scleroderma |

- **Electrical alternans**: QRS Alternating high and low amplitude beat-to-beat → Specific manifestation of **cardiac tamponade** (heart swinging in pericardial fluid).

# Chapter 7 Abnormal Q Wave

<a id="71-心肌梗死mi"></a>
## 7.1 Myocardial infarction〈MI〉

<a id="异常-q-波病理性-q-波的标准"></a>
### Criteria for abnormal Q waves (pathological Q waves)

| # | Standard |
|---|---|
| 1 | **Width ≥ 0.04 s** (use ≥ 0.02 s for V2–V3 and in Q or QS) |
| 2 | **Depth > 1/4 of the R wave in the same lead** (some textbooks use > 1/3) |
| 3 | **Occurs in ≥ 2 adjacent leads** |
| 4 | Often accompanied by reduced R wave amplitude and notching |

> **Exceptions**: Q/QS in aVR is normal; isolated Q waves in III and V1 are often meaningless (lead III Q disappears on deep inspiration = physiological).

<a id="定位诊断关键表"></a>
### Positioning diagnosis (key table)

| Site of infarction | Leads with abnormal Q/ST elevation | Corresponding (mirror) leads | Culprit vessels |
|---|---|---|---|
| **Anteroseptal** | **V1, V2 (V3)** | — | LAD septal branch |
| **FRONT WALL** | **V3, V4** | — | LAD |
| **Extensive Anterior Wall** | **V1–V6, I, aVL** | II, III, aVF | **Proximal LAD (High Risk)** |
| **Lateral wall (high lateral wall)** | **I, aVL (V5, V6)** | II, III, aVF | LCX / diagonal branch |
| **Inferior wall** | **II, III, aVF** | I, aVL (V1–V3) | **RCA (~80%)/LCX** |
| **Positive back wall** | **Q** of V7–V9; **V1–V2 with high R, R/S ≥ 1, ST depressed, T upright** | V1–V3 (mirror) | LCX/RCA |
| **Right Ventricle** | **V4R (V3R–V6R) ST elevation ≥ 0.1 mV** | — | **Proximal RCA** |
| Left main | **aVR ST elevation > ST elevation in V1**, widespread lead ST depression (≥6 leads) | | LMT |

<a id="mi-的时相演变用于判断新旧"></a>
### The temporal evolution of MI (used to judge the old and the new)

| Staging | Time | Electrocardiogram |
|---|---|---|
| **Hyperacute phase** | Several minutes to tens | **T wave peak widens (hyperacute T)**, ST begins to rise, no Q yet |
| **Acute phase** | Hours to days | **ST is significantly elevated (convex surface upward, unidirectional curve monophasic)**, **abnormal Q appears**, and the corresponding lead ST is depressed |
| **Subacute phase (recent)** | Days to weeks | ST gradually falls, **T wave inversion deepens (coronal T)**, Q wave is fixed |
| **Stale period** | Weeks to months later | **ST returns to baseline**, T can return to upright or remain inverted, **abnormal Q waves persist** |

**If ST elevation persists for >4–6 weeks → Suspect ventricular aneurysm** (see 10.4).

<a id="下壁-mi-的必查项"></a>
### Must-check items for lower wall MI
1. **Additional V4R** → Rule out right ventricular infarction (**Nitrates and diuretics are prohibited in right ventricular infarction, and large amounts of fluids are required**)
2. **Additional V7–V9** → rule out posterior wall involvement
3. Note **ST elevation in II, III, aVF III > II and V1 ST elevation** → RCA proximal; **I, aVL ST depression** supports RCA

<a id="72-左右电极接错lead-reversal"></a>
## 7.2 The left and right electrodes are connected incorrectly (lead reversal)

**Most common: left and right wrist (LA/RA) interchange**

| Features | Performance |
|---|---|
| **I Lead**: P, QRS, T **All Inverted** | ✅ KEY |
| **aVR upright** (P with QRS up) | ✅ KEY |
| II and III interchange, aVL and aVR interchange | |
| **Chest leads completely normal** (R wave progression normal) | ✅ **Key differences from dextrocardia** |

**Other connection errors**:
- **The right leg (black) is interchanged with other limbs** → A certain limb lead is **nearly flat (extremely low amplitude)**
- The order of the chest lead electrodes is wrong → "break" appears in the R wave increment (such as V3 > V4)

<a id="73-右位心dextrocardia"></a>
## 7.3 Dextrocardia

| Features | Performance |
|---|---|
| **I Lead** P, QRS, T **All inverted** | Same as wrong electrode connection |
| **aVR Upright** | Same as wrong electrode connection |
| **The R wave in the chest leads gradually decreases from V1 to V6** ("R wave decrement"), with minimal rS or QS in V5–V6 | ✅ **Decisive difference** |
| Axis deviation to the right | |

**Confirmation method**: Swap the limb leads left and right + place the chest leads on the right chest (V1R–V6R) → Record a normal electrocardiogram to confirm the diagnosis of mirror dextrocardia.

| Standard | Description |

# Chapter 9 Increased R wave in right chest lead/I, Deepened S wave in left chest lead

> **Entry point**: 6 major identifications when "high R wave" (R/S ≥ 1) appears in V1 - **① Counterclockwise transposition ② Posterior wall infarction ③ Right ventricular hypertrophy ④ RBBB ⑤ WPW type A ⑥ Normal variant/child**

<a id="91-逆钟向转位counterclockwise-rotation"></a>
## 9.1 Counterclockwise rotation

| Standard |
|---|
| **Transition area moves left to V2 or right** (V1 is already Rs) |
| V5, V6 are qR, no deep S |

- Causes: left ventricular hypertrophy, transverse heart disease (obesity, pregnancy, ascites), normal variation.
- **is a benign finding** and needs to be differentiated from posterior wall infarction and RVH.

<a id="92-后壁正后壁梗死"></a>
## 9.2 Posterior wall (directly posterior wall) infarction

| # | Standard | Lead |
|---|---|---|
| 1 | **R/S ≥ 1** (increased R wave) | **V1, V2** |
| 2 | **R wave time limit ≥ 0.04 s** | V1, V2 |
| 3 | **ST segment depression** (acute phase, mirror image of posterior wall ST elevation) | V1–V3 |
| 4 | **T wave upright and tall** (mirror image of posterior wall inverted T) | V1, V2 |
| 5 | **Confirmed diagnosis: additional V7–V9, ST elevation ≥ 0.05 mV (male <40 years old ≥0.1 mV) and/or abnormal Q wave** | **V7, V8, V9** |
| 6 | Often combined with inferior wall (II, III, aVF) or lateral wall changes | |

> Memory method: Turn the ECG of V1–V2 upside down + left and right to see the "ST elevation + Q wave" on the posterior wall.

<a id="93-右室肥大rvh"></a>
## 9.3 Right ventricular hypertrophy〈RVH〉

| # | Standard | Lead |
|---|---|---|
| 1 | **R/S ≥ 1**, or **R ≥ 0.7 mV (7 mm)** | **V1** |
| 2 | **R(V1) + S(V5 or V6) ≥ 1.05 mV (10.5 mm)** | V1, V5, V6 |
| 3 | **Right axis deviation ≥ +110°** | Limb leads |
| 4 | **Deep S waves appear in V5 and V6** (R/S ≤ 1) | V5, V6 |
| 5 | **ST-T Strain type**: V1–V3 ST depressed + T inverted | **V1–V3** |

| 7 | VAT for V1 > 0.035 s | V1 |

**Typology of V1 High R**:
- **qR type in V1** → indicates severe RVH (right atrial enlargement and compression) or anteroseptal MI
- **rSR' type** → Right ventricular volume load (ASD)
- **Pure R or Rs type** → RV pressure load (PS, primary pulmonary hypertension, TOF)
- **rS pattern persists until V6** → Chronic cor pulmonale (COPD)

<a id="94-右束支阻滞rbbb"></a>
## 9.4 Right bundle branch block〈RBBB〉

(See 5.1 for diagnostic criteria) - Significance in this chapter: **RBBB is the most common cause of high R waves (R') in V1**.
- Key to identification: The V1 high wave of RBBB is the **second R(R')**, and QRS **≥ 0.12 s**, I and V6 have wide S waves.
- **RBBB + right axis deviation + right atrial enlargement** → suggest combined RVH.

<a id="95-急性肺源性心脏病急性肺栓塞"></a>
## 9.5 Acute pulmonary heart disease (acute pulmonary embolism)

| # | Features | Leads |
|---|---|---|
| 1 | **S1Q3T3 type**: S wave in lead I, Q wave and inverted T wave in lead III | **I, III** |
| 2 | **T wave inversion in right chest leads** (one of the most sensitive findings) | **V1–V4** |
| 3 | **New Completeness/Incompleteness RBBB** | V1 |
| 4 | **Right axis deviation**, clockwise transposition (transition zone left) | |
| 5 | **P Pulmonary Type** (right atrial load) | II, III, aVF |
| 6 | **Sinus Tachycardia** (most common finding, but nonspecific) | |
| 7 | Atrial arrhythmias such as atrial fibrillation/atrial flutter | |
| 8 | V1–V3 ST elevation (rare, easily misdiagnosed as anteroseptal MI) | |

> **Note**: It is not uncommon for pulmonary embolism to have a **normal ECG (about 20–30%)**, and a normal ECG cannot be ruled out. S1Q3T3 is only seen in about 20%. **Dynamic changes (compared with the past) have the greatest value. **

<a id="第-10-章-st-段抬高"></a>
# Chapter 10 ST Segment Elevation

> **Entry point**: When you see ST elevation, judge in order - ① **morphology** (convex surface up vs concave surface up) ② **distribution** (limited to a certain coronary artery area vs widespread) ③ **whether there is mirror depression of the corresponding lead** ④ **whether there is dynamic evolution** ⑤ **whether there is abnormal Q wave**

| Quick Check on Differentiation Keys | AMI | Pericarditis | Early Repolarization | Brugada | Ventricular Aneurysm |
|---|---|---|---|---|---|
| Morphology | **convex up** (arched) | **concave up** | concave up + J wave | **coved (vault)** | convex, fixed |
| Distribution | Coronary territory (limited) | **Extensive (except aVR, V1)** | V2–V5, inferior wall | **V1–V3** | Original infarction site |
| Mirror suppression | **Yes** | **No** (except aVR) | None | None | None |
| PR segment | Normal | **Depression (aVR elevation)** | Normal | Normal | Normal |
| Evolution | **Yes (several hours to days)** | Yes (several days to weeks, 4 periods) | **No (unchanged in the long term)** | Variable (drug-induced) | **No (unchanged for >6 weeks)** |
| Q wave | Yes | No | None | None | **Yes (QS)** |

<a id="101-急性心肌梗死ami-stemi"></a>
## 10.1 Acute myocardial infarction〈AMI / STEMI〉

<a id="st-抬高的诊断阈值第四版心肌梗死通用定义"></a>
### Diagnostic threshold for ST elevation (4th edition universal definition of myocardial infarction)

| Lead | Threshold (measured at **J point**, ≥ 2 adjacent leads) |
|---|---|
| **V2, V3** | Male ≥40 years old: **≥ 0.2 mV**; Male <40 years old: **≥ 0.25 mV**; Female: **≥ 0.15 mV** |
| **All other leads** | **≥ 0.1 mV** |
| **V3R, V4R (right ventricle)** | Male ≥30 years old: ≥ 0.05 mV; Male <30 years old: ≥ 0.1 mV; Female: ≥ 0.05 mV |
| **V7–V9 (posterior wall)** | **≥ 0.05 mV** (Male <40 years old ≥ 0.1 mV) |

<a id="其他要素"></a>
### Other elements
- **morphology**: ST segment **convex side upwards**, merged with T wave into "**monophasic curve/tombstone**"
- **Mirror ST depression in corresponding lead** (reciprocal change) - strongly supports AMI rather than pericarditis
- **Dynamic evolution** (see table 7.1)
- **Positioning** (see 7.1 Positioning table)

<a id="高危征象"></a>
### High-risk signs
- **aVR ST elevation ≥ 0.1 mV + widespread lead ST depression** → Left main/three-vessel disease
- **de Winter type**: V1–V6 J-point depression + upsloping ST depression + **T wave apex symmetry**, aVR mild ST elevation → **LAD proximal occlusion equivalent**
- **Wellens Syndrome**: chest pain in remission **Biphasic or deep inversion of V2–V4 T waves**, preserved R waves, no Q waves → **Severe proximal LAD stenosis**, exercise testing contraindicated

<a id="102-右室梗死rv-infarction"></a>
## 10.2 Right ventricular infarction〈RV infarction〉

| # | Standard | Lead |
|---|---|---|
| 1 | **V4R (V3R–V6R) ST elevation ≥ 0.05–0.1 mV** (most specific, but short-lasting, **must be recorded within 12 hours of onset**) | **V4R** |
| 2 | Combined **Inferior MI** (II, III, aVF ST elevation) | II, III, aVF |
| 3 | **ST elevation III > II** | II, III |
| 4 | **V1 ST elevation** (V1 is the only lead toward the right ventricle among the standard 12 leads); V1 elevation + V2 depression is more suggestive | V1, V2 |
| 5 | Often accompanied by atrioventricular block and atrial infarction (PR segment deviation) | |

**Clinical significance (must remember)**: Triad = **hypotension + jugular venous distention + clear lung fields**; **nitrates, diuretics, and morphine** are prohibited in treatment, and **large amounts of fluids are required**.

<a id="103-变异型prinzmetal心绞痛vap"></a>
## 10.3 Variant (Prinzmetal) angina <VAP>

| # | Features |
|---|---|
| 1 | **Paroxysmal, transient ST-segment elevation** (convex side upward, same shape as AMI), accompanied by chest pain |
| 2 | **ST completely returns to normal after the attack is relieved** (a few minutes to tens of minutes) - Key |
| 3 | Visible during an attack: **T wave apex widens, R wave increases and widens, S wave disappears** |
| 4 | Corresponding lead image depression |
| 5 | Often accompanied by ventricular arrhythmias (PVC, VT, VF) or atrioventricular block** during ** attacks - causes of sudden death |
| 6 | It usually occurs at night ~ early morning and at rest; myocardial enzymes are not elevated (unless continued spasm causes infarction) |

- Diagnosis: Holter capture, acetylcholine/ergonovine challenge test.
- If there is only a transient episode of **ST depression or T wave changes** → non-ST elevation coronary spasm.

<a id="104-室壁瘤ventricular-aneurysm"></a>
## 10.4 Ventricular aneurysm

| # | Standard |
|---|---|
| 1 | History of old MI |
| 2 | **ST elevation that persists for ≥ 4–6 weeks** ("fixed ST elevation") |
| 3 | Presence of **QS wave or deep Q wave** in the same lead |
| 4 | Often accompanied by T wave inversion |
| 5 | No chest pain, no increase in myocardial enzymes, **no dynamic changes** |
| 6 | Prevalent sites: **V1–V4 (anterior wall apex)** |

<a id="105-急性心包炎"></a>
## 10.5 Acute pericarditis

| # | Standard | Lead |
|---|---|---|
| 1 | **ST elevation in broad leads (concave side up)**: I, II, aVF, V2–V6, etc. | Broad |
| 2 | **aVR (and often V1) ST depressed** - the only "mirror" | aVR, V1 |
| 3 | **PR (PQ) segment depression**, and **aVR PR segment elevation** - the most specific finding | II, V5, V6 / aVR |
| 4 | **No abnormal Q wave**, R wave amplitude maintained | |
| 5 | **ST/T ratio > 0.25** (V6, used to identify early repolarization) | V6 |
| 6 | Often accompanied by sinus tachycardia; low voltage + electrical alternans in pericardial effusion | |

**Evolution 4 (Spodick)**:
- **Stage I**: widespread ST elevation + PR depression (several days)
- **Phase II**: ST returns to baseline, T wave flattens (1–3 weeks)
- **Stage III**: **Extensive T-wave inversion** (3–several weeks)
- **Stage IV**: Return to normal (weeks to months, T inversion can also remain for a long time)

>Key difference from AMI: **ST elevation in pericarditis does not occur at the same time as T inversion** (in AMI, T has begun to invert while ST is still elevated).

<a id="106-脑血管障碍尤其蛛网膜下腔出血-sah"></a>
## 10.6 Cerebrovascular disorders (especially subarachnoid hemorrhage SAH)

| # | Features | Leads |
|---|---|---|
| 1 | **Giant inverted T wave〈GNT〉**: wide, deep (can > 1.0 mV), symmetrical, often called "**cerebral T**" | **Broad, especially V2–V6** |
| 2 | **Significant QT prolongation** (QTc may > 0.60 s) → **TdP risk** | II, V5 |
| 3 | **U wave elevation** (obvious) | V2–V4 |
| 4 | ST elevation or depression (can be similar to MI, "**Neurogenic myocardial stunning**") | |
| 5 | **Sinus bradycardia**, various cardiac arrhythmias | |

- Mechanism: Sympathetic storm → Catecholamine myocardial damage. Myocardial enzymes can be slightly elevated (easy to misdiagnose AMI, **Misuse of anticoagulation/thrombolysis can be fatal**).

<a id="107-takotsubo应激性心肌病"></a>
## 10.7 Takotsubo (stress-induced) cardiomyopathy

| Stages | EKG |
|---|---|
| **Acute phase (several hours)** | **Extensive ST elevation in anterior wall leads (V2–V6, I, aVL)**, but **aVR often ST depression**; **The mirror image depression of the corresponding lead is not obvious**; the elevation is smaller than that of AMI in the same range |
| **Subacute phase (2–5 days)** | **Giant inverted T wave (GNT) + significant QT prolongation (QTc often > 0.50 s)** |
| **Recovery period (weeks to months)** | Gradual recovery |

**Identification clues from anterior wall AMI**:
- **No abnormal Q wave**, or only transient Q wave (R wave preserved)
- **ST elevation range is wider than the territory dominated by a single coronary artery**, and **aVR ST depression + V1 no elevation**
- The magnitude of cardiac enzyme elevation** is disproportionate to the range of ST elevation (low)**
- Triggers: **Strong emotional/physical stress**, prone to **Older women**
- Diagnosis is confirmed by left ventricular angiography/ultrasound: apical spherical dilation ("Takotsubo")

<a id="108-brugada-综合征"></a>
## 10.8 Brugada syndrome

<a id="心电图分型v1v3尤其-v1v2"></a>
### ECG classification (V1–V3, especially V1, V2)

| Pattern | J point elevation | ST pattern | T wave |
|---|---|---|---|
| **Type 1 (coved/fornix type)** | **≥ 0.2 mV (2 mm)** | **Downslope type (coved), continuous with T wave** | **Inverted** |
| **Type 2 (saddleback/saddleback)** | ≥ 0.2 mV | Valley ST elevation **≥ 0.1 mV**, upsloping | Upright or biphasic |
| **Type 3** | Saddle or fornix type but ST elevation **< 0.1 mV** | | |

- **Only type 1 is diagnostic** ("Brugada type ECG"); type 2/3 requires drugs (sodium channel blockers: pixicanide, flecainide, ajmalin) to induce conversion to type 1.
- **Diagnostic sensitization technique**: Move the **V1 and V2 electrodes up to the 3rd or 2nd intercostal space** to record → the detection rate is significantly improved.
- Electrocardiogram can detect spontaneous fluctuations** (increased vagal tone, fever, aggravation after eating, drinking).
- Often accompanied by **rSR'-like morphology of V1 (easily mistaken for incomplete RBBB)**, but the absence of wide S waves in I and V6 is the distinguishing point.
- **Brugada Syndrome** = Brugada type ECG (type 1) + one of the following: documented VF/polymorphic VT, surviving cardiac arrest, family history (sudden death <45 years), type 1 ECG in family member, induced VF, nocturnal breathing/syncope.
- Common occurrence: **East Asian adult males, sudden death at night/during sleep**.

<a id="109-低体温hypothermia"></a>
## 10.9 Hypothermia

| # | Features | Leads |
|---|---|---|
| 1 | **Osborn wave (J wave)**: QRS **dome-shaped forward deflection** appearing at the junction of the terminal part and ST, the lower the body temperature, the greater | **V4–V6, II** (obvious in the left lead) |
| 2 | **Sinus bradycardia** | |
| 3 | **PR, QRS, and QT intervals were all prolonged** | |
| 4 | **Baseline Artifacts Caused by Muscle Tremors (Shivers)** | Limb Leads |
| 5 | Progression: atrial fibrillation → junctional rhythm → VF (< 28℃) → asystole | |

- **Other causes for identifying J waves**: Early repolarization, hypercalcemia, SAH, Brugada syndrome, sepsis.

# Chapter 11 T wave elevation

<a id="111-高钾血症hyperkalemia"></a>
## 11.1 Hyperkalemia

<a id="血钾浓度与心电图的对应记忆重点"></a>
### Correspondence between blood potassium concentration and electrocardiogram (memory focus)

| Serum potassium (mEq/L) | ECG changes |
|---|---|
| **5.5 – 6.5** | **Tented T**: **Narrow base, symmetrical, sharp**, QT shortened. Most obvious in **V2–V4** |
| **6.5 – 8.0** | **P wave amplitude decreases, widens → eventually disappears**; **PR prolongs**; **QRS begins to widen** |
| **8.0 – 10** | **QRS significantly widened**, merged with T → **sine wave**; **sinoventricular conduction** |
| **> 10** | **Ventricular fibrillation/ventricular asystole** |

**Identification of high-peaked T waves**:

| Reason | Characteristics |
|---|---|
| **High potassium** | **Narrow, symmetrical, sharp base**, QT shortening, and P wave changes |
| **Hyperacute phase MI** | **Broad base**, asymmetrical, with ST elevation, limited to the coronary artery territory |
| **Early repolarization** | With J wave, ST concave elevation, high R wave |
| Normal variation / high vagal tone | High amplitude but normal morphology |
| Left ventricular volume load | With deep q, high R |
| **de Winter type** | With J point depression + upsloping ST depression |

> **Hypokalemia** See 12.6 (low flat T + elevated U wave), which is the exact opposite of hyperkalemia.

<a id="第-12-章-st-压低t-波低平-倒置"></a>
# Chapter 12 ST depression, T wave flattening/inversion

> **Entry point**: First determine whether it is **primary** (QRS normal) or **secondary** (QRS abnormal: bundle branch block/hypertrophy/pre-excitation/pacing).

<a id="121-心肌缺血劳力性心绞痛-运动负荷试验"></a>
## 12.1 Myocardial ischemia (exertional angina/exercise stress test)

<a id="st-压低的形态学分类"></a>
### Morphological classification of ST depression

| Type | Form | Meaning |
|---|---|---|
| **Horizontal** | ST segment moves downward parallel to the baseline | **Ischemia (significant)** |
| **Downsloping/sagging** | Sloping downward from the J point | **Ischemia (most significant)** |
| **Upsloping** | J point is depressed but ST rises rapidly | Mostly **physiological** (tachycardia, Ta wave); only meaningful when ** is slowly upsloping and 0.08 s after J point is still ≥ 0.1 mV** |
| **sagging/scooped** | fishhook-like | **digitalis effect** |

<a id="定量标准"></a>
### Quantitative standards

| Occasion | Masculine Standard |
|---|---|
| **Resting ECG** | **0.06–0.08 s** after the J point, **horizontal or downsloping depression ≥ 0.05–0.1 mV** |
| **Exercise Stress Test** | **Horizontal or downsloping ST depression ≥ 0.1 mV (1 mm)**, lasting ≥ 0.08 s, occurring in ≥ 2 adjacent leads |
| **Strongly positive (high risk)** | Depression ≥ 0.2 mV; occurs at low load; recovery period lasts > 5 minutes; multiple leads involved; **blood pressure decreases during exercise**; exercise-induced VT |
| **ST elevation during exercise** | Tip **Transmural ischemia/coronary spasm/severe stenosis**, more dangerous than depression |

- Most commonly seen in **V4–V6, II, aVF**.
- **ST depression cannot localize the ischemic site** (unlike ST elevation); **aVR ST elevation + widespread depression** → left main/three branches.

<a id="缺血性-t-波改变"></a>
### Ischemic T wave changes
- **coronary T**: **deep, symmetrical, arrow-like inversion** - indicates subendocardial injury/ischemia
- **Pseudonormalization**: The originally inverted T **becomes upright** during ischemia attack → is a manifestation of ischemia!

<a id="122-心内膜下梗死非-q-波心肌梗死-nstemi"></a>
## 12.2 Subendocardial infarction (non-Q-wave myocardial infarction/NSTEMI)

| # | Standard |
|---|---|
| 1 | **Persistent ST depression** (horizontal/downsloping pattern) and/or **Deep symmetrical inverted T waves**, lasting for several days |
| 2 | **No abnormal Q waves** (R waves maintained), **No ST elevation** |
| 3 | **Elevated myocardial necrosis marker (troponin)** - the only difference from unstable angina pectoris |
| 4 | There is dynamic evolution (different from chronic ST-T changes) |

- **UA vs NSTEMI vs STEMI**: ST elevation → STEMI; no ST elevation + elevated troponin → NSTEMI; no ST elevation + normal troponin → unstable angina.

<a id="123-继发性-st-t-改变"></a>
## 12.3 Secondary ST-T changes

| Definition | Repolarization abnormalities that are bound to occur due to **ventricular depolarization (QRS) abnormalities** |
|---|---|
| **Judgment method** | **The direction of ST-T is opposite to the direction of the main wave of QRS** (discordant) |
| **Common causes** | **Bundle branch block (LBBB, RBBB), ventricular hypertrophy (strain type), WPW pre-excitation, ventricular pacing, PVC, ventricular tachycardia** |
| **Clinical Implication** | **Not to be interpreted as myocardial ischemia** |

- Example: V5–V6 (R wave upward) → ST depression + T inversion during LBBB; V1–V2 (S wave downward) → ST elevation + T upright. This is a "should have" performance.
- **Primary ST-T Clues for altered superposition**: ST-T direction opposite to expected (concordant) → Evaluate with Sgarbossa criteria.

<a id="124-非特异性-st-t-改变"></a>
## 12.4 Non-specific ST-T changes

| Description | Mild ST depression (< 0.1 mV), flat T wave (< 1/10 of R wave), mild T inversion, not fitting any specific pattern |
|---|---|
| **Possible causes** | Autonomic tone (hyperventilation, posture, postprandial, anxiety, cold), female gender, anemia, fever, infection, abnormal thyroid function, mild electrolyte imbalance, drugs, old cardiomyopathy, mild ischemia |
| **Interpretation Principles** | **Must be compared with previous electrocardiograms**; the value of non-specific changes recorded in a single time is limited and needs to be combined with clinical practice |

**Confirmation of postural/physiological T wave changes**: Lead III Q/T change after deep inspiration, standing T change, hyperventilation test, beta blocker test.

<a id="125-洋地黄效应digitalis-effect"></a>
## 12.5 Digitalis effect

| # | Features | Leads |
|---|---|---|
| 1 | **Basin-shaped (fishhook/sagging) ST depression** - Characteristic | **V5, V6, II** (R-wave dominant leads) |
| 2 | **T wave is flat, bidirectional or inverted** (the beginning of T is pulled down by ST) | V5, V6 |
| 3 | **QT interval shortening** - key points | |
| 4 | U wave amplitude increases | |
| 5 | Mild prolongation of PR interval | |

> **"Digitalis effect"≠"Digitalis poisoning"**. Effects are normal at therapeutic concentrations.

**Electrocardiogram of digitalis poisoning** (another story):
- **Atrial tachycardia with atrioventricular block (PAT with block)** - the most typical
- **Bidirectional ventricular tachycardia (bidirectional VT)** - Highly specific
- Accelerated junctional rhythm, atrial fibrillation with regular slow ventricular rate (=complete AVB)
- Various PVCs (bigeminy), II/III degree AVB, sinoatrial block

<a id="126-低钾血症hypokalemia"></a>
## 12.6 Hypokalemia

| Serum potassium | Electrocardiogram |
|---|---|
| **< 3.5** | **T wave amplitude decreased and flat**; **U wave increased** |
| **< 3.0** | **U 波 > T wave** (most obvious in V2–V3); **ST segment depression**; T-U fusion → looks like "QT prolongation" (actually **QU prolongation**) |
| **< 2.5** | T inversion, U wave significant, **QU significantly prolonged → torsade de pointes**; PR prolonged, P wave increased, QRS widened |

- Best observation leads: **V2, V3** (U wave is the most obvious)
- Inducers: Diuretics, Vomiting/Diarrhea, Aldolosis, Cushing, Insulin, Beta Agonists
- **Hypomagnesemia** has similar symptoms, and hypokalemia is often combined with hypomagnesium (magnesium supplementation is necessary when potassium supplementation is ineffective)

<a id="127-巨大倒置-t-波gnt-giant-negative-t"></a>
## 12.7 Giant inverted T wave〈GNT / giant negative T〉

**Definition**: T-wave inversion depth **> 1.0 mV (10 mm)**

**DIFFERENTIAL DIAGNOSIS (5 BIG CAUSES)**:

| Disease | Identification Clues |
|---|---|
| **Apical hypertrophic cardiomyopathy (APH)** | **V4 deepest** + **LV high voltage** + **No QT prolongation (or mild)** + No Q wave; more common in Japanese |
| **Takotsubo cardiomyopathy** | **Significant QT prolongation**, strong stress triggers, early ST elevation, and no apical motion |
| **Cerebrovascular disorders (SAH, cerebral hemorrhage, cerebral infarction)** | **Extreme QT prolongation + significant U wave** + sinus bradycardia; neurological symptoms |
| **Myocardial ischemia/Wellens syndrome** | **V2–V4** Biphasic or deep inverted T, preserved R waves, history of chest pain → proximal LAD lesion |
| **Complete atrioventricular block/after pacing (cardiac memory)** | After restoring sinus rhythm, the T wave remains inverted for a period of time, and the direction is consistent with previous pacing QRS |

Others: Pheochromocytoma, after massive pericardial effusion, acute pulmonary embolism, after intermittent LBBB.

<a id="第-13-章-qt-延长与缩短"></a>
# Chapter 13 QT extension and shortening

<a id="130-qt-的测量与判定"></a>
## 13.0 Measurement and Determination of QT

- Measurement leads: **II, V5 (whichever is the longest)**; avoid leads with U-wave interference
- **QTc（Bazett）= QT / √RR(s)**
- **Upper limit of normal**: 0.44 s for men, 0.46 s for women; **≥ 0.48 s (men)/0.48 s (women) definitely prolonged**; **≥ 0.50 s high risk**
- **Shortened**: QTc **≤ 0.34–0.36 s**
- **QT dispersion**: Longest QT − Shortest QT in 12 leads, > 0.06–0.08 s indicates uneven repolarization (arrhythmia risk)

<a id="131-低钙血症hypocalcemia"></a>
## 13.1 Hypocalcemia〈hypocalcemia〉

| Features |
|---|
| **ST segment prolongation (flattened, elongated)** → **QT interval prolongation** |
| **T wave shape and width are normal** (Key: ST is lengthened, not T) |
| In severe cases, T waves may be flattened/inverted |

- Causes: Hypoparathyroidism, chronic renal failure, vitamin D deficiency, massive blood transfusion (citrate), acute pancreatitis
- Differentiation from other QT prolongations: **Hypocalcemia = ST prolongation; Drug/LQTS = T wave widening**

<a id="132-高钙血症hypercalcemia"></a>
## 13.2 Hypercalcemia〈hypercalcemia〉

| Features |
|---|
| **ST segment shortened or disappeared** (T wave immediately after QRS) → **QT interval shortened** |
| In severe cases, the T wave widens and the amplitude increases; **J wave (Osborn wave)** may appear |
| Extremely severe: PR prolongation, QRS widening, atrioventricular block, cardiac arrest |

- Causes: Hyperparathyroidism, malignant bone metastasis/PTHrP, sarcoidosis, vitamin D toxicity, thiazides

<a id="133-先天性-qt-延长综合征congenital-lqts"></a>
## 13.3 Congenital QT prolongation syndrome〈congenital LQTS〉

<a id="诊断要素"></a>
### Diagnostic elements

| # | Project |
|---|---|
| 1 | **QTc Extended**: ≥ 0.48 s clear; 0.46–0.47 s doubtful |
| 2 | **Abnormal T-wave morphology** (see table below), **T-wave alternans** - Highly Warning |
| 3 | History of **TdP/Syncope/Cardiac Arrest** Episodes |
| 4 | **Family History** (LQTS or sudden unexplained death < 30 years old) |
| 5 | Bradycardia (relative to age) |
| ※ | **Schwartz score ≥ 3.5 points** can be diagnosed |

<a id="主要基因型的心电图与诱因"></a>
### ECG and triggers of major genotypes

| Type | Gene/Channel | T-wave morphology | Typical triggers |
|---|---|---|---|
| **LQT1 (~45%)** | KCNQ1 (IKs↓) | **Broad, smooth broad T wave with broad base** | **Exercise, especially swimming**; sympathetic excitement |
| **LQT2 (~40%)** | KCNH2/HERG (IKr↓) | **Low amplitude, notched/bimodal T wave** | **Sudden sound stimulation (alarm clock, phone)**, mood, postpartum |
| **LQT3 (~8%)** | SCN5A (late INa↑) | **ST segment is long and flat, followed by a delayed sharp T wave** | **During sleep and bradycardia** |

- **Jervell-Lange-Nielsen syndrome**: autosomal recessive + **congenital deafness**, extreme QT prolongation
- **Romano-Ward syndrome**: autosomal dominant, normal hearing

<a id="134-药物性-qt-延长drug-induced-lqt-获得性-lqts"></a>
## 13.4 Drug-induced QT prolongation (drug-induced LQT)/acquired LQTS

<a id="主要致病药物"></a>
### Main causative drugs

| Category | Representative medicine |
|---|---|
| **Antiarrhythmic drugs Class Ia** | Quinidine, disopyramide, cibendazoline |
| **Antiarrhythmic Class III** | Sotalol, amiodarone (significant QT prolongation but low TdP), nifekalant, dofetilide |
| **Antipsychotics/antidepressants** | Haloperidol, thioridazine, chlorpromazine, tricyclics (amitriptyline, etc.) |
| **Antimicrobials** | **Macrolides (erythromycin, clarithromycin)**, fluoroquinolones (moxifloxacin, etc.), pentamidine |
| **Antifungals** | Azoles (itraconazole, fluconazole) |
| **Digestive system drugs** | Cisapride (withdrawn from the market), domperidone, ondansetron |
| **Others** | Arsenic, tyrosine kinase inhibitors, hydroxychloroquine, methadone |

<a id="促发-tdp-的危险因素叠加效应"></a>
### Risk factors that contribute to TdP ("stacked" effect)
**Hypokalemia, Hypomagnesium, Hypocalcium**; **Bradycardia** (especially complete AVB, post-sinus arrest); Female gender; Heart failure/left ventricular hypertrophy; **Drug interactions (CYP3A4 inhibition)**; Hepatic and renal insufficiency; Rapid intravenous administration; **Long-short RR sequence**.

<a id="tdp-的先兆心电图"></a>
### ECG with aura in TdP
- QTc Progressive prolongation (> 0.50 s)
- **T-U wave deformation, U wave enlargement, T wave electrical alternation**
- **"Short-Long-Short" sequence** (PVC → compensatory interval → next move QT longer → R on T)

<a id="第-14-章-u-波增高与倒置"></a>
# Chapter 14 U wave heightening and inversion

<a id="140-u-波的基础"></a>
## 14.0 Basics of U waves
- Normal: in the same direction as T (upright), amplitude **< 1/2 of T**, **V2–V3 most pronounced**
- **U wave elevation**: > 0.1–0.2 mV, or **U > T**
- **U wave inversion (Yin Yu)**: **U wave inversion in any lead except aVR is abnormal**

| Classification | Causes |
|---|---|
| **U-wave elevation** | **Hypokalemia (most common)**, Hypomagnesium, bradycardia, digitalis, Class Ia/III antiarrhythmics, LQTS, SAH/cerebrovascular disorders, hyperthyroidism, athletes (physiological), **Posterior myocardial ischemia** |
| **U wave inversion** | **Myocardial ischemia (especially anterior wall/left main, LAD lesions)**, **Hypertension/left ventricular hypertrophy**, aortic regurgitation, mitral regurgitation, hyperkalemia (rare) |

<a id="141-心肌缺血-前壁缺血u-波倒置"></a>
## 14.1 Myocardial ischemia—anterior wall ischemia (U wave inversion)

| # | Features | Leads |
|---|---|---|
| 1 | **U wave inversion** | **V4–V6, I, aVL (left chest leads)** |
| 2 | **New U-wave inversion during/after exercise stress testing** → **Highly specific for LAD lesions** (specificity > 90%) | V4–V6 |
| 3 | Can appear alone when there is no change in the ST segment - the only clue | |
| 4 | U inversion at rest also indicates severe left anterior descending stenosis or left main disease | |

<a id="142-心肌缺血-后壁缺血u-波增高"></a>
## 14.2 Myocardial ischemia—posterior wall ischemia (increased U wave)

| # | Features | Leads |
|---|---|---|
| 1 | **U-wave increased amplitude (upright)** | **V1–V3 (right chest leads)** |
| 2 | Mechanism: Posterior wall U wave inversion manifests as **mirror image upright elevation** in the right chest leads** | |
| 3 | Tips for **RCA or LCX (posterior wall feeding vessels) lesions** | |

> Memory: **Inversion of U in left lead = anterior wall ischemia; Elevated U in right lead = posterior wall ischemia** (mirror images of each other).

<a id="第-15-章-提前出现的-p-或-qrs期前收缩"></a>
# Chapter 15 Premature P or QRS (pre-period contraction)

> **First judgment point**: Is the advanced QRS **wide or narrow**? Is there any advance P'** before it?

<a id="151-心室期前收缩pvc-vpc"></a>
## 15.1 Premature ventricular contraction 〈PVC / VPC〉

| # | Standard |
|---|---|
| 1 | **Early onset of wide deformity QRS, time limit ≥ 0.12 s** |
| 2 | **No relevant P wave before it** (sinus P may fall but is not relevant) |
| 3 | **Secondary ST-T change**: ST-T direction is opposite to QRS main wave** |
| 4 | **There is often a complete compensatory interval** (the distance between the two sinus R before and after the PVC = 2 times the normal RR) |
| 5 | There is often a fixed **coupling interval** |

**Presumption of origin**:

| V1 Form | Origin |
|---|---|
| **LBBB type (V1 main wave downward)** | **Right ventricle** (or near the left side of the interventricular septum) |
| **RBBB type (V1 main wave upward)** | **Left ventricle** |
| **Inferior leads (II, III, aVF) high R+ axis downward** | **Outflow tract (RVOT/LVOT)** |
| **The main wave of inferior wall leads is downward (electrical axis is upward)** | Apex/inferior wall |
| Transition zone ≤ V2 | LVOT / aortic sinus |

<a id="152-插入性-pvc-与伴代偿间歇的-pvc"></a>
## 15.2 Insertive PVC and PVC with compensated intervals

| Type | Definition | Meaning |
|---|---|---|
| **Compensatory pause** | Two sinus QRS intervals before and after the PVC **= 2 × normal RR**. Because retrograde impulses are blocked within the AVN, the sinoatrial node is not reorganized | Typical manifestations of PVC |
| **Interpolated PVC** | PVC **sandwiched between two normal sinus beats, uncompensated interval**, total RR unchanged; often seen in bradycardia | Sinus beats after PVC often have **PR prolongation** (occult retrograde AVN should not occur) |
| **Incomplete Compensation Interval** | Spacing < 2 × RR. Seen in **atrial/junctional premature contractions** (retrograde reorganization of the sinoatrial node) | suggestive of supraventricular origin |

<a id="153-pvc-的分类"></a>
## 15.3 Classification of PVC

<a id="形态学与配布"></a>
### Morphology and Distribution

| Classification | Definition |
|---|---|
| **Monogeny (monomorphism)** | Identical morphology in the same lead, fixed association interval |
| **Polymorphism (polymorphism)** | Forms ≥ 2, association interval is not fixed |
| **bigeminy** | 1 sinus beat followed by 1 PVC |
| **trigeminy** | every 2 sinus beats followed by 1 PVC |
| **couplet/pair** | 2 PVCs in a row |
| **Non-sustained VT** | ≥ 3 PVCs in a row, lasting < 30 s |
| **R on T phenomenon** | PVC falls near the peak of the T wave of the previous heartbeat (vulnerable period) → **can induce VF / TdP** |

<a id="lown-分级急性-mi-中的危险度分层现代已较少用于非缺血患者"></a>
### Lown classification (risk stratification in acute MI, less commonly used in non-ischemic patients in modern times)

| Level | Content |
|---|---|
| 0 | No PVC |
| 1 | Occasionally, < 30 times/hour |
| 2 | Frequent, ≥ 30 times/hour |
| 3 | Polygenesis (polymorphism) |
| **4a** | **Couplets (2 consecutive beats)** |
| **4b** | **Triplets or more (non-sustained VT)** |
| **5** | **R on T** |

> Modern perspective: **The presence or absence of organic heart disease (especially left ventricular function) is more prognostically significant than the Lown classification.** Frequent PVCs in the absence of organic heart disease are usually benign, but a PVC burden > 10–20% can lead to PVC-induced cardiomyopathy.

**Indicators of "benign PVCs"**: decrease/disappearance after exercise, monomorphic, fixed coupling interval, no organic heart disease, QRS duration relatively narrow (< 0.14 s), RVOT origin morphology.

<a id="154-并行心律parasystole"></a>
## 15.4 Parasystole

| # | Three Major Diagnostic Criteria |
|---|---|
| 1 | **Variable coupling interval** (variation in the interval between the ectopic beat and the preceding sinus beat > 0.08–0.1 s) |
| 2 | **The intervals between ectopic beats (ectopic intervals) have a greatest common divisor** (all ectopic intervals are integer multiples of the shortest interval) |
| 3 | **Presence of fusion beats** |

- Mechanism: An **entrance block** exists around the ectopic pacemaker, which is not reset by the sinus rhythm and fires independently.
- Can be ventricular (most common), atrial, or junctional.
- Generally good prognosis; poor response to antiarrhythmic drugs.

<a id="155-室上性期前收缩svpc-pac"></a>
## 15.5 Supraventricular Premature Contractions (SVPC / PAC)

| # | Criteria |
|---|---|
| 1 | **Premature P' wave with a morphology different from sinus P** (the earlier the prematurity, the greater the morphological difference; often hidden in the preceding T wave → **carefully examine whether the T wave morphology is distorted**) |
| 2 | **P'R interval ≥ 0.12 s** (atrial); PR may be longer than sinus (due to partial AVN refractoriness) |
| 3 | **QRS morphology identical to sinus (narrow)** |
| 4 | **Incomplete compensatory pause** (retrograde reset of the SA node) |
| 5 | Exception: **Aberrant conduction** causes QRS to widen, usually presenting as **RBBB type (V1 rsR')**, because the right bundle branch has the longest refractory period |

**Differentiation between SVPC with aberrancy and PVC**:

| Item | SVPC with Aberrancy | PVC |
|---|---|---|
| Premature P' | **Present** (hidden in the preceding T wave) | Absent |
| QRS morphology | **Usually RBBB type (V1 shows rsR', triphasic)** | Often monophasic/biphasic, more bizarre morphology |
| QRS initial vector | **Same as sinus** | Different from sinus |
| Compensatory pause | **Incomplete** | Complete |
| Preceding RR | **Occurs after a long RR (Ashman phenomenon)** | No such pattern |

<a id="156-室上性期前收缩的分类"></a>
## 15.6 Classification of Supraventricular Premature Contractions

| Classification Axis | Category |
|---|---|
| **Origin Site** | **Atrial (PAC)**: P' upright or abnormal morphology, P'R ≥ 0.12 s<br>**Junctional (PJC)**: P' retrograde (inverted in II/III/aVF) or absent, P'R < 0.12 s |
| **Conduction Outcome** | **Normal conduction**: narrow QRS<br>**Aberrant conduction**: wide QRS (usually RBBB type)<br>**Blocked (non-conducted)**: no QRS after P' |
| **Distribution** | Isolated / bigeminy / trigeminy / couplets / **short runs of atrial tachycardia (≥ 3 consecutive beats)** |
| **Clinical Significance** | Frequent PACs (> 100–500/day) are an **independent predictor of new-onset atrial fibrillation** |

<a id="第-16-章-该出现的-p-或-qrs-没有出现漏搏"></a>
# Chapter 16 Missing P or QRS (Dropped Beats)

> **Golden Rule: When seeing a "long pause," the first thing to do is check if there is a hidden premature P' in the preceding T wave (non-conducted SVPC is the most common cause).**

<a id="161-窦性停搏sinus-arrest-sinus-pause"></a>
## 16.1 Sinus Arrest (Sinus Pause)

| # | Criteria |
|---|---|
| 1 | **Simultaneous absence of P waves and QRS**, resulting in a long pause |
| 2 | **The long pause is not an integer multiple of the basic PP interval** — key distinction from SA block |
| 3 | Arrest **≥ 3.0 s** is clinically significant (when awake) |
| 4 | Junctional/ventricular escape beats may follow the long pause |

<a id="162-窦房阻滞sa-block"></a>
## 16.2 Sinoatrial Block (SA Block)

| Type | Criteria |
|---|---|
| **First-degree SA block** | **Cannot be diagnosed on ECG** (SA node potentials are not visible) |
| **Second-degree Mobitz Type I (Wenckebach)** | **PP intervals gradually shorten**, followed by a long pause; **long pause < 2 × shortest PP** |
| **Second-degree Mobitz Type II** | PP constant, **long pause exactly = integer multiple of basic PP (2×, 3×…)** — definitive criterion |
| **Third-degree (Complete) SA block** | P waves completely disappear, indistinguishable from sinus arrest |

<a id="163-mobitz-ii-型-ii-度房室阻滞"></a>
## 16.3 Second-Degree AV Block, Mobitz Type II

| # | Criteria |
|---|---|
| 1 | **Constant PR interval** (for conducted beats) |
| 2 | **Sudden absence of QRS after a P wave** (without warning) |
| 3 | PP intervals regular (including at the dropped beat) |
| 4 | **QRS often widened (with bundle branch block)** — suggests block site is **below the His bundle (His-Purkinje system)** |

**Clinical Significance**: **High risk!** Prone to progress to complete AV block and Stokes-Adams attacks → **Indication for permanent pacemaker (even if asymptomatic)**. Atropine is **ineffective or may worsen** the condition.

<a id="164-wenckebach-型mobitz-i-型ii-度房室阻滞"></a>
## 16.4 Second-Degree AV Block, Wenckebach Type (Mobitz Type I)

| # | Criteria |
|---|---|
| 1 | **PR interval progressively lengthens** until a P wave is not conducted (QRS dropped) |
| 2 | **PR increment gradually decreases** → **RR intervals gradually shorten** |
| 3 | **Long RR including the drop < 2 × shortest RR** |
| 4 | The first PR after the drop is the shortest (cycle restarts) |
| 5 | **QRS usually narrow** — block site is **within the AVN** |
| 6 | Conduction ratio expressed as 4:3, 3:2, etc. |

**Clinical Significance**: **Usually benign** (increased vagal tone, athletes, sleep, inferior MI, drugs). Exercise or atropine may improve it. Asymptomatic patients generally do not require a pacemaker.

<a id="165-未下传阻滞型室上性期前收缩blocked-svpc"></a>
## 16.5 Non-conducted (Blocked) Supraventricular Premature Contractions (Blocked SVPC)

| # | Criteria |
|---|---|
| 1 | **T wave morphology before the long pause differs from other T waves** (sharper, taller, notched) → **hiding a premature P'** |
| 2 | **No QRS follows this P'** (because it occurs too early, falling within the absolute refractory period of the AVN) |
| 3 | Sinus rhythm resumes after the long pause |

> **Most clinically valuable differentiating point**: This is the most common cause of "dropped beats," **completely benign**, but easily misdiagnosed as second-degree AV block or sinus arrest, leading to unnecessary pacemaker implantation. **Must compare T wave morphologies one by one!**

# Chapter 17 Bradycardia

<a id="171-窦性心动过缓sinus-bradycardia"></a>
## 17.1 Sinus Bradycardia

| Criteria | Sinus rhythm (normal P waves) + **Heart rate < 50–60 bpm** |
|---|---|
| Physiological | Athletes, during sleep, young people with high vagal tone |
| Pathological | Hypothyroidism, hypothermia, increased intracranial pressure, jaundice, **inferior MI**, SSS |
| Drug-induced | **Beta-blockers, calcium channel blockers (verapamil/diltiazem), digoxin, amiodarone, anticholinesterase drugs** |

<a id="172-窦房结功能不全综合征sss"></a>
## 17.2 Sick Sinus Syndrome (SSS)

**Rubenstein Classification**:

| Type | ECG |
|---|---|
| **Type I** | **Persistent significant sinus bradycardia** (< 50 bpm), non-drug induced |
| **Type II** | **Sinus arrest and/or SA block** (long pauses) |
| **Type III** | **Tachy-brady syndrome** (see 17.3) |

- Diagnostic aids: **Loss of heart rate variability, failure of heart rate to increase during exercise (chronotropic incompetence, maximum heart rate < 100–120）**、阿托品试验（心率上升 < 25% 或 < 90 次/分为阳性）、电生理检查（SNRT > 1500 ms, CSNRT > 550 ms)**
- **Symptoms (syncope, dizziness, heart failure, fatigue)** + **confirmed causal relationship** with bradycardia → Indication for pacemaker

<a id="173-徐脉-频脉综合征brady-tachy-syndrome"></a>
## 17.3 Brady-tachy syndrome

| # | Criteria |
|---|---|
| 1 | **Episodes of rapid atrial arrhythmias (AF, atrial flutter, atrial tachycardia)** |
| 2 | **Prolonged sinus arrest (pause) following termination** —— "**overdrive suppression**" |
| 3 | Long pauses often > 3–5 s → **Syncope (Adams-Stokes attacks)** |

- Therapeutic dilemma: Antiarrhythmic drugs exacerbate bradycardia → **Pacemaker + antiarrhythmic drugs/ablation often required**.

<a id="174-21-房室阻滞"></a>
## 17.4 2:1 Atrioventricular Block

| # | Criteria |
|---|---|
| 1 | **Every second P wave conducts** (Number of P waves = Number of QRS × 2) |
| 2 | **Constant PR interval** for conducted beats |
| 3 | **Cannot distinguish between Mobitz I and II based on 2:1 block alone** (because continuous PR changes are not visible) |

**Clues to infer the site of block**:

| Suggests AVN (Mobitz I-like, relatively benign) | Suggests below His bundle (Mobitz II-like, high risk) |
|---|---|
| **Narrow QRS** | **Wide QRS (bundle branch block)** |
| **Markedly prolonged PR (> 0.30 s)** | Normal PR |
| Conduction **improves** with exercise/atropine | Conduction **worsens** with exercise/atropine |
| Conduction **worsens** with carotid sinus massage | Conduction **improves** with massage |
| Often associated with inferior MI, digoxin, vagal tone | Often associated with anterior MI, degenerative conduction system disease |

<a id="175-高度房室阻滞advanced-high-grade-avb"></a>
## 17.5 Advanced / High-grade Atrioventricular Block

| Criteria | **≥ 2 consecutive P waves fail to conduct** (Conduction ratio ≥ 3:1, e.g., 3:1, 4:1) |
|---|---|
| Characteristics | Some P waves still conduct (fixed PR) → Distinguishes from complete AVB |
| Often accompanied by | Junctional/ventricular escape beats, escape-capture bigeminy |
| Significance | **High risk, indication for pacemaker** |

<a id="176-完全性房室阻滞iii-度-avb"></a>
## 17.6 Complete Atrioventricular Block (Third-degree AVB)

| # | Criteria |
|---|---|
| 1 | **P waves and QRS are completely dissociated (AV dissociation)** —— PR interval varies randomly |
| 2 | **Regular PP intervals** (Atrial rate > Ventricular rate) |
| 3 | **Regular RR intervals** (Escape rhythm, slower than PP) |
| 4 | Number of P waves > Number of QRS |

**Prognosis depends on the level of the escape rhythm**:

| Escape Origin | QRS | Rate | Risk |
|---|---|---|---|
| **AVN / His bundle (Junctional)** | **Narrow (< 0.12 s)** | **40–60 bpm** | Relatively stable, atropine may be effective |
| **Below His bundle (Ventricular)** | **Wide (≥ 0.12 s)** | **20–40 bpm** | **High risk** (prone to asystole, TdP), atropine ineffective |

**Special scenarios**:
- **AF + regular slow RR** → **AF with complete AVB** (often due to digoxin toxicity)
- **Congenital complete AVB**: Usually junctional escape, narrow QRS, faster rate (50–60 bpm), relatively better prognosis
- **Complete AVB + prolonged QT → TdP ("asystolic attacks")**, requires attention

**AV dissociation ≠ Complete AVB**: If ventricular rate > atrial rate (e.g., accelerated junctional rhythm, VT), it is called "interference AV dissociation," which has a completely different mechanism.

<a id="第-18-章-心动过速窄-qrs规则"></a>
# Chapter 18 Tachycardia: Narrow QRS, Regular

> **Analysis workflow**: ① What is the heart rate? ② Can P' waves be identified? ③ **Where are the P' waves (RP' interval)**? ④ Response to vagal maneuvers/adenosine?

<a id="180-窄-qrs-心动过速的鉴别流程"></a>
## 18.0 Differential diagnosis workflow for narrow QRS tachycardia

```
窄 QRS 心动过速（QRS < 0.12 s）
├── 不规则 → 房颤 / 房扑伴不等比传导 / 多源性房速
└── 规则
    ├── 有正常窦性 P（P 在 QRS 前，形态同窦性）
    │   ├── 心率 100–180，渐起渐止 → 窦性心动过速
    │   └── 突发突止 → 窦房结折返性心动过速（SANRT）
    ├── 找不到 P（藏在 QRS 内）→ AVNRT（典型型）
    ├── P' 在 QRS 之后、ST 段上（RP' 短，< 1/2 RR）
    │   ├── RP' < 70 ms → AVNRT
    │   └── RP' > 70 ms → AVRT（顺向型）
    ├── P' 在 T 波附近（RP' 长，> 1/2 RR）→ 房速 / 非典型 AVNRT / PJRT
    └── 锯齿状 F 波，心率 ≈150 → 2:1 心房扑动
```

**Response to Adenosine (ATP) / Vagal Stimulation**:
- **Sudden termination** → AVNRT or AVRT (AVN is part of the reentrant circuit)
- **Transient slowing followed by resumption** → Sinus tachycardia, Atrial tachycardia
- **Increased AV conduction ratio, exposing F/P' waves** → Atrial flutter, Atrial tachycardia

<a id="181-窦性心动过速sinus-tachycardia"></a>
## 18.1 Sinus Tachycardia

| # | Criteria |
|---|---|
| 1 | Sinus P waves (upright in II, III, aVF; inverted in aVR), identical in morphology to resting state |
| 2 | **Heart rate 100–180 bpm** (upper limit ≈ 220 − age) |
| 3 | **Gradual onset, gradual termination** (warm-up / cool-down) |
| 4 | Heart rate fluctuates slightly with respiration/position/emotion |
| 5 | At high rates, P may merge with the preceding T wave → watch for "camel-hump T" |

- Etiology: Fever, anemia, dehydration, pain, anxiety, hyperthyroidism, heart failure, shock, pulmonary embolism, caffeine/catecholamines/medications
- **It is a "symptom" rather than a disease** → Identify the cause; do not blindly use β-blockers

<a id="182-阵发性室上性心动过速-房室折返性心动过速avrt"></a>
## 18.2 Paroxysmal Supraventricular Tachycardia — Atrioventricular Reentrant Tachycardia (AVRT)

| # | Criteria |
|---|---|
| 1 | Heart rate **150–250 bpm**, rhythm **absolutely regular** |
| 2 | **Paroxysmal onset and termination** |
| 3 | **Orthodromic (90%): Narrow QRS** (antegrade conduction via AVN, retrograde via accessory pathway) |
| 4 | **Retrograde P' (inverted in II/III/aVF) located on the ST segment after the QRS**, **RP' > 70 ms**, and **RP' < P'R** |
| 5 | **QRS electrical alternans (QRS alternans)** —— relatively specific for AVRT |
| 6 | **δ wave (manifest WPW)** visible during sinus rhythm; sinus rhythm is normal with concealed accessory pathways |
| 7 | **Antidromic (5–10%): Wide QRS** (antegrade conduction via accessory pathway) → See Chapter 19 |
| 8 | **Bundle branch block (ipsilateral to the accessory pathway) during tachycardia prolongs the cycle length by ≥ 35 ms** → highly suggestive of AVRT |

<a id="183-阵发性室上性心动过速-房室结折返性心动过速avnrt"></a>
## 18.3 Paroxysmal Supraventricular Tachycardia — Atrioventricular Nodal Reentrant Tachycardia (AVNRT)

| # | Criteria |
|---|---|
| 1 | Heart rate **150–250 bpm** (often around 180), absolutely regular |
| 2 | Paroxysmal onset and termination; often triggered by a **PAC with a sudden jump in PR interval (jump up)** |
| 3 | **Typical (slow-fast, 90%): P' buried within the QRS, invisible**; or immediately following the QRS, **RP' < 70 ms** |
| 4 | **Pseudo-r' wave: Small r' in V1** not present during sinus rhythm |
| 5 | **Pseudo-s wave: Terminal small s in II, III, aVF** not present during sinus rhythm |
| 6 | **Atypical (fast-slow / slow-slow, 10%):** **Long RP'**, P' before the T wave, deeply inverted in II/III/aVF → easily confused with atrial tachycardia |
| 7 | **Most common PSVT** (~60%), prevalent in middle-aged women |

**Quick Reference: AVNRT vs AVRT**:

| Feature | AVNRT | AVRT (Orthodromic) |
|---|---|---|
| RP' | **< 70 ms** | **> 70 ms** |
| P' Location | Buried in QRS / adjacent | On ST segment, clearly visible |
| Pseudo-r'(V1), Pseudo-s(inferior) | **Present** | Absent |
| QRS electrical alternans | Rare | **More common** |
| δ wave during sinus rhythm | Absent | May be present (manifest WPW) |
| Typical Age/Gender | Middle-aged, mostly female | Young, mostly male |

<a id="184-阵发性室上性心动过速-窦房结折返性心动过速sanrt-sart"></a>
## 18.4 Paroxysmal Supraventricular Tachycardia — Sinoatrial Reentrant Tachycardia (SANRT / SART)

| # | Criteria |
|---|---|
| 1 | **P wave morphology identical or very similar to sinus P** (reentrant circuit within/around the SA node) |
| 2 | **Paroxysmal onset and termination** —— **definitive distinction** from sinus tachycardia |
| 3 | Relatively slower heart rate: **100–150 bpm** |
| 4 | PR interval normal or slightly prolonged (consistent with heart rate) |
| 5 | Can be triggered and terminated by PACs; vagal stimulation can terminate |
| 6 | Rare (< 5% of PSVT) |

<a id="185-房性心动过速at"></a>
## 18.5 Atrial Tachycardia (AT)

| # | Criteria |
|---|---|
| 1 | **P' wave morphology different from sinus P** (ectopic origin) |
| 2 | **Atrial rate 100–250 bpm** (mostly 150–200) |
| 3 | **Isoelectric line between P' waves** —— distinction from atrial flutter (no isoelectric line) |
| 4 | **P'R interval normal or prolonged**, and **RP' > P'R (long RP' type)** |
| 5 | **May be accompanied by AV block (e.g., 2:1) without terminating the tachycardia** —— definitive distinction from AVNRT/AVRT (where AVN is an essential part of the reentrant circuit) |
| 6 | Onset often shows **"warm-up" phenomenon** (automaticity mechanism) |

- **Multifocal Atrial Tachycardia (MAT)**: ≥ 3 P' morphologies, irregular PP/PR intervals, heart rate > 100 → **Severe COPD, theophylline toxicity, hypokalemia**
- **Atrial Tachycardia with AV Block (PAT with block)** → **First suspect digoxin toxicity**

<a id="186-21-传导的心房扑动"></a>
## 18.6 Atrial Flutter with 2:1 Conduction

| # | Criteria |
|---|---|
| 1 | **Ventricular rate constant at ~150 bpm (140–160)** —— **For any regular narrow QRS tachycardia at this rate, 2:1 atrial flutter must be ruled out first** |
| 2 | F wave frequency ~300 bpm, with half hidden in the QRS or T wave |
| 3 | Observe **sawtooth baseline in II, III, aVF** and **upright P-like waves in V1** |
| 4 | **Heart rate changes in "jumps"** (150 → 100 → 75, corresponding to 2:1 → 3:1 → 4:1) rather than continuous changes |
| 5 | **Confirmation method**: Carotid sinus massage / adenosine → increased AV ratio, F waves fully exposed |

<a id="第-19-章-心动过速宽-qrs规则"></a>
# Chapter 19 Tachycardia: Wide QRS, Regular

> **Principle: Wide QRS tachycardia should be treated as Ventricular Tachycardia (VT) until proven otherwise.** In the emergency setting, VT accounts for **80%** of wide QRS tachycardias (> 95% in patients with a history of old MI).
> **Contraindication**: Verapamil is contraindicated in undiagnosed wide QRS tachycardia (can cause hemodynamic collapse).

<a id="190-vt-vs-svt-伴差传的鉴别标准"></a>
## 19.0 Differentiation Criteria: VT vs SVT with Aberrancy

<a id="支持-vt-的决定性所见三大法宝"></a>
### Definitive Findings Supporting VT ("The Three Treasures")

| # | Finding | Description |
|---|---|---|
| 1 | **AV Dissociation** | Independent P waves appear at their own frequency, unrelated to QRS. **Most specific (specificity ~100%)**, but visible in only ~20–30% of cases. Check leads II, V1, esophageal lead |
| 2 | **Capture Beat** | Sudden appearance of a **narrow QRS** (sinus impulse conducting down) during tachycardia → confirms VT |
| 3 | **Fusion Beat** | Simultaneous ventricular activation by sinus and ventricular impulses, QRS morphology intermediate between the two → confirms VT |

<a id="其他支持-vt-的所见"></a>
### Other Findings Supporting VT

| Finding | Content |
|---|---|
| **Extreme QRS widening** | RBBB pattern > 0.14 s; LBBB pattern > 0.16 s |
| **Precordial Concordance** | **QRS main deflections in V1–V6 are all upward or all downward** (all downward = negative concordance, almost diagnostic of VT) |
| **Extreme Axis Deviation ("Northwest Axis")** | −90° to ±180° |
| **No RS Complex (Brugada Step 1)** | No RS morphology in any precordial lead → VT |
| **RS Interval > 100 ms (Brugada Step 2)** | From R onset to S nadir in any precordial lead > 100 ms → VT |
| **Initial R wave in aVR (Vereckei criteria)** | Initial R wave in aVR → VT |
| **V1 morphology (RBBB pattern)** | Monophasic R, **qR**, **Rsr' (left ear > right ear, "rabbit ear sign")** → VT; Triphasic rsR' (right ear > left ear) → SVT |
| **V6 morphology (RBBB pattern)** | **R/S < 1**, QS, qR → VT |
| **V1/V2 morphology (LBBB pattern)** | **r wave duration > 30 ms**, notching on S wave downstroke, **QRS onset to S wave nadir > 60 ms** → VT |
| **Q wave in V6 (LBBB pattern)** | qR or QS → VT |
| **Clinical clues** | **History of prior myocardial infarction, poor cardiac function, age > 35 years** → Strongly suggests VT |

<a id="支持-svt-伴差异传导的所见"></a>
### Findings supporting SVT with aberrancy
- **Typical RBBB or LBBB morphology** (V1 shows triphasic rsR', V6 has qRs)
- **QRS initial vector identical to sinus rhythm**
- **Identical** to pre-existing bundle branch block morphology in prior sinus rhythm ECGs
- Terminated by adenosine
- Tachycardia initiated by a premature P' wave

<a id="191-心室心动过速vt"></a>
## 19.1 Ventricular Tachycardia (VT)

| # | Criteria |
|---|---|
| 1 | **≥ 3 consecutive (generally defined as ≥ 3 or ≥ 5) ventricular beats**, rate **> 100 (usually 130–250) bpm** |
| 2 | **QRS ≥ 0.12 s (usually > 0.14 s), wide and bizarre** |
| 3 | Rhythm **approximately regular** (RR variation < 0.02–0.04 s) |
| 4 | **AV dissociation / capture beats / fusion beats** (see above) |
| 5 | ST-T direction opposite to QRS main deflection |

**Classification**:
- **Sustained**: Lasts ≥ 30 s or requires termination due to hemodynamic instability
- **Non-sustained (NSVT)**: < 30 s and terminates spontaneously
- **Monomorphic**: Constant QRS morphology — usually organic substrate (scar reentry from prior MI)
- **Polymorphic**: Variable morphology — acute ischemia, LQTS (→TdP), Brugada, CPVT
- **Bidirectional**: QRS axis alternates beat-to-beat — **Digoxin toxicity, CPVT**

<a id="192-特发性室性心动过速左室左后分支起源"></a>
## 19.2 Idiopathic Ventricular Tachycardia (Left Ventricular, Left Posterior Fascicle Origin)

**Synonyms**: Fascicular VT, **Verapamil-sensitive VT**, Belhassen type

| # | Features | Leads |
|---|---|---|
| 1 | **RBBB pattern** (V1 main deflection positive) | V1 |
| 2 | **Left axis deviation (left posterior fascicle origin, most common)** | Limb leads |
| 3 | **QRS relatively narrow (0.12–0.14 s)** — due to origin in His-Purkinje system | |
| 4 | If **left anterior fascicle origin** → RBBB pattern + **right axis deviation** | |
| 5 | Rate 150–200, common in **young males without structural heart disease** | |
| 6 | **Responsive to verapamil** (unresponsive to adenosine, lidocaine); good prognosis, high ablation success rate | |

<a id="193-特发性室性心动过速右室流出道起源rvot-vt"></a>
## 19.3 Idiopathic Ventricular Tachycardia (Right Ventricular Outflow Tract Origin, RVOT-VT)

| # | Features | Leads |
|---|---|---|
| 1 | **LBBB pattern** (V1 main deflection negative, rS/QS) | V1, V2 |
| 2 | **Tall upright R waves in inferior leads (inferior axis, approx. +90°)** | **II, III, aVF** |
| 3 | **Transition zone at V3–V4** (if ≤ V2 → suggests left ventricular outflow tract/aortic sinus origin) | V1–V6 |
| 4 | Lead I usually rS or QS (free wall origin) / R (septal origin) | I |
| 5 | Often triggered by exercise, stress (catecholamine-dependent); common in young/middle-aged adults without structural heart disease | |
| 6 | **Responsive to adenosine, β-blockers, verapamil**; good prognosis | |

> **Important differential: Arrhythmogenic Right Ventricular Cardiomyopathy (ARVC)** also presents with LBBB-pattern VT, but sinus rhythm shows **ε waves in V1–V3, T wave inversion, QRS terminal activation delay ≥ 55 ms**, and is often polymorphic with a family history → prognosis is completely different.

<a id="194-伴束支阻滞差异传导的-psvt"></a>
## 19.4 PSVT with Bundle Branch Block (Aberrancy)

| # | Features |
|---|---|
| 1 | Rate 150–250, absolutely regular |
| 2 | **QRS shows typical RBBB or LBBB morphology** (V1 triphasic rsR'; V6 has qRs, R/S > 1) |
| 3 | **No AV dissociation, no capture beats, no fusion beats** |
| 4 | **QRS initial vector identical to sinus rhythm** |
| 5 | Consistent with pre-existing bundle branch block morphology during sinus rhythm ("pre-existing BBB"); or appears only at fast rates ("rate-dependent/phase 3 block") |
| 6 | Terminated by adenosine/vagal maneuvers |

<a id="195-经旁路前传的-psvt逆向型-avrt-预激性心动过速"></a>
## 19.5 PSVT with Anterograde Conduction over Accessory Pathway (Orthodromic AVRT / Pre-excited Tachycardia)

| # | Features |
|---|---|
| 1 | **QRS wide and bizarre (fully pre-excited morphology)**, as ventricles are activated entirely via accessory pathway |
| 2 | Regular, rate 150–250 |
| 3 | Sinus rhythm ECG shows **δ wave (manifest WPW)**, and **QRS morphology during tachycardia is an "amplified version" of the sinus δ wave morphology** — key clue |
| 4 | Retrograde P' located after QRS (long RP') |
| 5 | Extremely difficult to distinguish from VT → **treat as VT if uncertain** |
| 6 | Treatment: **Procainamide / Ibutilide / Cardioversion; avoid digoxin, verapamil, adenosine (can cause VF)** |

<a id="第-20-章-心动过速不规则窄或宽-qrs"></a>
# Chapter 20 Tachycardia: Irregular (Narrow or Wide QRS)

<a id="201-心室颤动vf-vf"></a>
## 20.1 Ventricular Fibrillation (VF / Vf)

| # | Criteria |
|---|---|
| 1 | **Chaotic waveforms with no discernible P, QRS, or T waves** |
| 2 | **Amplitude, frequency, and intervals all irregular**, frequency 150–500 bpm |
| 3 | **Coarse VF**: Amplitude ≥ 0.5 mV, higher defibrillation success rate |
| 4 | **Fine VF**: Amplitude < 0.2–0.3 mV, near asystole, requires CPR/epinephrine first |
| 5 | Clinically always associated with loss of consciousness and pulselessness |

**Must exclude artifacts**: Muscle tremor, body movement, poor electrode contact, CPR compressions — **look at the patient, don't just look at the monitor**! Artifacts often show regular QRS "breaking through" the chaotic waves.

<a id="202-尖端扭转型室速torsade-de-pointes-tdp"></a>
## 20.2 Torsades de Pointes (TdP)

| # | Criteria |
|---|---|
| 1 | **Polymorphic VT, QRS polarity/amplitude "twists" around the baseline in a spiral**, flipping every 5–20 beats |
| 2 | **Frequency 200–250 bpm** |
| 3 | **Underlying rhythm before onset has QT prolongation (QTc > 0.50 s) + prominent U waves** — required for diagnosis |
| 4 | **Initiated by "short-long-short" sequence**: PVC → long compensatory pause → next beat has longer QT → **R-on-T PVC** triggers |
| 5 | Usually **self-limiting (seconds to tens of seconds)**, recurrent episodes → syncope; can degenerate into **VF** |

**Etiology**:
- **Acquired**: Drug-induced LQT (see 13.4), **hypokalemia/hypomagnesemia/hypocalcemia**, **bradycardia (complete AVB, sinus arrest)**, starvation/extreme dieting, cerebrovascular disorders, myocarditis
- **Congenital**: LQTS (see 13.3)

**Treatment**: **IV magnesium sulfate (first-line, even if serum magnesium is normal)**, correct electrolytes, stop offending drugs, **increase heart rate (isoproterenol or overdrive pacing)**; **avoid Class Ia/III antiarrhythmics**.
> Note: **Polymorphic VT on a short QT basis is not called TdP** (e.g., Brugada, CPVT, ischemia); treatment strategies differ (Brugada uses isoproterenol/quinidine, CPVT uses β-blockers).

<a id="203-假性室速pseudo-vt"></a>
## 20.3 Pseudo-VT

<a id="①-预激综合征合并心房颤动wpw-af-最重要的真病"></a>
### ① Pre-excitation Syndrome with Atrial Fibrillation (WPW + AF) — The Most Important "True Disease"

| # | Feature |
|---|---|
| 1 | **Extremely rapid ventricular rate (often > 200, up to 300 bpm)** |
| 2 | **Absolutely irregular RR intervals** — Key distinction from VT |
| 3 | **QRS are wide and distorted, with morphology varying beat-to-beat** (varying degrees of pre-excitation: fusion of complete pre-excitation, partial pre-excitation, and normal conduction) |
| 4 | Shortest RR **< 250 ms** → **High risk for VF** |
| 5 | Delta waves visible upon restoration of sinus rhythm |
| 6 | **Treatment: Immediate electrical cardioversion; drugs include procainamide/ibutilide. Absolutely contraindicated: digitalis, verapamil, diltiazem, adenosine, β-blockers** (blocking the AVN causes all impulses to conduct via the accessory pathway → VF) |

<a id="②-伪差artifact造成的假性-vt"></a>
### ② Pseudo-VT caused by Artifact

| Clues |
|---|
| **Regular sinus QRS "punching through" the chaotic waveform** ("sinus spikes") |
| Waveforms **appear only in certain leads** (corresponding to a specific electrode) |
| **Abrupt onset and offset**, with preceding and succeeding RR intervals completely unaffected |
| **Patient is in good condition, pulse is normal** |
| Common causes: Parkinsonian tremor, tooth brushing/scratching, loose electrodes, shivering |

<a id="③-其他易误认为-vt-的情形"></a>
### ③ Other Conditions Easily Mistaken for VT
- **Sine wave of hyperkalemia** (wide QRS + absent P waves)
- **Pacemaker-mediated tachycardia (PMT)**: Paced QRS are wide, frequency constant at the upper tracking limit (e.g., 120–130)
- Severe IVCD (Class Ic drug toxicity) + sinus tachycardia

<a id="第-21-章-先天性心脏病"></a>
# Chapter 21 Congenital Heart Disease

> Core logic of ECG in congenital heart disease: **Hemodynamic load type (volume vs. pressure) × Affected chamber (left vs. right) → Characteristic ECG findings**.

<a id="211-心房间隔缺损asd"></a>
## 21.1 Atrial Septal Defect (ASD)

<a id="继发孔型secundum-asd最常见"></a>
### Secundum Type (most common)

| # | Feature | Lead |
|---|---|---|
| 1 | **Incomplete right bundle branch block (rsR' pattern)** — **Most characteristic** (right ventricular volume overload) | **V1** |
| 2 | **Right axis deviation (+90° to +150°)** | Limb leads |
| 3 | **Right atrial enlargement** (tall, peaked P waves ≥ 0.25 mV) | II, III, aVF |
| 4 | **First-degree AV block** (prolonged PR, approx. 20%) | |
| 5 | **Crochetage sign**: Notch on the ascending limb of the R wave in inferior leads (high specificity) | **II, III, aVF** |
| 6 | In older patients: AF/AFL; with pulmonary hypertension, true RVH appears (tall R in V1 + ST-T strain) | |

<a id="原发孔型primum-asd-房室间隔缺损"></a>
### Primum Type (primum ASD / AV septal defect)

| # | Feature |
|---|---|
| 1 | **Left axis deviation (−30° to −90°) = Left anterior fascicular block pattern** — **Definitive differentiating point** (displacement of conduction system) |
| 2 | Incomplete RBBB (also present) |
| 3 | First-degree AV block is more common |
| 4 | Often associated with cleft mitral valve → left ventricular volume overload |

> **Mnemonic: ASD + Right Axis Deviation = Secundum; ASD + Left Axis Deviation = Primum.**

<a id="212-心室间隔缺损vsd-动脉导管未闭pda"></a>
## 21.2 Ventricular Septal Defect (VSD) / Patent Ductus Arteriosus (PDA)

| Shunt Size | ECG |
|---|---|
| **Small shunt (Roger's disease)** | **Normal ECG** |
| **Moderate shunt** | **Left ventricular volume overload pattern**: Deep, narrow q waves + tall R waves + tall, upright T waves in V5–V6; Left atrial enlargement |
| **Large shunt (pre-pulmonary hypertension)** | LV volume overload + RV overload → **Biventricular hypertrophy** |
| **Katz-Wachtel phenomenon** | **Tall, biphasic QRS in mid-precordial leads (V2–V4) (both R and S > 5 mm, "giant RS")** → Marker of biventricular hypertrophy |
| **After Eisenmengerization** | Shifts to **pure RV hypertrophy pattern**: Tall R in V1, right axis deviation, right atrial enlargement, V1–V3 ST-T strain; LV signs disappear |

- **PDA** ECG is essentially the same as VSD (both involve LV volume overload + increased pulmonary blood flow).

<a id="213-肺动脉瓣狭窄ps"></a>
## 21.3 Pulmonary Stenosis (PS)

**Core: Pure right ventricular pressure overload, the degree of which parallels the severity of stenosis** (one of the few diseases where ECG can "quantitatively" assess severity).

| Severity | ECG |
|---|---|
| **Mild** (gradient < 50 mmHg) | Normal or mild right axis deviation, rsR' in V1 |
| **Moderate** (50–80 mmHg) | **R ≥ 1.0 mV in V1**, right axis deviation +90° to +120° |
| **Severe** (> 80–100 mmHg) | **Tall, monophasic R wave (≥ 2.0 mV) or qR pattern in V1**, **ST depression + T wave inversion in V1–V3 (strain pattern)**, **Axis > +120°**, **Right atrial enlargement (tall, peaked P waves)** |

- Empirical estimation: **R wave amplitude in V1 (mm) × 5 ≈ Right ventricular systolic pressure (mmHg)**.
- **Presence of q wave in V1 (qR) → Suggests severe RV hypertrophy**.

<a id="214-法洛四联症tof"></a>
## 21.4 Tetralogy of Fallot (TOF)

| # | Feature | Lead |
|---|---|---|
| 1 | **Significant RV hypertrophy**: **Tall, monophasic R wave or qR in V1** | **V1** |
| 2 | **Abrupt transition**: Sudden change from tall R in V1 to rS in V2 — Characteristic | **V1 → V2** |
| 3 | **Right axis deviation (+90° to +150°)** | Limb leads |
| 4 | **Right atrial enlargement** (tall, peaked P waves), but usually less pronounced than in PS | II, V1 |
| 5 | Upright T wave in V1 (upright T after neonatal period = sensitive indicator of RVH) | V1 |
| 6 | **Post-op**: Almost invariably develops **Complete RBBB** (RV incision/outflow tract patch); **QRS duration ≥ 180 ms is a strong predictor of post-op sudden death/sustained VT** | V1 |

<a id="215-ebstein-畸形"></a>
## 21.5 Ebstein's Anomaly

| # | Feature | Lead |
|---|---|---|
| 1 | **Giant P waves ("Himalayan P waves")**: Height can be > 0.5 mV, width also increased — Extreme right atrial enlargement | **II, V1** |
| 2 | **Complete or incomplete RBBB, but QRS amplitude in V1 is very low, fragmented, and multiphasic (low voltage, coarse/blunted)** — Key distinction from typical RBBB (atrialized RV is thin-walled, ineffective myocardium) | **V1, V2** |
| 3 | **Prolonged PR interval (First-degree AV block)** | |
| 4 | **High association with WPW (Type B, right-sided accessory pathway) (approx. 20%)** → Short PR + delta wave, which may mask the above findings | V1 |
| 5 | Atrial arrhythmias common (AFL, AF, PSVT) | |
| 6 | Axis may be right-deviated or normal | |

<a id="216-矫正型大动脉转位先天性矫正型-tga-cctga"></a>
## 21.6 Congenitally Corrected Transposition of the Great Arteries (ccTGA)

**Core mechanism: Reversal of septal activation direction (from right-to-left to left-to-right)** — Due to reversal of the anatomical relationship between the conduction system and the ventricles.

| # | Feature | Lead |
|---|---|---|
| 1 | **q waves in right precordial leads (qR pattern in V1, V2)** — Characteristic | **V1, V2** |
| 2 | **Absence of septal q waves in left precordial leads (no q in V5, V6)** — Characteristic | **V5, V6** |
| 3 | Q waves may appear in inferior leads (II, III, aVF) (pseudo-inferior infarction) | II, III, aVF |
| 4 | **AV block of varying degrees (1st degree → Complete)**, incidence increases with age (**approx. 2% progress to complete AVB per year**) | |
| 5 | Left axis deviation (abnormal PQ axis); ectopic atrial rhythms may occur | |
| 6 | Often associated with VSD, pulmonary stenosis, Ebstein-like tricuspid valve anomaly → Superimposed corresponding findings | |

> **Mnemonic: q in V1, no q in V5–V6 + AV block → Think of Corrected Transposition of the Great Arteries.**

<a id="附录-b-从异常出发的鉴别流程速查"></a>
# Appendix B Differential Diagnosis Workflow Starting from Abnormalities (Quick Reference)

<a id="b1-宽-qrs的鉴别"></a>
## B.1 Differential Diagnosis of "Wide QRS"

```
QRS ≥ 0.12 s
├── 有提前的窦性/房性 P 且 PR 正常
│   ├── V1 呈 rsR'、I/V6 有宽 S → 右束支阻滞
│   ├── V1 呈 rS/QS、V5-V6 宽顿挫 R 无 q → 左束支阻滞
│   └── 都不像 → 非特异性 IVCD（查血钾、查药物！）
├── PR < 0.12 s + δ 波 → WPW 综合征
├── 无 P 波，规则，20-40/min → 心室固有节律
├── 无 P 波，规则，60-100/min → AIVR
├── 无 P 波，> 100/min → 室性心动过速（或 SVT 伴差传，见 19.0）
├── 无 P，QRS 与 T 无法区分，T 高尖 → 高钾血症
└── 有起搏钉（spike）→ 心室起搏心律
```

<a id="b2-v1-出现高-r-波的鉴别6-大原因"></a>
## B.2 Differential Diagnosis of "High R Wave in V1" (6 Major Causes)

| Cause | Key Differentiating Points |
|---|---|
| **Right Bundle Branch Block** | QRS ≥ 0.12 s, V1 shows rsR' pattern, wide S wave in I/V6 |
| **Right Ventricular Hypertrophy** | Right axis deviation ≥ +110°, V1 ST-T strain, right atrial enlargement, deep S waves in V5-V6 |
| **Posterior Wall Infarction** | ST depression + tall T waves in V1-V2, Q waves/ST elevation in V7-V9, often accompanied by inferior wall changes |
| **WPW (Type A)** | PR < 0.12 s, δ wave |
| **Counter-clockwise Rotation** | Transition zone shifts left to V2, otherwise normal |
| **Normal Variant / Children / Thin Body Habitus** | No other abnormalities |

<a id="b3-电轴左偏的鉴别"></a>
## B.3 Differential Diagnosis of "Left Axis Deviation"

Left anterior fascicular block / Old inferior MI (abnormal Q waves in II, III, aVF) / Left ventricular hypertrophy / LBBB / Horizontal heart (obesity, pregnancy, ascites) / Primum ASD / WPW / Hyperkalemia / Paced rhythm

<a id="b4-电轴右偏的鉴别"></a>
## B.4 Differential Diagnosis of "Right Axis Deviation"

Right ventricular hypertrophy / Left posterior fascicular block (diagnosis of exclusion) / Lateral MI (Q waves in I, aVL) / Vertical heart (thin and tall) / COPD・Emphysema / Acute pulmonary embolism / Secundum ASD / Dextrocardia・Incorrect electrode placement / Infants (physiological)

<a id="b5-长间歇漏搏的鉴别顺序"></a>
## B.5 Differential Diagnosis Sequence for "Long Pause (Dropped Beat)"

```
1. 看长间歇前的 T 波形态 → 有变形？→ 未下传的 SVPC（最常见，良性）
2. 长间歇是基本 PP 的整数倍？→ 是：II 度 SA 阻滞（Mobitz II 型）
                                → 否：窦性停搏
3. 有 P 波但后面没 QRS？→ II 度房室阻滞
   ├── PR 逐渐延长后脱落 → Wenckebach（良性，AVN 内）
   └── PR 固定后突然脱落 → Mobitz II（高危，His 以下）
4. P 与 QRS 完全无关 → 完全性房室阻滞
5. 房颤 + 长间歇 → 药物过量 / 合并 AVB
```

<a id="b6-窄-qrs-心动过速心率-150必查"></a>
## B.6 "Narrow QRS Tachycardia (Heart Rate ~150)" Mandatory Checks

**Always rule out 2:1 atrial flutter first** (look for sawtooth baseline in II/III/aVF, upright F waves in V1; use adenosine/vagal maneuvers if necessary).

<a id="b7-st-抬高的-5-秒判断"></a>
## B.7 5-Second Assessment of "ST Elevation"

**Convex upward + localized to coronary territory + reciprocal depression + dynamic evolution = STEMI, immediately initiate reperfusion protocol.**
