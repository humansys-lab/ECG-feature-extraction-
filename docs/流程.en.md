<a id="12-导联心电图自动判读系统-设计与实施规格书"></a>
# 12-Lead Electrocardiogram Automatic Interpretation System - Design and Implementation Specification

**Version** v1.0 | **Technical Roadmap** Deterministic signal processing + explicit rule reasoning (excluding machine learning)

---

<a id="0-文档说明"></a>
## 0. Document description

<a id="01-目的"></a>
### 0.1 Purpose

This document defines a set of complete engineering specifications for a 12-lead resting electrocardiogram automatic interpretation system, covering all processing links from raw sampling data to structured interpretation reports. The document is intended for algorithm engineers and system architects. Each section provides parameters, determinations, and acceptance conditions that can be directly entered into coding.

<a id="02-技术路线约束"></a>
### 0.2 Technical route constraints

**This system does not use any machine learning methods. ** Specific meaning:

- Waveform detection and delimitation use deterministic algorithms such as wavelet transform, adaptive threshold, morphological operators, etc.
- Heart beat classification uses template cross-correlation and time limit rules, without using classifiers
- Diagnostic reasoning uses an explicit rule base and an expert-calibrated rating scale, with weights set manually and traceable to the literature.
- All thresholds are managed centrally in the configuration table, and there are no parameters fitted from the data.

**Direct consequences** of this constraint (must be accepted when the project is approved):

| Impact | Consequences |
|---|---|
| Interpretability | Completely interpretable, any conclusion can be traced back to specific leads, specific measurement values, and specific criteria |
| Regulatory submissions | Significantly simplified. No need to submit training set representativeness, data drift monitoring, retraining change control and other materials |
| Development cost | Low in the early stage (no need to label data), high in the later stage (rule base maintenance and boundary patching are long-term tasks) |
| Sensitivity | Good sensitivity to cases with typical manifestations; sensitivity to atypical morphology (such as de Winter, Aslanger type) is significantly lower than morphological pattern recognition methods |
| Noise robustness | Weaker than learning methods. Therefore the quality gating in Chapter 5 is a **critical safety barrier** to this system and is not an optional module |

The design response strategy is: **Increase the abstention rate rather than increase the misjudgment rate**. The system would rather output "Insufficient signal quality/complex morphology, manual interpretation recommended" rather than give a low-confidence conclusion.

<a id="03-预期用途声明"></a>
### 0.3 Intended Use Statement

This system is an **auxiliary interpretation tool** and the output is reference information for doctors to review and does not constitute an independent diagnosis. All reports must bear this statement. Under no circumstances should it be designed as a closed-loop diagnostic path without human review.

<a id="04-术语与符号"></a>
### 0.4 Terminology and Notation

| Symbol | Meaning |
|---|---|
| `fs` | Sampling rate (Hz) |
| `L` | Lead set, `L = {I, II, III, aVR, aVL, aVF, V1..V6}` |
| `N_beat` | The total number of heart beats detected in a record |
| `RR[i]` | The interval from the i-th R peak to the i+1-th R peak (ms) |
| Median beat | Median beat, a representative waveform synthesized by taking the median of the dominant heart beat point by point |
| finding | finding Boolean or hierarchical intermediate semantic terms obtained by discretizing continuous measurements |
| statement | statement, final output diagnostic conclusion entry |
| Gating | gating, the execution of a certain module depends on the judgment result of the upstream module |

<a id="12-设计不变式"></a>
### 1.2 Design invariants

The following four are hard constraints of the architecture and must not be violated by any optimization:

1. **Strict separation of measurement and reasoning. ** L5 and below only produce numerical values ​​and do not produce any medical judgment; L7 only consumes finding and does not directly access the original signal.
2. **One-way data flow. ** Downstream is not allowed to write back upstream results. The only exception is the missed beat lookback search within L3 (see 6.3).
3. **Each finding and statement must carry evidence references. ** The citation format is `(导联, 测量项, 数值, 阈值, 判据条款号)`. Conclusions for which complete evidence citations cannot be generated shall not be output.
4. **Abstention takes precedence over guessing. ** When any layer determines that the input is unreliable, it will pass the `UNRELIABLE` flag to the downstream instead of the default value; the downstream must abstain when encountering necessary input with this flag.

<a id="13-模块接口契约"></a>
### 1.3 Module interface contract

| Module | Input | Output | Failure Mode |
|---|---|---|---|
| L0 | Device original file | `Recording{signal[12][n], fs, gain, age, sex, filter_meta}` | Missing fields → Terminate, reporting "Incomplete data" |
| L1 | `Recording` | `FilteredSignal`, `RawSignal` | None (filtering does not fail) |
| L2 | `FilteredSignal` | `QualityReport{sqi[12], usable_leads, lead_swap_flag}` | All leads unavailable → Terminate |
| L3 | `FilteredSignal`, `QualityReport` | `Delineation{beats[], fiducials}` | Heartbeat detected < 3 → Terminate |
| L4 | `Delineation` | `BeatClasses[]`, `MedianBeat[12]` | Dominant category proportion < 30% → Mark `MORPH_COMPLEX` |
| L5 | `MedianBeat`, `Delineation` | `FeatureSet` (see Chapter 7) | Single item cannot be measured → This item is set to `NULL` |
| L6 | `FeatureSet` | `Findings[]` | The dependent feature is `NULL` → finding set `UNKNOWN` |
| L7 | `Findings[]` | `Statements[]` | Gating prerequisite is not met → This module skips |
| L8 | `Statements[]` | `RankedStatements[]` | None |
| L9 | `RankedStatements[]` | `Report` | None |

<a id="14-三值逻辑约定"></a>
### 1.4 Three-valued logic convention

The value range of all finding is `{TRUE, FALSE, UNKNOWN}`. The rules engine evaluates according to three-valued logic:

- `TRUE AND UNKNOWN = UNKNOWN`
- `FALSE AND UNKNOWN = FALSE`
- `TRUE OR UNKNOWN = TRUE`
- `FALSE OR UNKNOWN = UNKNOWN`

When the diagnostic rule evaluates to `UNKNOWN`, a waiver entry is output instead of a negative conclusion. **This item is the core of the security of the entire system** and must be covered by unit tests when implemented.

<a id="2-l0-数据接入与标准化"></a>
## 2. L0 data access and standardization

<a id="21-输入要求"></a>
### 2.1 Input requirements

| Item | Requirements | Description |
|---|---|---|
| Sampling rate | ≥ 500 Hz, 1000 Hz recommended | Below 500 Hz QRS timing error ≥ 2 ms, the pacing nail may be completely lost |
| Resolution | ≤ 5 μV/LSB | |
| Duration | ≥ 10 s | When shorter than 8 s, it is prohibited to output rhythmic conclusions |
| Leads | 8 independent leads (I, II, V1–V6) | III, aVR, aVL, aVF are calculated and derived from I and II, see 2.3 |
| Metadata | Age, gender, device filter settings | When age and gender are missing, multiple criteria in Chapters 10 and 11 cannot be evaluated |

<a id="22-强制元数据"></a>
### 2.2 Mandatory metadata

**Age and gender are not optional fields. **The following criteria are dependent on sex stratification: Cornell voltage, Cornell product, Peguero-Lo Presti, QTc threshold, V2–V3 ST elevation threshold. The following criteria depend on age stratification: V2–V3 ST elevation threshold (40-year-old cutoff), normal heart rate range. When missing, the corresponding finding setting is `UNKNOWN`.

Selection of processing strategies for missing situations (**needs to be decided at the project level and written into the configuration**):

- Strategy A (conservative, recommended): Set `UNKNOWN`, and abstain from related diagnoses
- Strategy B (aggressive): Take the strictest threshold (such as judging Cornell according to the female threshold), and mark "Unknown gender, judge according to the conservative threshold" in the report

<a id="23-导出导联计算"></a>
### 2.3 Export lead calculation

If the device only provides 8 channels, export as follows:

```
III  = II - I
aVR  = -(I + II) / 2
aVL  = I - II/2
aVF  = II - I/2
```

**Note**: If the device has provided all 12-channel data, **Do not** recalculate, use the device value directly, and perform consistency check (when the difference between the exported value and the device value is > 50 μV and the proportion of sample points > 5%, the data is marked as abnormal).

<a id="24-单位标准化"></a>
### 2.4 Unit Standardization

μV and ms are used internally uniformly. The conversion is completed once at L0, after which all modules no longer perform unit conversion. **This is a key convention to prevent dimensional bugs and should be checked during code reviews. **

<a id="25-设备滤波元数据的用途"></a>
### 2.5 Purpose of device filtering metadata

The pre-filter settings of different devices systematically alter ST segment levels and QRS amplitudes. L0 must record the high-pass/low-pass cutoff frequency of the device and be used in the following scenarios:

- Equipment Qualcomm > 0.05 Hz: ST segment measurement results are marked "may be affected by filtering", and the confidence level of ST-related criteria is reduced by one level.
- Equipment low pass < 100 Hz: QRS amplitude criterion (Sokolow-Lyon, Cornell) confidence level reduced by one level
- The device has "myoelectric filtering" or "smoothing" turned on: notching/fragmentation QRS related finding settings `UNKNOWN`

<a id="3-l1-预处理"></a>
## 3. L1 preprocessing

<a id="31-滤波链"></a>
### 3.1 Filter chain

Processing sequence: **Baseline Correction → Power Frequency Suppression → Low Pass**. The order is not interchangeable.

<a id="311-基线漂移校正"></a>
#### 3.1.1 Baseline drift correction

Recommended solution: **Cascade median filter** (phase distortion is zero, safest for ST segment)

```
step1 = medfilt(x, win = 200 ms)    # 消除 QRS
step2 = medfilt(step1, win = 600 ms) # 消除 P、T
baseline = step2
y = x - baseline
```

The window length must be an odd number of sample points. When `fs = 500`, win1 = 101 points, win2 = 301 points.

Alternative: Zero-phase high-pass IIR, cutoff 0.05 Hz, using forward-backward filtering (`filtfilt`) to achieve zero phase.

**The use of one-way IIR Qualcomm is prohibited. ** The phase distortion introduced by unidirectional IIR after QRS will cause artificial ST segment depression, which is one of the most common systematic errors in self-developed systems.

If linear phase FIR is used, the cutoff frequency can be relaxed to 0.67 Hz (equivalent diagnostic performance).

<a id="312-工频抑制"></a>
#### 3.1.2 Power frequency suppression

Priority order:

1. **Adaptive Notch**: LMS adaptive cancellation centered on power frequency, Q value ≤ 30
2. If the power frequency (50/60 Hz) cannot be determined, first perform automatic peak detection at 45–65 Hz.
3. Alternative: Moving average elimination method (window length = an integer multiple of 1 power frequency cycle)

**High Q static notching is prohibited** (Q > 50). The high-Q notch will ring after QRS and will be misjudged as a notch or J wave by the downstream.

<a id="313-低通"></a>
#### 3.1.3 Low pass

| Object | Cutoff Frequency | Order |
|---|---|---|
| Adults | 150 Hz | Zero-phase FIR, order calculated as fs such that transition zone < 20 Hz |
| Children under 12 | 250 Hz | Same as above |

At `fs = 500 Hz`, the 250 Hz low pass is meaningless (equal to Nyquist), and pediatric scenarios require `fs ≥ 1000 Hz`.

<a id="32-未滤波支路"></a>
### 3.2 Unfiltered branch

Reserve a signal that only performs baseline correction and **not low-pass** exclusively for pacing pulse detection (see 8.5). The pacing spike width can be as low as 0.1 ms and any low pass will smooth it out.

<a id="33-测量专用支路"></a>
### 3.3 Measurement dedicated branch

ST segment and amplitude measurements should be made on the **median beat** (see Chapter 6), which itself is a powerful means of noise suppression. Do not add additional filtering to the measurement branch just to be "cleaner".

<a id="4-l2-信号质量评估与导联合法性校验"></a>
## 4. L2 signal quality assessment and lead legality verification

This chapter is the security barrier of the system. The rule system is less robust to noise than the learning method. If the quality gating is not done well, all the subsequent fine criteria will be self-deception.

<a id="41-逐导联质量指标"></a>
### 4.1 Lead-by-lead quality indicators

The following metrics are calculated independently for each lead, all [0,1] normalized or Boolean:

| Metrics | Definition | Failure Threshold (Default) |
|---|---|---|
| `flatline` | Peak-to-peak value in sliding 1 s window < 50 μV 的时间占比 | > 10% |
| `saturation` | \|x\| ≥ 0.95 × ADC full-scale sample ratio | > 0.5% |
| `baseline_drift` | 0.05–0.5 Hz band energy / 0.05–40 Hz total energy | > 0.30 |
| `powerline` | (f0 ± 1 Hz) frequency band energy / 0.05–100 Hz total energy | > 0.15 |
| `emg` | 40–100 Hz energy in TQ segment / total energy in TQ segment | > 0.40 |
| `pSQI` | 5–15 Hz energy / 5–40 Hz energy | < 0.40 或 > 0.90 |
| `kSQI` | Signal kurtosis | < 5 (normal ECG has high kurtosis, low kurtosis indicates noise dominance) |
| `bSQI` | Consistency rate of results from two independent QRS detectors | < 0.85 |

`bSQI` requires two QRS detectors with different principles (such as Pan-Tompkins and wavelet mode maximum method). The difference between the two detection positions is less than 100 ms and is considered consistent. **This is the most effective single quality indicator and should be implemented first. **

<a id="42-导联可用性判定"></a>
### 4.2 Lead availability determination

```
lead_usable[l] = NOT flatline AND NOT saturation
                 AND baseline_drift < T_bd
                 AND emg < T_emg
                 AND bSQI > T_b
```

<a id="43-整体门控决策"></a>
### 4.3 Overall gating decision

| Condition | Action |
|---|---|
| Available leads ≥ 10 and include II, V1, V5 | Execute all modules normally |
| Available Leads 6–9 | Executed, but with criteria involving unavailable leads `UNKNOWN` |
| Available leads < 6, or neither II nor V1 are available | **Termination**, output "Insufficient signal quality, re-acquisition is recommended" |
| `bSQI` All leads < 0.7 | **Termination**, same as above |

<a id="44-导联反接检测"></a>
### 4.4 Lead reverse connection detection

Reverse polarity detection must be completed prior to any diagnosis. Mistaking reversal for pathology is one of the most dangerous types of errors in clinical practice.

<a id="441-肢导反接的确定性规则"></a>
#### 4.4.1 Deterministic rules for reverse connection of limb leads

| Reverse connection type | Characteristic expression | Determinant expression |
|---|---|---|
| LA ↔ RA | I guide P/QRS/T all inverted; II and III interchange; aVR and aVL interchange | `P_I < 0 AND R_I < S_I AND corr(II_obs, III_ref) > 0.9` |
| RA ↔ LL | II guide is inverted; I and III are interchanged and inverted; aVR and aVF are interchanged | `net_area(II) < 0 AND P_II < 0` |
| LA ↔ LL | I and II are interchanged; III is inverted; aVL and aVF are interchanged | `corr(I_obs, II_ref) > 0.9 AND net_area(III) < 0` |
| RA ↔ RL(N) | II conductor is approximately flat (amplitude < 100 μV) | `pp_amplitude(II) < 100 μV` |
| LL ↔ RL(N) | III derivative approximates a straight line | `pp_amplitude(III) < 100 μV` |

<a id="442-胸导反接检测"></a>
#### 4.4.2 Chest lead reverse connection detection

Progressive analysis based on pattern cross-correlation between leads: Calculate the cross-correlation coefficient sequence `c[k] = corr(Vk, Vk+1)` of adjacent lead median beats for V1→V6. Under normal circumstances, the sequence is smooth and each item is > 0.5. If there is a significant trough or progressive reversal somewhere, the lead swap at that location is positioned.

At the same time, check the progressive amplitude of the R wave: the normal R amplitude of V1→V6 rises monotonically to V4–V5 and then decreases slightly, and the S amplitude monotonically decreases. Flag suspicious when a non-monotonic jump occurs in progression.

<a id="443-与右位心的鉴别关键"></a>
#### 4.4.3 Identification from dextrocardia (key)

LA↔RA reverse connection behaves the same as dextrocardia in the limb leads (total inversion of the I lead). Identification relies on chest guidance:

| | I conduction | Chest conduction R wave progression |
|---|---|---|
| LA↔RA reverse connection | full inversion | **normal increment** |
| Dextrocardia | Total inversion | **V1→V6 amplitude decrease** |

Determining formula:
```
IF I导全倒置:
    IF R振幅(V6) < R振幅(V1) AND R振幅单调递减:
        → finding: DEXTROCARDIA
    ELSE:
        → finding: LEAD_SWAP_LA_RA
```

<a id="444-反接检出后的动作"></a>
#### 4.4.4 Action after reverse connection detection

**Do not continue reading after automatic correction. ** The correct action is:

1. Output a clear reverse connection warning statement and place it at the top of the report
2. Terminate subsequent diagnostic modules, or only output measured values without outputting diagnostic conclusions.
3. Prompt to re-acquire

Reason: Automatic correction will cover up collection operation problems, and if the reverse connection judgment itself is wrong, it will introduce greater errors.

<a id="45-起搏信号预检"></a>
### 4.5 Pace signal pre-check

A quick scan is performed on the unfiltered branch. If the pacing pulse is detected, the `PACED_CANDIDATE` flag is set for use by the M0 module of L7 (see 8.5 and 10.1).

<a id="5-l3-波形检测与定界"></a>
## 5. L3 waveform detection and delimitation

The delimitation accuracy determines the upper limit of the entire system. If the measurement is inaccurate, all subsequent criteria will be correct inferences based on wrong values.

<a id="51-算法选型"></a>
### 5.1 Algorithm selection

The **Dyadic Wavelet Transform Modular Maximum Method** (the classic scheme of Martínez et al.) is used as the main algorithm, and Pan-Tompkins is used as the second detector for `bSQI` and redundancy check.

Reason for selection: The wavelet method is naturally multi-scale, can handle QRS (high frequency), P/T (low frequency) within the same framework, and is not sensitive to baseline drift; it is purely deterministic and does not require training.

<a id="52-小波配置"></a>
### 5.2 Wavelet configuration

- Wavelet base: quadratic spline wavelet, whose first-order derivative characteristics make the inflection point of the waveform correspond to the mode maximum and the wave peak correspond to the zero-crossing point
- Scale: `2^1 … 2^5` (defined for `fs = 250 Hz`; when `fs = 500 Hz` is used, move the whole scale up by one scale, that is, use `2^2 … 2^6`)
- Main uses of each scale:

| Scale (fs=500Hz) | Main energy correspondence | Purpose |
|---|---|---|
| 2^2 | 40–125 Hz | Noise Assessment, Pacing Nails |
| 2^3 | 20–60 Hz | QRS Detection main scale |
| 2^4 | 10–30 Hz | QRS boundary, QRS internal structure |
| 2^5 | 5–15 Hz | T wave, P wave detection |
| 2^6 | 2–8 Hz | T-wave boundary |

<a id="53-r-峰检测"></a>
### 5.3 R peak detection

```
1. 在尺度 2^3、2^4 上计算小波系数 W3、W4
2. 阈值 T = k × RMS(W3, 全段)，k 初值 = 0.35
3. 在 W3 上寻找超过 T 的模极大值
4. 配对：寻找"正极大 → 负极大"（或反向）且间隔 < 120 ms 的模极大值对
5. 该对之间的过零点 = R 峰位置
6. 在 W4 上验证同一位置存在对应模极大值对（跨尺度一致性）
7. 不应期：两个 R 峰间隔 < 200 ms 时，保留幅值大者
8. 漏搏回溯：若某 RR > 1.5 × 局部中位 RR，在该区间内以 0.5×T 重新搜索
9. 多导联融合：见 5.7
```

**Adaptation of parameter `k`**: After the initial detection, use the median amplitude of the detected R peak to reset `T = 0.4 × median(peak_amplitude)` and run again. Beats with inconsistent results are marked as low confidence.

<a id="54-qrs-起终点定界"></a>
### 5.4 QRS Delimitation of start and end points

For each R peak, on scale 2^4:

```
QRS 起点：从 R 峰对应的第一个模极大值向前搜索，
          至 |W4| 降到该极大值的 ξ_on 倍（ξ_on = 0.05）
          或出现符号相反的模极大值为止
QRS 终点：从最后一个模极大值向后搜索，
          至 |W4| 降到 ξ_off 倍（ξ_off = 0.10）
```

`ξ_off > ξ_on` is intentionally designed: the end point of QRS is immediately adjacent to the ST segment. If the threshold is too low, the ST start segment will be merged into QRS, causing the QRS time limit to be systematically longer.

<a id="55-t-波检测与定界"></a>
### 5.5 T wave detection and delimitation

```
1. 搜索窗：QRS 终点后 [100 ms, min(0.7×RR, 600 ms)]
   （窗口右界随 RR 自适应，心动过速时必须收窄）
2. 在尺度 2^5、2^6 上寻找该窗内最大模极大值对
3. 过零点 = T 峰
4. T 波极性：由模极大值对的符号顺序判定
   正向 T：负极大 → 正极大（对应上升-下降）
   负向 T：正极大 → 负极大
   双向 T：窗内存在两组显著模极大值对
5. T 终点定界：优先用小波阈值法（|W| 降至峰值的 0.125 倍）
   备选用切线法：过 T 波下降支最大斜率点作切线，与等电位线交点
```

**The T-wave endpoint is the measurement item with the largest error throughout the entire process**, directly determining the QT interval and QTc. It is recommended to implement both the wavelet method and the tangent method; if the difference between the two exceeds 40 ms, the QT interval should be marked as low confidence.

<a id="56-p-波检测与定界"></a>
### 5.6 P-wave Detection and Delineation

```
1. 搜索窗：QRS 起点前 [50 ms, min(0.35×RR, 250 ms)]
2. 在尺度 2^5、2^6 上寻找模极大值对，阈值取 QRS 阈值的 0.15 倍
3. 形态分类：正向 / 负向 / 双向（存在两组反向模极大值对）
4. 起终点定界方法同 T 波
```

<a id="561-未下传-p-波的补充搜索必需"></a>
#### 5.6.1 Supplementary Search for Undetected P Waves (Mandatory)

The threshold method may miss isolated P waves occurring in the middle of the RR interval during high-grade atrioventricular block. A secondary search must be implemented:

```
FOR 每个 RR 间期:
    IF 该区间内已检出 P 波数 == 1 AND RR > 1.5 × median(RR):
        在该区间的非搜索窗区域，用 P 波模板做匹配搜索
        模板 = 该导联已确认 P 波的平均形态
        候选点须同时满足:
            (a) 时限 ≥ 60 ms
            (b) 振幅 > 5% × 相邻 QRS 振幅
            (c) 与模板极性一致（正/负/双向同类）
            (d) 与模板互相关系数 > 0.7
        → 标记为"未下传 P 波"
```

**This step is the decisive factor in whether second-degree Type II and third-degree atrioventricular block can be detected.** Systems that fail to implement this logic will misclassify third-degree atrioventricular block as a junctional escape rhythm.

<a id="57-多导联融合规则"></a>
### 5.7 Multi-lead Fusion Rules

Single-lead delineation results are synthesized into global reference points using the following rules:

| Rule | Description |
|---|---|
| Existence Confirmation | A wave is considered present only if it is detected at the same time (±20 ms) in **≥ 4 available leads** |
| Global Onset | The **earliest** onset among all supporting leads |
| Global Offset | The **latest** offset among all supporting leads |
| Duration Calculation | Global offset − Global onset |

The "earliest onset / latest offset" approach is an internationally accepted practice, as the initial and terminal components of the cardiac vector may be perpendicular to certain lead axes, resulting in no deflection. **If the QRS duration is measured based on a single lead, the result will be systematically shorter by 10–20 ms**, directly leading to missed diagnoses of bundle branch block.

<a id="58-生理约束后处理"></a>
### 5.8 Post-processing with Physiological Constraints

The following constraints are strictly enforced; violations are discarded:

1. At most one T wave per RR interval; if multiple candidates appear, select the one temporally closest to `QT_expected = 0.4 × sqrt(RR)`
2. The P wave must not overlap with QRS
3. The QRS duration must be within [40 ms, 250 ms]; out-of-range values are marked as `UNRELIABLE`
4. The PR interval must be within [80 ms, 500 ms]
5. The interval between the onsets of QRS in adjacent beats must be ≥ 200 ms

<a id="59-验收标准"></a>
### 5.9 Acceptance Criteria

| Metric | Dataset | Target |
|---|---|---|
| QRS Detection Se / +P | MIT-BIH Arrhythmia, NST | ≥ 99.5% / ≥ 99.5% (per ANSI/AAMI EC57 protocol) |
| P-wave Delineation Error | QT Database, LUDB | Onset/Offset SD ≤ 10 ms |
| QRS Delineation Error | Same as above | SD ≤ 8 ms |
| T-offset Error | Same as above | SD ≤ 25 ms |

<a id="6-l4-心搏模板聚类与中位搏合成"></a>
## 6. L4 Beat Template Clustering and Median Beat Synthesis

<a id="61-目的"></a>
### 6.1 Objectives

- Distinguish dominant beats from ectopic beats; ectopic beats must not participate in morphological measurements
- Synthesize a median beat to serve as the baseline for all amplitude and duration measurements

<a id="62-模板聚类算法"></a>
### 6.2 Template Clustering Algorithm

```
1. 对齐：以 R 峰为基准，截取窗口 [-250 ms, +450 ms]
   （窗口须覆盖 P 波起点到 T 波终点）
2. 参与聚类的导联：选择 R 波振幅最大的 3 个导联，拼接为特征向量
3. 逐拍与已有模板计算 Pearson 相关系数：
       IF max(corr) ≥ 0.90:  归入该模板类，更新模板（滑动平均）
       ELSE:                 新建模板类
4. 类合并：若两模板互相关 ≥ 0.95，合并
5. 主导类 = 成员数最多的类
```

The correlation coefficient threshold of 0.90 is an empirical value that needs to be calibrated on the validation set. A threshold that is too high will split morphological fluctuations caused by noise into multiple classes, while a threshold that is too low will merge premature ventricular contractions (PVCs) into the dominant class.

<a id="63-心搏类型判定规则"></a>
### 6.3 Beat Type Determination (Rules)

For each template class:

| Type | Determination Criteria |
|---|---|
| Dominant (N) | The class with the largest number of members |
| Ventricular Ectopic (V) | QRS duration > 120 ms **AND** correlation coefficient with the dominant template < 0.80 **AND** no preceding associated P wave **AND** coupling interval < 0.85 × median RR |
| Supraventricular Ectopic (S) | QRS duration ≤ 120 ms **AND** correlation coefficient with the dominant template ≥ 0.80 **AND** presence of a morphologically abnormal preceding P' wave **AND** coupling interval < 0.85 × median RR |
| Fusion Beat (F) | Coupling interval between ventricular and dominant types, morphology intermediate between the two (correlation coefficients with both templates are between 0.75 and 0.90) |
| Paced Beat (P) | Pacing spike detected and QRS appears within 40 ms after the spike |
| Escape Beat | Coupling interval > 1.15 × median RR (**not** premature, but delayed) |

**Determination of Coupling Interval and Compensatory Pause**:
- Complete compensatory pause: `RR(前) + RR(后) ≈ 2 × 基础 RR` (tolerance ±60 ms) → supports ventricular origin
- Incomplete compensatory pause: `RR(前) + RR(后) < 2 × 基础 RR − 60 ms` → supports atrial origin

<a id="64-中位搏合成"></a>
### 6.4 Median Beat Synthesis

```
1. 取主导类全部成员，按 QRS 起点对齐（不是 R 峰对齐 —— R 峰位置受形态影响）
   实际做法：先按 R 峰粗对齐，再用互相关做 ±10 ms 精对齐
2. 逐导联、逐采样点取中位数（不是均值 —— 中位数对异常点鲁棒）
3. 若主导类成员数 < 3，不合成中位搏，直接使用形态最典型的单拍，
   并设置标志 MEDIAN_BEAT_WEAK
```

<a id="65-等电位线基准"></a>
### 6.5 Isoelectric Line Reference

**The zero baseline for all amplitude measurements must be uniformly defined as the PR segment** (the mean of a 20 ms window near the midpoint between the end of the P wave and the beginning of QRS).

If the P wave is indistinguishable (e.g., in atrial fibrillation), fall back to using the TP segment; if the TP segment is also indistinguishable (e.g., in tachycardia), use a 20 ms window preceding the beginning of QRS, and flag the ST measurement as low confidence.

**This is a highly error-prone implementation point.** Different baselines can cause ST level discrepancies of tens of μV, directly affecting STEMI diagnosis. The baseline strategy must be explicitly declared in the configuration and be auditable in the report.

<a id="66-形态复杂度门控"></a>
### 6.6 Morphological Complexity Gating

```
IF 主导类成员占比 < 30%  OR  模板类数 > 5:
    设置标志 MORPH_COMPLEX
    → 所有基于中位搏的形态学判据（肥大、缺血、束支阻滞）置 UNKNOWN
    → 仅输出节律相关结论
```

## 9. L7 Execution Order and Gating DAG

<a id="91-为什么必须有执行顺序"></a>
### 9.1 Why Execution Order Is Mandatory

The most common architectural error in rule systems is implementing N diagnoses as N independent binary classifications. In reality, diagnoses are strongly interdependent: the validity of certain diagnoses can **completely invalidate the criteria for others**. For example, when LBBB is present, standard ST-segment deviation criteria cannot be used to assess ischemia; instead, the Sgarbossa criteria must be applied.

Therefore, L7 must execute in a fixed topological order, with upstream results serving as gating conditions for downstream logic.

```
               [M4]   │ 缺血与心肌梗死         │  ← 受 M0/M2 门控
                      └──────────┬───────────┘
                                 ▼
                      ┌──────────────────────┐
               [M5]   │ 复极异常 / 电解质 / 药物│
                      └──────────┬───────────┘
                                 ▼
                      ┌──────────────────────┐
               [M6]   │ 其他（低电压、电交替、  │
                      │  心包炎、右位心等）     │
                      └──────────────────────┘
```

<a id="93-m2-先于-m1-的理由"></a>
### 9.3 Reasons for M2 Preceding M1

M2 (intraventricular conduction) is executed before M1 (rhythm) because the differential diagnosis of wide QRS tachycardia requires knowledge of the baseline bundle branch block morphology.

**However, a circular dependency exists:** If the entire recording consists of wide QRS tachycardia, there are no supraventricular beats available for M2 to analyze. Handling approach:

```
IF 主导型心搏均为宽 QRS AND HR > 100:
    跳过 M2 的束支阻滞判定
    直接进入 M1 的宽 QRS 心动过速鉴别流程
    M3、M4 全部关闭
```

<a id="10-l7-诊断规则库"></a>
## 10. L7 Diagnostic Rule Base

<a id="101-m0-起搏与设备识别"></a>
### 10.1 M0 —— Pacing and Device Identification

| Statement | Decision Criteria |
|---|---|
| Ventricular Paced Rhythm | `PACED_VENTRICULAR` and paced beats proportion > 80% |
| Atrial Paced Rhythm | `PACED_ATRIAL` and paced beats proportion > 80% |
| Dual-Chamber Paced Rhythm | `PACED_DUAL` |
| Intermittent Pacing | Paced beats proportion 20–80% |
| Pacing Failure to Capture (Suggestion) | Pacing spike detected but no corresponding depolarization wave within 40 ms thereafter, occurring ≥ 2 times |
| Pacing Under-sensing (Suggestion) | Pacing spike appears within 40–200 ms after intrinsic QRS |

Pacing-related capture/sensing abnormalities are output only as suggestions and mandate a manual review flag.

<a id="102-m2-心室内传导"></a>
### 10.2 M2 —— Intraventricular Conduction

<a id="1021-心室预激wpw-型"></a>
#### 10.2.1 Ventricular Pre-excitation (WPW Type)

Must satisfy **all** of the following:

| # | Condition |
|---|---|
| 1 | `PR_int < 120 ms` |
| 2 | `QRS_dur ≥ 110 ms` |
| 3 | `DELTA_WAVE`: The average slope of the initial 40–60 ms segment of QRS is < 50% of the average slope of the subsequent QRS segment, and this slurring is visible in ≥ 2 leads |
| 4 | Presence of secondary ST-T changes (ST-T direction opposite to the terminal vector of QRS) |

If established, output "Ventricular Pre-excitation" and **force disable all M3 and M4 criteria**, noting in the report: "Pre-excitation pattern, unable to assess myocardial infarction and ventricular hypertrophy."

<a id="1022-完全性左束支阻滞lbbb"></a>
#### 10.2.2 Complete Left Bundle Branch Block (LBBB)

| # | Condition |
|---|---|
| 1 | `QRS_dur ≥ 120 ms` |
| 2 | `V1_QS_OR_rS`: V1, V2 show QS or rS (r wave amplitude < 200 μV) |
| 3 | I, aVL, V5, V6 show broad monophasic R waves, with mid-portion notching or slurring in ≥ 2 leads (`LATERAL_NOTCHED_R`) |
| 4 | `NO_Q_LATERAL`: No q waves in I, V5, V6 (narrow q allowed in aVL) |
| 5 | `VAT_LATERAL_LONG`: R peak time in V5 or V6 > 60 ms |
| 6 | ST-T and QRS main deflection directions are opposite |

Conditions 1–5 all met → "Complete Left Bundle Branch Block" (HIGH)
Conditions 1–4 met, item 5 `UNKNOWN` → Output but downgraded to MEDIUM

**Strict Criteria (Strauss, additional statements output only if configured):**
- `QRS_dur ≥ 140 ms` (Male) / `≥ 130 ms` (Female)
- V1, V2 show QS or rS
- ≥ 2 leads among I, aVL, V1, V2, V5, V6 show mid-portion notching or slurring of QRS

This criterion is used for screening candidates for cardiac resynchronization therapy; it has lower sensitivity than conventional criteria but high specificity.

<a id="1023-完全性右束支阻滞rbbb"></a>
#### 10.2.3 Complete Right Bundle Branch Block (RBBB)

| # | Condition |
|---|---|
| 1 | `QRS_dur ≥ 120 ms` |
| 2 | `V1_RSR_PATTERN`: V1 or V2 shows rsr', rsR', or rSR', usually with R' > r |
| 3 | `WIDE_S_LATERAL`: Wide S waves in I and V6 (duration > 40 ms and S duration > R duration) |
| 4 | `VAT[V1] > 50 ms` |

Conditions 1, 2, and 3 are required; Condition 4 is supportive.

<a id="1024-不完全性束支阻滞"></a>
#### 10.2.4 Incomplete Bundle Branch Block

`QRS_BORDERLINE` (110–119 ms) and morphological criteria met → Output "Incomplete Left/Right Bundle Branch Block."

<a id="1025-左前分支阻滞lafb"></a>
#### 10.2.5 Left Anterior Fascicular Block (LAFB)

| # | Condition |
|---|---|
| 1 | `QRS_axis ∈ [−90°, −45°]` |
| 2 | aVL shows qR |
| 3 | `VAT[aVL] ≥ 45 ms` |
| 4 | II, III, aVF show rS |
| 5 | `QRS_dur < 120 ms` (unless combined with RBBB) |

**Exclusion Criteria** (if any are met, do not output): Inferior myocardial infarction, ventricular pre-excitation, left axis deviation due to ventricular hypertrophy.

<a id="1026-左后分支阻滞lpfb"></a>
#### 10.2.6 Left Posterior Fascicular Block (LPFB)

| # | Condition |
|---|---|
| 1 | `QRS_axis ∈ [+90°, +180°]` |
| 2 | I, aVL show rS |
| 3 | II, III, aVF show qR |
| 4 | `QRS_dur < 120 ms` |

**Exclusion Criteria**: Right ventricular hypertrophy, lateral myocardial infarction, chronic lung disease, asthenic body habitus (body habitus information is usually unavailable).

Since most exclusion criteria rely on clinical information rather than ECG, LPFB is **always output at the "Possible" level** with the note "Requires clinical and body habitus assessment."

<a id="1027-非特异性室内传导延迟ivcd"></a>
#### 10.2.7 Nonspecific Intraventricular Conduction Delay (IVCD)

`QRS_dur ≥ 120 ms` and does not meet morphological criteria for LBBB or RBBB.

<a id="103-m3-心房异常与心室肥大"></a>
### 10.3 M3 —— Atrial Abnormalities and Ventricular Hypertrophy

<a id="1031-心房异常"></a>
#### 10.3.1 Atrial Abnormalities

| Statement | Criteria (Meet any one) |
|---|---|
| Left Atrial Abnormality | `P_dur[II] ≥ 120 ms`; or `PTFV1 ≥ 0.04 mm·s` (V1 negative component depth ≥ 100 μV and duration ≥ 40 ms) |
| Right Atrial Abnormality | `P_amp[II] ≥ 250 μV`; or initial positive component of P wave in V1 ≥ 150 μV |
| Biatrial Abnormality | Both of the above are established |

Gating: If `P_ABSENT` is TRUE (e.g., atrial fibrillation), set all to `UNKNOWN`.

<a id="1032-左心室肥大-多判据并行评估"></a>
#### 10.3.2 Left Ventricular Hypertrophy —— Parallel Evaluation of Multiple Criteria

**All criteria must be calculated in parallel and fused; do not rely on a single criterion.** AHA/ACCF/HRS explicitly states that the sensitivity of individual criteria is generally below 50%, specificity is approximately 85%–90%, and there are significant differences between criteria—in a large group of patients with mild-to-moderate hypertension, only about 11% of LVH patients met both the Cornell voltage and Sokolow-Lyon criteria.

| Criterion | Threshold |
|---|---|
| Sokolow-Lyon | `S_amp[V1] + max(R_amp[V5], R_amp[V6]) ≥ 3500 μV` |
| Cornell Voltage | `R_amp[aVL] + S_amp[V3] > 2800 μV` (Male) / `> 2000 μV` (Female) |
| Cornell Product | `(R_amp[aVL] + S_amp[V3] + 女性?600:0) × QRS_dur > 244000 μV·ms` |
| Peguero-Lo Presti | `max(全导联最深 S) + S_amp[V4] ≥ 2300 μV` (Male) / `≥ 1900 μV` (Female) |
| Romhilt-Estes | See 10.3.3, ≥ 5 points |
| aVL single lead | `R_amp[aVL] ≥ 1100 μV` |
| Limb lead voltage | Any limb lead `QRS_amp_pp ≥ 2000 μV` |

**Fusion rules**:

```
n = 阳性判据数量
strain = 存在继发性 ST-T 改变（见下）

IF Romhilt_Estes ≥ 5 OR n ≥ 2:
    → "左心室肥大"                    confidence = HIGH
ELIF n == 1 AND strain:
    → "左心室肥大"                    confidence = MEDIUM
ELIF n == 1:
    → "左心室高电压"（不下肥大结论）   confidence = MEDIUM
ELIF Romhilt_Estes == 4:
    → "可能左心室肥大"                confidence = LOW
ELSE:
    → FALSE
```

**Criteria for Secondary ST-T Changes ("Strain" Pattern)**: In leads dominated by R waves (V5, V6, I, aVL), `ST_J < −50 μV` and ST segment is downsloping (`ST_slope < 0`) and T wave is asymmetrically inverted (`T_amp < 0` and `T_symmetry < 0.8`).

<a id="1033-romhilt-estes-积分表"></a>
#### 10.3.3 Romhilt-Estes Score

| Item | Score |
|---|---|
| R or S amplitude ≥ 2000 μV in any limb lead, or `S_amp[V1或V2] ≥ 3000 μV`, or `R_amp[V5或V6] ≥ 3000 μV` | 3 |
| Secondary ST-T changes, **not** on digoxin | 3 |
| Secondary ST-T changes, on digoxin | 1 |
| Left atrial abnormality (`PTFV1 ≥ 0.04 mm·s`) | 3 |
| Left axis deviation ≤ −30° | 2 |
| `QRS_dur ≥ 90 ms` | 1 |
| `VAT[V5或V6] ≥ 50 ms` | 1 |

≥ 5 points: Left Ventricular Hypertrophy (LVH) ｜ 4 points: Probable LVH

Note: Digoxin usage information is often unavailable. In implementation, set this field as optional input; if missing, score as "not used" and annotate this assumption in the evidence chain.

<a id="1034-门控关键"></a>
#### 10.3.4 Gating (Critical)

| Upstream Status | Handling |
|---|---|
| LBBB | **Prohibit** output of LVH-related conclusions. The AHA stance is that LVH should not be attempted to be diagnosed when LBBB is present. Output "Left bundle branch block present, unable to assess ventricular hypertrophy" |
| RBBB | Switch to RBBB-specific criteria set: `S_amp[V1] > 200 μV`, `R_amp[V5或V6] > 1500 μV`, `QRS_axis < −30°`. This set of criteria has a sensitivity of approximately 46%–68% and specificity of approximately 57%–71%, so confidence is forced to LOW, and wording uses "possible" |
| Ventricular Pacing | Prohibit output |
| Pre-excitation | Prohibit output |

<a id="1035-右心室肥大"></a>
#### 10.3.5 Right Ventricular Hypertrophy

| # | Condition |
|---|---|
| 1 | `RS_ratio[V1] > 1` and `R_amp[V1] ≥ 700 μV` |
| 2 | `R_amp[V1] + max(S_amp[V5], S_amp[V6]) ≥ 1050 μV` |
| 3 | `QRS_axis > +90°` (Strict: `≥ +110°`) |
| 4 | `RS_ratio[V5或V6] ≤ 1` |
| 5 | Secondary ST-T changes present in V1–V3 |

≥ 2 items met → "Right Ventricular Hypertrophy" (MEDIUM); ≥ 3 items → HIGH

**Exclusion Criteria**: Posterior myocardial infarction (can cause tall R in V1), RBBB, Type B pre-excitation, dextrocardia, reversed leads. If any are present, set `UNKNOWN`.

<a id="104-m4-缺血与心肌梗死"></a>
### 10.4 M4 —— Ischemia and Myocardial Infarction

<a id="1041-导联解剖分组与相邻关系"></a>
#### 10.4.1 Lead Anatomical Grouping and Adjacency

```
下壁    : II, III, aVF
前间壁  : V1, V2
前壁    : V3, V4
前侧壁  : V5, V6
高侧壁  : I, aVL
后壁    : 由 V1–V3 镜像推断（或 V7–V9 直接记录）
右室    : V3R, V4R（需额外导联）
```

Definition of "adjacent leads":
- Adjacent precordial lead chain: `V1–V2–V3–V4–V5–V6`
- Adjacent limb lead chain (Cabrera sequence): `aVL – I – (−aVR) – II – aVF – III`

**Implementation Note**: Lead III and aVF are adjacent, and aVF and Lead II are adjacent, but Lead III and Lead II are **not adjacent**. Determining adjacency based on the order of leads on the ECG paper is incorrect.

<a id="1042-st-段抬高阈值表"></a>
#### 10.4.2 ST Segment Elevation Threshold Table

According to the Fourth Universal Definition of Myocardial Infarction, the measurement point is the **J point** (`ST_J`), and **two adjacent leads must simultaneously meet** the following criteria:

| Lead | Sex/Age | Threshold |
|---|---|---|
| V2, V3 | Male ≥ 40 years | ≥ 200 μV |
| V2, V3 | Male < 40 years | ≥ 250 μV |
| V2, V3 | Female (any age) | ≥ 150 μV |
| Other standard leads | Any | ≥ 100 μV |
| V3R, V4R | Male < 30 years | ≥ 100 μV |
| V3R, V4R | Others | ≥ 50 μV |
| V7–V9 | Any | ≥ 50 μV |

If age or sex is missing, the determination for V2/V3 is set to `UNKNOWN` (see Strategy Selection in 2.2).

<a id="1043-st-段压低与-t-波倒置"></a>
#### 10.4.3 ST Segment Depression and T Wave Inversion

| Item | Threshold |
|---|---|
| ST depression | `ST_J ≤ −50 μV` in two adjacent leads, with horizontal or downsloping ST segment (`ST_slope ≤ 0`) |
| T wave inversion | `T_amp ≤ −100 μV` in two adjacent leads, and `RS_ratio > 1` in that lead |

Upsloping ST depression is not counted (commonly physiological, especially during tachycardia).

<a id="1044-高危形态学模板"></a>
#### 10.4.4 High-Risk Morphological Templates

The following templates are used to identify acute coronary occlusion manifestations that typical threshold criteria may miss. **The sensitivity of rule-based implementation is limited; all outputs are at the "suggestion" level and require mandatory manual review flags.**

**(a) de Winter type**
```
count over V1..V6 where:
    ST_J[l] ∈ [−300, −100] μV
    AND ST_slope[l] > 1.0 μV/ms   (上斜型)
    AND T_amp[l] > 500 μV          (高尖)
    AND T_symmetry[l] ∈ [0.8, 1.2] (对称)
≥ 4
AND ST_J[aVR] ≥ 0
→ "提示前降支近段闭塞（de Winter 型改变）"
```

**(b) Wellens type B**
```
T_amp[V2..V4] ≤ −200 μV （≥2 个导联）
AND T_symmetry ∈ [0.85, 1.15]
AND R_amp[V3] > 300 μV        (R 波保留)
AND ST_J[V2..V4] < 100 μV     (无显著抬高)
AND NOT PATHOLOGIC_Q[前壁]
→ "提示前降支近段严重狭窄（Wellens 型改变）"
```

**(c) Wellens Type A**: The `T_morph` in V2–V4 is biphasic (positive first, then negative), with the rest being the same as above.

**(d) Left main / three-vessel disease type**
```
ST_J[aVR] ≥ 100 μV
AND count(全导联 ST_J ≤ −100 μV) ≥ 6
AND ST_J[aVR] > ST_J[V1]
→ "提示左主干或三支病变，广泛心内膜下缺血"
```

**(e) Posterior wall myocardial infarction**
```
count(V1..V3 where ST_J ≤ −50 μV) ≥ 2
AND RS_ratio[V2] > 1
AND R_dur[V2] ≥ 40 ms
AND T_amp[V2] > 0
→ "提示后壁心肌梗死，建议加做 V7–V9"
```

**(f) Terminal QRS Morphology**: In leads with ST elevation, the absence of both an S wave and a J-point notch in the terminal QRS → suggests acute complete occlusion, increasing priority.

<a id="1045-lbbb-或心室起搏下的急性心肌梗死判定"></a>
#### 10.4.5 Diagnosis of Acute Myocardial Infarction in LBBB or Ventricular Pacing

Standard ST criteria are completely ineffective in LBBB and ventricular pacing (secondary ST-T changes themselves manifest as significant deviation). At this point, switch to the Sgarbossa pathway.

**Original Sgarbossa Score**

| Condition | Points |
|---|---|
| ST elevation ≥ 100 μV (in ≥ 1 lead) **concordant** with the QRS main deflection | 5 |
| ST depression ≥ 100 μV in V1–V3 **concordant** with the QRS main deflection | 3 |
| ST elevation ≥ 500 μV **discordant** with the QRS main deflection | 2 |

Total score ≥ 3 → suggests acute myocardial infarction (high specificity, low sensitivity)

**Modified Smith Criteria (Recommended for simultaneous implementation)**

Replace the third criterion with a ratio-based criterion:
```
对每个不一致导联 l（ST 抬高方向与 QRS 主波方向相反）:
    ratio = ST_J[l] / S_amp[l]        # 两者符号相反，比值为负
    IF ratio ≤ −0.25:  阳性
```
That is, the ST elevation amplitude is ≥ 25% of the S wave depth in that lead. The sensitivity of this criterion is significantly superior to the original third criterion.

The first and second criteria remain unchanged. A positive result for any one criterion triggers an output alert.

<a id="105-病理性-q-波与心肌梗死定位"></a>
### 10.5 Pathological Q Waves and Myocardial Infarction Localization

<a id="1051-病理性-q-波判定"></a>
#### 10.5.1 Criteria for Pathological Q Waves

| Lead | Condition |
|---|---|
| V2, V3 | Any `Q_dur ≥ 20 ms`, or QS morphology |
| I, II, aVL, aVF, V4, V5, V6 | **Two adjacent leads** with `Q_dur ≥ 30 ms` and `Q_amp ≥ 100 μV`, or QS morphology |
| V1, V2 (posterior equivalent) | `R_dur ≥ 40 ms` and `RS_ratio ≥ 1` with upright T waves |

**aVR is not included in the assessment of pathological Q waves** (aVR can normally exhibit QS morphology).
**An isolated Q wave in lead III is insufficient for diagnosis**; it must be accompanied by findings in lead II or aVF.

<a id="1052-排除条件"></a>
#### 10.5.2 Exclusion Criteria

If any of the following conditions are present, all pathological Q wave assessments are set to `UNKNOWN`:

- Complete left bundle branch block
- Ventricular pre-excitation
- Ventricular pacing
- Left ventricular hypertrophy (which can cause QS morphology in V1–V3)
- Dextrocardia / reversed leads
- `MORPH_COMPLEX`

<a id="1053-定位与分期"></a>
#### 10.5.3 Localization and Staging

| Region | Leads |
|---|---|
| Anteroseptal | V1, V2 |
| Anterior | V3, V4 |
| Anterolateral | V5, V6 |
| High lateral | I, aVL |
| Extensive anterior | V1–V6 (+ I, aVL) |
| Inferior | II, III, aVF |
| Posterior | Mirror image in V1–V3 |

Staging rules (based on a single ECG only, with limited reliability):

```
IF 病理性Q波 AND 该区域 ST 抬高:
    → "心肌梗死，急性期改变"（优先级：急症）
ELIF 病理性Q波 AND 该区域 T 波倒置 AND 无 ST 抬高:
    → "心肌梗死，演变期改变"
ELIF 病理性Q波 AND ST-T 正常:
    → "陈旧性心肌梗死（或既往梗死）"
```

**Must be annotated**: "ECG cannot reliably determine the time of infarction; staging conclusions must be combined with clinical context and comparison with previous ECGs."

<a id="106-m1-节律与房室传导"></a>
### 10.6 M1 —— Rhythm and Atrioventricular Conduction

<a id="1061-基础节律决策树"></a>
#### 10.6.1 Basic Rhythm Decision Tree

```
1. 起搏搏动占比 > 80% ?
      → 起搏心律（分型见 10.1），结束

2. 心房活动分类:
   a) P 波均一、P_axis ∈ [0°, 75°]、每 P 后有 QRS、PR 恒定
        → 窦性来源
   b) P 波形态异常但均一、心房率 100–250、规整
        → 房性心动过速
   c) ≥ 3 种 P 形态 + RR 不齐 + HR > 100
        → 多源性房性心动过速
   d) F_WAVE_PRESENT（心房率 240–340、规整锯齿）
        → 心房扑动
   e) P_ABSENT + RR_IRREGULAR_ABSOLUTE + f 波谱宽平
        → 心房颤动
   f) P 波倒置于 II/III/aVF 且 PR < 120 ms，或 P 缺如而 QRS 窄
        → 交界性来源

3. 窦性来源者按心率细分:
      HR < 60  → 窦性心动过缓
      HR > 100 → 窦性心动过速
      RR 变异 > 120 ms 且呈周期性 → 窦性心律不齐
      否则 → 窦性心律

4. 交界性/室性来源者按心率细分:
      交界性: 40–60 逸搏心律 / 60–100 加速性 / >100 交界性心动过速
      室性:   20–40 逸搏心律 / 40–100 加速性室性自主心律 / >100 室性心动过速
```

<a id="1062-心房颤动的三重证据要求"></a>
#### 10.6.2 Triple Evidence Requirement for Atrial Fibrillation

**Relying solely on RR irregularity to diagnose atrial fibrillation will result in a large number of false positives in the presence of frequent atrial premature beats.** All three of the following conditions must be met simultaneously:

| # | Condition |
|---|---|
| 1 | `RR_IRREGULAR_ABSOLUTE`: `RR_CV > 0.15` and `RR_entropy > T_ent` and `SD1/SD2 > 0.4` |
| 2 | `P_ABSENT`: Proportion of identifiable P waves < 20% (assessed in leads II and V1) |
| 3 | f-wave morphology: No sharp dominant peak within 3–9 Hz (`f_wave_regularity < 3`); if the TQ segment is too short, this item is set to `UNKNOWN` |

If item 3 is `UNKNOWN`, output is still permitted provided items 1 and 2 are satisfied, but the confidence level is reduced to MEDIUM.

**Differentiation from frequent atrial premature beats**: The Poincaré plot for atrial premature bigeminy/trigeminy shows multi-cluster aggregation (low `SD1/SD2`), whereas atrial fibrillation presents as a single diffuse cloud. This feature is the most effective means of distinguishing between the two and must be implemented.

<a id="1063-心房扑动"></a>
#### 10.6.3 Atrial Flutter

```
F_WAVE_PRESENT
AND 心房率 ∈ [240, 340] 次/分
AND 锯齿波在 II、III、aVF 或 V1 可辨
→ 心房扑动
   传导比 = 心房率 / 心室率，四舍五入至整数或标注"不等比传导"
```

**Mandatory Trigger Rules**: Regular narrow QRS tachycardia with a ventricular rate between 140–160 must mandatorily execute the atrial flutter check branch (atrial flutter with 2:1 conduction is easily misdiagnosed as sinus tachycardia). Even if F waves are not detected, the report should indicate "ventricular rate close to 150, exclude atrial flutter with 2:1 conduction".

<a id="1064-异位搏动"></a>
#### 10.6.4 Ectopic Beats

| Statement | Condition |
|---|---|
| Premature Ventricular Contractions (PVCs) | Beat type is V (see 6.3), output by quantity: occasional (< 1%) / frequent (≥ 1%) / couplets / bigeminy / trigeminy |
| Premature Atrial Contractions (PACs) | Beat type is S |
| Multiform PVCs | Presence of ≥ 2 V-type templates with different morphologies |
| Non-sustained Ventricular Tachycardia | Consecutive V-type beats ≥ 3 and < 30 s，率 > 100 |
| Escape Beats | Coupling interval > 1.15 × median RR |

Coupling pattern determination: Bigeminy = one ectopic beat follows each dominant beat, repeated ≥ 3 times.

<a id="1065-房室传导阻滞"></a>
#### 10.6.5 Atrioventricular Block

Prerequisite for determination: Presence of an identifiable P wave sequence (`P_presence_ratio > 0.5`). Set all to `UNKNOWN` during atrial fibrillation.

| Degree | Determination Formula |
|---|---|
| First-degree | `PR_int > 200 ms` and all P waves are conducted |
| Second-degree Type I (Wenckebach) | Presence of non-conducted P waves; progressive PR prolongation before drop (total increase > 40 ms); first PR after drop is shorter than the last PR before drop by ≥ 30 ms; progressive RR shortening |
| Second-degree Type II | Presence of non-conducted P waves; constant PR before and after drop (SD < 10 ms) |
| 2:1 AV Block | Exactly 1 out of every 2 P waves is conducted, **cannot distinguish between Type I and Type II** |
| High-grade AV Block | ≥ 2 consecutive non-conducted P waves, but conducted beats still exist |
| Third-degree (Complete) | `AV_DISSOCIATION` and atrial rate > ventricular rate and PP and RR are each regular |

**2:1 block must be output as a separate category**, and must not be forcibly classified as Type I or Type II. Report wording: "2:1 atrioventricular block, this tracing cannot distinguish between Mobitz Type I and Type II".

**The necessary condition for third-degree block is AV dissociation + atrial rate faster than ventricular rate**. Cases with only AV dissociation where the ventricular rate is faster than the atrial rate are interference AV dissociation (e.g., accelerated junctional rhythm), not third-degree block. This is a common point of misdiagnosis.

<a id="1066-宽-qrs-心动过速鉴别"></a>
#### 10.6.6 Differential Diagnosis of Wide QRS Tachycardia

Entry conditions: `QRS_dur ≥ 120 ms` and `HR > 100` and lasting ≥ 3 beats.

Determine in the order of the Brugada four-step algorithm; if any step is "Yes", diagnose as ventricular tachycardia:

| Step | Determination |
|---|---|
| 1 | Are there no RS morphologies in all leads V1–V6? |
| 2 | Is the RS interval (from R wave onset to S wave nadir) in any precordial lead > 100 ms? |
| 3 | Is there AV dissociation (`AV_DISSOCIATION`), fusion beats, or ventricular capture? |
| 4 | Do the morphologies in V1/V2 and V6 meet ventricular criteria? |

If all four steps are "No" → Supraventricular tachycardia with intraventricular conduction abnormality.

**Additional evidence supporting VT** (used to increase confidence): Precordial concordance (V1–V6 QRS main deflection direction is consistent), electrical axis falls in `AXIS_EXTREME` (no man's land).

**Safety Strategy (Mandatory)**:
```
IF 宽QRS心动过速:
    无论四步法结论如何，均设置 CRITICAL 标志与强制人工复核
    IF 四步法结论为 SVT:
        措辞 = "宽 QRS 心动过速，形态学倾向室上性伴差异传导，
                但不能排除室性心动过速，建议立即人工判读"
```

Rationale: The clinical consequences of misclassifying ventricular tachycardia (VT) as supraventricular tachycardia (SVT) are far more severe than the reverse misclassification. The rule system must therefore err on the side of caution here.

<a id="107-m5-复极异常电解质与药物"></a>
### 10.7 M5 — Repolarization Abnormalities, Electrolytes, and Medications

All conclusions in this section must be appended with "ECG findings suggest; confirmation requires laboratory tests or clinical information."

| Statement | Decision Rule |
|---|---|
| Prolonged QT interval | `QTcB > 450 ms` (male) / `> 460 ms` (female) |
| Significantly prolonged QT interval | `QTcB > 500 ms` → Escalate to emergency priority |
| Shortened QT interval | `QTcB < 340 ms` |
| Brugada Type 1 (suggested) | ≥ 1 lead in V1, V2 with `ST_J ≥ 200 μV` and coved-type downsloping ST (`ST_slope < 0` and `ST_shape = CONVEX`) followed by inverted T wave |
| Early repolarization | J-point notch or slur in ≥ 2 contiguous leads in the inferior (II, III, aVF) or lateral (I, aVL, V4–V6) leads, with J-point elevation ≥ 100 μV |
| Hyperkalemia (suggested) | Tall, symmetric T waves (`T_amp > 1.5 × 正常上限` and `T_symmetry ∈ [0.9,1.1]` and narrow T-wave base) + `P_amp[II] < 100 μV` or absent P waves + `QRS_dur` wider than expected |
| Hypokalemia (suggested) | `U_amp > 0.5 × T_amp` + ST depression + flat T waves (`\|T_amp\| < 100 μV`) |
| Hypocalcemia (suggested) | Prolonged `QTcB` with normal T-wave morphology and timing (due to prolonged ST segment) |
| Hypercalcemia (suggested) | Shortened `QTcB`, ST segment nearly absent |
| Digoxin effect | "Sagging" downsloping ST depression (`ST_slope < 0` and `ST_shape = CONCAVE` concave upward) + shortened QT + flat or inverted T waves, commonly seen in V5, V6 |

**Gating for QT measurement**: During `QRS_dur ≥ 120 ms` (bundle branch block, pacing), QT prolongation is partly due to delayed depolarization. In such cases, output the `JT` interval (`QT − QRS_dur`) as an aid, and annotate the report with "QRS widened, QTc interpretation limited."

**Important limitations of Brugada**: Standard V1, V2 positions have insufficient sensitivity for Brugada-type changes; additional leads at the 2nd and 3rd intercostal spaces are required. When the system detects suspicious patterns, it should output "Recommend adding high precordial leads (V1, V2 moved up 1–2 intercostal spaces)."

<a id="108-m6-其他"></a>
### 10.8 M6 — Others

| Statement | Decision Rule |
|---|---|
| Low voltage in limb leads | All 6 limb leads `QRS_amp_pp < 500 μV` |
| Low voltage in precordial leads | All 6 precordial leads `QRS_amp_pp < 1000 μV` |
| Low voltage in all leads | Both of the above conditions are met |
| Electrical alternans | `QRS_alternans > 0.1` and lasting ≥ 6 beats; when coexisting with low voltage, escalate to "suggests pericardial effusion/cardiac tamponade" |
| Acute pericarditis (suggested) | Widespread ST elevation in ≥ 6 leads with concave upward morphology (`ST_shape = CONCAVE`) + PR segment depression (`PR_seg < −50 μV`) + PR segment elevation in aVR + **no reciprocal ST depression** (except in aVR, V1) + no pathological Q waves |
| Pulmonary embolism (suggested, low sensitivity) | `S_amp[I] > 150 μV` + `Q_amp[III] > 150 μV` + `T_amp[III] < 0` (S1Q3T3) + any of the following: incomplete/complete RBBB, T-wave inversion in V1–V4, `AXIS_RIGHT` |
| Dextrocardia | See 4.4.3 |
| Lead reversal | See 4.4.1, 4.4.2 |
| Nonspecific ST-T changes | Presence of ST or T-wave abnormalities that do not meet any of the above specific patterns |

**Differentiating pericarditis from STEMI is the most critical and error-prone task in this module.** The key distinguishing features are "widespread distribution + no reciprocal depression + PR segment changes." When uncertain, **prioritize outputting STEMI and mandate manual review** (the consequences of missing STEMI are far more severe than falsely reporting pericarditis).

<a id="11-l8-冲突消解优先级与序列比对"></a>
## 11. L8 Conflict Resolution, Priority, and Sequence Comparison

<a id="111-互斥规则表"></a>
### 11.1 Mutually Exclusive Rules Table

| Group | Mutually Exclusive Members | Resolution Strategy |
|---|---|---|
| Bundle branch block | LBBB / RBBB / IVCD | The three are mutually exclusive. If multiple are met, prioritize in the order LBBB > RBBB > IVCD |
| Fascicular block | LBBB vs. LAFB/LPFB | If LBBB is present, suppress output of fascicular block |
| Pre-excitation | Pre-excitation vs. any bundle branch block | Pre-excitation takes priority; suppress output of bundle branch block |
| Basal rhythm | Sinus / AF / AFlutter / Junctional / Ventricular | Mutually exclusive, single selection. In case of conflict, rank by evidence strength (number of conditions met) and select the highest |
| AV block | Various degrees | Mutually exclusive; select the highest degree |
| Normal determination | "Normal ECG" | Mutually exclusive with any abnormal statement |
| Hypertrophy | "Left ventricular hypertrophy" vs. "Left ventricular high voltage" | Mutually exclusive; the former takes priority |

<a id="112-输出优先级报告排序"></a>
### 11.2 Output Priority (Report Ordering)

| Level | Content |
|---|---|
| P0 Technical Warning | Lead reversal, insufficient signal quality, dextrocardia |
| P1 Emergency | ST-elevation myocardial infarction, wide QRS tachycardia, third-degree/high-grade AV block, ventricular rate < 40 或 > 150, `QTcB > 500`, Brugada Type 1, hyperkalemia suggestion, left main equivalent changes |
| P2 Rhythm | Basal rhythm, ectopic beats, AV block (first-degree, second-degree) |
| P3 Conduction | Bundle branch block, fascicular block, pre-excitation, IVCD |
| P4 Structure | Atrial abnormalities, ventricular hypertrophy |
| P5 Old Changes | Old myocardial infarction, evolving changes |
| P6 Nonspecific | Nonspecific ST-T changes, low voltage, etc. |

Within the same level, sort in descending order of confidence.

<a id="113-序列比对若存在既往心电图"></a>
### 11.3 Sequence Comparison (If Previous ECG Exists)

Sequence comparison is one of the highest clinical value functions provided by the rule system, and its implementation cost is lower than adding new diagnostic modules. **Strongly recommended for inclusion in v1.0 scope.**

Comparison items and significant change thresholds (exceeding physiological variation range for retesting):

| Measurement Item | Significant Change Threshold |
|---|---|
| `QRS_dur` | ±10 ms |
| `QT_int` | ±25 ms |
| `PR_int` | ±20 ms |
| `ST_J` (any lead) | ±100 μV |
| `QRS_axis` | ±30° |
| `T_amp` (any lead) | Polarity reversal, or ±200 μV |

Trigger rules:

```
IF 新出现 病理性Q波:                → 输出"较前新出现 Q 波"，提升至 P1
IF 新出现 ST 抬高 ≥ 100 μV:        → 提升至 P1
IF T 波极性由正转负（≥2 相邻导联）: → 输出"较前 T 波演变"，提升至 P2
IF 基础节律改变（如窦性 → 房颤）:   → 输出"较前节律改变"，提升至 P1
IF 无显著变化:                      → 输出"与 [日期] 心电图比较大致相同"
```

Before comparison, it is necessary to verify that the acquisition conditions (lead positions, filter settings) of the two records are consistent. If they are inconsistent, mark it as "Acquisition conditions differ; comparison results are for reference only."

<a id="122-置信度到措辞的映射必须固定并全系统一致"></a>
### 12.2 Mapping of Confidence to Phrasing (Must Be Fixed and Consistent Across the Entire System)

| Confidence | Phrasing Template | Meaning |
|---|---|---|
| HIGH | "〈Diagnosis〉" | All necessary criteria are met; measurements are reliable |
| MEDIUM | "Consider 〈Diagnosis〉" | Necessary criteria are met but there are factors degrading measurement quality, or some supportive criteria are not met |
| LOW | "Possible 〈Diagnosis〉; clinical correlation recommended" | Criteria are partially met, or the criteria used have limited specificity |
| Abstain | "Unable to assess 〈Item〉 due to 〈Reason〉" | Gating is closed or input is UNKNOWN |
| Hint | "Suggests 〈Finding〉; manual review recommended" | High-risk morphological template matched |

AHA/ACCF/HRS notes that qualifiers such as "probable," "possible," and "consider" are susceptible to multiple interpretations and can be used to indicate partial fulfillment of criteria or proximity to thresholds. Therefore, **this system must fix the precise meaning of each qualifier in this table and prohibit any deviation from these definitions in any module**.

<a id="123-正常心电图的输出条件"></a>
### 12.3 Output Conditions for "Normal ECG"

All of the following must be **fully** satisfied to output "Normal ECG":

```
1. L2 质量门控：12 导全部可用，无反接警告
2. 全部异常 finding 均为 FALSE（无一为 TRUE）
3. 全部 finding 均非 UNKNOWN
4. 全部测量值落在正常范围内：
     HR ∈ [60, 100]
     P_dur < 120 ms
     PR_int ∈ [120, 200] ms
     QRS_dur < 110 ms
     QTcB ≤ 450 (男) / 450 (女) ms   ← 采用更严格的下限
     QRS_axis ∈ [−30°, +90°]
5. 无 MORPH_COMPLEX、MEDIAN_BEAT_WEAK 标志
```

**Output "Normal" is prohibited if any UNKNOWN exists**; instead, use: "No definite abnormalities seen, but <item list> cannot be evaluated."

This is a critical safety rule. The system must never declare "Normal" simply because "no abnormalities were detected"—non-detection may be due to the inability to evaluate.

<a id="124-强制人工复核触发条件"></a>
### 12.4 Mandatory Manual Review Trigger Conditions

If any of the following conditions are met, the report must display a review flag at the top:

- Any P0 or P1 level statement
- Any "Hint" level statement (high-risk morphological template match)
- Presence of ≥ 3 abstentions
- `MORPH_COMPLEX` or `MEDIAN_BEAT_WEAK`
- Wide QRS tachycardia (regardless of conclusion)
- Inability to distinguish between suspected pericarditis and STEMI
- Available leads < 12

<a id="125-陈述编码"></a>
### 12.5 Statement Coding

All output statements must be mapped to standardized codes. It is recommended to adopt the SCP-ECG statement codes or the MDC_ECG coding system, with a reserved field for mapping to SNOMED CT.

Reason: Statement texts and data structures from algorithms of different manufacturers are mutually incompatible. Without standardization, subsequent data analysis, quality control statistics, and cross-system integration will be impossible. This layer must be established in v1.0; the cost of retrofitting later is extremely high.

<a id="14-验证与测试计划"></a>
## 14. Verification and Testing Plan

<a id="141-分层验证原则"></a>
### 14.1 Layered Verification Principle

**Each layer must be verified independently; end-to-end testing alone is not sufficient.** End-to-end metrics may look good but cannot pinpoint problems, and errors in rule-based systems are often systematic biases in one layer amplified by downstream processes.

<a id="142-各层验收标准"></a>
### 14.2 Acceptance Criteria for Each Layer

| Layer | Dataset | Metrics | Target |
|---|---|---|---|
| L2 Reversal Detection | Artificially constructed reversal samples (synthesized from normal records using the transformation relationships in 4.4.1) + real reversal samples | Se / Sp | Limb lead reversal Se ≥ 95%, Sp ≥ 99% |
| L3 QRS Detection | MIT-BIH Arrhythmia, NST (noise stress test) | Se / +P, per ANSI/AAMI EC57 protocol | ≥ 99.5% / ≥ 99.5% |
| L3 Waveform Delineation | QT Database, LUDB | Mean and standard deviation of onset/offset errors | P onset/offset SD ≤ 10 ms; QRS SD ≤ 8 ms; T offset SD ≤ 25 ms |
| L5 Measurement Accuracy | CSE Multilead Database | Mean difference from reference values | P duration, PR, QRS within ±10 ms each; QT, RR within ±25 ms each. Standard deviation limits must be verified against the original CSE standard text |
| L7 Diagnosis | See 14.3 | Per-class Se / Sp / PPV / NPV | See 14.4 |

The CSE mean difference limits are the watershed for whether the measurement layer of this system can be considered diagnostic-grade. Published commercial and research-grade algorithms all use this as the pass criterion.

<a id="143-诊断层测试集构成"></a>
### 14.3 Composition of Diagnostic Layer Test Sets

| Purpose | Dataset | Size | Description |
|---|---|---|---|
| Development & Tuning | PTB-XL | ~21,800 10-second 12-lead records, 18,869 patients, 500 Hz, 71 statement classes | Use official 10-fold split by patient; first 8 folds for tuning |
| Internal Validation | PTB-XL folds 9 & 10 | — | Must not be accessed during tuning |
| External Validation A | CPSC2018 | 6,877 records, 9 label classes, 500 Hz, 6–60 seconds | Chinese population, closer to domestic deployment scenarios |
| External Validation B | Chapman-Shaoxing / Ningbo | ~45,000 records, 10 seconds, 500 Hz | Acquired with GE MUSE, tests for device differences |
| External Validation C | PhysioNet/CinC 2020–2021 collection (including Georgia) | — | Multi-device, multi-region |
| Rare Class Supplement | Self-built specialized set | ≥ 30 cases per class | Classes with very few samples in public sets, such as third-degree AV block, Brugada, de Winter, Wellens, dextrocardia, etc. |
| Gold Standard Validation Set | **Self-built** | ≥ 2,000 cases | See 14.5 |

<a id="144-指标要求"></a>
### 14.4 Metric Requirements

**Using accuracy as the primary metric is prohibited** (meaningless when classes are highly imbalanced).

| Metric | Purpose |
|---|---|
| Per-class Sensitivity (Se) | Primary metric. Safety-critical classes (STEMI, VT, third-degree AVB) must have separate targets and meet them |
| Per-class Specificity (Sp) and PPV | Control the review burden caused by false positives |
| Abstention Rate | Statistically separate. **Abstentions do not count as errors**, but a high abstention rate (> 20%) indicates overly strict gating, requiring parameter tuning |
| macro-F1 | Overall reference |

Suggested targets for safety-critical classes (to be determined through clinical scenario negotiation):

| Class | Se Target | Sp Target |
|---|---|---|
| ST-elevation myocardial infarction | ≥ 90% | ≥ 95% |
| Ventricular tachycardia | ≥ 95% | ≥ 90% |
| Third-degree AV block | ≥ 95% | ≥ 98% |
| Atrial fibrillation | ≥ 95% | ≥ 97% |
| Complete left/right bundle branch block | ≥ 95% | ≥ 98% |

<a id="145-关于公开数据集标签的重要警告"></a>
### 14.5 Important Warning Regarding Labels in Public Datasets

**A significant portion of labels in public datasets originate from device-embedded algorithm outputs + manual review.** Using these directly as the gold standard for tuning is equivalent to fitting the errors of other manufacturers' algorithms and will mask true performance.

Required countermeasure: Establish a self-built gold standard set of ≥ 2,000 cases, independently interpreted by ≥ 2 ECG specialists, with disagreements arbitrated by a third person, to serve as the final acceptance basis. This set must be strictly sealed during development.

<a id="146-回归测试"></a>
### 14.6 Regression Testing

The greatest risk of rule-based systems is **breaking another previously passing sample when patching a boundary sample**. It is necessary to establish:

- Unit test samples for each diagnostic rule: at least 5 positive examples + 5 negative examples
- Complete truth table testing for the three-valued logic evaluator
- Run full regression after every rule change; any previously passing sample that fails blocks the merge
- Combinatorial coverage testing for the gating matrix (9.4)

<a id="147-鲁棒性测试"></a>
### 14.7 Robustness Testing

| Test | Method | Pass Condition |
|---|---|---|
| Noise Tolerance | Superimpose baseline wander, electromyographic, and power-line noise on clean records according to the NST protocol, increasing intensity step by step | Performance should manifest as an **increase in abstention rate** with increasing noise, rather than an increase in misclassification rate |
| Filter Domain Shift | Re-process the same raw record using different pre-filter settings | Diagnostic conclusion consistency ≥ 95% |
| Lead Missing | Mask individual leads one by one | Diagnoses dependent on that lead should correctly abstain; those not dependent should maintain their conclusions |
| Sampling Rate | Compare homologous data at 500 / 1000 Hz | Measurement differences within acceptance limits |

The first item is a direct test of this system's design philosophy: **Under noise, abstain rather than guess.**

<a id="15-风险与已知局限"></a>
## 15. Risks and Known Limitations

<a id="151-技术路线固有局限须书面告知使用方"></a>
### 15.1 Inherent Limitations of the Technical Approach (Must Be Disclosed in Writing to Users)

| Limitation | Manifestation | Mitigation Measures |
|---|---|---|
| Low sensitivity to atypical morphology | Rule-based implementation has limited recall for de Winter, Aslanger type, atypical Wellens, etc. | Output at "suggestion" level with mandatory review; report states that not all acute coronary occlusion presentations are covered |
| Threshold fragility | Conclusions are unstable when measurements are near thresholds | Confidence degradation mechanism (8.1); boundary samples output qualifiers rather than definitive statements |
| Weak noise robustness | Delineation fails under moderate to severe noise | Quality gating + high abstention rate |
| Inability to learn local population characteristics | Thresholds are derived from international literature and may deviate from local population distributions | After launch, statistically analyze the positive rate of each criterion, compare with epidemiological expectations, and manually adjust configuration if necessary (**not** automatic fitting) |

<a id="152-数据与场景局限"></a>
### 15.2 Data and Scenario Limitations

| Limitation | Description |
|---|---|
| Fundamental limitation of 10-second records | Paroxysmal arrhythmias and intermittent blocks may not appear at all. The system must strictly distinguish between "not seen in this tracing" and "excluded"; report wording must not use the term "excluded" |
| Lack of clinical information | Electrolytes, medications, body habitus, and symptoms are unavailable; exclusion conditions for multiple criteria cannot be fully executed |
| No right chest and posterior leads | Right ventricular and posterior wall infarctions can only be inferred indirectly; additional tests must be actively recommended |
| Pediatric applicability | Thresholds in this specification are based on adults. **Pediatrics requires an independent age-stratified threshold system, which is out of scope for v1.0**; the system must explicitly reject processing records for patients < 16 years old or mark them as "thresholds not applicable" |

<a id="153-需要项目层面决策的开放问题"></a>
### 15.3 Open Issues Requiring Project-Level Decisions

1. Whether to adopt Strategy A (abstention) or Strategy B (conservative thresholds) when age/gender is missing
2. The acceptable upper limit for the abstention rate (affects the review burden in clinical workflows)
3. Whether to include sequence comparison (recommended, but requires access to historical data)
4. Se/Sp targets for safety-critical classes (must be negotiated with clinical partners; both cannot be maximized simultaneously)
5. Choice of statement coding system (SCP-ECG vs MDC_ECG)

<a id="154-监管相关"></a>
### 15.4 Regulatory Considerations

If intended for submission as medical device software:

- Relevant standards include IEC 60601-2-25 (diagnostic ECG equipment) and ISO/IEC 80601-2-86. A significant change in the latter is: **Algorithm testing requirements, testing methods, and datasets will be applicable based on the intended use of the algorithm, not solely based on the type of device hosting the algorithm**. Therefore, "we are just software" does not constitute grounds for exemption.
- The pure rule-based approach has significant advantages in submission: no need to submit training data representativeness, no need for a data drift monitoring plan, and no need for a retraining change control process. **This is the primary benefit of choosing this approach and should be clearly recorded in the project initiation documents.**
- Every threshold change in the configuration file constitutes a software change and must go through the change control process with retained literature justification.

| **P7 Rule Library B** | M3 hypertrophy, M5 repolarization, M6 other | Same as above | 4–5 weeks |
| **P8 Rule Library C** | M4 ischemia/infarction (including high-risk templates, Sgarbossa) | Same as above | 6–8 weeks |
| **P9 Sequence Comparison** | L8 sequence comparison module | | 3 weeks |
| **P10 System Acceptance** | Gold standard set acceptance, robustness testing, documentation | Acceptance report | 4 weeks |

<a id="162-排序理由"></a>
### 16.2 Rationale for Ordering

- **P2 before P3**: Quality gating is the lifeline of the rule-based system and must be established before measurement. Doing delineation first and adding gating later will result in significant rework.
- **P3 is a long-cycle, high-risk item**: Delineation accuracy determines the system's upper limit; do not compress this phase. If CSE acceptance fails, the value of all subsequent work will be discounted.
- **No skipping between P4 and P5**: Decoupling the finding layer from the rule layer is key to maintainability; do not write directly from features to diagnoses to save time.
- **P6 before P8**: Rules for rhythm and conduction have the highest certainty, the most rigid clinical needs, and are easiest to pass acceptance. Doing them first builds confidence and exposes architectural issues; ischemia/infarction is the most difficult and should be done after the architecture is stable.
- **P9 sequence comparison has low cost and high clinical value**; if resources are tight, it can run in parallel with P7.

<a id="163-里程碑门禁"></a>
### 16.3 Milestone Gates

| Gate | Condition |
|---|---|
| G1 (P3 Exit) | CSE measurement accuracy meets all standards; QRS detection meets EC57 target |
| G2 (P6 Exit) | Se ≥ 90% for rhythm and conduction classes on external validation set |
| G3 (P8 Exit) | Safety-critical classes meet 14.4 targets, and noise testing shows an increase in abstention rate |
| G4 (P10 Exit) | Self-built gold standard set acceptance passed; all documentation complete |

No phase may proceed if any gate is not passed.
