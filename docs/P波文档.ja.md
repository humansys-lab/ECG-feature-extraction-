# マルチリード ECG P 波のオンセット/オフセットの正確な定義

**技術的ソリューション: 信頼性の高いリードスクリーニング + 堅牢な融合 (純粋な信号処理ルート、機械学習は使用しません)**

---

<a id="0-方法学边界"></a>
## 0. 方法論の境界

このソリューションでは、注釈付きデータのトレーニングを必要とするモデルは使用されません。次の方法は **機械学習ではありません** が使用できます。これらの方法にはトレーニング セットや学習されたパラメータがなく、すべてビートごとにオンラインで計算される決定論的な変換です。

|利用可能 (決定論的 DSP / 数値的手法) |除外 (トレーニングが必要) |
|---|---|
|ウェーブレット変換、モジュラー最大解析 | U-Net / DENS-ECG およびその他のセグメンテーション ネットワーク |
| PCA / SVD 空間投影 (各撮影ウィンドウで計算) |トレーニングされた分類子とリグレッサー |
|カルマン フィルタリング、メディアン フィルタリング |ラベル付きデータセットの適合に依存するパラメータ |
|非線形最小二乗曲線フィッティング (LM) | |
|テンプレート関連（テンプレートはこのレコードそのものを重ね合わせたものです） | |
| Kors / Dower 変換行列 (公開された固定定数) | |

**ネットワークを放棄した後の主な損失**は、境界精度ではなく、リードバイリードのソフト証拠 (サンプルごとの確率) です。セクション 4 では、この問題に対処します。

<a id="1-问题特性与精度上限"></a>
## 1. 問題の特性と精度の上限

P 波の振幅は通常 **50 ～ 250 μV** で、主エネルギーは **15 Hz** 未満で、ベースライン ドリフト、呼吸変調、および筋電図の周波数帯域と重複します。オンセット/オフセットの本質は、**低スロープの転換点**、つまり「信号のスロープがノイズ レベルを下回る」瞬間を決定することです。

したがって、精度の最終的な上限は **SNR とベースラインの安定性**によって決まり、アルゴリズムはこの上限に近づくことしかできませんが、それを超えることはできません。

**評価スケール (CSE 専門家間協定、2SD)**

|境界 |許容差 |
|---|---|
|発症 | 10.2ミリ秒 |
| P オフセット | 12.7ミリ秒 |
| QRS 発症 | 6.5ミリ秒 |
| QRS オフセット | 11.6ミリ秒 |
| T オフセット | 30.6ミリ秒 |

<a id="2-预处理影响大于算法选择"></a>
## 2. 前処理 (アルゴリズムの選択よりも大きな影響)

<a id="21-基线去除"></a>
### 2.1 ベースラインの削除
- **推奨**: 前のビート T オフセットと現在のビート P オンセットの間にあることが確認された TP のみを使用します。
  等電点は、3 次スプライン ノードとして機能します。 **PQ/PR セグメントには Ta (心房再分極) コンポーネントが含まれているため、デフォルトにしないでください。
  等電位線として。 **
- 高い心拍数により TP セグメントが消失した場合、「測定されたベースライン」があるとは主張されなくなりました。両側で P 個の候補のみが許可されます。
  低次の連続トレンドは部分的に再構築され、低信頼としてマークされ、境界カバレッジを単独でトリガーすることは禁止されています。
- 2 番目の選択肢: ゼロ位相ハイパス (filtfilt)、カットオフ ≤ 0.5 Hz。
- ⚠️ **一方向 IIR クアルコムは避けてください**。 0.5 Hz を超えるクアルコムは、系統的に P オンセットを押し戻し、P 振幅を下げ、各リードのオフセットは一貫します。ロバスト フュージョンは、この **コモン モード エラー**を検出できません。

<a id="22-低通-3040-hz"></a>
### 2.2 ローパス 30 ～ 40 Hz
P 波には 30 Hz 以上の成分はほとんどありません。これをカットすると SNR が大幅に向上し、ゼロ位相を前提としたオンセット位置のずれはほとんどありません。

<a id="23-上采样至-1000-hz"></a>
### 2.3 1000 Hz へのアップサンプリング
純粋な量子化誤差は、元の 250 Hz で 4 ms です。補間後に再区切ると、数ミリ秒を取り戻すことができます。

<a id="24-选择性叠加平均"></a>
### 2.4 選択的重ね合わせ平均化
タスクが許可する場合（ビートごとの分析ではない）、形態に従ってクラスタリングした後、同様の P 波に対して R 波または P ピークのアライメント平均を実行すると、SNR が √N 改善されます。これは SAECG が行っていることであり、低振幅の P 波に対して最もコスト効率の高い方法です。

> 異所性 P と洞 P は最初にクラスター化する必要があり、**形態全体で決して平均化してはなりません**。

<a id="3-单导联确定性定界方法"></a>
## 3. 単一リードの確定的区切り方法

|メソッド |対象ポイント |注意事項 |
|---|---|---|
| **ウェーブレット モードの最大値** (Martínez 2004) |メインメソッド、スケール 2⁴/2⁵、良好なアンチノイズ | Biphasic P (特に V1) は、3 つのテンプレート `+−` / `−+` / `+−+` を明示的に区別する必要があり、「最初の最大値」ルールは使用できません。
| **フェーザー変換** (フェーザー変換) |低振幅の P 波用に特別に設計されており、小さな振幅の変化を大きな位相角の変化にマッピングします。 P ピークの位置決めは優れていますが、境界はしきい値を使用して決定する必要があります。
| **接線法** |シンプルでわかりやすい |単一点導関数は不安定すぎます。代わりに、最大傾斜セクションで **最小二乗フィッティング直線** を実行し、ベースラインと交差すると、安定性が約 1 桁向上します。
| **面積 / 台形法** | P オフセット (低勾配終点) はしきい値法よりも優れています |信頼できるベースライン参照に依存する |
| **曲線長変換/スライディング ウィンドウ絶対微分積分** |グローバル検出機能に適したスムーズな「アクティビティ」エンベロープを生成 |ウィンドウの長さによって時間分解能が決まり、P 波には 20 ～ 30 ミリ秒かかります。
| **ガウス/スキュード ガウス LM フィッティング** |サブサンプリング ポイントの精度、残差は当然信頼度として使用できます。初期値は適切なものである必要があります。ウェーブレットの結果を初期値として使用することをお勧めします。

<a id="31-推荐组合"></a>
### 3.1 推奨される組み合わせ

```
小波模极大值  →  定位 P 峰 + 判定极性模式
      ↓
窄窗内精定界：最小二乘切线法（onset）+ 面积法（offset）
      ↓
高斯拟合交叉校验  →  三者分歧大即判为低置信
```

3 つの方法の故障モードは相互に関連していないため、不一致の程度を信頼水準として使用できます。

### 3.2 等電位ウィンドウ検査 (重要な適応ステップ)

P ピークから前方に検索して、長さ W (15 ～ 20 ミリ秒) の **最後の** ウィンドウを見つけます。これにより、ウィンドウ内の傾きの絶対値と分散が両方ともしきい値を下回ります。

**閾値は定数ではありません** が、そのショットからの T オフセットによって検証される TP セグメントで測定されたノイズ レベルに比例します。
エクスポート (例: 3σ_noise)。 PR/PQ セグメントには Ta が含まれているため、ノイズ ウィンドウとして使用できません。長さが足りない場合
TP セグメントでは、ローカル SNR は使用不可として報告される必要があり、境界はより低い信頼度のフォールバックにのみ設定できます。

<a id="4-无-ml-的置信度构造替代-softmax-的核心"></a>
## 4. ML を使用しない信頼構築 (ソフトマックスのコアを置き換える)

各リードと各ビートは、後続の重み付き融合の使用のために境界不確実性 σᵢ を出力する必要があります。次の方法は、費用対効果の高い順に分類されています。

1. **閾値摂動法 (推奨、コストがほぼゼロ)**
   ウェーブレットしきい値 ξ を 3% ～ 10% の範囲の 5 ～ 7 つの値にわたってスイープすると、一連のオンセット推定値が得られます。
   - 点推定値 = 一連の値の中央値
   - **不確実性 σᵢ = この値セットの分散**

2. **マルチスケールの一貫性**
   23、2⁴、2⁵ の 3 つのスケールで区切られます。スケール間の偏差が大きい → このリードの P 波はノイズによって支配されています。

3. **複数メソッドの一貫性**
   接線法、面積法、フィッティング法の間の乖離の度合い。

4. **ノイズ注入モンテカルロ**
   T offset で検証された TP セグメントの測定ノイズレベルに応じて、同じ色のノイズの重ね合わせを 10 回生成し、再定義します
   分散を取ります。 TP セグメントが存在しない場合、PR セグメントのノイズを偽装することはできません。

5. **残差のフィッティング**
   ガウスフィットの正規化された残差。

6. **ビート間のジッター**
   同じリード内の最新の N 拍開始マーカーの MAD (真の値を必要とせずに信頼性を評価できます)。

σᵢ を使用すると、後続の重み付けされた融合は「ネットワークを使用した場合」とまったく同じになります。重み **wᵢ ∝ 1/σᵢ²** に SNR ゲーティングを乗算します。

<a id="5-多导联全局检测函数"></a>
## 5. 多リードグローバル検出機能

これは、商用 ECG プログラム (マーケット/グラスゴーの種類) では何十年にもわたって標準的な慣行であり、ML にはまったく依存しません。

<a id="51-空间速度函数spatial-velocity-推荐主力"></a>
### 5.1 空間速度関数 - 推奨される主力

$$SV(t)=\sqrt{\sum_{i\in\mathcal{L}} w_i\left(\frac{dx_i}{dt}\right)^2}$$

8 独立リード (または VCG の場合は X/Y/Z) を法とする微分ベクトルを求めます。

**原理**: 心房活性化が始まる瞬間に、**すべてのリード**が同時に電位変化を経験するため、SV は P 開始時に明確に上昇します。一方、各リードの独立したノイズは二乗和の後にインコヒーレントに重畳され、SNR は √L 改善されます。

**判定**: P onset = SV が最初に k・σ_SV (検証された TP セグメント) より長く続いた瞬間。
TP が存在しない場合、この適応閾値の証拠は利用できません。

**実践的なポイント**
- 微分には、単純な差分を使用せずに **Savitzky-Golay** (2 次、25 ～ 35 ミリ秒ウィンドウ) を使用します。そうしないと、ノイズが増幅されます。
- **品質のしきい値を超えるリードのみを含めます**。二乗和に入る悪いリードはバックグラウンドを高めるだけです。
- SV は、CSE ゴールド スタンダードの定義と一致する「世界最古」を示します。これは SVD 投影よりも一貫しています。

<a id="52-svd-空间投影-保留作互补"></a>
### 5.2 SVD 空間投影 - 補完のために予約されています

ショットごとに、SVD は P ウィンドウ内のマルチリード データ マトリックスに対して実行され、最初の特異ベクトル (P リングの主方向) に投影されます。純粋な線形代数演算。

**重要な詳細**
- 投影方向は P ウィンドウ内でのみ推定する必要があります (T または QRS を含むと主方向が汚染されます)。
- **反復する必要があります**: 粗い P ウィンドウ → プロジェクト → 区切り → 狭いウィンドウ → 再投影。通常、収束するまでに 2 ラウンドかかります。
- 利点: 「P 軸が特定のリードに対して垂直であるため、リード P がほぼ等電位になる」という致命的な問題を自動的に回避します。
- 口径に注意してください。投影によって得られる開始は「実際の 3 次元の興奮の開始点」に近く、CSE の定義である「各リードで最も早い」からは系統的に逸脱しています。

<a id="53-两者互补"></a>
### 5.3 2 つは相互に補完します

- **SV**は「変化があったかどうか」を重視
- **投影**は「最大の P エネルギー方向」を強調します。

2 つの結果間の矛盾は、それ自体が貴重な警告サインです。

その他の等価なグローバル関数: 各誘導の絶対導関数の加重和、RMS 合成誘導、VCG ベクトルの大きさ。通常、SV が最もシャープです。

<a id="6-可靠导联判据全部纯-dsp"></a>
## 6. 信頼性の高いリード基準 (すべて純粋な DSP)

|基準 |説明 |
|---|---|
| **P 波ローカル SNR** | P ピーク振幅 / 検証済み TP セグメント ノイズ RMS - **重み主**; TP が消滅した場合は N/A |
|テンプレート相関係数 |現在の P 波と同じリードオンライン重ね合わせテンプレート間の相関係数、< 0.8 重量減少 |
|ベースラインの定常性 | PQ / TP セグメント等電位差、残留傾き |
|形態学的閾値 | P 時間制限 60 ～ 140 ms、振幅 0.03 ～ 0.35 mV、P-QRS 間隔は妥当です。範囲外は直接削除されます。
|ビート間の安定性 |最新の N ビート開始マーカーの MAD |
|一貫性メトリクス |セクション 4 閾値摂動/マルチスケール/マルチメソッド分散 |
|リードロス/飽和/フラットライン |ハード除外 |

<a id="最重要的一条等电位导联判定"></a>
### ⚠️ 最も重要なこと: 等電位リードの決定

特定のリードの P 振幅が < 2σ_noise の場合、「情報なし」としてマークされ、重みは 0 にリセットされ、境界は出力されません。

マルチリード融着におけるほとんどのロールオーバーケースの根本原因は、等電位リード上のノイズが P 波として使用されることです。

<a id="7-稳健融合"></a>
## 7. 堅牢な統合

<a id="71-不要直接取-min-max"></a>
### 7.1 最小値/最大値を直接取得しないでください
CSE の「最も早い開始、最も遅いオフセット」の定義は、単一の不良リードに対して非常に敏感です。

**堅牢な代替方法**: SQI 基準を満たすリードのセット内の注文統計を取得します—
- **2** 最も早い発症 (最も早いわけではない)
- **2** 最新のオフセット (最新ではありません)
- または 15 / 85 パーセンタイルを取得します

<a id="72-加权稳健估计"></a>
### 7.2 重み付けされたロバスト推定
加重中央値、または重み wᵢ ∝ SQIᵢ / σᵢ² を使用した **Huber M 推定値**。

<a id="73-迭代重加权剔除"></a>
### 7.3 反復重み付き消去
```
计算稳健中心
  → 偏离 > 2.5 × MAD 的导联权重置 0
  → 重算
  → 通常 2 轮收敛
```

<a id="74-跨导联一致性硬约束"></a>
### 7.4 クロスリード一貫性のハード制約
同じ心房興奮の場合、各誘導における開始の真の分散は **< 20 ～ 30 ms** である必要があります。

異常値を除去した後も分散が基準を超えている場合 → **出力は「信頼できない」となり、明確な数値を与えないでください**。これは通常、心房粗動、広範囲のアーチファクト、リードの誤接続などの全身的な問題があることを意味します。

<a id="8-拍间时间一致性"></a>
## 8. ビート間の時間の一貫性

- **PR 間隔** および **P 時間** シリーズに対してメディアン フィルタリングまたはスカラー カルマン平滑化を実行します。
- 突然変異が閾値を超えるタグは異常とみなされます。
- **最初にテンプレート相関によるクラスタリング** (洞性 P / 異所性 P)、**クラスタ間では決して滑らかではありません**。

<a id="9-推荐落地流水线"></a>
## 9. 推奨される床から天井までの組立ライン

```
① 预处理
   样条去基线（仅用已验证 TP 等电位点）
   TP 消失 → 连续低阶局部趋势、低置信标记
   + 40 Hz 零相位低通
   + 上采样至 1000 Hz
        ↓
② 参考点检测
   QRS 检测 → T offset 检测
   → 依 RR 自适应给出 P 搜索窗
        ↓
③ 多导联粗定界
   SV 函数 → 全局 P 区间
   + 「P 是否存在」门控（房颤 / 房扑在此拦截）
        ↓
④ 单导联精定界（窄窗下发）
   小波模极大值 + 最小二乘切线法 / 面积法
        ↓
⑤ 置信度评估
   阈值扰动法 → σᵢ
   质量指标   → SQIᵢ
        ↓
⑥ 稳健融合
   加权中位数 + 迭代重加权
   → 全局 P onset / offset
        ↓
⑦ 后处理
   拍间中位数 / Kalman 平滑
   + 跨导联一致性校验
   → 输出边界及置信度（或「不可信」标记）
```

ナロー ウィンドウ配信 (ステップ ③→④) は中核となる設計です。これは、グローバル関数の SNR 配当を取得するだけでなく、誤検出を大幅に削減しながら、単一リードの時間分解能を維持します。

<a id="10-参数标定无训练集情况下"></a>
## 10. パラメーターの調整 (トレーニング セットなし)

既知の真の値を持つシミュレートされた信号を使用して校正します。

1. ECGSYN を使用して、実際の低ノイズ P 波の形態学的テンプレートを生成または作成します。
2. 制御可能な SNR によって **実際のノイズ** を重ね合わせます - MIT-BIH ノイズ ストレス テスト データベースからの `bw` (ベースライン ドリフト) / `ma` (筋電) / `em` (電極運動) 記録。
3. パラメータをスキャンし、誤差の平均値と SD を観察します。
4. 最小の **SD​​* を持つパラメーターを選択し、**固定偏差としての平均値**を差し引きます。
5. LUDB/CSE に関する独立した検証。

> これはトレーニングではなく **キャリブレーション**です。パラメーターは明確な物理的意味 (しきい値比、ウィンドウの長さ、微分次数) を持ついくつかの定数であり、オーバーフィッティングの危険はありません。

## 11. よくある落とし穴

|問題 |対策 |
|---|---|
| **Ta 波は PR/PQ ベースラインを汚染します** | PR/PQ は P ノイズ ウィンドウまたは等電位ノードとしては使用されません。 Ta は低周波の生理学的成分であり、detrend | の後に「低ノイズ」と誤ってラベル付けされてはなりません。
| **心拍数が高く、TP が消失、または P-on-T** |まず、前の拍動の T オフセットに基づいて、まだ観察可能な TP があるかどうかを判断します。 TP を使用しない場合、連続的な低次トレンドのみを使用して信頼性の低い検出ビューが生成され、元の境界が保持され、積極的な最古/最新の融合が無効になります。 T テンプレートの減算はデフォルトではオフです。
| **本当に必要な T/QRST キャンセル** |同型クラスター、ビートごとの ST-T 時間シフトと振幅適応、ローパス検出ビュー、シーム テーパー、および残留高周波アーティファクト ゲートがすべて合格した場合にのみ、セカンド オピニオンとして使用できます。固定 R アライメント テンプレートのポイントバイポイントのハード リダクションは使用できません。心拍数が全体的に高く、P と T が位相ロックで重なっている場合、それらは区別できないため、厳密に分離するのではなく拒否する必要があります。
| **心房細動/心房粗動** |事前に設定された「P 波存在識別」ゲート制御が必要です。それ以外の場合、バウンダは一貫して f 波の誤差範囲を高い信頼度で出力します。
| **フィルター位相オフセット** |ゼロ以外の位相フィルタリングは系統的にオンセットをシフトし、オフセットはリード全体で一貫しており、ロバストな融合によって検出されません。オンラインにする前に、シミュレーション信号を使用してフィルター チェーン全体の固有の偏差を校正します。
| **二相 P(V1)** |モジュラー最大モードは単相とは異なり、3 つのテンプレートを明示的に処理する必要があります。
| **等電位リード** |セクション 6、重みを 0 にリセットするを参照してください。
| **システム偏差と分散** |偏差はキャリブレーションによって差し引くことができます。**SD は実際のスキル**であり、評価中に個別に報告する必要があります。

<a id="13-预期性能与边界"></a>
## 13. 期待されるパフォーマンスと限界

許容可能な信号対雑音比を備えた 12 誘導安静時 ECG では、純粋な DSP ソリューションの境界精度は基本的にディープ モデルの境界精度と同じです。

違いは主に次の点に現れます。
- 強い筋電干渉
- 病理学的形態（心房内ブロック P の断片化、深部二相性反転 P）

この部分は、政府が門管理を強化し、厳しい刑罰を科すよりも判決を拒否することを好むことに依存している。明確な「信頼できない」マークを与えることは、多くの場合、誤った信頼度の高い限界を与えるよりも価値があります。
