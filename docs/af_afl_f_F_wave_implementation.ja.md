# AF/AFL F 波および F 波識別の実装手順

ルールセット: `clinical_rules.v2 / 2026.07.9`

<a id="目标"></a>
## ターゲット

AF/AFL の判断を、単純な RR 異常および P 波の欠落から、監査可能な複数証拠の判断に拡張します。

- 心房細動：不規則なRR、一貫した伝導P波の欠如、広帯域で組織化が不十分な心房細動の`f`波の証拠と組み合わされる。
- 心房粗動: QRST 減算後、一貫した周波数を持つ狭帯域で組織化された心房粗動 `F` 波が複数の独立した誘導で検出されました。
- 不十分な証拠または矛盾する証拠: `atrial_fibrillation_flutter_indeterminate` を出力します。2 つのうちの 1 つを選択することは強制されません。

<a id="信号处理"></a>
## 信号処理

1. 信頼できる I、II、III、V1、および V2 リードでそれぞれ連続リズム QRST テンプレートの減算を実行します。
   QRS は R アライメントを維持します。 ST-T セグメントは、ビートごとの微分相関によって変換され、堅牢なアフィン フィッティングでフィッティングされます。
   現在のビート振幅/オフセット。 QRS→ST-T ハードジョイントを避けるために、インターフェイスとテンプレートウィンドウの両端でコサイン勾配を使用します。
2. テンプレートの相関係数、心拍数、減算後の残留エネルギー、高周波（2次差分）エネルギー比、
   利用可能なリードの数。残留高周波エネルギーが元の波形に対して `1.25` を超えて増幅されている場合、検証は拒否されます。
3. 中央値 RR が `<520 ms` の場合、固定 QRST テンプレート ウィンドウが次の P エリアに侵入する可能性があります。
   P-on-T を見つけるために結果を減算しない限り、連続残差パスの直接ラベル付けは使用できません。
4. 異なる誘導/拍動を結合した後に単一の FFT を実行する代わりに、各誘導の連続心房残差に対してウェルチ PSD を実行します。
5. 220 ～ 400 bpm で F 波の基本周波数を検索し、次のように計算します。
   - 心房帯バックグラウンドに対するピークの比。
   - 基本周波数と高調波電力集中;
   - スペクトルエントロピー;
   - 時間領域の再現性と安定性。
6. F 波マルチリード候補は、少なくとも 2 つのリードと利用可能なリードの少なくとも 40% が ±30 bpm 以内に一致する場合に形成されます。
7. `f` 波は、サポート スコアを形成するために、高いスペクトル エントロピー、低い組織化、および低い時間的再現性を使用します。複数のリードの一致を形成するには、利用可能なリードのサポートの少なくとも 60% が必要です。

<a id="判定策略"></a>
## 決定戦略

|出力 |必要な証拠 |
|---|---|
| `atrial_fibrillation` | RR-CV ≥ 0.15、一貫した P 波がない、または検証された強い F 波が疑似 P シーケンスを拒否する、強い F 波がない |
| `atrial_flutter` |マルチリード F 波一貫性、F 波信頼度 ≥ 0.60。最終的な臨床出力が合格するには、QRST 減算検証も必要です。
| `af_afl_indeterminate` | f/F 証拠の矛盾、RR-CV が 0.12 ～ 0.15 の境界、検証されていない強い f 波と P 波の結果が矛盾、または F 波の信頼度が 0.50 ～ 0.60 |
| `none` |上記の条件を満たしていない |

可変性房室伝導を伴う心房粗動では、RR が不規則になる可能性があるため、証明された強力なマルチリード F 波が RR 不規則よりも優先され、無条件に AF の対象にはなりません。

<a id="输出证据"></a>
## 証拠を出力する

`rhythm_inputs.af_afl` および `metadata.rhythm_analysis` は次のように出力されるようになりました。

- `atrial_rhythm_classification`
- `diagnostic_confidence`
- `probable_af` / `probable_flutter`
- `af_afl_indeterminate` / `indeterminate_reasons`
- `f_wave_confidence` / `f_wave_multilead_consensus`
- `F_wave_confidence` / `F_wave_multilead_consensus`
- `F_wave_rate_bpm`
- `flutter_supporting_leads`
- `fibrillatory_supporting_leads`
- リードごとのスペクトルおよび組織的証拠

`RHYTHM SUMMARY` のテキスト レポートには、分類、RR-CV、P 波比、f/F 信頼度、F 波周波数、サポートリード、QRST 検証ステータスが同時に表示されます。

<a id="验证边界"></a>
## 境界を検証する

これらの修正により、アルゴリズムの解釈可能性と保守性が向上しますが、現在の弱いラベル データのみに基づいて臨床診断の精度を主張することはできません。正式に使用する前に、次のものが必要です。

- 専門家によって項目ごとにレビューされたAF、典型的な心房粗動、非定型心房粗動および騒音制御セット。
- 患者レベルの独立したトレーニング/検証の分割。
- 感度、特異度、陽性的中率、および AF/AFL 混同行列;
- 心房性早発性、心室性期外性、心房性頻脈、ペーシング、筋電図ノイズに特化した負荷テスト。

さらに、拍動ごとの振幅/時間シフト適応は、呼吸と RR の変化によって引き起こされるテンプレートの不一致を軽減することしかできませんが、問題を解決することはできません。
「全てのビートPが同位相でTに埋もれてしまう」という認識できない問題。このシナリオでは残差を出力する必要があります
利用できない/信頼性が低いため、テンプレートの減算は復元された真の P 波と見なされません。
