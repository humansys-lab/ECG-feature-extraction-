# 診断特徴のギャップ登録

`docs/心电图诊断规则系统综述.md` に対する診断レイヤーの整合化を実施する際、**必要な特徴量が不足している**ためスキップされた項目。
各レコード：必要な特徴 → 現状 → 阻害要因。

基準体系は `clinical_rules/sources.py: BASELINE_STANDARD`（AHA/ACCF/HRS 2009 + UDMI 2018）を参照。

---

<a id="一本次实施中直接受影响的缺口"></a>
## 一、今回の実装で直接影響を受けるギャップ

<a id="11-21-房室阻滞文档-174-已探测未发布诊断"></a>
### 1.1 2:1 房室ブロック（ドキュメント 17.4）—— 検出済み、診断未発行

**必要**: QRS に依存しない心房イベントのシーケンス、および「2つのP波に対して1つが伝導される」ことを証明し、T波をP波と誤検出していることを排除できること。

**現状**: `rhythm_rules.detect_pauses_and_av_block` は現在
`two_to_one_conduction_suspected` をセットするが、`av_block_evidence.constant_multiple_atrial_events_requires_validation`
のガードがそれをブロックしている —— **すべての** RR 間隔に2つの心房イベントが含まれている場合、真の2:1伝導とT波の全体的な誤検出を区別できないため、
`second_degree_avb` は `None` のままとなり、診断は発行されない。

**欠落している特徴**:
- `atrial_rate_bpm` の**マルチリード独立検証**（現在の `GlobalFeatures.atrial_rate_bpm` はP波検出が劣化すると心室率にフォールバックする）
- QRST 区間以外のP波検出の信頼度（単なるカウントではなく、各心房イベントごとのconfidence）

**結論**: 一旦スキップ。フラグを証拠（evidence）に含め、手動レビューに供する。

<a id="12-完全性三分支阻滞文档-56-只发-pattern不发诊断"></a>
### 1.2 完全性三枝ブロック（ドキュメント 5.6）—— パターンのみ発行、診断は発行しない

**必要**: 交替性束枝ブロック（同一記録内でRBBBとLBBBが交替する）、またはHV間隔。

**現状**: `CLIN-CONDUCTION-TRIFASCICULAR-01` は「二枝ブロック + PR > 200 ms」の場合のみ
`trifascicular_block_pattern` を発行し、文書内でブロック部位を特定できないことを明記している。

**欠落している特徴**:
- ビートごとの QRS 形態分類結果と束枝型の対応（`grouping.py` にはテンプレートクラスタリングがあるが、テンプレートをRBBB型/LBBB型としてラベリングしていない）
- 10秒の記録では通常、交替を観察するには不十分

**結論**: パターンレベルでは実装済み。完全性三枝ブロックはスキップ。

<a id="13-r-波递增不良的鉴别项文档-81"></a>
### 1.3 R波増高不良の鑑別項目（ドキュメント 8.1）

**必要**: 電極位置のメタデータ（第2–3肋間に貼付されているか）、体型/性別に基づく胸壁減衰の推定。

**現状**: `CLIN-MORPH-RPROG-01` は
`high_precordial_electrode_placement` / `body_habitus` を
`confounders_require_review` に含めるが、自動的に除外することはできない。

**欠落している特徴**:
- 収集メタデータ内の電極位置フィールド（`PatientMeta` にはこのフィールドがない）
- BMI / 胸囲

**結論**: 手動レビューが必要な交絡因子としてリストアップし、自動除外は行わない。

<a id="三非特征缺口但需要决策的条目"></a>
## 三、特徴のギャップではないが、意思決定が必要な項目

- **先天性心疾患（ドキュメント第21章）**: ASD/VSD/PS/TOF/Ebstein/ccTGA の判定基準はすべて既存の特徴量から計算可能
  （V1の形態、電気軸、P波振幅、移行区）、**特徴は不足していない**。未実装は範囲の意思決定によるもので、能力の制限ではない。
- **狭い QRS 頻脈の鑑別（第18章）**: RP' 間隔が必要。150–250 bpm でのP波検出の信頼性は検証されていないため、
  実装するかどうかを決定する前に信頼性評価を行うべき。
- **VT vs SVT 差伝導の形態学（19.0）**: Brugada 4ステップ法に必要な
  `rs_interval_ms`（R起点→S谷）**現在エクスポートされていない**、これは本章で最も重要な単一の欠落量である。

<a id="四100-条实测wfdbrecords01019暴露出的新问题"></a>
## 四、100 条实测（WFDBRecords/01/019）で明らかになった新問題

結果ディレクトリ：`ecgfeat_diagnosis_01_019/`。

<a id="41-lafb-在-99-条中-0-次匹配-需要复核电轴窗口"></a>
### 4.1 LAFB が 99 件中 0 回マッチ —— 電気軸ウィンドウの再検討が必要

- 電気軸 ≤ −45°（現在の LAFB ウィンドウ下限）の記録は**わずか 1 件**であり、形態基準も満たされていなかった；
- しかし、電気軸が −45° ～ −30° の範囲にある記録が **3 件**あり、参照ラベルには 3 件の `Axis left shift` が含まれていた。

ドキュメント 5.4 では「一部の教科書では ≤ −30° を使用」と記載されている。現在のウィンドウは −45°～−90°（AHA/ACCF/HRS の基準）を採用している。
**結論**：これは特徴の欠如ではなく、閾値の基準選択の問題である。LAFB の感度を向上させるには、
`MorphologyThresholds.lafb_axis_max_deg` を −30° まで緩和し、形態基準を厳格化する必要がある
（`S(III) > S(II)`、`R(aVL) > R(I)` を追加するが、これらは現在**未実装**であり、必要な特徴量は既に揃っている）。

<a id="42-双分支阻滞-0-次触发-符合预期非缺陷"></a>
### 4.2 双枝ブロックが 0 回トリガー —— 期待通りであり、欠陥ではない

99 件中 RBBB 系は 7 件マッチ（すべて `probable_rbbb_pattern`）したが、LAFB/LPFB との共現はなかったため、`bifascicular_block_pattern` はトリガーされなかった。ルール自体はユニットテストでカバー済みである。

<a id="43-rs-移行区判定曾产生系统性假阳性已修"></a>
### 4.3 R/S 移行域判定で系統的な偽陽性が発生していた（修正済み）

最初の 100 件中、`counterclockwise_rotation` が 24 回トリガーされた。サンプリング調査で、
JS00956 の R(V1)=0.054 mV と S(V1)=−0.028 mV がともにノイズレベルであるにも関わらず、
`R ≥ |S|` を満たし、V1 移行 → 逆時針回転と判定されたが、実際には
V2 で QS 波を示す**順時針回転 + R 波増高不良**であった。

2 つの制約を追加した（`MorphologyThresholds.transition_min_r_mv` = 0.10 mV
振幅下限 + 移行は次の誘導で維持されること）。再実行後、
逆時針は 24 → 18、順時針は 11 → 13 となり、JS00956 は順時針 + 増高不良として正しく分類された。

**残課題**：振幅下限は経験値であり、低電圧記録に対してキャリブレーションされていない。低電圧記録（全胸誘導 < 1.0 mV）
ではこの下限が高すぎる可能性があり、**該記録の胸誘導電圧スケールに対する適応的下限**が必要である。
必要な特徴量（各誘導の QRS ピークツーピーク値）は既に存在するが、未実装である。

<a id="44-窦性心动过速召回率-110-根因是快心率下的-p-波检出不是阈值"></a>
### 4.4 洞性頻脈の再現率 1/10 —— 根本原因は速心拍下での P 波検出であり、閾値ではない

10 件の参照ラベル `Sinus Tachycardia` の記録のうち、`sinus_tachycardia` を出力したのは 1 件のみ。
各記録の `sinus_mechanism` ルール証拠を確認：

| 記録 | 状態 | organized_p_ratio | P 電気軸 | HR |
|---|---|---:|---:|---:|
| JS00949 | unavailable | 0.11 | — | 111 |
| JS00960 | not_matched | 0.10 | 29.9° | 130 |
| JS00964 | not_matched | 0.53 | 4.6° | 105 |
| JS00966 | not_matched | 0.05 | 34.8° | 138 |
| JS00978 | not_matched | 0.35 | 74.1° | 102 |
| JS00984 | not_matched | 0.12 | 71.3° | 106 |
| JS00990 | not_matched | 0.24 | 94.8° | 104 |
| JS01008 | not_matched | 0.10 | 46.2° | 126 |
| JS01035 | unavailable | **0.88** | **—** | 107 |

**根本原因**：洞性基準は `organized_p_ratio ≥ 0.70` を要求するが、100–140 bpm の条件下では 8/10 件の値が 0.05–0.53 にとどまる。P 電気軸自体は概ね正常（0–75°）である。これはドキュメント 18.1 で述べられている
「速い場合、P 波は前の T 波と融合する可能性がある」状況に該当する —— **これは速心拍下での P 波検出能力の低下であり、閾値が厳しすぎるわけではない**。
0.70 を下げると、偽陽性も同時に許容してしまう。

**欠落している特徴量**：T-P 融合域における P 波の回復能力。必要なのは、
（a）拍ごとの T 波テンプレート減算後の残差で再度 P 波を検出すること（`atrial.py` には QRST テンプレート残差パスがあるが、f/F 波スペクトル解析にのみ使用され、P 波の拍ごとの検出にはフィードバックされていない）、
（b）または RR 間隔に適応する P 検索ウィンドウ。

**別の独立した欠陥**：JS01035 の `organized_p_ratio` は 0.88（P 波検出良好）に達しているが、
`p_axis_deg` が空 → ルールにより unavailable と判定された。P 波検出と P 電気軸計算の間に
可用性の不整合があり、個別に調査が必要である。

## 五、morphological ドキュメントとの整合（2026-07-29 追加実装）

`docs/morphological`（P/QRS-Q/ST/T/QT/U の 6 章 + 12 誘導区分）と照合して項目ごとに確認し、

<a id="51-u-波文档第-6-节-从仅服务于-t-波终点升级为独立诊断特征"></a>
### 5.1 U 波（ドキュメント第 6 章）——「T 波終点のみに従属」から独立診断特徴へ

**現状**：`u_amp_mv` は `max(|signal − baseline|)`（符号なしウィンドウ最大値、ピーク検証なし）であり、
`_clamp_t_end_to_tu_nadir` の「T 波終点を T-U 谷で止めるべきか」の判断にのみ使用されていた。
符号なし ⇒ **逆転 U 波はデータ層で不可視**。

**新規追加**：`feature_extraction/ecgfeat/u_wave.py`、U 波を真の局所極値として再測定：
符号付き振幅、極性、prominence、時間幅、T-U 等電間期、および拍ごとの集約（`features._u_wave_params`、
まず多数決で極性を決定し中央値を取得、極性が同数の場合は報告を拒否）。

**診断ルール**：`clinical_rules/u_wave.py` → `prominent_u_wave` / `inverted_u_wave`。

**実測で明らかになった 3 種類の偽陽性（すべて修正済み）**：

| 偽陽性 | 現象 | 修正 |
|---|---|---|
| 双相性 T 波の終末負性葉が逆転 U 波として読み取られる | LUDB 103：prominence 0.19–0.25 mV、U/T≈1.0 | T-U の間に **≥20 ms の等電段**を要求（「ベースラインにタッチする」だけでなく、持続時間が必要）。双相性 T がゼロを越えてさらに下降 ⇒ 条件を満たさない |
| ベースラインドリフトが逆転 U 波として読み取られる | LUDB 100/132：prominence はわずか 0.028–0.037 mV | 逆転 U は **prominence ≥0.05 mV** でフィルタリング（振幅は拍ベースラインに対する相対値であり、ゆっくりしたドリフトは振幅を容易に得られる） |
| 狭い尖ったノイズパルスが U 波として読み取られる | PTB-XL 11072/11076/11088（ラベルはすべて **NORM**）：U 時間幅はわずか 27–51 ms | **時間幅 ≥60 ms** を要求。U 波は体表心電図で最も遅い波（基底 150–250 ms）であり、振幅/prominence では狭いパルスを遮断できず、時間幅のみが可能 |

修正後、120 件の PTB-XL において `inverted_u_wave` は 3 例（すべて NORM ラベル）から 0 例に減少。

**付随修正**：低カリウム血症ルールは以前、符号なし `u_amp_mv` で `u_amp ≥ 0.05` を判定していたが、
深い逆転U波は「顕著な直立U波」と誤認され、低カリウム判定基準にカウントされる可能性があります。符号付きフィールドに変更済みです。

<a id="52-t-波亚型文档-42-超急性期-t-与巨大阴性-t"></a>
### 5.2 T波サブタイプ（ドキュメント4.2）—— 超急性期T波と巨大陰性T波

`clinical_rules/t_morphology.py`：

- `hyperacute_t_wave_pattern`：**振幅では超急性T波と高カリウムT波（両方とも高振幅）を区別できない**ため、
  「QRSに対する不均衡（T/QRS ≥0.75）+ 基底幅の拡大（≥160 ms）」を主要判定基準とし、
  160–200 msの重なり帯域内では対称性（0.8–1.2を高カリウム様と判定）で裁決します。
  エンジン層には追加の抑制があります：`acute_occlusion_pattern`（ST上昇が既に出現しており、超急性T波は追加情報を持たない）
  または`hyperkalemia_pattern`の発生時に抑制されます。
- `giant_negative_t_wave`：胸電極で≤ −1.0 mV（10 mm）+ 第2電極で≤ −0.5 mVが裏付けとなります。
  **文面は意図的に虚血性深逆転と心尖肥大型心筋症の両方を列挙しています**：PTB-XL 11006がトリガーされた場合、ラベルは
  ISCIL+ISCAS（虚血）となり、深逆転の最も一般的な原因が虚血でありapical HCMではないことを示しています。
  HCMのみを記載すると、読者は稀な診断へ導かれてしまいます。LVHなどの交絡因子は、抑制ではなく`differential_confounders`で並列報告されます。

<a id="53-st-段四型命名文档-34"></a>
### 5.3 STセグメントの4タイプ命名（ドキュメント3.4）

`st_localization.classify_st_pattern`：`j_point_elevation`（J型）/ `slow_upsloping`（SU型）/
`horizontal`（H型）/ `downsloping`（DS型）。**`trend`の改名ではありません**：J型はトレンドを横断します
（J点上昇かつノッチ/ブレイクがあり、その後は平坦または上昇傾向）。これを通常の傾斜型と分離することが、良性早期再分極を
虚血性STセグメント変化と誤読しないための鍵です。下傾型が最優先されます——下傾するSTセグメントは、J点がフック状に似ていようとも早期再分極とは判定されません。
各電極ごとに`leads[*].st.hybrid_robust.pattern_class`へ出力されます。

<a id="54-心房激动起源与多源性文档-12"></a>
### 5.4 心房興奮の起源と多源性（ドキュメント1.2）

`clinical_rules/atrial_rhythm.py`：

- `junctional_rhythm_pattern` / `ectopic_atrial_rhythm_pattern`：下壁電極でのP波逆転 + PR境界
  （<120 msは房室結節性、≥120 msは低位異所性心房性）。**四肢電極の逆接はこの規則の典型的な偽陽性**（逆接もまた下壁P波を逆転させる）であり、
  抑制項目としてリストアップ済みです。洞性機構が確認された場合は全体を抑制——洞性判定基準は多電極P波軸 + organized_p_ratioを使用し、
  本規則の2–3電極の振幅よりも証拠が強力です。
- `multifocal_atrial_rhythm` / `multifocal_atrial_tachycardia`：II誘導のビートごとのP波形態クラスタリング
  （振幅0.06 mV / 時間幅30 msの許容誤差、各クラスタは≥2ビートでノイズが1つの焦点を3つに分割するのを防止）+ PR変動 + RR不規則性。

**実測で露呈した偽陽性**：PTB-XL 11026（ラベル**AFIB**）は、かつてすべての教科書的判定基準を満たしていました。
心房細動こそが真の鑑別対象であり、教科書的判定基準はそれを除外しません——f波は真のP波と同様に「多様な形態」にクラスタリングされます。
したがって、**`organized_p_ratio ≥ 0.60`**という硬性判定基準を追加しました：MATとAFを真に区別するのは「ほぼすべてのQRSの前に離散的なP波が存在する」ことであり、
形態のカウントではありません。追加後、この事例はトリガーされなくなりました。`probable_af`フラグのみを依存するのは不十分です。なぜなら、それは検出漏れを起こす検出器に依存しているからです。

<a id="55-仍未实现-刻意不做"></a>
### 5.5 未実装 / 意図的に未対応

| 項目 | 理由 |
|---|---|
| 右室V4R、後壁V7–V9の直接解析 | 標準12誘導にはこれらの誘導が含まれていない（データソースの制限であり、アルゴリズムの欠陥ではない）；V1–V3のミラーリングパスは既に存在する |
| U波とT波の方向性の「正常性」判定 | 極性データは既に存在するが、正常/異常の境界はまだ定義されていない。実測データがない状態で閾値を設定するのは避ける |

**規則の可用性設計**：追加されたrhythm / ischemiaドメインの規則はすべて`normality_role="supporting"`に設定されています
（`basic_rhythm`における2:1心房粗動スクリーニングの既存の precedents を踏襲）。したがって、データが不足して`unavailable`の場合でも、
**ドメイン全体を未評価に引きずり下ろしたり**、正常な記録を`incomplete`にダウングレードしたりすることはありません。30件の記録を実測検証した結果、
新規則によってドメインが利用不能になった事例は1件もありません。repolarizationドメインは元々`REQUIRED_DOMAINS`に含まれていません。
