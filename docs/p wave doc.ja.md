# マルチリード ECG P 波の限界: コード変更の重要なガイドライン

> 適用範囲: マルチリード P 波のオンセット/オフセットの境界設定は、機械学習を使用せずに決定論的な信号処理によって実現されます。  
> エンジニアリングの目標: 結果の信頼性、解釈可能性、および校正性を確保することを優先し、信号が識別できない場合は信号を明確に拒否します。

---

<a id="1-核心设计"></a>
## 1. コア設計

次の主なプロセスを採用することをお勧めします。

**収集品質チェック → デュアルブランチ前処理 → 心房活動状態の判断 → マルチリードの粗い位置決め → シングルリードの正確な境界設定 → 信頼性評価 → ロバスト融合 → 心拍間検証 **

最も重要な原則は次のとおりです。

1. **最初にマルチリード情報を使用して P 波のおおよその範囲を決定し、次に狭いウィンドウ内でリードごとに正確に位置決めします。 **
2. **等電位または高ノイズのリード線は、境界設定と融合に関与しません。 **
3. **グローバル オンセット/オフセットは「最も早いまたは最も遅い信頼できる境界」であり、すべてのリード境界の平均ではありません。 **
4. **Ta 波は実際の心房再分極活動であり、単純にベースラインまたは除去するノイズとして使用することはできません。 **
5. **高心拍数で TP セグメントが消失した場合、ベースライン推定モードを切り替える必要があります。 **
6. **P-on-T シーンは、固定 T テンプレートを使用したハード サブトラクションによって直接サブトラクションすることはできません。 **
7. **P、T、Ta、またはアーティファクトを確実に区別できない場合、拒否を許可する必要があります。 **

---

<a id="2-输出内容"></a>
## 2. 出力内容

システムはオンセットとオフセットのみを出力すべきではありません。少なくともビートごとに出力:

- 厳密にグローバルなオンセット/オフセット
- オンセット/オフセットの強力なサポート
- オンセット/オフセット信頼区間
- P波の状態
- 有効なリードのリスト
- 各リードの境界、品質スコア、および不確実性
- 現在使用中のベースライン モード
- T波再構成を受けたかどうか
- Ta波の曖昧さはありますか？
- ステータスの承認または拒否
- 拒否の理由

<a id="两套全局边界"></a>
### 2 セットのグローバル境界

|出力 |意味 |使い方 |
|---|---|---|
|厳格なグローバル境界 |厳しい品質管理に合格したリードの中で、最も早いオンセットと最も遅いオフセット |従来のマルチリード測定器に近い |
|堅牢なサポート境界 |複数の比較的独立したリード グループによってサポートされる、最も初期/最新の信頼できる境界線 |エンジニアリングマスター出力 |

2 つの結果セットの差が大きすぎる場合は、信頼水準を下げる必要があります。一般的な原因には、単一リードのアーティファクト、チャネルの非同期、T/Ta 残留物、またはリードの誤接続などが含まれます。

<a id="建议的-p-波状态"></a>
### 推奨される P 波ステータス

- `P_PRESENT`: 安定した P 波が検出されました
- `AF_LIKE`: 安定した P テンプレートがなく、心房細動に近いパフォーマンス
- `ORGANIZED_ATRIAL_ACTIVITY`: 心房粗動または複数の組織化された心房波
- `OVERLAP_UNCERTAIN`: P-on-T、Ta 干渉、または不十分な証拠

<a id="建议的拒判原因"></a>
### 提案される拒否理由

- `BASELINE_UNOBSERVABLE`
- `P_ON_T_UNRESOLVED`
- `P_OFFSET_TA_AMBIGUOUS`
- `INSUFFICIENT_INFORMATIVE_LEADS`
- `CROSS_LEAD_DISAGREEMENT`
- `CHANNEL_DESYNCHRONIZED`
- `LEAD_CONFIGURATION_INVALID`
- `MODEL_DISAGREEMENT`

<a id="3-采集链与通道质量检查"></a>
## 3. 取得チェーンとチャネルの品質検査

このステップは、すべてのフィルタリングと区切りの前に行う必要があります。

<a id="必查项目"></a>
### 必ずご確認ください

- サンプリング レート、タイムスタンプ、データ長は一致していますか?
- 信号の単位とゲインは正しいですか?
- 飽和、平らな線、リードの欠落、または大きなスパイクはありますか?
- 各リードが同期されているかどうか
- 各チャンネルが異なる方法でフィルタリングまたはリサンプリングされるかどうか
- 半分のサンプルポイントまたは固定チャンネル遅延はありますか
- 四肢誘導間の代数的関係は合理的ですか?
- リードの反転、重複チャネル、または異常なゲインがあるかどうか

<a id="修改重点"></a>
### 修正のポイント

- チャネル遅延の推定と補償を追加しました。
- QRS の高傾斜領域を使用して、クロスリードタイム同期を確認します。
- 接続エラー、ゲイン異常、同期外れを検出するための四肢リード関係チェックを追加しました。
- 取得チェーンエラーが検出された場合、マルチリード融合は続行すべきではありません。

<a id="4-双分支预处理"></a>
## 4. 二重分岐前処理

強力なローパス信号の同じセットで、大まかな検出と最終的な細かい境界設定の両方を処理させないでください。

<a id="检测分支"></a>
### ブランチを検出する

用途:

- QRS/T 検出
- P 波の粗い位置決め
- 空間速度の計算
・テンプレート関連
- 心房活動状態の判定

全体的な安定性を向上させるために、より強力なローパスを使用することをお勧めします。

<a id="精定界分支"></a>
### 細かく定義されたブランチ

用途:

- 最終的なオンセット/オフセットの位置決め
- 小さな切り傷や欠けのP検査
- 局所変化点検出
- ブロードバンド結果の相互検証

弱い初期コンポーネントまたは最終コンポーネントの強力なローパス消去を避けるために、広い診断帯域幅を維持することをお勧めします。

<a id="上采样说明"></a>
### アップサンプリングの手順

アップサンプリングにより次のことが可能になります。

- 元のサンプリング ラスターで出力がロックされる問題を軽減します。
- 異なるサンプリングレートでのタイムウィンドウ構成を統一
- 接線交差と連続曲線フィッティングをサポート

ただし、**取得段階で失われた情報を回復することはできません**。

---

<a id="5-基线估计普通模式与无-tp-模式"></a>
## 5. ベースライン推定: 通常モードおよび TP モードなし

<a id="普通模式"></a>
### 通常モード

PQ または TP セグメント内のポイントを無条件に「ゼロ電位ノード」として使用することはできません。以下の条件が同時に満たされる場合にのみ、ベースラインのソフト観測として使用できます。

- 複数のリードのアクティビティが低い
- 局所的な傾斜が低く、微細なエネルギー
- P、QRS、または T アクティビティ ゾーンにいない
・T/Ta残存が少ない
- 複数のリードを同時に変更することはできません

これらの点は、強制ゼロポテンシャルとしてではなく、不確実性のあるソフト制約として使用する必要があります。

<a id="高心率tp-消失模式"></a>
### 高心拍数、TP 消滅モード

TP の消失は、ベースラインが一時的に直接観察されなくなり、拍ごとのフリー スプライン フィッティングを続行できなくなることを意味します。

提案:

- 複数のショットにわたって状態空間ベースライン モデルを使用します。
- 信頼できる低アクティビティのサンプルがある場合は、ベースラインを更新します。
- 信頼できるサンプルがない場合にのみ予測を行ってください。
- 非観測時間が増加するにつれて、ベースラインの不確実性が自動的に増加します。
- 双方向スムージングは​​オフライン処理に使用できます。固定遅延平滑化はオンライン処理に使用できます。

<a id="多导联基线"></a>
### マルチリードベースライン

ベースラインを次のように分割することに優先順位を付けます。

- 呼吸や体の動きなど、複数のリードが共有する部分がゆっくりと変化する
- 各リード独自の遅い残骸

これは、各リードに個別に高自由度スプラインを使用する場合よりも、真の P 波がベースラインに吸収される可能性が低くなります。

<a id="失败处理"></a>
### 障害の処理

信頼できる等電位観測が長期間存在せず、ベースライン、T テール、Ta テール、および P 波を確実に分離できない場合、出力は次のようになります。

`BASELINE_UNOBSERVABLE`

<a id="6-ta-波感知"></a>
## ６．Ta波の知覚

Ta 波は現在の P 波のオフセットに影響を与える可能性があり、ルームレートが高い場合には次の拍動の P オンセット近くまで広がる可能性があります。

<a id="主要风险"></a>
### 主なリスク

- 前の拍の Ta の末尾が、次の拍の P の初期アクティビティと誤認されます。
- 現在の Ta の最初の部分は、P 波をゼロ形状に戻します。
- PQ/TP セグメントは真の等電位ではなくなりました
- エリア法またはベースライン交差法は系統的な偏差を生成します
- 安定した Ta テールが高信頼端末 P と誤判定される

<a id="代码处理原则"></a>
### コード処理の原則

- Ta 波は、制限されたゆっくりと変化する干渉項としてのみ扱われ、ビートごとの完全な再構成は追求されません。
- Ta/T テールを記述するために少数の滑らかな基底関数を使用できるようにします。
- P 波コア領域は、Ta モデルの自由フィッティングを禁止します。
・TaとPの逆極性はソフトティップとしてのみ使用でき、ハードルールとしては使用できません。
- 不確実性への境界変化を考慮して、Ta の強度、幅、位置を摂動させます。

<a id="onset-与-offset-分开处理"></a>
### オンセットとオフセットは個別に処理されます

P onset はゆっくりと変化する背景上でローカルなアクティビティの開始ポイントを見つけることができるため、通常はオフセットよりも安定性を維持するのが簡単です。

P オフセットは Ta の影響を受けやすくなります。 Ta-aware モードに入った後:

- エリアゼロ化方法がダウングレードまたは無効になっている
- 重量を軽減するベースライン交差法
- ファインスケール ウェーブレット、微分アクティビティ、空間方向の連続性の重みを増加します。
・複数の手法が明らかに分岐している場合、高信頼境界は出力されません。

端子 P と初期 Ta を区別できない場合、出力は次のようになります。

`P_OFFSET_TA_AMBIGUOUS`

<a id="7-p-on-t受约束的-t-波重建"></a>
## 7. P-on-T: 拘束された T 波再構成

<a id="禁止固定模板直接硬相减"></a>
### 固定テンプレートの直接ハード減算を無効にする

直接減算の主な問題は次のとおりです。

- T 波の振幅はビートごとに変化し、明らかな低周波残留物が残ります。
- T 波はわずかに時間的にずれており、鋭い微分形状の残基を生成します。
- 長方形のウィンドウが開始および停止すると、エッジの不連続性や広帯域アーチファクトが発生します。
- 固定 PR リズムの下では、P 波を T/QRST テンプレートに書き込み、一緒に減算することができます。

<a id="推荐方式"></a>
### 推奨される方法

「テンプレート減算」を「制約付きマルチリード T 波再構成」に変更します。

- P 候補領域は T 波パラメータ推定に参加しません
- 現在録音されている同様のビートからの T テンプレート
- テンプレートは、QRS/T 形態、RR、呼吸位相、空間方向によってフィルタリングされます。
- 限られた振幅スケーリング、時間シフト、わずかな伸縮、空間調整のみが可能
- 制約のないタイムワーピングを無効にする
- 再構成結果は滑らかで連続的なものでなければなりません
- 長方形ウィンドウのハードスプライシングを禁止します。

<a id="三分支交叉验证"></a>
### 3 ブランチ相互検証

同時に 3 つのブランチを維持します。

1. **オリジナルのブロードバンド ブランチ**: 減算は行わず、ゆっくりと変化する背景のみを処理します。
2. **T 波再構成ブランチ**: 制約付き再構成後の残差信号を使用します。
3. **T 空間部分空間抑制ブランチ**: マルチリード空間方向からの T 波を抑制します。

判定ルール：

- 3 つのブランチで一貫した結果が得られ、信頼性が向上します
- 結果の乖離が小さい: 信頼区間を拡大する
- 結果は明らかに異なります: 出力 `P_ON_T_UNRESOLVED`

<a id="t-重建失败检查"></a>
### T リビルド失敗チェック

必ず確認してください:

- 再構築領域の端に新しいピークが現れるかどうか
- P を含まない T 領域残差は実際に減少しますか?
- 類似したテンプレートを置き換えた後、境界は安定していますか?
- 既知の P 波パターンが再構成後に減衰するかどうか
- 元の広帯域信号ではまったくサポートされていない新しい境界を生成するかどうか
- 新しい境界が複数の独立したリードグループによってサポートされているかどうか

<a id="8-多导联粗定位"></a>
## 8. マルチリードの粗位置決め

<a id="主方法白化空间活动度"></a>
### 主な方法: 空間アクティビティを白くする

通常のマルチリード二乗和は、各リードのノイズが独立しており、分散が近いことを前提としていますが、これは通常、実際には当てはまりません。

まず、低アクティビティ領域に基づいてマルチリードノイズの共分散を推定し、次に白色化された空間アクティビティを計算して以下を削減することをお勧めします。

- 単一のノイズの多いリード
- リード間のコモンモードアーティファクト
- 四肢リードの冗長化
- 異なるリードにおけるノイズ振幅の違い

しきい値は、まず低アクティビティ領域の経験的分布から取得され、高値と低値の二重しきい値が使用されます。

- 高い閾値は活動の存在を確認します
- 真の開始点または終了点にバックトラックするための低いしきい値
- 単一点のノイズトリガーを回避するために、アクティビティを一定期間継続する必要があります

<a id="svd-互补分支"></a>
### SVD 補完ブランチ

常に最初の主成分のみを使用するとは限りません。

提案:

- 最初にノイズレベルによって白色化します
- リードの質によって再度重み付け
- 1番目と2番目の空間成分が近い場合、2次元の部分空間が保持されます
- 空間方向が不安定な場合、不確実性が増加します
- 誤った初期ウィンドウの自己強化を防ぐために、多くても少数の反復を実行します。

SVD の結果は、好ましい体表面の空間投影としてのみ解釈でき、解剖学的活性化の起点としては解釈できません。

<a id="9-单导联精定界"></a>
## 9. 単一リードの正確な境界設定

単一の方法で最終的な境界を独立して決定することはできません。

<a id="onset-主证据"></a>
### 発症マスター証拠

- マルチスケールウェーブレット
- ローカル変更点
- 最小二乗接線
- ブロードバンドと検出ブランチの一貫性

<a id="offset-主证据"></a>
### 主な証拠を相殺する

- マルチスケール ウェーブレット アクティビティが消える
- 派生活動の削除
- 条件付きエリア法
- 制約付き曲線フィッティング
- Taを意識した結果

<a id="关键修改"></a>
### 主な変更点

- 二相および三相 P 波、特に V1 は明示的に処理する必要があります。
- 「最初の極値が開始する」などの固定ルールは使用しないでください。
- 接線法では、単一点導関数の使用を避けるために、最大勾配に近い小さなセクションで直線フィッティングを実行する必要があります。
- エリア法は、ベースラインが信頼でき、明らかな Ta がなく、重大な P-on-T がない場合にのみ有効になります。
- カーブ フィッティングは主にサブサンプリング推定と相互検証に使用され、すべての複雑なパターンを強制的に説明することはできません。
- 複数のスケールまたは複数の方法の不一致を不確実性の計算に入力する必要があります。

<a id="10-导联可靠性"></a>
## 10. リードの信頼性

<a id="硬排除"></a>
### ハード除外

- フラットライン
- 飽和した
- 鉛の損失
- 大きなスパイク
- 深刻な同期のずれ
- 明らかなゲイン異常
- リード設定エラー

<a id="软质量指标"></a>
### ソフト品質指標

- P 波のローカル信号対雑音比
- P波ローカルエネルギー
- 派生エネルギー
- このレコードテンプレートとの関連性
- ベースラインの安定性
- マルチスケールの一貫性
- 複数のメソッドの一貫性
- 閾値摂動の安定性
- ビート境界ジッター
- T 再構成感度
- Taモデルの感度

<a id="等电位导联"></a>
### 等電位リード線

単一のピークだけを見ることはできません。以下を共同で確認する必要があります。

- ピークは重要ですか?
- 総エネルギーは重要ですか?
- 微分エネルギーは重要ですか?
- 安定したテンプレート構造があるかどうか
- 複数の規模にわたって一貫した活動があるか?

複数の証拠が有効な P 情報がないことを示している場合:

- 情報のない見込み客としてマークする
- オンセット/オフセット ウェイトをゼロにリセット
- このリード境界を出力しません

<a id="生理范围"></a>
### 生理学的範囲

一般的な範囲外の P 波の持続時間または振幅は実際の病状である可能性があり、簡単に無視すべきではありません。

- 取得失敗: ハードトラブルシューティング
- 生理的範囲の交差: ソフトな罰
- 病理学的形態: 残ることは許されるが、不確実性が増大する

<a id="11-不确定度与置信区间"></a>
## 11. 不確実性と信頼区間

閾値の摂動は不安定性の一部のみを反映しており、真の信頼度を単独で表すことはできません。

不確実性は少なくとも以下をカバーする必要があります。

- 高周波ランダムノイズ
- ベースライン推定誤差
- ウェーブレット スケールとしきい値の変更
- 微分ウィンドウの変更
- 区切り方法の違いによる違い
-T テンプレートの選択と再構築パラメータの変更
-Taモデルチェンジ
- ビート間のジッター

<a id="实现要点"></a>
### 実装のポイント

- 関連するパラメータに小規模で合理的な妨害を加え、境界設定を繰り返します。
- ノイズのリサンプリングでは、時間相関と相互誘導相関を保存する必要があります。
- 無限の重みを避けるために、各リードに最小の不確かさを設定します。
- 単一のパスが融合を支配するのを避けるために、単一のリードとリード グループの最大重みを設定します。
- 単なる抽象的な品質スコアではなく、最終出力の信頼区間。

<a id="校准检查"></a>
### 校正チェック

検証セットを確認します。

- 名目信頼区間が対応する実際の適用範囲に達しているかどうか
- 信頼区間が広い場合、一般に真の誤差は大きくなりますか?
- 信頼性の低いサンプルが拒否された後、受け入れられた結果が大幅に改善されたかどうか

---

<a id="12-单侧稳健融合"></a>
## 12. 一方的なロバストな融合

すべての誘導の加重中央値は、開始を遅らせてオフセットを進める傾向があり、それによって P 波の持続時間が短くなる傾向があるため、最終的なグローバル境界としては適していません。

<a id="onset-融合"></a>
### オンセットフュージョン

- リードの開始を時間順に並べ替える
- 限られた時間範囲内で候補時間クラスターを形成する
- 少なくとも 2 つの比較的独立したリード グループからのサポートが必要
- 信頼できる重みのしきい値に達する最も早い時間クラスターを選択します
- クラスター内で初期の加重位置を取得します

<a id="offset-融合"></a>
### オフセットフュージョン

- 同じ原理を使用して、信頼できる最新のタイム クラスターを見つけます。
- クラスター内で後で重み付けされた位置を取得します

<a id="导联分组"></a>
### リードのグループ化

少なくとも以下を区別してください:

- 四肢リードグループ
- 右前胸部リードグループ
- 左前胸部リードグループ

関連するノイズが繰り返しカウントされるのを防ぐために、各グループの重みに上限を設定します。

<a id="拒判条件"></a>
### 拒否の条件

明らかな外れ値のリードを排除した後でも、境界が依然として高度に分散している場合、出力は次のようになります。

`CROSS_LEAD_DISAGREEMENT`

---

<a id="13-拍间一致性"></a>
## 13. ビートごとの一貫性

ビート スムージングまたは重ね合わせは、同じ形態クラスター内でのみ実行できます。

分離する必要があるフォームには、少なくとも次のものが含まれます。

- 副鼻腔P
- 心房期外収縮
- レトログラードP
- その他の安定した異所性 P

異形態クラスターは禁止されています。

- 積み上げ平均
- PR間隔の平滑化
- P 制限時間の平滑化
- 境界カルマン平滑化

突然変異は、まず形態またはリズム パターンの切り替えチェックをトリガーする必要があり、直接平滑化するべきではありません。

<a id="17-验收指标"></a>
## 17. 受け入れインジケーター

平均誤差と標準偏差に加えて、少なくとも次の情報を報告します。

- 中央絶対誤差
- 95% 分位絶対誤差
- 検出率
-拒否率
- P リズムでの偽陽性率なし
- 信号対雑音比、心拍数、形態、重複によって階層化されたエラー
- Ta-awareモードでのオフセットエラー
- 信頼区間の実際の範囲
- 厳密な境界とロバストな境界の違い
- 有効なリードの数と有効なリード グループの数
- 遅延と最悪の場合の稼働時間のオンライン処理

「受け入れ率と誤差」の関係を観察することに重点を置きます。

> 拒否閾値が厳しくなるにつれて、受け入れられた結果の誤差は着実に減少するかどうか。

これは、すべてのサンプルにわたる平均誤差を単に報告するよりも、システムの実際の信頼性をよりよく反映します。

## 18. パラメータの凍結と外部検証

- 開発およびパラメータ選択のためのシミュレーションとデータベース

- 統計的信頼区間は、個々のショットごとに個別にサンプリングされるのではなく、レコードごとにサンプリングされます。

- リードゲイン、リバース接続、チャンネル遅延

<a id="19-最终工程原则"></a>
## 19. 最終的なエンジニアリング原則

1. **アップサンプリングはラスター効果を軽減するために使用され、元の情報を復元することを意味するものではありません。 **
2. ** より強力なローパスが検出に適しており、最終的な境界はより広い帯域幅の分岐によって確認される必要があります。 **
3. **グローバル境界は片側の信頼できる境界であり、リード結果の中心値ではありません。 **
4. **Ta 波は実際の心房活動に属しており、ベースラインとして直接削除することはできません。 **
5. **TP の消失は、ベースラインの可観測性が低下することを意味します。 **
6. **固定 PR リズムの下では、マスクされていない QRST テンプレートはターゲット P 波を一緒に除去する可能性があります。 **
7. **T 波処理の目的は、P 境界を安定に保つことであり、最もきれいな残差を追求することではありません。 **
8. **情報のないリードは境界を出力したり、融合に参加したりしてはなりません。 **
9. **ベースライン、T 再構成、Ta の曖昧さは不確実性の中に入れる必要があります。 **
10. **判定を識別できない場合は、判定を明示的に拒否します。これは、間違っているが信頼性の高い結果を出力するよりも優れています。 **
