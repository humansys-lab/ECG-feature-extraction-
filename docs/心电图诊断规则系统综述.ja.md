<a id="第-0-章-基础事项判读前必须掌握"></a>
# 第0章 基本事項（通訳前に必ず習得してください）

<a id="01-心电图的原理"></a>
## 0.1 心電図の原理

- 心筋の脱分極/再分極によって生成される電位差は、体表面電極を介して電圧-時間曲線として記録されます。
- **コアルール**: 脱分極波**は特定のリードの正極に向かって**移動します → リードは**上向き(正)**の波を記録します。 **ポジティブ→**下向き(ネガティブ)**の波から遠ざかります。リード軸に対して**垂直** → 双方向または等電位。
- 正常な心室の再分極の方向は脱分極の方向と**反対**であるため (心外膜が最初に再分極します)、通常の T 波は QRS 主波と **同じ方向**になります。
- 心電図は、各リード軸上の瞬時積分ベクトル (合成ベクトル) の投影を反映します。

<a id="02-心电计的操作与记录条件"></a>
## 0.2 心電計の動作および記録条件

|アイテム |基準値 |説明 |
|---|---|---|
|紙送り速度 | **25 mm/秒** | 1 つの小さなグリッド (1 mm) = **0.04 秒**; 1 つの大きなグリッド (5 mm) = **0.20 秒** |
|ゲイン(基準電圧) | **10 mm/mV** | 1 分割 = 0.1 mV;スケールされた方形波の高さ 10 mm |
|低周波遮断(時定数) | ≥ 3.2 秒 (0.05 Hz) |短すぎると誤った ST オフセットが発生します。
|高周波カットオフ | 100 ～ 150 Hz (成人 ≥150 Hz) |低すぎると R 波が減少し、ノッチが隠れてしまいます。
| ACフィルタリング（Hzフィルタリング） |使用しないようにしてください | QRS を変形させ、デルタ波と J 波をカバーします。

**最初に記録条件を確認する必要があります**: 紙が 50 mm/s で移動する場合、読み取り値は常に ÷2 である必要があります。ゲインが 5 mm/mV (標準の半分) の場合、電圧は ×2 必要です。 **「LV 高電圧」と「低電圧」の誤判定の多くは、未確認の校正に起因しています。 **

<a id="电极位置必须记忆"></a>
### 電極の位置 (必ず記憶してください)

- **四肢リード**: 右手首 (赤)、左手首 (黄)、左足首 (緑)、右足首 (黒、接地)
- **チェストリード**:
  - V1: 胸骨の右側の第 4 肋間腔
  - V2: 胸骨の左側の第 4 肋間腔
  - V3: V2 と V4 を結ぶ線の中点
  - V4: 左鎖骨中央線の第 5 肋間
  - V5: V4 レベル、前腋窩線
  - V6: V4 レベル、腋窩中央線
  - **V7–V9** (後壁): V6 レベルの後腋窩線/肩甲下線/傍脊柱線
  - **V3R–V6R** (右心室): V3–V6 の右胸の対称位置 (V4R が最も一般的に使用されます)

<a id="03-波形名称与测量法"></a>
## 0.3 波形名と測定方法

|ウェーブ/インターバル |定義 |反射 |
|---|---|---|
| **P ウェーブ** |心房脱分極 |前半 = 右心房、後半 = 左心房 |
| **PQ (PR) 間隔** | P 始点 → QRS 始点 |房室伝導時間 (心房内、AVN、ヒス・プルキンエを含む) |
| **QRS グループ** |心室脱分極 |心室内伝導 |
| **J ポイント** | QRS 終点 = ST 始点 | STオフセット測定基準点 |
| **ST セグメント** | J点→T波原点 |初期の心室再分極 (プラトー相) |
| **T 波** |心室再分極 | |
| **QT 間隔** | QRS 開始 → T 波終了 |総心室電気活動時間 |
| **U 波** | T | 後のウェーブレットプルキンエ線維・乳頭筋再分極（理論は未定） | プルキンエ線維・乳頭筋再分極

<a id="测量要点"></a>
### 測定箇所

- **ベースライン (等電位線)**: **TP セグメント** に基づきます (頻脈では PR セグメントを使用します)。
- **ST オフセット測定ポイント**: J ポイントから **0.06 ～ 0.08 秒** (日本の教科書では主に J ポイントから 0.08 秒が使用されています。ST 上昇の診断は **J ポイント**で測定されます)。
- **QT エンドポイント**: T 波の下降枝の接線とベースラインの交点 (接線法)。 U 波がある場合、U 波は含まれません。 T-U が融合すると、T 谷と U 谷が取られます。
- **リード II または V5 の QT 間隔のいずれか長い方**。
- **心拍数の計算**:
  - ルール: `HR = 300 ÷ (RR 大格数)` または `1500 ÷ (RR 小格数)`
  - 不規則（心房細動など）：**6秒以内にカウント（30分割） QRSカウント×10**
- **QT 修正 (QTc)**:
  - Bazett: `QTc = QT / √RR(s)` - 最も一般的に使用されますが、心拍数が速すぎる/遅すぎると誤差が大きくなります
  - Fridericia: `QTc = QT / RR^(1/3)` - 頻脈における信頼性が向上

<a id="04-qrs-波形的命名规则"></a>
## 0.4 QRS 波形の命名規則

- **Q 波**: QRS の **最初の下降**波であり、その前に上昇波はありません
- **R 波**: **任意の上向き** 波 (2 番目の上向き波は R' としてマークされます)
- **S 波**: R 波** の後の下降**波
- **QS 波**: QRS グループ全体**には下降波が 1 つだけあります**
- **ケース**: 振幅 **≥ 5 mm (0.5 mV) には大文字** (Q、R、S) を使用し、**< 5 mm には小文字** (q、r、s) を使用します。

例：`rSr'`（V1の不完全右脚ブロックタイプ）、`qR`、`RS`、`QS`、`rsR'`（Mタイプ）

<a id="05-各导联的观察方向定位诊断的根本"></a>
## 0.5 各リードの「観察方向」（位置決め診断の基礎）

|リードグループ |観察サイト |冠動脈に対応 |
|---|---|---|
| **II、III、aVF** | **下壁 (隔膜面)** | RCA (ほとんど)/LCX |
| **私、aVL** | **ハイサイドウォール** | LCX または LAD 斜め分岐 |
| **V1、V2** | **前中隔壁 (心室中隔)**、これも右心室方向 | LAD近位中隔枝 |
| **V3、V4** | **正面壁** |ラッド |
| **V5、V6** | **側壁 (左心室下外側壁)** | LCX/LAD 遠位 |
| **V1 ～ V6 すべて** | **広範な前壁** | LAD近位 |
| **V7 ～ V9** | **後壁 (前壁)** | LCX/RCA |
| **V3R–V6R (V4R)** | **右心室** | RCA近位 |
| **aVR** |右上/心臓内 |隆起は左主管疾患または三枝疾患を示します。

**「隣接リード」の定義** (MI の診断には「隣接リード 2 つ以上」が必要):
`V1-V2-V3-V4-V5-V6` は順番に隣接しています。 `aVL-I-(-aVR)-II-aVF-III` が順番に隣接しています。

<a id="06-平均电轴qrs-电轴"></a>
## 0.6平均電動軸(QRS電動軸)

**検索方法（視覚的方法）**:
1. 四肢誘導の中で QRS 代数和が 0 に最も近い誘導を見つける → 電気軸は誘導軸に対して **垂直**
2. 垂直リードの主波方向を見る→垂直方向のどちら側かを判断する
3. 簡易判定：**I、aVFともに陽性→0°～+90°(正常)**

|電気軸 |範囲 |一般的な原因 |
|---|---|---|
|通常 | **−30°～+90°** (ルーズ -30°～+110°) | |
| **左偏差** | −30°〜−90° |左前筋膜ブロック、下壁MI、LVH、横性心筋症、肥満、妊娠 |
| **右偏差** | +110°～+180° | RVH、左後筋膜ブロック、側方MI、垂直心臓、COPD、肺塞栓症 |
| **不確実な軸 (北西軸)** | −90°〜±180° |重度の心臓病、心室頻拍、高カリウム血症、右心症、電極の誤接続 |

<a id="07-术语约定"></a>
## 0.7 用語規則

- **「性別」と「類似」**: 形態学的記述では、「RBBB タイプ」などの「...パターン」が使用されますが、これは真のバンドル分岐ブロックを意味しません。
- **主な ST-T の変化**: QRS は正常、ST-T 自体は異常 (虚血、電解質、薬物)。
- **二次的な ST-T 変化**: QRS の異常 (束枝ブロック、肥大、前興奮、ペーシング) により「偶発的に」発生する ST-T 変化。
- **「疑い/示唆/一貫性」**: ECG 診断は、ほとんどが **確率的** 表現です。いくつかの例外（心房細動、完全な AVB、前興奮など）を除いて、病理学的診断を主張することは適切ではありません。

# 第 1 章 通常の心電図と解釈シーケンス

<a id="10-判读的固定顺序务必按此顺序防漏诊"></a>
## 1.0 解釈の順序を固定 (診断の見逃しを防ぐために、この順序に従う必要があります)

1. **記録条件の確認**（紙送り速度、ゲイン、アーティファクトの有無、電極の接続間違いの有無）
2. **リズム** - 副鼻腔炎ですか?ルールがあるかどうか？
3. **心拍数（レート）**
4. **P 波** - 存在、形状、サイズ、各 P の後に QRS が続くかどうか
5. **PQ 間隔**
6. **QRS**: 制限時間 → 電気軸 → 振幅 → 異常の有無 Q → 胸部伝導 R 波増加
7. **ST セグメント**: 上昇 / 低下 / パターン
8. **T 波**: 方向、振幅、対称性
9. **QT 間隔 (QTc)**
10. **U ウェーブ**
11. **以前の心電図との比較** (最も重要なステップ!)

<a id="11-节律心率p-波pq"></a>
## 1.1 リズム、心拍数、P 波、PQ

<a id="窦性心律的诊断标准4-条全部满足"></a>
### 洞調律の診断基準 (4 つの基準がすべて満たされている)

1. II、III、aVF では **P 波は正立**、**aVR は反転**
2. 各 P 波の後に QRS (PQ 定数、0.12 ～ 0.20 秒)
3. **PP 間隔ルール** (洞性不整脈の場合は < 0.16 s；> を 0.16 秒変更します)
4. 頻度 **50/60 ～ 100 回/分**

<a id="正常-p-波"></a>
### 通常の P 波

|プロジェクト |正常値 |最も観察されたリード |
|---|---|---|
|制限時間 | **< 0.12 秒 (< 3 セル)** | Ⅱ |
|振幅 | **< 0.25 mV (< 2.5 mm)** | II、III、aVF |
|形態学 |丸くて鈍い単一のピーク。 V1 は正と負の二相性にすることができます。 II、V1 |
| V1端子マイナス部(Ptf) |面積 > -0.04 mm·s (つまり、深さ <1 mm または幅 <0.04 秒) | V1 |

<a id="正常-pqpr间期"></a>
### 通常の PQ (PR) 間隔

- **0.12 – 0.20 秒** (小児/頻脈ではわずかに短く、高齢者/徐脈では最大 0.21 秒)
- 測定は最長の PQ** (II または V1) から取得する必要があります。

<a id="12-qrs-群的检查点"></a>
## 1.2 QRS グループのチェックポイント

|プロジェクト |通常の標準 |
|---|---|
| **制限時間** | **< 0.10 秒** (0.10 ～ 0.11 秒は軽度の伸長、**≧ 0.12 秒は幅広の伸長 QRS**) |
| **電気軸** | −30°〜＋90° |
| **通常の q 波 (間隔 q)** | I、aVL、V5、V6 は小さな q を持つ可能性があります: **同じリード内の R 波の幅 < 0.04 秒、深さ < 1/4** |
| **aVR** |通常はQSまたはrS（主波下向き） |
| **V1** | Normal は QS または rS です。 **V1 には q 波があり、異常です** |
| **胸部伝導 R 波が増加します** | V1→V5は徐々に増加します。 **V1 の R < S**，**V6 的 R > S** |
| **移行ゾーン (R=S)** | **V3 – V4** (V2 または右 = 反時計回りのトランスポーズ、V5 または左 = 時計回りのトランスポーズ) |
| **心室活動時間 VAT (古典的蛇行)** | V5、V6 **< 0.05 秒**; V1、V2 **< 0.03 s** |
| **振幅 (低すぎない)** |少なくとも 1 つの四肢リード ≥ 0.5 mV、少なくとも 1 つの胸部リード ≥ 1.0 mV |

<a id="13-st-段的检查点"></a>
## 1.3 STセグメントのチェックポイント

- 通常の ST セグメントはベースライン (TP セグメント) と **面一**であり、**滑らかな上向き凹型**の曲線です。
- 許容範囲:
  - **上昇**: 四肢誘導 **< 0.1 mV**; V1～V3 **< 0.2 mV (男性 40 歳以上) / < 0.25 mV (男性 <40 歳) / < 0.15 mV (女性) **
  - **うつ病**: **< 0.05 mV** (任意のリード線)
- **早期再分極 (正常変異)**: J 波 (ノッチ/挫傷) を伴う J ポイントの上昇、ST は **優れた凹面**を示し、T 波はそびえ立ち、直立しており、V2 ～ V5 および下壁、若い男性、運動選手によく見られます。 **重要なのは、凹面形態 + 動的進化がない + 対応するリードの落ち込みがないことです**。

<a id="14-t-波的检查点"></a>
## 1.4 T 波チェックポイント

- 方向: **QRS メインウェーブと同じ方向**
  - I、II、V3–V6: **直立**
  - aVR: **反転**
  - III、aVL、V1、V2: **反転可能 (通常のバリエーション)**; V1 反転は特に女性によく見られます
- 形状: **非対称** (上昇肢は遅く、下降肢は急です)
- 振幅: 四肢誘導 < 0.5 mV、胸部誘導 < 1.0 ～ 1.5 mV。通常、同じリードの R 波の **≥ 1/10** (低すぎると、T 波が低く平坦であることを意味します)
- **持続性若年性 T**: 若い女性における V1-V3 T 逆位、正常変動

<a id="15-qt-间期与-u-波"></a>
## 1.5 QT間隔とU波

|プロジェクト |正常値 |
|---|---|
| **QTc (バゼット)** |男性 **≤ 0.44 s**、女性 **≤ 0.46 s** (≧0.48 秒は確実に延長、≤0.34 ～ 0.36 秒は短縮) |
| **簡易判断** | **QT < RR の半分** (心拍数が 60 ～ 100 の場合に適用) |
| **U 波** | T と同じ方向 (直立)、振幅 **< 1/2** T 波** (通常 < 0.1 ～ 0.2 mV)、V2 ～ V3 が最も顕著です。

**U 波反転はどのリードでも異常です** (aVR を除く)。

<a id="第-2-章-p-qrs-关系异常基本节律异常非心动过速"></a>
# 第2章 P-QRS 異常な関係：基本リズムの異常（非頻脈）

> **エントリ ポイント**: 通常の P 波が見つからないか、P が QRS に対応しません。

<a id="21-心房颤动af-af"></a>
## 2.1 心房細動〈AF / Af〉

|診断要素 |具体的な基準 |最適なリード |
|---|---|---|
| **P 波が消える** | **薄い微動 f 波**、周波数 **350 ～ 600 拍/分**、不規則な振幅形状に置き換えられます。 **V1** (f 波が最も鮮明)、II |
| **RR 間隔は完全に不規則です** |規則性がない (「まったく不規則」) |任意 |
| **QRS 形態** |通常は正常（狭い）。バンドル分岐ブロックまたは差動伝導で拡張 | |

**追加解釈**:
- **心室心拍数分類**: < 50 次/分＝慢心室率型（提示 AVN 传导障碍或药物过量）；50–100＝控制良好；> 100 = 心室心拍数が速いタイプ
- **粗い AF**: f 波 ≥ 0.1 mV、僧帽弁狭窄症および重大な左心房拡大によく見られます。
- **アッシュマン現象**: 長い RR の後の短い RR が広く QRS (主に RBBB タイプ) として表示されます。これは PVC ではなく **差動伝導**です
- **AF + 通常の遅い心室心拍数** → **AF と組み合わせた完全な房室ブロック** (重要! 診断を見逃さないでください)
- **AF + 規則的な急速な心室心拍数 (>100、規則的)** → 接合部頻脈 / ジギタリス中毒
- **AF + 非常に高速 (>200) 不規則ワイド QRS** → **AF による事前励起 (擬似 VT)**、ジギタリス/ベラパミルは無効

<a id="22-心房扑动afl"></a>
## 2.2 心房粗動〈AFL〉

|診断要素 |具体的な基準 |最適なリード |
|---|---|---|
| **F 波 (ノコギリ波)** |頻度 **250 ～ 350 回/分** (通常 ~300) | **II、III、aVF** (典型的な負の鋸歯状)、**V1** (正の正立 P 状) |
| **等電位線なし** | F 波は連続波であり、ベースラインは連続波です。 II、III、aVF |
| **房室伝導率** | 2:1 (心室心拍数 ~150)、3:1 (~100)、4:1 (~75)。比率が固定されている場合は RR ルール、固定されていない場合は不規則になります。 |
| **QRS** |通常狭い | |

**重要なポイント**:
- **150 拍/分付近の一定の心室拍数に対する狭い規則 QRS 頻脈 → 最初の 2:1 AFL を疑う** (QRS と T に隠れる F 波)
- 曝露方法：頸動脈洞マッサージまたはアデノシン→房室伝導率の増加、F波曝露
- **通常 (共通/反時計回り)**: II/III/aVF マイナスのこぎり波、V1 プラス
- **非定型 (逆定型)**: II/III/aVF 陽性、V1 陰性

<a id="23-房室交界区节律-加速性交界区节律"></a>
## 2.3 房室接合部調律/加速接合調律

|タイプ |周波数 |定義 |
|---|---|---|
| **ジャンクションエスケープリズム** | **40 ～ 60 ビート/分** |洞結節不全または房室ブロックにおける受動的逃避拍動 |
| **加速された接合リズム** | **60 ～ 100 拍/分** |接合部の自動性の増加（指中毒、下壁MI、心筋炎、心臓手術） |
| **結合性頻脈** | > 100 拍/分 | |

**診断要素**:
1. **QRS ナロー** (バンドル分岐ブロックと組み合わせない場合)
2. **P 波逆行**: **II、III、aVF 倒立**、**aVR 正立**
3. P と QRS の位置関係 (逆方向送信と順方向送信の相対速度によって決まります):
   - **QRS** 前の P: PR **< 0.12 s** (「上部ジャンクション ゾーン」)
   - **QRS** に埋め込まれた P: P が見えません (最も一般的)
   - **QRS** 後の P: RP **< 0.20 s** (「下部ジャンクション ゾーン」)
4. RR間隔ルール

<a id="24-心室固有节律-加速性心室固有节律aivr"></a>
## 2.4 固有心室調律・加速固有心室調律〈AIVR〉

|タイプ |周波数 |意味 |
|---|---|---|
| **固有の心室（逃避）リズム** | **20 ～ 40 拍/分** |完全な AVB、臨死リズム。非常に危険です |
| **加速された固有心室調律 AIVR** | **60 ～ 100 (~120) 拍/分** | **急性心筋梗塞再灌流の兆候**;ほとんどが一時的で良性です。

**診断要素**:
1. **広範囲の変形 QRS ≥ 0.12 s**、T 波は QRS の主波の方向と逆です。
2. **関連する P 波なし** (または房室解離の存在)
3. リズム** ルールまたは一般ルール**
4. **緩やかな開始と終了** (「ウォームアップ/クールダウン」) - 心室頻拍の突然の停止とは異なります。
5. 周波数が洞調律に近いため、フュージョンビートとキャプチャーウェーブが共通

**AIVR 対 VT**: AIVR 周波数 < 120、渐起渐止、血流动力学稳定；VT ≥ 100（通常 >130)、突然停止。

<a id="25-心房静止as-窦室传导"></a>
## 2.5 心房静寂〈AS〉/洞室伝導

**心房停止**:
- **P 波が完全に存在しない** (V1 を含むすべてのリードに存在しない)
- 規則的な接合部または心室収縮リズム
- 原因：高カリウム血症、ジギタリス中毒、心房筋症（心房性麻痺）、末期心臓病

**洞心室伝導 - 高カリウム血症の特徴的な症状**:
1. **P 波が消失** (心房筋は脱分極できませんが、洞房結節のインパルスは節間束を介して心室に伝達されます)
2. **QRS は大幅に広がっています** (正弦波形、QRS と T を区別できません)
3. **T 波ピーク**
4. リズムのルール
>正常カリウム血症 >8 mEq/L、**緊急** (カルシウム + グルコース インスリン + 透析)

# 第3章 異常なP波形の形状と大きさ

> **P 波は II 誘導 (時間制限、振幅) + V1 誘導 (二相成分) を観察します**。これら 2 つの誘導が P 波診断の主戦場です。

<a id="31-左房扩大p-mitrale"></a>
## ３．１ 左心房拡大（僧帽弁Ｐ）

|標準 |値 |リード |
|---|---|---|
| **P 波の持続時間が延長されました** | **≥ 0.12 秒 (≥ 3 分割)** | **II** (または I、aVL) |
| **ダブルピーク P (ノッチ付き)** | 2 つのピーク間の距離 **≥ 0.04 s** | **II** |
| **P波端子電位(Ptf-V1)** | **≤ −0.04 mm・s** (つまり、終端陰性波 **深さ ≥ 1 mm、幅 ≥ 0.04 s**) | **V1** |

- 原因：**僧帽弁狭窄症/逆流**、左心室肥大/心不全による左房負荷、高血圧
- 注: Ptf-V1 異常は **最も敏感な**指標であり、左心室拡張機能障害でも見られることがあります (真の左心房拡大とは限りません)。

<a id="32-右房扩大p-pulmonale"></a>
## 3.2 右心房の拡大 (P pulmonale)

|標準 |値 |リード |
|---|---|---|
| **P 波ピーク** | **≧0.25mV（≧2.5mm）** | **II、III、aVF** |
| **V1 初期の正の部分が増加します** | **≧0.15mV（≧1.5mm）** | **V1** (または V2) |
| **P 波の持続時間** | **正常 (< 0.12 秒)** - 左心房拡大との主な違い | Ⅱ |
|電気軸 | P 電気軸が右に偏向 (> +75°) | |

- 原因: **COPD/肺性心、肺高血圧症、三尖弁疾患、先天性心疾患(PS、ASD、TOF、エブスタイン)**
- **両心房拡大**: II 誘導 P は高く (≧2.5 mm) かつ広い (≧0.12 秒) + V1 は、両方向で P の正成分と負成分の両方を増加させます。

<a id="33-异位心房节律冠状窦节律-左房节律"></a>
## ３．３ 異所性心房調律（冠状静脈洞調律／左心房調律）

**共通点**: P 波の形態は異常だが、**PQ ≥ 0.12 s** (接合部リズムとの重要な差別化要因)

|タイプ |特徴 |リード |
|---|---|---|
| **冠洞洞リズム** | II、III、aVF では **P 反転**、**PQ ≥ 0.12 s**; I で直立した P、V5–V6 | II、III、aVF |
| **左心房調律** | I および/または aVL** の **P 反転** (キー!); V1 は P | のような **「ドームとダーツ」** です。 **I、aVL、V1** |
| **右心房調律の低下** | II、III、aVF P は倒立、I は正立 | |

> **関数**: P 反転 + PQ ≥ 0.12 秒 → 異所性心房特性。 P 反転 + PQ < 0.12 s → 接合特性。

<a id="34-游走性起搏点wandering-pacemaker"></a>
## ３．４ 徘徊ペースメーカー

**診断要素 (同じリード、通常は II を参照)**:
1. **P 波形は 3 つ以上**あり、拍ごとに徐々に変化します (正立→低平坦→反転→再び正立)。
2. **PQ 間隔はそれに応じて変化します** (0.12 秒を超えて 0.12 秒未満)
3. **PP間隔が若干不規則**
4. 心拍数は通常は正常か遅いです (**100 拍/分を超える場合 → 「多因性心房頻脈 MAT」と呼ばれます**、重度の COPD でより一般的です)

- メカニズム: ペースメーカーは洞房結節 ↔ 心房 ↔ 接合部の間を移動します。
- 主に迷走神経の緊張の増加によって引き起こされる**生理学的現象** (スポーツ選手、若者、睡眠)

# 第4章 PQ(PR)間隔の短縮と延長

<a id="41-wpw-综合征心室预激"></a>
## 4.1 WPW 症候群（心室早期興奮）

<a id="诊断三联征"></a>
### 診断の三徴

| # | 基準 | 数値 |
|---|---|---|
| 1 | **PQ 間期の短縮** | **< 0.12 秒** |
| 2 | **δ（デルタ）波** | QRS の起始部が粗鈍・頓挫しており、QRS の起始 0.03–0.05 秒を緩慢にする |
| 3 | **QRS の増幅** | **≥ 0.12 秒**（PJ 間期は正常で ≤ 0.26 秒であるため、PQ + QRS の和は一定） |
| 付 | **二次的 ST-T 変化** | ST-T の方向は δ 波/QRS の主波と逆向き |

<a id="分型依据-v1-的-δ-波qrs-主波极性"></a>
### 分類（V1 の δ 波/QRS 主波の極性に基づく）

| 型 | V1 の QRS 主波 | 傍路の位置 | 誤診されやすいもの |
|---|---|---|---|
| **A 型** | **正性（R または Rs）** | **左側壁 / 左後方** | **RBBB、後壁心筋梗塞、右室肥大** |
| **B 型** | **負性（rS または QS）** | **右側壁 / 右前方** | **LBBB、前間壁心筋梗塞** |
| **C 型** | V1–V4 で正性、V5–V6 で負性 | 左後方中隔 | 稀 |

**重要な罠**：
- 早期興奮は**偽性 Q 波**（δ 波が下方を向く場合）を生じ、古傷心筋梗塞（特に下壁）と誤診されることがある
- 早期興奮に伴う ST-T 変化は**二次的**であり、虚血と診断してはならない
- **WPW + 心房細動 = 偽性 VT**（非常に速く、不規則で、幅の広い QRS）→ **ジギタリス、ベラパミル、β遮断薬は禁忌**（傍路伝導を加速し → 心室細動を誘発）
- **間欠的早期興奮**（δ 波が時折現れる）は傍路の不応期が長いことを示し、突然死のリスクは低い

<a id="42-lgl-综合征"></a>
## 4.2 LGL 症候群

| 基準 | |
|---|---|
| **PQ < 0.12 秒** | ✅ |
| **δ 波なし** | ✅ |
| **QRS 時間幅は正常（< 0.10 秒）** | ✅ |
| 発作性上室性頻拍の既往あり | 「症候群」と診断するために必要 |

- 機序仮説：ジェームズ束（房結傍路）または AVN 内の高速伝導路
- 頻拍発作がない場合は、単に「**短 PQ（PR）間期**」と記述する

<a id="43-i-度房室阻滞"></a>
## 4.3 第 I 度房室ブロック

| 基準 | 数値 |
|---|---|
| **PQ 間期の延長** | **> 0.20 秒**（高齢者では > 0.22 秒まで許容；小児では > 0.18 秒） |
| **すべての P 波の後に QRS が続く** | ドロップなし（これが第 II 度との違い） |
| PQ は一定 | |

**ブロック部位の推定**：
- **QRS が狭く + PQ 延長** → ブロックは主に **AVN 内**（良性、アトロピンで改善）
- **QRS が広い（束枝ブロック）+ PQ 延長** → ブロックは **His 束以下**の可能性あり（高度 AVB への進行に注意）
- PQ **> 0.30 秒** は「顕著な第 I 度 AVB」と呼ばれ、房室同期の喪失（「ペースメーカー症候群」様症状）を引き起こすことがある
- 病因：迷走神経緊張の亢進、アスリート、ジギタリス/β遮断薬/カルシウム拮抗薬、下壁心筋梗塞、心筋炎（特にライム病）、高齢による伝導系の退行性変性

<a id="第-5-章-qrs-增宽与电轴异常"></a>
# 第 5 章 QRS の増幅と電気軸異常

> **アプローチ**：QRS ≥ 0.12 秒の場合、まず **V1 の波形**（正性＝RBBB 型、負性＝LBBB 型）を確認し、次に電気軸を見る。

<a id="51-完全性右束支阻滞crbbb"></a>
## 5.1 完全性右束枝ブロック〈CRBBB〉

| # | 基準 | 誘導 |
|---|---|---|
| 1 | **QRS ≥ 0.12 秒** | 任意 |
| 2 | **V1（V2）で rsR'、rSR'、M 型**（「ウサギの耳」）、R' > r | **V1, V2** |
| 3 | **I、aVL、V5、V6 で幅広で頓挫した S 波**（S の幅 > R の幅 または > 0.04 秒） | **I, aVL, V5, V6** |
| 4 | **V1 の VAT（インナーデフレクション）> 0.05 秒** | V1 |
| 5 | **二次的 ST-T 変化**：V1–V2 で ST 低下、T 逆転 | V1, V2 |

- **不完全性 RBBB（IRBBB）**：波形は同じだが **QRS は 0.10–0.12 秒**。正常な若年者、**ASD（重要！）**、右室容量負荷増大で頻見。
- **RBBB は心筋梗塞の診断を妨げない**：QRS の起始ベクトル（中隔脱分極）は正常であり、Q 波の評価が可能だから。
- V1 で **qR** 型の RBBB → 合併する**前間壁心筋梗塞**または右室肥大を疑う。

<a id="52-完全性左束支阻滞clbbb"></a>
## 5.2 完全性左束枝ブロック〈CLBBB〉

| # | 基準 | 誘導 |
|---|---|---|
| 1 | **QRS ≥ 0.12 秒** | 任意 |
| 2 | **V5、V6、I、aVL で幅広で頓挫または平坦な R 波**、**q 波なし**（中隔 q 消失） | **I, aVL, V5, V6** |
| 3 | **V1、V2 で rS または QS**（r が極めて小さいか欠如） | **V1, V2** |
| 4 | **V5、V6 の VAT > 0.06 秒** | V5, V6 |
| 5 | **二次的 ST-T 変化**：I、aVL、V5、V6 で ST 低下 + T 逆転；V1–V3 で ST 上昇 + T 正立 | |
| 6 | 電気軸はしばしば左偏 | |

**臨床的要点**：
- CLBBB はほぼ常に**器質性心疾患**の兆候（虚血性心筋症、高血圧、拡張型心筋症、大動脈弁病変）であり、RBBB とは異なる。
- **CLBBB は心筋梗塞の診断を隠蔽する** → 急性心筋梗塞の判定には **Sgarbossa 基準**を使用：
  - ST 上昇 **≥ 1 mm かつ QRS 主波と同方向（concordant）** —— 5 点
  - V1–V3 で ST 低下 **≥ 1 mm かつ QRS 主波と同方向** —— 3 点
  - ST 上昇 **≥ 5 mm かつ QRS 主波と逆方向（discordant）** —— 2 点
  - （修正版 Smith 基準：ST/S 比 ≤ −0.25）
  - **≥ 3 点**で急性心筋梗塞を疑う
- **新規発症の LBBB + 胸痛** は STEMI と同等に扱う。
- LBBB の場合、**左室肥大、心筋梗塞、虚血の診断は不可能**（二次的変化が干渉するため）。

<a id="53-非特异性室内传导障碍nonspecific-ivcd"></a>
## 5.3 非特異的室内伝導障害〈nonspecific IVCD〉

| 基準 |
|---|
| **QRS ≥ 0.11–0.12 秒** |
| **典型的な RBBB でも典型的な LBBB でもない波形** |
| しばしば広範な QRS の増幅、粗鈍、ノッチを呈する |

- 病因：**高カリウム血症、Ia/Ic 系抗不整脈薬（フロカインなど）、三環系抗うつ薬中毒、重症心筋病変、心筋線維化、高度心筋虚血**
- IVCD を認めた場合は、直ちに**血清カリウム**と**服薬歴**を確認する。

<a id="54-左前分支阻滞lah-lafb"></a>
## 5.4 左前枝ブロック〈LAH / LAFB〉

| # | 基準 | 誘導 |
|---|---|---|
| 1 | **電気軸の顕著な左偏：−45° ～ −90°**（一部の教科書では ≤ −30°） | 四肢誘導 |
| 2 | **II、III、aVF で rS 型**、かつ **S(III) > S(II)** | II, III, aVF |
| 3 | **I、aVL で qR 型**、**R(aVL) > R(I)** | I, aVL |
| 4 | **QRS 時間幅は正常または軽度延長（< 0.12 秒）** | |
| 5 | aVL の VAT ≥ 0.045 秒 | aVL |
| 6 | 下壁心筋梗塞、左室肥大、垂位心、肺气腫などの他の左偏原因を**除外**する必要がある | |

- 最も一般的な枝ブロックである。**V1–V3 の R 波増高不良**（偽性前間壁心筋梗塞）や **aVL の偽性 Q 波**を引き起こすことがある。

<a id="55-左后分支阻滞lph-lpfb"></a>
## 5.5 左後枝ブロック〈LPH / LPFB〉

| # | 基準 | 誘導 |
|---|---|---|
| 1 | **電気軸の右偏：+90° ～ +180°**（多くの場合 ≥ +110° を要求） | 四肢誘導 |
| 2 | **I、aVL で rS 型** | I, aVL |
| 3 | **II、III、aVF で qR 型**、かつ **R(III) > R(II)** | II, III, aVF |
| 4 | **QRS < 0.12 s** | |
| 5 | **除外诊断**：右室肥大、垂位心（瘦长体型）、侧壁心肌梗死、肺气肿、肺栓塞 | |

- 左后分支粗大且双重供血 → **单纯 LPH 罕见**，出现时提示病变广泛、预后不良。
- **LPH 的诊断属于除外诊断**，务必首先排除右室肥大（RVH）。

## 5.6 双分支阻滞与三分支阻滞

| 类型 | 心电图组合 |
|---|---|
| **双分支阻滞（bifascicular block）** | ① **RBBB + LAH**（最常见：V1 呈 rsR' 型 + 电轴 ≤−45°）<br>② **RBBB + LPH**（V1 呈 rsR' 型 + 电轴 ≥+110°，预后较差）<br>③ 单纯性 CLBBB（视为左前分支与左后分支同时受累） |
| **三分支阻滞（trifascicular block）** | 双分支阻滞 **+ I 度房室传导阻滞（PQ 间期延长）**（“不完全性三分支阻滞”）<br>或 双分支阻滞 **+ 交替出现的另一分支阻滞**<br>或 双分支阻滞 **+ II 度/III 度房室传导阻滞**（“完全性三分支阻滞”＝完全性房室传导阻滞） |

- 双分支阻滞 + 晕厥 → 强烈提示间歇性完全性房室传导阻滞，**需评估起搏器植入适应证**。

## 5.7 双侧束支阻滞、交替性束支阻滞

- **交替性束支阻滞（alternating BBB）**：在同一份或连续记录中，**RBBB 与 LBBB 交替出现**，或 RBBB+LAH 与 RBBB+LPH 交替出现 → **双侧束支病变，极高风险，永久起搏器植入 I 类适应证**。
- **双侧束支阻滞**：表现为**完全性房室传导阻滞 + 宽 QRS 逸搏心律**，阻滞部位位于希氏束以下（逸搏频率 < 40 次/分，对阿托品无反应）。

# 第 6 章 左室电位过高 / 过低

## 6.1 左室高电压（high voltage）

> 仅电压增高、**无 ST-T 改变**时，只能诊断为“左室高电压”，不能诊断为左室肥大。

| 标准名称 | 公式 | 导联 |
|---|---|---|
| **Sokolow-Lyon（胸导联）** | **S(V1) + R(V5 或 V6) ≥ 3.5 mV（35 mm）** | V1, V5, V6 |
| **R(V5) 或 R(V6)** | **≥ 2.6 mV（26 mm）** | V5, V6 |
| **Sokolow-Lyon（肢导联）** | **R(I) + S(III) ≥ 2.5 mV** | I, III |
| **R(aVL)** | **≥ 1.1 mV（1.2 mV）** | aVL |
| **Cornell 电压** | **R(aVL) + S(V3) > 2.8 mV（男）/ > 2.0 mV（女）** | aVL, V3 |
| **Cornell 乘积** | (Cornell 电压 + 女性 0.6 mV) × QRS 时限 > 2440 mm·ms | |

**注意**：青年、瘦体型、运动员常出现假阳性；肥胖、肺气肿、心包积液常出现假阴性。

## 6.2 左室肥大〈LVH〉

诊断 = **电压标准 + 支持性表现**：

| 支持性表现 | 具体描述 | 导联 |
|---|---|---|
| **① ST-T 劳损型（strain pattern）** | ST 段**下斜型压低** + **非对称性倒置 T 波**（降支陡峭、升支平缓，呈反向“鱼钩”状） | **V5, V6, I, aVL** |
| ② 左房扩大 | Ptf-V1 ≤ −0.04 mm·s | V1 |
| ③ 电轴左偏 | ≤ −15° ～ −30° | |
| ④ QRS 时限轻度延长 | 0.09–0.11 s | |
| ⑤ VAT 延长 | V5, V6 **> 0.05 s** | V5, V6 |
| ⑥ V1–V3 R 波递增不良 | | V1–V3 |

**Romhilt-Estes 积分法（≥ 5 分＝确诊，4 分＝可能）**

| 项目 | 分值 |
|---|---|
| 任一肢导联 R 或 S ≥ 2.0 mV，或 S(V1,V2) ≥ 3.0 mV，或 R(V5,V6) ≥ 3.0 mV | 3 |
| ST-T 劳损型（未使用洋地黄） | 3（使用洋地黄时为 1） |
| 左房扩大（Ptf-V1 ≤ −0.04 mm·s） | 3 |
| 电轴左偏 ≤ −30° | 2 |
| QRS 时限 ≥ 0.09 s | 1 |
| VAT(V5/V6) ≥ 0.05 s | 1 |

- 病因：高血压、主动脉瓣狭窄、肥厚型心肌病、主动脉缩窄

## 6.3 左室容量（舒张期）负荷

> 与“压力负荷（劳损型）”相对，形态学表现相反。

| 特征 | 描述 | 导联 |
|---|---|---|
| **深而窄的 q 波** | 间隔 q 波增大（但宽度 < 0.04 s） | **V5, V6, I, aVL** |
| **高 R 波** | 电压增高 | V5, V6 |
| **ST 段抬高（轻度）或等电位** | 非压低 | V5, V6 |
| **T 波高耸直立** | 与劳损型的倒置 T 波相反 | V5, V6 |

- 病因：**主动脉瓣关闭不全、二尖瓣关闭不全、室间隔缺损（VSD）、动脉导管未闭（PDA）、动静脉瘘、贫血/甲亢等高排量状态**
- 记忆要点：压力负荷 → ST-T 劳损（T 波倒置）；容量负荷 → 深 q 波 + 高 T 波。

## 6.4 肥厚型心肌病〈HCM〉

### 一般型（非对称性室间隔肥厚）

| 特征 | 描述 | 导联 |
|---|---|---|
| **左室高电压** | 通常显著 | V4–V6 |
| **异常 Q 波（假性梗死型）** | **窄（< 0.04 s）而深**的 Q 波，源于室间隔肥厚 | **II, III, aVF, V4–V6, I, aVL** |
| ST-T 改变 | T 波倒置、ST 段压低 | 侧壁导联 |
| 左房扩大 | | V1, II |

- **关键鉴别点**：HCM 的 Q 波**窄而深**（<0.04 s），心肌梗死（MI）的 Q 波**宽**（≥0.04 s）。

### 心尖肥厚型（APH，日本多见）

| 特征 | 数值 | 导联 |
|---|---|---|
| **巨大倒置 T 波〈GNT〉** | **深度 > 1.0 mV（10 mm）**，最深通常见于 V4 | **V3–V5**（V4 最深） |
| **左室高电压** | R(V4–V5) 增高，常 ≥ 2.6 mV | V4, V5 |
| ST 段压低 | 伴随出现 | V4–V6 |
| **无异常 Q 波** | 用于与心肌梗死鉴别 | |

- 心脏超声/MRI 可见心尖部呈“黑桃 A（spade）”样的左室腔。

## 6.5 低电压（low voltage）

| 标准 | 数值 |
|---|---|
| **肢导联低电压** | **全部 6 个肢导联的 QRS 振幅（R+S 绝对值之和）< 0.5 mV（5 mm）** |
| **胸导联低电压** | **全部 6 个胸导联 QRS 振幅 < 1.0 mV（10 mm）** |
| **广泛低电压** | 二者兼有 |

**病因鉴别**：

| 机制 | 疾病 |
|---|---|
| 心脏与电极间绝缘/短路 | **心包积液（+ 电交替 → 心脏压塞）**、胸腔积液、**肺气肿/COPD**、气胸、肥胖、皮下水肿 |
| 心肌本身电活动减少 | **心肌淀粉样变（低电压 + 假性梗死 Q 波，重要！）**、广泛心肌梗死、扩张型心肌病末期、**黏液性水肿（甲减）**、限制型心肌病 |
| 其他 | 缩窄性心包炎、硬皮病 |

- **电交替（electrical alternans）**：QRS 振幅逐搏高低交替 → **心脏压塞**的特异性表现（心脏在心包液中摆动）。

# 第 7 章 异常 Q 波

## 7.1 心肌梗死〈MI〉

### 异常 Q 波（病理性 Q 波）的标准

| # | 标准 |
|---|---|
| 1 | **宽度 ≥ 0.04 s**（V2–V3 采用 ≥ 0.02 s 且呈 Q 波或 QS 型） |
| 2 | **深さ > 同導聯 R 波の 1/4**（一部の教科書では > 1/3 を使用） |
| 3 | **≥ 2 個の隣接する導聯に出現** |
| 4 | R 波振幅の低下、切欠きを伴うことが多い |

> **例外**：aVR の Q/QS は正常である；III および V1 の孤立した Q 波はしばしば無意味である（III 導聯の Q 波が深吸入時に消失する＝生理的）。

<a id="定位诊断关键表"></a>
### 病巣定位診断（重要表）

| 梗塞部位 | 異常 Q / ST 上昇が出現する導聯 | 対応（ミラー）導聯 | 責任血管 |
|---|---|---|---|
| **前間壁** | **V1, V2 (V3)** | — | LAD 中隔枝 |
| **前壁** | **V3, V4** | — | LAD |
| **広範前壁** | **V1–V6, I, aVL** | II, III, aVF | **LAD 近位（高リスク）** |
| **側壁（高側壁）** | **I, aVL (V5, V6)** | II, III, aVF | LCX / 対角枝 |
| **下壁** | **II, III, aVF** | I, aVL (V1–V3) | **RCA（~80%）/ LCX** |
| **正後壁** | **V7–V9 の Q**；**V1–V2 に高 R、R/S ≥ 1、ST 低下、T 直立** | V1–V3（ミラー） | LCX / RCA |
| **右室** | **V4R（V3R–V6R）ST 上昇 ≥ 0.1 mV** | — | **RCA 近位** |
| 左主幹 | **aVR の ST 上昇 > V1 の ST 上昇**、広範な導聯で ST 低下（≥6 導聯） | | LMT |

<a id="mi-的时相演变用于判断新旧"></a>
### MI の時相的変化（新旧の判断に使用）

| 時期 | 時間 | 心電図 |
|---|---|---|
| **超急性期** | 数分〜数十分 | **T 波が高尖・広大（hyperacute T）**、ST が上昇し始め、Q 波は存在しない |
| **急性期** | 数時間〜数日 | **ST が著明に上昇（上凸、単相性曲線 monophasic）**、**異常 Q 波出現**、対応導聯で ST 低下 |
| **亜急性期（近位）** | 数日〜数週 | ST が徐々に回落、**T 波の逆転が深くなる（冠 T）**、Q 波が固定 |
| **陳旧期** | 数週〜数ヶ月以降 | **ST が基線に戻る**、T は直立に回復するか逆転を維持、**異常 Q 波が持続** |

**ST 上昇が 4–6 週間以上持続して回落しない場合 → 心室瘤を疑う**（10.4 参照）。

<a id="下壁-mi-的必查项"></a>
### 下壁 MI の必須チェック項目
1. **V4R を追加** → 右室梗塞の除外（**右室梗塞では硝酸エステル系薬物、利尿剤は禁忌であり、大量の輸液が必要**）
2. **V7–V9 を追加** → 後壁関与の除外
3. **II、III、aVF において ST 上昇が III > II であり、かつ V1 で ST 上昇** → RCA 近位；**I、aVL で ST 低下** は RCA を支持

<a id="72-左右电极接错lead-reversal"></a>
## 7.2 左右電極の誤接続（lead reversal）

**最も一般的：左右手首（LA/RA）の入れ替え**

| 特徴 | 所見 |
|---|---|
| **I 導聯**：P、QRS、T **すべて逆転** | ✅ 重要 |
| **aVR が直立**（P と QRS が上方） | ✅ 重要 |
| II と III が入れ替わり、aVL と aVR が入れ替わる | |
| **胸導聯は完全に正常**（R 波の増大が正常） | ✅ **右位心との重要な鑑別点** |

**その他の誤接続**：
- **右足（黒）と他の肢体の入れ替え** → 特定の肢体導聯が**ほぼ平坦（振幅が極めて低い）**になる
- 胸導聯電極の順序ミス → R 波増大に「断層」が生じる（例：V3 > V4）

## 7.3 右位心（dextrocardia）

| 特徴 | 所見 |
|---|---|
| **I 導聯** P、QRS、T **すべて逆転** | 電極誤接続と同じ |
| **aVR が直立** | 電極誤接続と同じ |
| **胸導聯で R 波が V1 から V6 にかけて徐々に減少**（「R 波の減小」）、V5–V6 で極めて小さな rS または QS を呈する | ✅ **決定的な鑑別点** |
| 電気軸右偏 | |

**確認方法**：肢体導聯を左右入れ替え + 胸導聯を右胸に配置（V1R–V6R） → 正常な心電図が記録されれば、鏡像右位心と診断できる。

<a id="第-8-章-胸导联-r-波递增不良"></a>
# 第 8 章 胸導聯 R 波増大不良

<a id="81-r-波递增不良poor-r-progression-prp"></a>
## 8.1 R 波増大不良〈poor R progression, PRP〉

| 基準（いずれかを満たす） |
|---|
| **R(V3) ≤ 0.3 mV（3 mm）** |
| **R(V1) ≤ R(V2) ≤ R(V3) ≤ R(V4)** 正常な増大パターンを示さない |
| V1–V4 の R 波振幅に明らかな増加がない |

**鑑別診断（重要、「前壁陳旧梗塞」と誤って報告されることが多いため）**：

| 原因 | 鑑別の手がかり |
|---|---|
| **前壁/前間壁陳旧 MI** | QS または異常 Q、T 逆転、既往歴を伴う |
| **左室肥大** | V5–V6 で高電圧、負荷型 ST-T |
| **左束枝ブロック / 左前枝ブロック** | QRS が広いか、電気軸左偏 |
| **COPD / 気腫** | 低電圧、電気軸右偏、肺型 P 波、順時計方向転位 |
| **拡張型心筋症** | 広範な低電圧、心拡大 |
| **電極位置が高すぎる**（第 2–3 肋間に配置） | 再貼付で回復；深吸入で改善 |
| **WPW（B 型）** | δ 波、短 PQ |
| 肥満、女性の乳房 | |

<a id="82-反向-r-波递增reversed-r-progression"></a>
## 8.2 逆 R 波増大〈reversed r progression〉

- **R 波が V1 から V4 にかけて逆に徐々に小さくなる**（V1 > V2 > V3…）
- 意義は PRP と同じだが、**前壁広範梗塞**または**右位心/電極誤配置**をより強く示唆する。

<a id="83-顺钟向转位clockwise-rotation"></a>
## 8.3 順時計方向転位（clockwise rotation）

| 基準 | 説明 |
|---|---|
| **移行区（R = S の部位）が V5、V6 またはそれより左に右移** | 正常は V3–V4 |
| V1–V4（場合によっては V5）がすべて **rS 型** | |
| 電気軸右偏を伴うことが多い | |

- 意義：心尖から上方を見たとき、心臓が長軸に沿って**順時計方向**に回転し、右室が前方に向く。
- 病因：**右室肥大、COPD/気腫、垂位心（細長い体型）、肺塞栓症**；正常人にも見られる。

<a id="第-9-章-右胸导联-r-波增高-i左侧胸导联-s-波加深"></a>
# 第 9 章 右胸導聯 R 波増高 / I、左側胸導聯 S 波深化

> **切入点**：V1 に「高 R 波」（R/S ≥ 1）が出現した際の 6 大鑑別 —— **① 逆時計方向転位 ② 後壁梗塞 ③ 右室肥大 ④ RBBB ⑤ WPW A 型 ⑥ 正常変異/小児**

<a id="91-逆钟向转位counterclockwise-rotation"></a>
## 9.1 逆時計方向転位（counterclockwise rotation）

| 基準 |
|---|
| **移行区が V2 またはそれより右に左移**（V1 ですでに Rs を呈する） |
| V5、V6 が qR を呈し、深い S 波がない |

- 病因：左室肥大、横位心（肥満、妊娠、腹水）、正常変異。
- **良性所見**であり、後壁梗塞や RVH との鑑別が必要。

<a id="92-后壁正后壁梗死"></a>
## 9.2 後壁（正後壁）梗塞

| # | 基準 | 導聯 |
|---|---|---|
| 1 | **R/S ≥ 1**（R 波増高） | **V1, V2** |
| 2 | **R 波時間 ≥ 0.04 s** | V1, V2 |
| 3 | **ST 低下**（急性期、後壁 ST 上昇のミラー像） | V1–V3 |
| 4 | **T 波が直立・高尖**（後壁 T 逆転のミラー像） | V1, V2 |
| 5 | **確定診断：V7–V9 を追加し、ST 上昇 ≥ 0.05 mV（男性<40歳では ≥0.1 mV）および/または異常 Q 波が出現** | **V7, V8, V9** |
| 6 | 下壁（II, III, aVF）または側壁の変化を合併することが多い | |

> 記憶法：V1–V2 の心電図を**上下反転 + 左右反転**して見ると、後壁の「ST 上昇 + Q 波」になる。

## 9.3 右室肥大〈RVH〉

| # | 基準 | 導聯 |
|---|---|---|
| 1 | **R/S ≥ 1**、または **R ≥ 0.7 mV（7 mm）** | **V1** |
| 2 | **R(V1) + S(V5 または V6) ≥ 1.05 mV（10.5 mm）** | V1, V5, V6 |
| 3 | **電軸右偏 ≥ +110°** | 四肢誘導 |
| 4 | **V5、V6 に深い S 波出現**（R/S ≤ 1） | V5, V6 |
| 5 | **ST-T 虚血型**：V1–V3 で ST 低下 + T 逆転 | **V1–V3** |
| 6 | しばしば**右房拡大**（II で P ≥ 0.25 mV）、不完全性 RBBB を伴う | II, V1 |
| 7 | V1 の VAT > 0.035 s | V1 |

**V1 の高 R 波の分類**：
- **V1 で qR 型** → 重度 RVH（右房拡大による圧迫）または前間壁心筋梗塞を示唆
- **rSR' 型** → 右室容量負荷（ASD）
- **純 R 型または Rs 型** → 右室圧負荷（肺動脈狭窄、原発性肺高血圧、TOF）
- **rS 型が V6 まで持続** → 慢性肺性心型（COPD）

<a id="94-右束支阻滞rbbb"></a>
## 9.4 右束枝ブロック〈RBBB〉

（診断基準は 5.1 参照）—— 本章における意義：**RBBB は V1 の高 R 波（R'）の最も一般的な原因である**。
- 鑑別の鍵：RBBB における V1 の高波は**第 2 の R 波（R'）**であり、QRS **≥ 0.12 s** で、I および V6 に広い S 波を認める。
- **RBBB + 電軸右偏 + 右房拡大** → RVH の合併を示唆。

<a id="95-急性肺源性心脏病急性肺栓塞"></a>
## 9.5 急性肺性心（急性肺塞栓症）

| # | 特徴 | 誘導 |

| 2 | **右胸誘導の T 波逆転**（最も感度の高い所見の一つ） | **V1–V4** |

<a id="第-10-章-st-段抬高"></a>
# 第 10 章 ST 段上昇

> **アプローチ**：ST 上昇を認めた場合、順次判断する —— ① **形態**（上方への凸 vs 上方への凹）② **分布**（特定の冠動脈領域に局限 vs 広範）③ **対応誘導の鏡像低下の有無** ④ **動態変化の有無** ⑤ **異常 Q 波の有無**

| 鑑別ポイント速查 | AMI | 心膜炎 | 早期再分極 | Brugada | 室壁瘤 |
|---|---|---|---|---|---|
| 形態 | **上方への凸**（弓背状） | **上方への凹** | 上方への凹 + J 波 | **coved（ドーム状）** | 凸状、固定 |
| 分布 | 冠動脈支配領域（局限） | **広範（aVR、V1 以外）** | V2–V5、下壁 | **V1–V3** | 既往梗塞部位 |
| 鏡像低下 | **あり** | **なし**（aVR 以外） | なし | なし | なし |
| PR 段 | 正常 | **低下（aVR で上昇）** | 正常 | 正常 | 正常 |
| 動態変化 | **あり（数時間〜数日）** | あり（数日〜数週、4 期） | **なし（長期不変）** | 変動あり（薬剤誘発） | **なし（6 週以上不変）** |
| Q 波 | あり | なし | なし | なし | **あり（QS）** |

<a id="101-急性心肌梗死ami-stemi"></a>
## 10.1 急性心筋梗塞〈AMI / STEMI〉

<a id="st-抬高的诊断阈值第四版心肌梗死通用定义"></a>
### ST 上昇の診断閾値（第 4 版心筋梗塞のユニバーサル定義）

| 誘導 | 閾値（**J 点**で測定、隣接する 2 誘導以上で） |
|---|---|
| **V2, V3** | 男性 ≥40 歳：**≥ 0.2 mV**；男性 <40 歳：**≥ 0.25 mV**；女性：**≥ 0.15 mV** |
| **その他の全誘導** | **≥ 0.1 mV** |
| **V3R, V4R（右室）** | 男性 ≥30 歳：≥ 0.05 mV；男性 <30 歳：≥ 0.1 mV；女性：≥ 0.05 mV |
| **V7–V9（後壁）** | **≥ 0.05 mV**（男性 <40 歳は ≥ 0.1 mV） |

<a id="其他要素"></a>
### その他の要素
- **形態**：ST 段が**上方へ凸（弓背状）**で、T 波と融合して"**単相曲線（monophasic curve）/ 墓碑様**"を呈する
- **対応誘導の鏡像 ST 低下**（reciprocal change）—— AMI を強く支持し、心膜炎ではないことを示す
- **動態変化**（7.1 の表参照）
- **病巣定位**（7.1 の定位表参照）

<a id="高危征象"></a>
### 高リスク徴候
- **aVR の ST 上昇 ≥ 0.1 mV + 広範誘導の ST 低下** → 左主幹/三枝病変
- **de Winter 型**：V1–V6 で J 点低下 + 上向き ST 低下 + **T 波の高大対称**、aVR で軽度 ST 上昇 → **LAD 近位閉塞に相当**
- **Wellens 症候群**：胸痛緩解期に **V2–V4 で T 波の双相性または深い逆転**、R 波保存、Q 波なし → **LAD 近位の重度狭窄**、運動負荷試験禁忌

<a id="102-右室梗死rv-infarction"></a>
## 10.2 右室梗塞〈RV infarction〉

| # | 基準 | 誘導 |
|---|---|---|
| 1 | **V4R（V3R–V6R）の ST 上昇 ≥ 0.05–0.1 mV**（最も特異的だが持続時間が短く、**発症 12 時間以内に記録必須**） | **V4R** |
| 2 | **下壁心筋梗塞**（II, III, aVF の ST 上昇）を合併 | II, III, aVF |
| 3 | **ST 上昇が III > II** | II, III |
| 4 | **V1 の ST 上昇**（V1 は標準 12 誘導で唯一右室を向く誘導）；V1 上昇 + V2 低下がより示唆的 | V1, V2 |
| 5 | しばしば房室ブロック、心房梗塞（PR 段の偏移）を伴う | |

**臨床的意義（記憶必須）**：三徴＝**低血圧 + 頸静脈怒張 + 肺野の明瞭**；治療上は**硝酸エステル類、利尿剤、モルヒネの禁忌**、**大量輸液**が必要。

<a id="103-变异型prinzmetal心绞痛vap"></a>
## 10.3 変異型（Prinzmetal）狭心症〈VAP〉

| # | 特徴 |
|---|---|
| 1 | **発作性、一過性の ST 段上昇**（上方への凸で AMI と同じ形態）、胸痛を伴う |
| 2 | **発作緩解後に ST が完全に正常に戻る**（数分〜数十分）—— 重要 |
| 3 | 発作時に **T 波の高大広大、R 波の高大広大、S 波の消失**が見られる |
| 4 | 対応誘導の鏡像低下 |
| 5 | しばしば**発作時の室性不整脈（PVC、VT、VF）または房室ブロック**を伴う —— 突然死の原因 |
| 6 | **夜間〜早朝、安静時**に好発；心筋酵素は上昇しない（持続的痙攣による梗塞を除く） |

- 診断：Holter による捕捉、アセチルコリン/エルゴタミン負荷試験。
- **ST 低下または T 波変化**のみを一過性に認める場合 → ST 上昇を伴わない冠動脈痙攣。

## 10.4 室壁瘤（ventricular aneurysm）

| # | 基準 |
|---|---|
| 1 | 既往に心筋梗塞の病歴あり |
| 2 | **ST 段上昇が ≥ 4–6 週持続して回落しない**（"固定性 ST 上昇"） |
| 3 | 同誘導に **QS 波または深い Q 波**が存在 |
| 4 | しばしば T 波逆転を伴う |
| 5 | 胸痛なし、心筋酵素上昇なし、**動態変化なし** |
| 6 | 好発部位：**V1–V4（前壁心尖部）** |

<a id="105-急性心包炎"></a>
## 10.5 急性心膜炎

| # | 基準 | 誘導 |
|---|---|---|
| 1 | **広範誘導の ST 上昇（上方への凹）**：I, II, aVF, V2–V6 など | 広範 |
| 2 | **aVR（通常还有 V1）ST 压低** —— 唯一的“镜像”改变 | aVR, V1 |
| 3 | **PR（PQ）段压低**，而 **aVR 的 PR 段抬高** —— 最具特异性的表现 | II, V5, V6 / aVR |
| 4 | **无异常 Q 波**、R 波振幅保持 | |
| 5 | **ST/T 比值 > 0.25**（V6，用于与早期复极鉴别） | V6 |
| 6 | 常伴窦性心动过速；心包积液时低电压 + 电交替 | |

**4 期演变（Spodick）**：
- **I 期**：广泛 ST 抬高 + PR 压低（数日）
- **II 期**：ST 回到基线，T 波变平（1–3 周）
- **III 期**：**广泛 T 波倒置**（3–数周）
- **IV 期**：恢复正常（数周~数月，也可长期遗留 T 波倒置）

> 与 AMI 的关键区别：心包炎的 **ST 抬高与 T 波倒置不同时出现**（AMI 中 ST 尚抬高时 T 波已开始倒置）。

## 10.6 脑血管障碍（尤其蛛网膜下腔出血 SAH）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **巨大倒置 T 波〈GNT〉**：宽大、深（可 > 1.0 mV）、对称，常称"**cerebral T**" | **广泛，尤 V2–V6** |
| 2 | **QT 间期显著延长**（QTc 可 > 0.60 s） → **TdP 风险** | II, V5 |
| 3 | **U 波增高**（明显） | V2–V4 |
| 4 | ST 抬高或压低（可类似 MI，"**神经源性心肌顿抑**"） | |
| 5 | **窦性心动过缓**、各种心律失常 | |

- 机制：交感神经风暴 → 儿茶酚胺心肌损伤。心肌酶可轻度升高（易误诊 AMI，**误用抗凝/溶栓可致命**）。

## 10.7 Takotsubo（应激性）心肌病

| 阶段 | 心电图 |
|---|---|
| **急性期（数小时）** | **广泛前壁导联（V2–V6, I, aVL）ST 抬高**，但 **aVR 常 ST 压低**；**对应导联镜像压低不明显**；抬高幅度小于同范围的 AMI |
| **亚急性期（2–5 日）** | **巨大倒置 T 波（GNT）+ 显著 QT 延长（QTc 常 > 0.50 s）** |
| **恢复期（数周~数月）** | 逐渐恢复 |

**与前壁 AMI 的鉴别线索**：
- **无异常 Q 波**，或仅一过性 Q 波（R 波保留）
- **ST 抬高范围广于单支冠脉支配区**，且 **aVR ST 压低 + V1 无抬高**
- 心肌酶升高幅度**与 ST 抬高范围不成比例（偏低）**
- 诱因：**强烈情绪/躯体应激**，好发**老年女性**
- 确诊靠左室造影/超声：心尖部球形扩张（"章鱼壶"）

## 10.8 Brugada 综合征

### 心电图分型（V1–V3，尤其 V1、V2）

| 型 | J 点抬高 | ST 形态 | T 波 |
|---|---|---|---|
| **1 型（coved / 穹窿型）** | **≥ 0.2 mV（2 mm）** | **下斜型（coved），与 T 波连续** | **倒置** |
| **2 型（saddleback / 马鞍型）** | ≥ 0.2 mV | 谷底 ST 抬高 **≥ 0.1 mV**，上斜型 | 直立或双相 |
| **3 型** | 马鞍或穹窿型，但 ST 抬高 **< 0.1 mV** | | |

- **只有 1 型具有诊断意义**（"Brugada 型心电图"）；2/3 型需药物（钠通道阻滞剂：匹莫齐特、氟卡尼、阿义马林）诱发转为 1 型。
- **诊断敏感化技巧**：将 **V1、V2 电极上移至第 3 或第 2 肋间**记录 → 检出率显著提高。
- 心电图可**自发波动**（迷走张力增高、发热、饱餐、饮酒后加重）。
- 常伴 **V1 的 rSR' 样形态（易误为不完全性 RBBB）**，但 I、V6 无宽 S 波是区别点。
- **Brugada 综合征** = Brugada 型心电图（1 型）+ 以下之一：VF/多形性 VT 记录、心脏骤停幸存、家族史（<45 岁猝死）、家族成员 1 型心电图、诱发性 VF、夜间濒死呼吸/晕厥。
- 好发：**东亚成年男性、夜间/睡眠中猝死**。

## 10.9 低体温（hypothermia）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **Osborn 波（J 波）**：QRS 终末部与 ST 交界处出现的**圆顶状正向偏转**，体温越低越大 | **V4–V6, II**（左侧导联明显） |
| 2 | **窦性心动过缓** | |
| 3 | **PR、QRS、QT 间期均延长** | |
| 4 | **肌肉震颤（寒战）造成的基线伪差** | 肢体导联 |
| 5 | 进展：房颤 → 交界性节律 → VF（< 28℃）→ 心停 | |

- **鉴别 J 波的其他原因**：早期复极、高钙血症、SAH、Brugada 综合征、败血症。

# 第 11 章 T 波增高

## 11.1 高钾血症〈hyperkalemia〉

### 血钾浓度与心电图的对应（记忆重点）

| 血钾 (mEq/L) | 心电图变化 |
|---|---|
| **5.5 – 6.5** | **T 波高尖（tented T）**：**窄基底、对称、尖锐**，QT 缩短。最明显于 **V2–V4** |
| **6.5 – 8.0** | **P 波振幅降低、变宽 → 最终消失**；**PR 延长**；**QRS 开始增宽** |
| **8.0 – 10** | **QRS 显著增宽**，与 T 融合 → **正弦波（sine wave）**；**窦室传导** |
| **> 10** | **心室颤动 / 心室停搏** |

**高尖 T 波的鉴别**：

| 原因 | 特征 |
|---|---|
| **高钾** | **基底窄、对称、尖锐**，QT 缩短，同时 P 波变化 |
| **超急性期 MI** | **基底宽**、不对称，伴 ST 抬高，局限于冠脉支配区 |
| **早期复极** | 伴 J 波、ST 上凹抬高，R 波高 |
| 正常变异 / 迷走张力高 | 振幅高但形态正常 |
| 左室容量负荷 | 伴深 q、高 R |
| **de Winter 型** | 伴 J 点压低 + 上斜 ST 压低 |

> **低钾血症**见 12.6（T 低平 + U 波增高），与高钾恰好相反。

# 第 12 章 ST 压低、T 波低平 / 倒置

> **切入点**：先判断是**原发性**（QRS 正常）还是**继发性**（QRS 异常：束支阻滞/肥大/预激/起搏）。

## 12.1 心肌缺血（劳力性心绞痛 / 运动负荷试验）

### ST 压低的形态学分类

| 类型 | 形态 | 意义 |
|---|---|---|
| **水平型（horizontal）** | ST 段与基线平行下移 | **缺血（有意义）** |
| **下斜型（downsloping / sagging）** | 从 J 点向下倾斜 | **缺血（意义最大）** |
| **上斜型（upsloping）** | J 点压低但 ST 迅速上升 | 多为**生理性**（心动过速、Ta 波）；仅当**缓慢上斜且 J 点后 0.08 s 仍 ≥ 0.1 mV** 时有意义 |
| **盆状（sagging / scooped）** | 鱼钩样 | **洋地黄效应** |

### 定量标准

| 场合 | 阳性标准 |
|---|---|
| **静息心电图** | J 点后 **0.06–0.08 s** 处，**水平或下斜型压低 ≥ 0.05–0.1 mV** |
| **运动负荷试验** | **水平或下斜型 ST 压低 ≥ 0.1 mV（1 mm）**，持续 ≥ 0.08 s，出现在 ≥ 2 个相邻导联 |
| **強陽性（高リスク）** | ST 低下 ≥ 0.2 mV；低負荷で出現；回復期に > 5 分持続；多導联の関与；運動中の**血圧低下**；運動誘発性 VT |
| **運動中の ST 上昇** | **全層虚血/冠攣縮/重症狭窄**を示唆し、ST 低下よりも危険 |

- **V4–V6、II、aVF** に最も頻繁に出現する。
- **ST 低下は虚血部位を特定できない**（ST 上昇とは異なる）；**aVR の ST 上昇 + 広範な ST 低下** → 左主幹/三枝病変。

<a id="缺血性-t-波改变"></a>
### 虚血性 T 波変化
- **冠 T 波（coronary T）**：**深く、対称的で、矢じり様の逆転** —— 心内膜下損傷/虚血を示唆
- **偽性正常化（pseudonormalization）**：本来逆転していた T 波が虚血発作時に**直立に変わる** → これは虚血の所見である！

<a id="122-心内膜下梗死非-q-波心肌梗死-nstemi"></a>
## 12.2 心内膜下梗塞（非 Q 波心筋梗塞 / NSTEMI）

| # | 基準 |
|---|---|
| 1 | **持続的な ST 低下**（水平型/下降型）および/または **深く対称的な逆転 T 波**が数日持続 |
| 2 | **異常 Q 波なし**（R 波は保持）、**ST 上昇なし** |
| 3 | **心筋壊死マーカー（トロポニン）の上昇** —— 不安定狭心症との唯一の違い |
| 4 | 動的変化がある（慢性 ST-T 変化との鑑別） |

- **UA vs NSTEMI vs STEMI**：ST 上昇 → STEMI；ST 上昇なし + トロポニン上昇 → NSTEMI；ST 上昇なし + トロポニン正常 → 不安定狭心症。

<a id="123-继发性-st-t-改变"></a>
## 12.3 二次性 ST-T 変化

| 定義 | **心室脱分極（QRS）異常**に伴って必然的に出現する再分極異常 |
|---|---|
| **判定法** | **ST-T の方向が QRS の主波方向と逆**（不一致 / discordant） |
| **一般的な原因** | **束枝ブロック（LBBB、RBBB）、心室肥大（strain 型）、WPW 症候群、心室ペーシング、PVC、室性頻拍** |
| **臨床的意味** | **心筋虚血として解釈してはならない** |

- 例：LBBB の場合、V5–V6（R 波が上向き）→ ST 低下 + T 逆転；V1–V2（S 波が下向き）→ ST 上昇 + T 直立。これは「あるべき」所見である。
- **原発性 ST-T 変化の重畳**を示す手がかり：ST-T の方向が予想と逆（一致 / concordant）→ Sgarbossa 基準で評価する。

<a id="124-非特异性-st-t-改变"></a>
## 12.4 非特異的 ST-T 変化

| 記述 | 軽度の ST 低下（< 0.1 mV）、T 波の低平（R 波の 1/10 未満）、軽度の T 逆転で、特定のパターンに該当しない |
|---|---|
| **可能性のある原因** | 自律神経緊張（過換気、体位、食後、不安、寒冷）、女性、貧血、発熱、感染症、甲状腺機能異常、軽度の電解質異常、薬剤、陳旧性心筋病変、軽度虚血 |
| **判読原則** | **必ず既往の心電図と比較する**；単独記録での非特異的変化は価値が限定的であり、臨床所見と併せて判断する必要がある |

**体位/生理的 T 波変化の確認**：深呼吸後の III 誘導の Q/T 変化、立位での T 変化、過換気試験、β遮断薬試験。

<a id="125-洋地黄效应digitalis-effect"></a>
## 12.5 デジタルス効果（digitalis effect）

| # | 特徴 | 誘導 |
|---|---|---|
| 1 | **鉢型（フック様 / sagging）ST 低下** —— 特徴的 | **V5, V6, II**（R 波主体の誘導） |
| 2 | **T 波の低平、両相性、または逆転**（T の起始部が ST によって引き下げられる） | V5, V6 |
| 3 | **QT 間期の短縮** —— 重要なポイント | |
| 4 | U 波振幅の増大 | |
| 5 | PR 間期の軽度延長 | |

> **「デジタルス効果」≠「デジタルス中毒」**。効果は治療濃度下での正常な所見である。

**デジタルス中毒の心電図**（別個の事柄）：
- **房室ブロックを伴う心房頻拍（PAT with block）** —— 最も典型的
- **双方向性室性頻拍（bidirectional VT）** —— 高度に特異的
- 加速性接合部リズム、規則的で徐脈性の心室率を伴う心房細動（＝完全 AVB）
- 各種 PVC（二連律）、II 度/III 度 AVB、洞房ブロック

<a id="126-低钾血症hypokalemia"></a>
## 12.6 低カリウム血症〈hypokalemia〉

| 血清カリウム | 心電図 |
|---|---|
| **< 3.5** | **T 波振幅の低下、低平**；**U 波の増大** |
| **< 3.0** | **U 波 > T 波**（V2–V3 で最も顕著）；**ST 低下**；T-U 融合 → 「QT 延長」のように見える（実際は **QU 延長**） |
| **< 2.5** | T 逆転、U 波の顕著化、**QU の顕著な延長 → 多形性室性頻拍（torsade de pointes）**；PR 延長、P 波の増高、QRS の増幅 |

- 観察に最適な誘導：**V2, V3**（U 波が最も顕著）
- 誘因：利尿薬、嘔吐/下痢、原発性アルドステロン症、クッシング症候群、インスリン、β刺激薬
- **低マグネシウム血症**は類似した所見を示し、低カリウムはしばしば低マグネシウムを合併する（カリウム補充で効果がない場合はマグネシウムを補充する必要がある）

<a id="127-巨大倒置-t-波gnt-giant-negative-t"></a>
## 12.7 巨大逆転 T 波〈GNT / giant negative T〉

**定義**：T 波逆転の深さが **> 1.0 mV（10 mm）**

**鑑別診断（5 つの主要な原因）**：

| 疾患 | 鑑別の手がかり |
|---|---|
| **心尖部肥大型心筋症（APH）** | **V4 で最も深い** + **左室高電圧** + **QT 延長なし（または軽度）** + Q 波なし；日本人に多い |
| **タコツボ心筋症** | **顕著な QT 延長**、強いストレス誘因あり、前期に ST 上昇あり、心尖部運動低下 |
| **脳血管障害（SAH、脳出血、脳梗塞）** | **極度の QT 延長 + 顕著な U 波** + 洞徐脈；神経学的症状あり |
| **心筋虚血 / Wellens 症候群** | **V2–V4** で両相性または深く逆転した T 波、R 波保持、胸痛の既往 → LAD 近位病変 |
| **完全房室ブロック / ペーシング後（心臓記憶 cardiac memory）** | 洞調律回復後も T 波がしばらく逆転し、方向は既往のペーシング QRS と一致 |

その他：副腎髄質腫、大量の心嚢液貯留後、急性肺塞栓症、間欠性 LBBB 後。

<a id="第-13-章-qt-延长与缩短"></a>
# 第 13 章 QT 延長と短縮

<a id="130-qt-的测量与判定"></a>
## 13.0 QT の測定と判定

- 測定誘導：**II、V5（最も長いものを選択）**；U 波の干渉がある誘導は避ける
- **QTc（Bazett）= QT / √RR(s)**
- **正常上限**：男性 0.44 秒、女性 0.46 秒；**≥ 0.48 秒（男性）/ 0.48 秒（女性）で明確な延長**；**≥ 0.50 秒は高リスク**
- **短縮**：QTc **≤ 0.34–0.36 秒**
- **QT 分散度（QT dispersion）**：12 誘導中最も長い QT − 最も短い QT で、> 0.06–0.08 秒は再分極の不均一性（不整脈リスク）を示唆

<a id="131-低钙血症hypocalcemia"></a>
## 13.1 低カルシウム血症〈hypocalcemia〉

| 特徴 |
|---|
| **ST 延長（平坦で引き伸ばされた状態）** → **QT 間期延長** |
| **T 波の形態、幅は正常**（重要：延長するのは ST であり T ではない） |
| 重症例では T 波の低平/逆転が見られる場合がある |

- 病因：副甲状腺機能低下症、慢性腎不全、ビタミン D 欠乏、大量輸血（クエン酸）、急性膵炎
- 他の QT 延長との鑑別：**低カルシウム = ST 延長型；薬剤/LQTS = T 波増幅型**

<a id="132-高钙血症hypercalcemia"></a>
## 13.2 高カルシウム血症〈hypercalcemia〉

| 特徴 |
|---|
| **ST 短縮または消失**（T 波が QRS の直後に続く）→ **QT 間期短縮** |
| 重症例では T 波の増幅、振幅増大；**J 波（Osborn 波）**が出現する場合がある |
| 極重度：PR 延長、QRS の増幅、房室ブロック、心停止 |

- 病因：副甲状腺機能亢進症、悪性腫瘍の骨転移/PTHrP、サルコイドーシス、ビタミン D 中毒、チアジド系利尿薬

<a id="133-先天性-qt-延长综合征congenital-lqts"></a>
## 13.3 先天性 QT 延長症候群〈congenital LQTS〉

<a id="诊断要素"></a>
### 診断要素

| # | 項目 |
|---|---|
| 1 | **QTc 延長**：≥ 0.48 秒で明確；0.46–0.47 秒で疑わしい |
| 2 | **T 波の形態異常**（下表参照）、**T 波電気交替（T-wave alternans）** —— 強く示唆 |
| 3 | **TdP / 失神 / 心停止**の発作歴 |
| 4 | **家族歴**（LQTS または 30 歳未満の不明原因突然死） |
| 5 | 徐脈（年齢に対して） |

<a id="主要基因型的心电图与诱因"></a>
### 主要な遺伝子型の心電図と誘因

| 型 | 遺伝子/チャネル | T 波の形態 | 典型的な誘因 |
|---|---|---|---|
| **LQT1（~45%）** | KCNQ1（IKs↓） | **基底が広く、滑らかな広大な T 波** | **運動、特に水泳**；交感神経興奮 |
| **LQT2（~40%）** | KCNH2/HERG（IKr↓） | **低振幅、ノッチ（切れ目）あり / 二峰性の T 波** | **突然の音刺激（目覚まし時計、電話）**、感情、産後 |

- **Romano-Ward 症候群**：常染色体優性、聴力正常

<a id="第-14-章-u-波增高与倒置"></a>
# 第 14 章 U 波の増高と逆転

<a id="140-u-波的基础"></a>
## 14.0 U 波の基礎
- 正常：T 波と同方向（直立）、振幅は **T の 1/2 未満**、**V2–V3 で最も明瞭**
- **U 波増高**：> 0.1–0.2 mV、または **U > T**
- **U 波逆転（陰転）**：**aVR 以外**のどの誘導でも U 波が逆転している場合は異常

| 分類 | 病因 |
|---|---|
| **U 波増高** | **低カリウム血症（最も一般的）**、低マグネシウム、徐脈、ジゴキシン、Ia/III 群抗不整脈薬、LQTS、SAH/脳血管障害、甲状腺機能亢進症、アスリート（生理的）、**後壁心筋虚血** |
| **U 波逆転** | **心筋虚血（特に前壁 / 左冠動脈主幹、LAD 病変）**、**高血圧/左室肥大**、大動脈弁閉鎖不全、僧帽弁閉鎖不全、高カリウム（稀） |

<a id="141-心肌缺血-前壁缺血u-波倒置"></a>
## 14.1 心筋虚血 — 前壁虚血（U 波逆転）

| # | 特徴 | 誘導 |
|---|---|---|
| 1 | **U 波逆転** | **V4–V6, I, aVL（左側胸誘導）** |
| 2 | **運動負荷試験中/後に新たに出現した U 波逆転** → **LAD 病変に対して高度に特異的**（特異度 > 90%） | V4–V6 |
| 3 | ST 部に変化がない場合でも単独で出現し得る —— 唯一の手がかり | |
| 4 | 安静時に出現する U 波逆転も、重度の左前降支狭窄または左冠動脈主幹病変を示唆 | |

<a id="142-心肌缺血-后壁缺血u-波增高"></a>
## 14.2 心筋虚血 — 後壁虚血（U 波増高）

| # | 特徴 | 誘導 |
|---|---|---|
| 1 | **U 波振幅の増高（直立）** | **V1–V3（右側胸誘導）** |
| 2 | 機序：後壁の U 波逆転が右胸誘導で**鏡像的な直立増高**として現れる | |
| 3 | **RCA または LCX（後壁を灌流する血管）の病変**を示唆 | |

> 記憶法：**左側誘導の U 波逆転 = 前壁虚血；右側誘導の U 波増高 = 後壁虚血**（互いに鏡像関係）。

<a id="第-15-章-提前出现的-p-或-qrs期前收缩"></a>
# 第 15 章 早期に出現する P 波または QRS（期外収縮）

> **最初の判断ポイント**：早期に出現する QRS **は幅広いか狭いか**？その前に**早期の P' 波はあるか**？

<a id="151-心室期前收缩pvc-vpc"></a>
## 15.1 心室期外収縮〈PVC / VPC〉

| # | 基準 |
|---|---|
| 1 | **早期に出現する幅広で変形した QRS、時間幅 ≥ 0.12 秒** |
| 2 | **その前に関連する P 波がない**（洞性 P 波が混在することはあるが関連しない） |
| 3 | **二次的 ST-T 変化**：ST-T の方向は QRS の主波と**逆** |
| 4 | **多くの場合、完全な代償間歇を伴う**（PVC の前後の 2 つの洞性 R 波の間の距離 = 正常 RR の 2 倍） |
| 5 | 固定された**連律間隔（coupling interval）**をしばしば伴う |

**起源部位の推定**：

| V1 の形態 | 起源 |
|---|---|
| **LBBB 型（V1 の主波が下向き）** | **右室**（または室中隔の左側近傍） |
| **RBBB 型（V1 の主波が上向き）** | **左室** |
| **下壁誘導（II, III, aVF）で高 R 波 + 電気軸が下向き** | **流出路（RVOT / LVOT）** |
| **下壁誘導の主波が下向き（電気軸が上向き）** | 心尖部 / 下壁 |
| 移行領域 ≤ V2 | LVOT / 大動脈窦 |

<a id="152-插入性-pvc-与伴代偿间歇的-pvc"></a>
## 15.2 挿入性 PVC と代償間歇を伴う PVC

| 型 | 定義 | 意義 |
|---|---|---|
| **完全代償間歇（compensatory pause）** | PVC の前後の 2 つの洞性 QRS の間の距離 **= 2 × 正常 RR**。逆伝導が AVN 内でブロックされ、洞房結節が再設定されないため | PVC の典型的な所見 |
| **挿入性（interpolated）PVC** | PVC が**2 つの正常な洞性拍動の間に挟まり、代償間歇がない**、総 RR は変化しない；徐脈時に頻見 | PVC 後の洞性拍動はしばしば **PR 延長**を伴う（隠蔽的逆伝導による AVN の不応期） |
| **不完全代償間歇** | 距離 < 2 × RR。**房性/結節性期外収縮**（逆伝導により洞房結節が再設定される）でみられる | 室上性起源を示唆 |

<a id="153-pvc-的分类"></a>
## 15.3 PVC の分類

<a id="形态学与配布"></a>
### 形態学と分布

| 分類 | 定義 |
|---|---|
| **単一源（単形性）** | 同じ誘導で形態が同一、連律間隔が固定 |
| **多源（多形性）** | 形態が 2 種類以上、連律間隔が固定されない |
| **二連律（bigeminy）** | 1 回の洞性拍動の後に 1 回の PVC が続く |
| **三連律（trigeminy）** | 2 回の洞性拍動の後に 1 回の PVC が続く |
| **対（couplet / pair）** | 連続する 2 回の PVC |
| **非持続性 VT** | 連続する 3 回以上の PVC、持続時間 < 30 秒 |
| **R on T 現象** | PVC が前の拍動の T 波の頂点付近に落ちる（脆弱期）→ **VF / TdP を誘発し得る** |

<a id="lown-分级急性-mi-中的危险度分层现代已较少用于非缺血患者"></a>
### Lown 分類（急性心筋梗塞における危険度層別化、現代では虚血性でない患者にはあまり使用されない）

| 級 | 内容 |
|---|---|
| 0 | PVC なし |
| 1 | 偶発的、1 時間あたり < 30 回 |
| 2 | 頻発、1 時間あたり ≥ 30 回 |
| 3 | 多源（多形性） |
| **4a** | **対（2連発）** |
| **4b** | **3連発以上（持続性でないVT）** |
| **5** | **R on T** |

> 現代の視点：**器質的疾患の有無（特に左室機能）は、Lown分類よりも予後を決定する**。器質的疾患のない頻発PVCは多くが良性であるが、PVC負荷が10–20%を超えるとPVC誘発性心筋症を引き起こす可能性がある。

**「良性PVC」のヒント**：運動後に減少/消失する、単形性、連律間期が固定されている、器質的疾患がない、QRSの時間幅が相対的に狭い（< 0.14秒）、RVOT起源の形態。

<a id="154-并行心律parasystole"></a>
## 15.4 並行律（parasystole）

| # | 3つの診断基準 |
|---|---|
| 1 | **連律間期が不固定**（異位拍動と直前の洞拍動との間隔の変化 > 0.08–0.1秒） |
| 2 | **異位拍動間の間隔（異位間隔）に最大公約数がある**（すべての異位間隔が最短間隔の整数倍である） |
| 3 | **融合拍動（fusion beat）の出現** |

- 機序：異位起搏点の周囲に**伝入ブロック（entrance block）**が存在し、洞調律による再整列を受けず、独立して発火する。
- 室性（最も一般的）、房性、結節性の場合がある。
- 一般的に予後は良好であり、不整脈薬への反応は悪い。

<a id="155-室上性期前收缩svpc-pac"></a>
## 15.5 室上性期外収縮〈SVPC / PAC〉

| # | 基準 |
|---|---|
| 1 | **早期に出現するP'波で、洞性P波とは形態が異なる**（早期化が大きいほど形態差が大きくなる；直前のT波の中に隠れていることが多い → **T波の形態が変形していないか注意深く観察する**） |
| 2 | **P'R間隔 ≥ 0.12秒**（房性）；PRは洞性より長くなることがある（AVNの部分不応期のため） |
| 3 | **QRSの形態は洞性と同一（狭い）** |
| 4 | **不完全補償間歇**（逆伝導により洞房結節が再整列される） |
| 5 | 例外：**差伝導（aberrant conduction）**時にはQRSが広くなり、右束枝の不応期が最も長いため、多くは**RBBB型（V1でrsR'）**を示す |

**SVPC伴差伝導 vs PVCの鑑別**：

| 項目 | SVPC伴差伝導 | PVC |
|---|---|---|
| 早期のP' | **あり**（直前のT波の中に隠れている） | なし |
| QRSの形態 | **多くはRBBB型（V1でrsR'、三相波）** | 多くは単相/双相で、形態がより不規則 |
| QRSの初期ベクトル | **洞性と同一** | 洞性と異なる |
| 補償間歇 | **不完全** | 完全 |
| 直前のRR | **長いRRの後に出現（Ashman現象）** | このような規則性はない |

<a id="156-室上性期前收缩的分类"></a>
## 15.6 室上性期外収縮の分類

| 分類軸 | 類別 |
|---|---|
| **起源部位** | **房性（PAC）**：P'が直立または形態異常、P'R ≥ 0.12秒<br>**結節性（PJC）**：P'が逆行性（II/III/aVFで逆位）または欠如、P'R < 0.12秒 |
| **伝導結果** | **正常伝導**：狭いQRS<br>**差伝導（aberrant）**：広いQRS（多くはRBBB型）<br>**非伝導（blocked / 下伝しない）**：P'の後にQRSがない |
| **分布** | 散発 / 二連律 / 三連律 / 対 / **短陣房性頻拍（≥ 3連発）** |
| **臨床的意義** | 頻発PAC（> 100–500回/日）は**新規心房細動の独立した予測因子**である |

---

<a id="第-16-章-该出现的-p-或-qrs-没有出现漏搏"></a>
# 第16章 出現すべきP波またはQRSが出現しない（脱落拍動）

> **鉄則：「長い間歇」を見つけたら、まず最初に前のT波の中に早期のP'（下伝しないSVPCが最も一般的な原因）が隠れていないか確認すること。**

<a id="161-窦性停搏sinus-arrest-sinus-pause"></a>
## 16.1 洞性停止（sinus arrest / sinus pause）

| # | 基準 |
|---|---|
| 1 | **P波とQRSが同時に欠如**し、長い間歇が出現する |
| 2 | **長い間歇は基本PP間隔の整数倍ではない** —— 洞房ブロックとの決定的な違い |
| 3 | 停止が**≥ 3.0秒**の場合、臨床的意義がある（覚醒時） |
| 4 | 長い間歇の後、結節性/室性逸脱拍動が出現することがある |

<a id="162-窦房阻滞sa-block"></a>
## 16.2 洞房ブロック〈SA block〉

| 型 | 基準 |
|---|---|
| **I度SAブロック** | 心電図では**診断不能**（洞房結節の電位は観測できない） |
| **II度Mobitz I型（Wenckebach型）** | **PP間隔が徐々に短縮**し、その後長い間歇が出現；**長い間歇 < 最短PPの2倍** |
| **II度Mobitz II型** | PPが一定で、**長い間歇はちょうど基本PPの整数倍（2倍、3倍…）に等しい** —— 決定的な基準 |
| **III度（完全性）SAブロック** | P波が完全に消失し、洞性停止と区別できない |

<a id="163-mobitz-ii-型-ii-度房室阻滞"></a>
## 16.3 Mobitz II型II度房室ブロック

| # | 基準 |
|---|---|
| 1 | **PR間隔が一定**（下伝する拍動） |
| 2 | **突然、P波の後にQRSがない**（予兆なし） |
| 3 | PP間隔は規則的（脱落箇所を含む） |
| 4 | **QRSはしばしば広くなる（束枝ブロックを合併）** —— ブロック部位が**His束以下（His-Purkinje系）**であることを示唆 |

**臨床的意義**：**高リスク**！完全性房室ブロックやAdams-Stokes症候群へ進展しやすい → **永久ペースメーカーの適応（無症状の場合でも）**。アトロピンは**無効または悪化させる**。

<a id="164-wenckebach-型mobitz-i-型ii-度房室阻滞"></a>
## 16.4 Wenckebach型（Mobitz I型）II度房室ブロック

| # | 基準 |
|---|---|
| 1 | **PR間隔が拍動ごとに延長**し、あるP波が下伝しない（QRSの脱落） |
| 2 | **PRの増分が徐々に減少** → **RR間隔が徐々に短縮** |
| 3 | **脱落を含む長いRR < 最短RRの2倍** |
| 4 | 脱落後の最初のPRが最も短い（周期が再開） |
| 5 | **QRSは多くが狭い** —— ブロック部位は**AVN内** |
| 6 | 伝導比は4:3、3:2などで表される |

**臨床的意義**：**多くは良性**（迷走神経緊張の亢進、アスリート、睡眠中、下行壁心筋梗塞、薬剤）。運動やアトロピンで改善する。無症状の場合は一般的にペースメーカーは不要。

<a id="165-未下传阻滞型室上性期前收缩blocked-svpc"></a>
## 16.5 下伝しない（ブロック型）室上性期外収縮〈blocked SVPC〉

| # | 基準 |
|---|---|
| 1 | 長い間歇の直前の**T波の形態が他のT波と異なる**（尖る、高くなる、ノッチが現れる）→ **その中に早期のP'が隠れている** |
| 2 | そのP'の後に**QRSがない**（早期すぎてAVNの絶対不応期に落ちるため） |
| 3 | 長い間歇の後、洞調律が回復する |

> **臨床的に最も価値のある鑑別点**：これは「脱落拍動」の最も一般的な原因であり、**完全に良性**であるが、II度房室ブロックや洞性停止と誤診され、不要なペースメーカー植え込みにつながる可能性が非常に高い。**T波の形態を一つずつ比較しなければならない！**

<a id="第-17-章-心动过缓"></a>
# 第17章 徐脈

<a id="171-窦性心动过缓sinus-bradycardia"></a>
## 17.1 洞性徐脈（sinus bradycardia）

| 基準 | 洞調律（P波正常）+ **心拍数 < 50–60回/分** |
|---|---|
| 生理的 | アスリート、睡眠中、迷走神経緊張の高い若年者 |
| 病的 | 甲状腺機能低下症、低体温、頭蓋内圧亢進、黄疸、**下行壁心筋梗塞**、SSS |
| 薬物的 | **β遮断薬、カルシウム拮抗薬（ベラパミル/ジルチアゼム）、ジギタリス、アミオダロン、抗コリンエステラーゼ薬** |

<a id="172-窦房结功能不全综合征sss"></a>
## 17.2 洞房結節機能不全症候群〈SSS〉

**Rubenstein分類**：

| 型 | 心電図 |
|---|---|
| **I型** | **持続的で顕著な洞性徐脈**（< 50回/分）、非薬物的 |
| **II型** | **洞性停止および/または洞房ブロック**（長い間歇） |
| **III型** | **徐脈-頻脈症候群**（17.3参照） |

- 診断補助：**心拍数変動の消失、運動時の心拍数上昇不良（クロノトロピック機能不全、最大心拍数< 100–120）**、阿托品试验（心率上升 < 25% 或 < 90 次/分为阳性）、电生理检查（SNRT > 1500 ms、CSNRT > 550 ms）**
- **症状（失神、めまい、心不全、易疲労）あり** + 徐脈との**因果関係の確認** → ペースメーカー適応

<a id="173-徐脉-频脉综合征brady-tachy-syndrome"></a>
## 17.3 徐脈-頻脈症候群（brady-tachy syndrome）

| # | 基準 |
|---|---|
| 1 | **頻拍性心房性不整脈（心房細動、心房粗動、心房頻拍）の発作** |
| 2 | その**終了後に長時間の洞停止（洞停止）** が出現 —— "**過剰抑制（overdrive suppression）**" |
| 3 | 長い間歇は通常 > 3–5 秒 → **失神（Adams-Stokes 発作）** |

- 治療上のジレンマ：抗不整脈薬は徐脈を悪化させる → **ペースメーカー + 抗不整脈薬/カテーテル焼灼術の併用がしばしば必要**。

<a id="174-21-房室阻滞"></a>
## 17.4 2:1 房室ブロック

| # | 基準 |
|---|---|
| 1 | **P 波 2 個につき 1 個が伝導**（P 数 = QRS 数 × 2） |
| 2 | 伝導した拍動の **PR 間隔が一定** |
| 3 | **2:1 伝導のみでは Mobitz I 型か II 型か判断不能**（PR 間隔の連続的な変化が見えないため） |

**ブロック部位を推定する手がかり**：

| AVN 内を示唆（I 型様、比較的良性） | His 束以下を示唆（II 型様、高リスク） |
|---|---|
| **QRS が狭い** | **QRS が広い（束枝ブロック）** |
| **PR 間隔が著しく延長（> 0.30 秒）** | PR 間隔は正常 |
| 運動/アトロピン投与後に伝導が**改善** | 運動/アトロピン投与後に**悪化** |
| 頸動脈洞圧迫後に伝導が**悪化** | 圧迫後に**改善** |
| 下壁心筋梗塞、ジギタリス、迷走神経緊張の亢進を伴うことが多い | 前壁心筋梗塞、伝導系の加齢性変化を伴うことが多い |

<a id="175-高度房室阻滞advanced-high-grade-avb"></a>
## 17.5 高度房室ブロック（advanced / high-grade AVB）

| 基準 | **連続する ≥ 2 個の P 波が伝導しない**（伝導比 ≥ 3:1、例：3:1、4:1） |
|---|---|
| 特徴 | 一部の P 波は伝導する（PR 間隔は固定）→ 完全性 AVB との区別点 |
| 頻繁に伴うもの | 房室結節性/心室性逸脱拍動、逸脱-奪取二重脈 |
| 意義 | **高リスク、ペースメーカー適応** |

<a id="176-完全性房室阻滞iii-度-avb"></a>
## 17.6 完全性房室ブロック（III 度 AVB）

| # | 基準 |
|---|---|
| 1 | **P 波と QRS が完全に無関係（房室分離）** —— PR 間隔は不規則に変動 |
| 2 | **PP 間隔は規則的**（心房拍数 > 心室拍数） |
| 3 | **RR 間隔は規則的**（逸脱リズム、PP より遅い） |
| 4 | P 波数 > QRS 数 |

**逸脱リズムのレベルが予後を決定する**：

| 逸脱の起源 | QRS | 頻度 | リスク度 |
|---|---|---|---|
| **AVN / His 束（房室結節性）** | **狭い（< 0.12 秒）** | **40–60 回/分** | 比較的安定、アトロピンが有効な場合あり |
| **His 束以下（心室性）** | **広い（≥ 0.12 秒）** | **20–40 回/分** | **高リスク**（心停止や TdP を起こしやすい）、アトロピンは無効 |

**特殊な状況**：
- **心房細動 + 規則的で徐脈性の RR** → **心房細動合併完全性 AVB**（ジギタリス中毒が原因の場合が多い）
- **先天性完全性 AVB**：多くは房室結節性逸脱、狭い QRS、頻度は速め（50–60 回/分）、予後は比較的良い
- **完全性 AVB + QT 延長 → TdP（「心停止発作」）** に注意が必要

**房室分離 ≠ 完全性 AVB**：心室拍数が心房拍数より多い場合（加速性房室結節性リズム、心室頻拍など）は「干渉性房室分離」と呼ばれ、機序は全く異なる。

<a id="第-18-章-心动过速窄-qrs规则"></a>
# 第 18 章 頻脈：狭い QRS、規則的

> **解析手順**：① 心拍数は？② P'波は見つかるか？③ **P'の位置は（RP'間隔）**？④ 迷走神経刺激/アデノシンへの反応は？

<a id="180-窄-qrs-心动过速的鉴别流程"></a>
## 18.0 狭い QRS 頻脈の鑑別手順

```
窄 QRS 心动过速（QRS < 0.12 s）
├── 不规则 → 房颤 / 房扑伴不等比传导 / 多源性房速
└── 规则
    ├── 有正常窦性 P（P 在 QRS 前，形态同窦性）
    │   ├── 心率 100–180，渐起渐止 → 窦性心动过速
    │   └── 突发突止 → 窦房结折返性心动过速（SANRT）
    ├── 找不到 P（藏在 QRS 内）→ AVNRT（典型型）
    ├── P' 在 QRS 之后、ST 段上（RP' 短，< 1/2 RR）
    │   ├── RP' < 70 ms → AVNRT
    │   └── RP' > 70 ms → AVRT（顺向型）
    ├── P' 在 T 波附近（RP' 长，> 1/2 RR）→ 房速 / 非典型 AVNRT / PJRT
    └── 锯齿状 F 波，心率 ≈150 → 2:1 心房扑动
```

**アデノシン（ATP）/ 迷走神経刺激への反応**：
- **突然の停止** → AVNRT または AVRT（AVN が再入ループの一部である）
- **一時的な徐化後の回復** → 洞性頻脈、心房性頻脈
- **房室伝導比の増加、F/P' 波の露出** → 心房粗動、心房性頻脈

<a id="181-窦性心动过速sinus-tachycardia"></a>
## 18.1 洞性頻脈（sinus tachycardia）

| # | 基準 |
|---|---|
| 1 | 洞性 P 波（II、III、aVF で直立、aVR で逆転）、形態は安静時と同じ |
| 2 | **心拍数 100–180 回/分**（上限 ≈ 220 − 年齢） |
| 3 | **徐々な開始、徐々な停止**（ウォームアップ / クールダウン） |
| 4 | 心拍数は呼吸/体位/感情によって軽微に変動する |
| 5 | 速い場合、P 波が前の T 波と融合することがある → 「こぶ状の T 波」に注意 |

- 病因：発熱、貧血、脱水、疼痛、不安、甲状腺機能亢進症、心不全、ショック、肺塞栓症、カフェイン/カテコールアミン/薬剤
- **「症状」であり疾患ではない** → 原因を探し、β遮断薬を盲目的に使用しない

<a id="182-阵发性室上性心动过速-房室折返性心动过速avrt"></a>
## 18.2 発作性上室性頻脈 — 房室再入性頻脈〈AVRT〉

| # | 基準 |
|---|---|
| 1 | 心拍数 **150–250 回/分**、リズムは**完全に規則的** |
| 2 | **突然の開始と突然の停止（発作性）** |
| 3 | **順行性（orthodromic、90%）：狭い QRS**（AVN を介して前伝、傍路を介して逆伝） |
| 4 | **逆行性 P'（II/III/aVF で逆転）は QRS 後の ST 区上に位置し**、**RP' > 70 ms** かつ **RP' < P'R** |
| 5 | **QRS 電気交替（QRS alternans）** —— AVRT に比較的固有 |
| 6 | 洞調律時に **δ 波（顕性 WPW）** が認められる；潜性傍路では洞調律は正常 |
| 7 | **逆行性（antidromic、5–10%）：広い QRS**（傍路を介して前伝）→ 第 19 章参照 |
| 8 | 頻脈中に**束枝ブロック（傍路と同じ側）が出現し、周期が ≥ 35 ms 延長** → AVRT を強く示唆 |

<a id="183-阵发性室上性心动过速-房室结折返性心动过速avnrt"></a>
## 18.3 発作性上室性頻脈 — 房室結再入性頻脈〈AVNRT〉

| # | 基準 |
|---|---|
| 1 | 心拍数 **150–250 回/分**（通常 180 前後）、完全に規則的 |
| 2 | 突然の開始と突然の停止；**PR 間期の突然な飛躍的延長（jump up）を伴う PAC** によって誘発されることが多い |
| 3 | **典型例（slow-fast、90%）：P' が QRS 内に埋没し、見えない**；または QRS の直後に続き、**RP' < 70 ms** |
| 4 | **偽性 r' 波（pseudo-r'）：V1** に洞調律時に見られない小さな r' が出現（洞調律時はなし） |
| 5 | **偽性 S 波（pseudo-s）：II、III、aVF** に洞調律時に見られない終末の小さな s が出現 |
| 6 | **非典型例（fast-slow / slow-slow、10%）**：**RP' が長く**、P' が T 波の前にあり、II/III/aVF で深く逆転 → 心房性頻脈と混同しやすい |
| 7 | **最も一般的な PSVT**（約 60%）、中年女性に好発 |

**AVNRT vs AVRT 速習表**：

| 項目 | AVNRT | AVRT（順行性） |
|---|---|---|
| RP' | **< 70 ms** | **> 70 ms** |
| P' の位置 | QRS 内に埋没 / 直後 | ST 区上にあり、明確に見える |
| 偽性 r'(V1)、偽性 s(下壁) | **あり** | なし |
| QRS 電気交替 | 少ない | **多い** |
| 洞調律時の δ 波 | なし | あり得る（顕性 WPW） |
| 好発年齢 | 中年、女性が多い | 若年、男性が多い |

<a id="184-阵发性室上性心动过速-窦房结折返性心动过速sanrt-sart"></a>
## 18.4 発作性上室性頻脈 — 洞房結再入性頻脈〈SANRT / SART〉

| # | 基準 |
|---|---|
| 1 | **P 波の形態が洞性と完全に同一、または極めて類似**（再入ループは洞房結内/周囲にある） |
| 2 | **突然の開始と突然の停止** —— 洞性頻脈との**決定的な違い** |
| 3 | 心拍数は比較的遅い：**100–150 回/分** |
| 4 | PR 間期は正常またはやや延長（心拍数に一致） |
| 5 | PAC によって誘発および停止可能；迷走神経刺激で停止可能 |
| 6 | 稀（PSVT の < 5%） |

<a id="185-房性心动过速at"></a>
## 18.5 心房性頻脈〈AT〉

| # | 基準 |
|---|---|
| 1 | **P' 波の形態が洞性 P と異なる**（異所性起源） |
| 2 | **心房率 100–250 回/分**（多くは 150–200） |
| 3 | **P' 波の間に等電位線がある** —— 心房粗動（等電位線なし）との違い |
| 4 | **P'R 間期は正常または延長** しており、**RP' > P'R（長 RP' 型）** |
| 5 | **房室ブロック（2:1 など）を伴うことがあり、頻脈は停止しない** —— AVNRT/AVRT との決定的な違い（後者では AVN は再入ループの必須部分である） |
| 6 | 開始時に**「ウォームアップ（warm-up）現象」**が認められることが多い（自律性機構） |

- **多源性心房性頻脈（MAT）**：P' の形態 ≥ 3 種類、PP/PR が不規則、心拍数 > 100 → **重症 COPD、テオフィリン中毒、低カリウム血症**
- **房室ブロックを伴う心房性頻脈（PAT with block）** → **まずジギタリス中毒を疑う**

<a id="186-21-传导的心房扑动"></a>
## 18.6 2:1 伝導の心房粗動

| # | 基準 |
|---|---|
| 1 | **心室率は ~150 回/分（140–160）で一定** —— **この心拍数の規則的な狭い QRS 頻脈が見られた場合、まず 2:1 心房粗動を除外する必要がある** |
| 2 | F 波の周波数は ~300 回/分、その半分は QRS または T 波の中に隠れている |
| 3 | **II、III、aVF ののこぎり状の基線** と **V1 の直立の P 様波** を観察する |
| 4 | **心拍数の変化は「ジャンプ式」**（150 → 100 → 75、2:1 → 3:1 → 4:1 に相当）であり、連続的な変化ではない |
| 5 | **確認方法**：頸動脈洞マッサージ / アデノシン → 房室比が増加し、F 波が完全に露出する |

<a id="第-19-章-心动过速宽-qrs规则"></a>
# 第 19 章 頻脈：広い QRS、規則的

> **原則：広い QRS 頻脈は、確定診断が出るまで、すべて室性頻脈（VT）として扱う。** 救急現場では、VT は広い QRS 頻脈の **80%** を占める（既往に心筋梗塞がある場合は > 95%）。
> **禁忌**：原因不明の広い QRS 頻脈にはベラパミルは禁忌（血流力学的崩壊を引き起こす可能性がある）。

<a id="190-vt-vs-svt-伴差传的鉴别标准"></a>
## 19.0 VT vs 差伝を伴う SVT の鑑別基準

<a id="支持-vt-的决定性所见三大法宝"></a>
### VT を支持する決定的所見（「三大法宝」）

| # | 所見 | 説明 |
|---|---|---|
| 1 | **房室分離（AV dissociation）** | 独立した P 波が独自の周波数で出現し、QRS とは無関係。**最も特異的（特異度 ~100%）** だが、約 20–30% しか認められない。II、V1、食道誘導で確認 |
| 2 | **心室奪取（capture beat）** | 頻脈中に突然 1 つの**狭い QRS**（洞性興奮の伝導）が出現 → VT の確定診断 |
| 3 | **融合拍（fusion beat）** | 洞性興奮と室性興奮が同時に心室を興奮させ、QRS の形態が両者の中間になる → VT の確定診断 |

<a id="其他支持-vt-的所见"></a>
### VT を支持するその他の所見

| 所見 | 内容 |
|---|---|
| **QRS の著しい広大化** | RBBB 型 > 0.14 秒；LBBB 型 > 0.16 秒 |
| **胸誘導の同向性（concordance）** | **V1–V6 の QRS の主波がすべて上向き、またはすべて下向き**（すべて下向き＝陰性同向性、VT をほぼ確定） |
| **電気軸の極端な偏移（「無人地帯軸」）** | −90° ～ ±180°（北西軸） |
| **RS 型の欠如（Brugada 第 1 段階）** | すべての胸誘導で RS 形態がない → VT |
| **RS 間隔 > 100 ms（Brugada 第 2 段階）** | いずれかの胸誘導で R の開始から S の最低点まで > 100 ms → VT |
| **aVR 起始 R 波（Vereckei 基準）** | aVR に起始 R 波 → VT |
| **V1 波形（RBBB 型の場合）** | 単相 R、**qR**、**Rsr'（左耳 > 右耳、「ウサギ耳徴候」）** → VT；三相 rsR'（右耳>左耳）→ SVT |
| **V6 波形（RBBB 型の場合）** | **R/S < 1**、QS、qR → VT |
| **V1/V2 波形（LBBB 型の場合）** | **r 波幅 > 30 ms**、S 波降支にノッチ、**QRS 起点から S 底まで > 60 ms** → VT |
| **V6 に Q 波あり（LBBB 型の場合）** | qR または QS → VT |
| **臨床的ヒント** | **陈旧性心筋梗塞の既往、心機能低下、年齢 > 35 歳** → VT を強く示唆 |

<a id="支持-svt-伴差异传导的所见"></a>
### SVT 伴う差伝導を支持する所見
- **典型的な RBBB または LBBB 波形**（V1 で三相 rsR'、V6 に qRs）
- **QRS 起始ベクトルが洞調律時と同じ**
- 既往の洞調律心電図で既に存在する束枝ブロック波形と**完全に一致**
- アデノシンで終息可能
- 頻拍の開始が早期 P' 波によって誘発される

<a id="191-心室心动过速vt"></a>
## 19.1 心室頻拍〈VT〉

| # | 基準 |
|---|---|
| 1 | **連続 ≥ 3 拍（一般的定義では ≥ 3 または ≥ 5 拍）の室性拍動**、頻度 **> 100（多くは 130–250）回/分** |
| 2 | **QRS ≥ 0.12 s（多くは > 0.14 s）、広大で歪んだ波形** |
| 3 | 律動は**概ね規則的**（RR 変動 < 0.02–0.04 s） |
| 4 | **房室分離 / 奪取拍動 / 融合拍動**（上記参照） |
| 5 | ST-T の方向が QRS の主波と逆 |

**分類**：
- **持続性（sustained）**：30 秒以上持続、または血流力学的不安定により終息が必要
- **非持続性（non-sustained, NSVT）**：30 秒未満で自発的に終息
- **単形性（monomorphic）**：QRS の波形が一定 —— 多くは器質的基盤（陈旧性 MI による瘢痕折返）あり
- **多形性（polymorphic）**：波形が変化 —— 急性虚血、LQTS（→TdP）、Brugada、CPVT
- **双方向性（bidirectional）**：QRS の電軸が拍動ごとに交互に変化 —— **ジギタリス中毒、CPVT**

<a id="192-特发性室性心动过速左室左后分支起源"></a>
## 19.2 特発性心室頻拍（左室、左後枝起源）

**別名**：枝頻拍（fascicular VT）、**ベラパミル感受性 VT**、Belhassen 型

| # | 特徴 | 誘導 |
|---|---|---|
| 1 | **RBBB 型**（V1 の主波が上向き） | V1 |
| 2 | **左軸偏位（左後枝起源、最も一般的）** | 四肢誘導 |
| 3 | **QRS が比較的狭い（0.12–0.14 s）** —— His-Purkinje 系起源のため | |
| 4 | **左前枝起源**の場合 → RBBB 型 + **右軸偏位** | |
| 5 | 心拍数 150–200、**器質性心疾患のない若年男性**に多い | |
| 6 | **ベラパミルに有効**（アデノシン、リドカインには無効）；予後良好、カテーテル焼灼成功率が高い | |

<a id="193-特发性室性心动过速右室流出道起源rvot-vt"></a>
## 19.3 特発性心室頻拍（右室流出路起源、RVOT-VT）

| # | 特徴 | 誘導 |
|---|---|---|
| 1 | **LBBB 型**（V1 の主波が下向き、rS/QS 型） | V1, V2 |
| 2 | **下壁誘導で高大な直立 R 波（電軸が下向き、約 +90°）** | **II, III, aVF** |
| 3 | **移行域が V3–V4**（V2 以下の場合 → 左室流出路/大動脈洞起源を疑う） | V1–V6 |
| 4 | I 誘導は多く rS または QS（遊離壁起源）/ R（中隔起源） | I |
| 5 | 運動や精神的緊張で誘発されやすい（カテコールアミン依存性）；若年～中年、器質性心疾患なしに多い | |
| 6 | **アデノシン、β遮断薬、ベラパミルに有効**；予後良好 | |

> **重要な鑑別：不整脈性右室心筋症（ARVC）** も LBBB 型 VT を呈するが、洞調律時に **V1–V3 の ε 波、T 波逆転、QRS 終末興奮遅延 ≥ 55 ms** を認め、多形性で家族歴がある → 予後が全く異なる。

<a id="194-伴束支阻滞差异传导的-psvt"></a>
## 19.4 束枝ブロック（差伝導）を伴う PSVT

| # | 特徴 |
|---|---|
| 1 | 心拍数 150–250、完全に規則的 |
| 2 | **QRS が典型的な RBBB または LBBB 波形**（V1 で三相 rsR'；V6 に qRs、R/S > 1） |
| 3 | **房室分離、奪取拍動、融合拍動なし** |
| 4 | **QRS 起始ベクトルが洞調律時と同じ** |
| 5 | 既往の洞調律時に既に存在する束枝ブロック波形と一致（「既存性束枝ブロック」）；または速い心拍数のみで出現（「頻度依存性/第3相ブロック」） |
| 6 | アデノシン/迷走神経刺激で終息可能 |

<a id="195-经旁路前传的-psvt逆向型-avrt-预激性心动过速"></a>
## 19.5 傍路前伝を伴う PSVT（逆向性 AVRT / 前興奮性頻拍）

| # | 特徴 |
|---|---|
| 1 | **QRS が広大で歪む（完全前興奮波形）**、心室全体が傍路によって興奮されるため |
| 2 | 規則的、心拍数 150–250 |
| 3 | 洞調律時の心電図に **δ 波（顕性 WPW）** があり、**頻拍時の QRS 波形は洞調律時の δ 波波形の「拡大版」** —— 重要な手がかり |
| 4 | 逆行性 P' が QRS の後に位置する（RP' 長） |
| 5 | VT との鑑別が極めて困難 → **不確かな場合は VT として治療** |
| 6 | 治療：**プロカインアミド / イブリド / 電気的除細動；ジギタリス、ベラパミル、アデノシンは禁忌（VF を誘発する可能性）** |

<a id="第-20-章-心动过速不规则窄或宽-qrs"></a>
# 第 20 章 頻拍：不規則（狭いまたは広い QRS）

<a id="201-心室颤动vf-vf"></a>
## 20.1 心室細動〈VF / Vf〉

| # | 基準 |
|---|---|
| 1 | **P、QRS、T が全く識別できない無秩序な波形** |
| 2 | **振幅、頻度、間隔がすべて不規則**、頻度 150–500 回/分 |
| 3 | **粗細動（coarse VF）**：振幅 ≥ 0.5 mV、除細動成功率が高い |
| 4 | **細細動（fine VF）**：振幅 < 0.2–0.3 mV、心停止に近い、まず CPR/アドレナリンが必要 |
| 5 | 臨床的には必ず意識消失、脈拍消失を伴う |

**除外すべきアーチファクト（偽差）**：筋電図、体動、電極接触不良、CPR 圧迫 —— **患者を見よ、モニターだけを見ないこと！** アーチファクト時は、無秩序な波の中に規則的な QRS が「透けて見える」ことがある。

<a id="202-尖端扭转型室速torsade-de-pointes-tdp"></a>
## 20.2 尖捻転型心室頻拍〈torsade de pointes, TdP〉

| # | 基準 |
|---|---|
| 1 | **多形性 VT、QRS の極性/振幅が基線周りで螺旋状に「捻転」**、5–20 拍ごとに反転 |
| 2 | **頻度 200–250 回/分** |
| 3 | **発作前の基礎律動に QT 延長（QTc > 0.50 s）+ 顕著な U 波** —— 診断に必須 |
| 4 | **「短-長-短（short-long-short）」系列で開始**：PVC → 長い補償間歇 → 次の拍で QT がさらに延長 → **R on T 型 PVC** によって誘発 |
| 5 | 多くは**自己制限性（数秒〜数十秒）**、再発 → 失神；**VF** へ移行する可能性あり |

**病因**：
- **獲得性**：薬剤性 LQT（13.4 参照）、**低カリウム/低マグネシウム/低カルシウム**、**徐脈（完全性 AVB、洞停止）**、飢餓/極端な食事制限、脳血管障害、心筋炎
- **先天性**：LQTS（13.3 参照）

**治療**：**硫酸マグネシウムの静注（第一選択、血中マグネシウムが正常でも）**、電解質の是正、原因薬剤の中止、**心拍数の上昇（イソプロテレノールまたはオーバードライブペーシング）**；**Ia/III 群抗不整脈薬は禁忌**。
> 注意：**短 QT 背景の多形性 VT は TdP とは呼ばない**（Brugada、CPVT、虚血など）。治療戦略が異なる（Brugada はイソプロテレノール/キニジン、CPVT は β 遮断薬）。

<a id="203-假性室速pseudo-vt"></a>
## 20.3 偽性心室頻拍〈pseudo-VT〉

### ① 预激综合征合并心房颤动（WPW + AF）—— 最重要的“真病”

| # | 特征 |
|---|---|
| 1 | **极快的心室率（常 > 200，可达 300 次/分）** |
| 2 | **RR 间期绝对不整** —— 与 VT 的关键区别 |
| 3 | **QRS 宽大畸形，且形态逐搏变化**（预激程度不同：完全预激、部分预激、正常传导的融合） |
| 4 | 最短 RR **< 250 ms** → **VF 高危** |
| 5 | 窦律恢复后可见 δ 波 |
| 6 | **治疗：立即电复律；药物用普鲁卡因胺/伊布利特。绝对禁用洋地黄、维拉帕米、地尔硫䓬、腺苷、β 阻滞剂**（阻断 AVN 会使全部冲动经旁路下传 → VF） |

### ② 伪差（artifact）造成的假性 VT

| 线索 |
|---|
| 杂乱波形中**可辨认出规则的窦性 QRS"穿透"其间**（"sinus spikes"） |
| 波形**仅出现在部分导联**（对应某一个电极） |
| 起止**突兀**，前后 RR 完全不受影响 |
| **患者状态良好、脉搏正常** |
| 常见原因：帕金森病震颤、刷牙/搔抓、电极松脱、寒战 |

### ③ 其他易误认为 VT 的情形
- **高钾血症的正弦波**（宽 QRS + 无 P 波）
- **起搏器介导性心动过速（PMT）**：起搏 QRS 宽，频率恒定在上限跟踪频率（如 120–130）
- 严重 IVCD（Ic 类药物中毒）+ 窦速

# 第 21 章 先天性心脏病

> 先天性心脏病心电图的核心逻辑：**血流动力学负荷类型（容量 vs 压力）× 受累心腔（左 vs 右）→ 特征性心电图**。

## 21.1 心房间隔缺损〈ASD〉

### 继发孔型（secundum ASD，最常见）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **不完全性右束支阻滞（rsR' 型）** —— **最具特征**（右室容量负荷） | **V1** |
| 2 | **电轴右偏（+90° ～ +150°）** | 肢体导联 |
| 3 | **右房扩大**（P 高尖 ≥ 0.25 mV） | II, III, aVF |
| 4 | **I 度房室阻滞**（PR 延长，约 20%） | |
| 5 | **Crochetage 征**：下壁导联 R 波升支上的切迹（特异性高） | **II, III, aVF** |
| 6 | 年长后：房颤/房扑；肺高压时呈真正的 RVH（V1 高 R + ST-T 劳损） | |

### 原发孔型（primum ASD / 房室间隔缺损）

| # | 特征 |
|---|---|
| 1 | **电轴左偏（−30° ～ −90°）＝左前分支阻滞型** —— **决定性鉴别点**（传导系统移位） |
| 2 | 不完全性 RBBB（同样存在） |
| 3 | I 度房室阻滞更常见 |
| 4 | 常合并二尖瓣裂缺 → 左室容量负荷 |

> **口诀：ASD + 电轴右偏 = 继发孔型；ASD + 电轴左偏 = 原发孔型。**

## 21.2 心室间隔缺损〈VSD〉/ 动脉导管未闭〈PDA〉

| 分流量 | 心电图 |
|---|---|
| **小分流（Roger 病）** | **正常心电图** |
| **中等分流** | **左室容量负荷型**：V5–V6 **深而窄的 q 波 + 高 R 波 + 高耸直立 T 波**；左房扩大 |
| **大分流（肺高压前）** | 左室容量负荷 + 右室负荷 → **双心室肥大** |
| **Katz-Wachtel 现象** | **中间胸导联（V2–V4）出现高大的双向 QRS（R 与 S 均 > 5 mm，"RS 巨大"）** → 双心室肥大的标志 |
| **Eisenmenger 化后** | 转为**纯右室肥大型**：V1 高 R、电轴右偏、右房扩大、V1–V3 ST-T 劳损；左室征象消失 |

- **PDA** 与 VSD 的心电图基本相同（均为左室容量负荷 + 肺血流增加）。

## 21.3 肺动脉瓣狭窄〈PS〉

**核心：纯粹的右室压力负荷，其程度与狭窄严重度平行**（是心电图能"定量"评估的少数疾病）。

| 严重度 | 心电图 |
|---|---|
| **轻度**（跨瓣压差 < 50 mmHg） | 正常或轻度电轴右偏、V1 rsR' |
| **中度**（50–80 mmHg） | **V1 的 R ≥ 1.0 mV**、电轴右偏 +90°～+120° |
| **重度**（> 80–100 mmHg） | **V1 呈高大单相 R 波（≥ 2.0 mV）或 qR 型**、**V1–V3 ST 压低 + T 倒置（劳损型）**、**电轴 > +120°**、**右房扩大（P 高尖）** |

- **V1 的 R 波振幅（mm）× 5 ≈ 右室收缩压（mmHg）** 的经验估算。
- **V1 出现 q 波（qR）→ 提示重度右室肥大**。

## 21.4 法洛四联症〈TOF〉

| # | 特征 | 导联 |
|---|---|---|
| 1 | **显著右室肥大**：V1 呈**高大单相 R 波或 qR** | **V1** |
| 2 | **移行突然（abrupt transition）**：从 V1 的高 R **骤然**变为 V2 的 rS —— 特征性 | **V1 → V2** |
| 3 | **电轴右偏（+90° ～ +150°）** | 肢体导联 |
| 4 | **右房扩大**（P 高尖），但通常不如 PS 显著 | II, V1 |
| 5 | V1 的 T 波直立（新生儿期后 T 直立＝RVH 的敏感指标） | V1 |
| 6 | **术后**：几乎必然出现 **完全性 RBBB**（右室切开/流出道补片）；**QRS 时限 ≥ 180 ms 是术后猝死/持续性 VT 的强预测因子** | V1 |

## 21.5 Ebstein 畸形

| # | 特征 | 导联 |
|---|---|---|
| 1 | **巨大的 P 波（"喜马拉雅 P 波 / Himalayan P wave"）**：高度可 > 0.5 mV，宽度也增加 —— 极度右房扩大 | **II, V1** |
| 2 | **完全性或不完全性 RBBB，但 V1 的 QRS 振幅极低、呈碎裂多相波（低电压、粗钝）** —— 与普通 RBBB 的关键区别（房化右室是薄壁无效心肌） | **V1, V2** |
| 3 | **PR 间期延长（I 度房室阻滞）** | |
| 4 | **合并 WPW（B 型，右侧旁路）的比例高（约 20%）** → 短 PR + δ 波，可掩盖上述表现 | V1 |
| 5 | 常有房性心律失常（房扑、房颤、PSVT） | |
| 6 | 电轴可右偏或正常 | |

## 21.6 矫正型大动脉转位（先天性矫正型 TGA / ccTGA）

**核心机制：室间隔的激动方向逆转（从右向左变为从左向右）** —— 因传导系统与心室的解剖关系反转。

| # | 特征 | 导联 |
|---|---|---|
| 1 | **右侧胸导联出现 q 波（V1、V2 呈 qR 型）** —— 特征性 | **V1, V2** |
| 2 | **左侧胸导联的间隔 q 波消失（V5、V6 无 q）** —— 特征性 | **V5, V6** |
| 3 | 下壁导联（II, III, aVF）可出现 Q 波（假性下壁梗死） | II, III, aVF |
| 4 | **各种程度的房室阻滞（I 度 → 完全性）**，发生率随年龄增加（**每年约 2% 进展为完全性 AVB**） | |
| 5 | 电轴左偏（PQ 轴异常）；可有异位心房节律 | |
| 6 | 常合并 VSD、肺动脉狭窄、Ebstein 样三尖瓣畸形 → 叠加相应表现 | |

> **口诀：V1 有 q、V5–V6 无 q + 房室阻滞 → 想到矫正型大血管转位。**

<a id="附录-b-从异常出发的鉴别流程速查"></a>
# 付録B 異常からの鑑別フロー（クイックリファレンス）

<a id="b1-宽-qrs的鉴别"></a>
## B.1 「広幅 QRS」の鑑別

```
QRS ≥ 0.12 s
├── 有提前的窦性/房性 P 且 PR 正常
│   ├── V1 呈 rsR'、I/V6 有宽 S → 右束支阻滞
│   ├── V1 呈 rS/QS、V5-V6 宽顿挫 R 无 q → 左束支阻滞
│   └── 都不像 → 非特异性 IVCD（查血钾、查药物！）
├── PR < 0.12 s + δ 波 → WPW 综合征
├── 无 P 波，规则，20-40/min → 心室固有节律
├── 无 P 波，规则，60-100/min → AIVR
├── 无 P 波，> 100/min → 室性心动过速（或 SVT 伴差传，见 19.0）
├── 无 P，QRS 与 T 无法区分，T 高尖 → 高钾血症
└── 有起搏钉（spike）→ 心室起搏心律
```

## B.2 「V1 出现高 R 波」的鉴别（6 大原因）

| 原因 | 关键鉴别点 |
|---|---|
| **右束支阻滞** | QRS ≥ 0.12 s，V1 呈 rsR'，I/V6 宽 S |
| **右室肥大** | 电轴右偏 ≥ +110°，V1 ST-T 劳损，右房扩大，V5-V6 深 S |
| **后壁梗死** | V1-V2 ST 压低 + 高 T，V7-V9 有 Q/ST 抬高，常伴下壁改变 |
| **WPW（A 型）** | PR < 0.12 s，δ 波 |
| **逆钟向转位** | 移行区左移至 V2，其余正常 |
| **正常变异 / 儿童 / 瘦体型** | 无其他异常 |

## B.3 「电轴左偏」的鉴别

左前分支阻滞 / 下壁陈旧 MI（II、III、aVF 有异常 Q）/ 左室肥大 / LBBB / 横位心（肥胖、妊娠、腹水）/ 原发孔型 ASD / WPW / 高钾 / 起搏心律

## B.4 「电轴右偏」的鉴别

右室肥大 / 左后分支阻滞（排除性诊断）/ 侧壁 MI（I、aVL 有 Q）/ 垂位心（瘦长）/ COPD・肺气肿 / 急性肺栓塞 / 继发孔型 ASD / 右位心・电极接错 / 婴幼儿（生理性）

## B.5 「长间歇（漏搏）」的鉴别顺序

```
1. 看长间歇前的 T 波形态 → 有变形？→ 未下传的 SVPC（最常见，良性）
2. 长间歇是基本 PP 的整数倍？→ 是：II 度 SA 阻滞（Mobitz II 型）
                                → 否：窦性停搏
3. 有 P 波但后面没 QRS？→ II 度房室阻滞
   ├── PR 逐渐延长后脱落 → Wenckebach（良性，AVN 内）
   └── PR 固定后突然脱落 → Mobitz II（高危，His 以下）
4. P 与 QRS 完全无关 → 完全性房室阻滞
5. 房颤 + 长间歇 → 药物过量 / 合并 AVB
```

<a id="b6-窄-qrs-心动过速心率-150必查"></a>
## B.6 「狭い QRS 頻脈（心拍数 ~150）」の必須チェック

**まず一律に2:1心房粗動を除外する**（II/III/aVFの鋸歯状基線、V1の直立F波を確認；必要に応じてアデノシン/迷走神経刺激）。

<a id="b7-st-抬高的-5-秒判断"></a>
## B.7 「ST上昇」の5秒判断

**上凸＋冠動脈支配領域に局在＋鏡像的ST低下＋動態的変化 ＝ STEMI、直ちに再灌流プロトコルを開始。**
