# 統合臨床ルール v2 検証監査

日付: 2026-07-12

ルールセット: `clinical_rules.v2` / `2026.07.3`

ステータス: エンジニアリング検証のみ。この監査は臨床検証や医療機器のパフォーマンスを確立するものではありません。

フォローアップ: P3エンジニアリングカバレッジはルールセット `2026.07.4` で追加されました。`docs/unified_clinical_rules_p3_implementation.md` を参照してください。以下の分布は、歴史的な P0-P2 / `2026.07.3` 監査のものであり、P3結果として書き換えられていません。

<a id="scope"></a>
## 範囲

この監査は、P0–P2 の診断ユーザビリティ再設計をカバーします：

- 標準的な代表測定契約；
- 助言的および確認されたリード反転の処理；
- 独立したルールカバレッジと正常性の役割；
- 構成的な全体ステータス；
- 測定固有の ST 品質；
- 地域認識 Q 波の可用性；
- 後壁虚血のエビデンス階層；
- 短 QT 階層および広域 QRS JT/JTc のレビュー；
- 組織化された伝導 P/PR クラスタリングおよび古典的 AF の優先順位；
- AF/AFL 中の P 波形の非適用性。

`data/010` 下の 100 件のレコードは、現在のソースを使用してメモリ内で抽出されました。既存のルートレベルの `JS*_features.json` および `JS*_report.txt` アーティファクトは上書きされず、明示的に再生成されるまで v1 エビデンスとして残ります。

<a id="root-cause-repairs"></a>
## 根本原因の修復

<a id="measurement-contracts"></a>
### 測定契約

- 代表パラメータは、現在、主要グループのビート測定から `r_prime_amp_mv` および
  `s_prime_amp_mv` をエクスポートします。
- 代表パラメータは、ネイティブの Twelve-SL
  `qrs_signed_area_uv_ms` を公開します。Sgarbossa は、単位変換を捏造することなく、ネイティブの符号付き面積極性にフォールバックできます。
- RAE は、代表レイヤーによって生成されるフィールドである `p_dur_consensus_ms` を消費し、存在しない `p_duration_ms` キーではありません。

観察されたエンジニアリング結果：

- RAE 評価のために利用可能な P 持続時間: 92/100。
- ビートレベルの R-prime は存在するが、代表 R-prime は欠如している: 0 件。
- RBBB 出力: 1 つの確定パターンと 3 つの確からしいパターン。4 つの参照
  RBBB ラベルは、確からしい階層と確定階層を同等として扱う前に、ステートメントレベルのレビューが必要です。

<a id="precordial-reversal"></a>
### 前胸壁リード反転

単調な R 進行ヒューリスティックは、現在、`possible` のみを返し、`confirmed` は返しません。可能性のある反転は観察として残り、どのリードも除外しません。独立して確認された反転のみが、明示的に関与するリードペアを除外できます。

バッチ状態：

- `possible`: 64
- `not_suspected`: 36
- ヒューリスティックによる全 V1–V6 除外: 0

これにより、助言的信号を保持しつつ、以前のすべての胸部リードエビデンスの致命的な損失を除去します。

<a id="availability-and-resolver"></a>
### 可用性とリゾルバー

ルール評価は、結論とは独立して `coverage` および `normality_role` を保持します。オプションのスクリーンはコアの正常性をブロックしません。リゾルバーは、限られたカバレッジと技術的制限を持つ異常所見と、信頼できる所見をサポートします。頻度異常は、独立したグローバル疾患分類ではなく、観察です。

メモリ内バッチ中のスキーマ/ルールセットの一貫性: 100/100。

<a id="clinical-rule-changes"></a>
## 臨床ルールの変更

<a id="q-waves"></a>
### Q 波

Q 波の持続時間は、Q 振幅または Q/R 比が病的基準を満たし得る場合にのみ決定的です。未解決の候補リードが依然として必要な 2 リードパターンを形成し得る場合のみ、地域は不確定になります。

利用できない虚血ドメインへの影響：

- P0/P1 中間: 92/100 利用不可。
- P2 最終: 35/100 利用不可。

4 つの既往梗塞 Q 波パターンは最終所見として残り、手動の波形/交絡因子レビューが必要です。

<a id="posterior-ischemia"></a>
### 後壁虚血

2 つのマイナスの ST-J 測定値ではもはや十分ではありません。最終画面
必要なもの:

- 少なくとも 2 つの V1 ～ V3 誘導におけるうつ病。
- ST-mid/ST80 または水平/下向きの形態における持続的な低下。
- ポジティブターミナル T またはドミナント R サポート。
- 未処理の BBB/IVCD 交絡因子がない。

中間 P0/P1 結果: 38 件の後部パターン陽性。

最初の P2 サポートのみの結果: 28 件の陽性。レビューでは、63/66 件の潜在顧客が関与していることが判明

P2 持続性うつ病の最終結果: 陽性は 0 件。

ゼロは完全な特異性を証明するものではありません。以前の呼び出しが
この工学セットでは持続的な後部 ST 低下によって裏付けられていません。
