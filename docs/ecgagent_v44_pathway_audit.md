# ECGAgent v44 disease-pathway audit

Audit date: 2026-09-22. Scope: all **123 catalog codes**, their aliases and record-local extension fallback in `ecgagent/agent/diagnostic_pathways.py`. Pathway contract version: **ecgagent.diagnostic-pathways.v9**. This audit follows [the prior review](../ecgagent_review_20260922/analysis_zh.md), especially its missing atrial-quality reproduction and its distinction between evidence provenance and measurement truth.

The pathway definitions work with deterministic fact validation, bounded adjudication, explicit applicability handling and targeted raw measurement review. Clinical accuracy and calibration require separate validation.

## Evidence contract and changes

Every catalog code now has a bounded, explicit definition path; none uses the extension fallback. New interpretation nodes are model-owned. Numeric IDs remain program-owned where their meaning is unchanged, and `program_owned=False` continues to disable adult deterministic policy. Adding a seventh node now raises an error instead of silently discarding a required condition. Fallback extension views preserve caller arguments and require an operational definition and a measurable countercheck; absence of contradiction cannot establish a diagnosis.

A required node needs affirmative, visible evidence. A missing/null/unreliable criterion is unknown, not normal, absent or refuting. Alternative routes must be independently established: for example, a missing Q duration does not become zero, and a missing R amplitude does not establish QS. Definitions explicitly separate rate, QRS/ST/T/voltage phenotypes from atrial/ventricular mechanisms, chamber anatomy, electrolyte concentrations, coronary anatomy and infarct timing.

Applicability metadata is coordinated with the orchestrator: `unknown_blocks_confirmation=True` and `failure_means_not_applicable=True` on selected `invalidator` nodes mean unknown eligibility prevents confirmation and failed eligibility leaves the criterion inapplicable/unresolved rather than rejecting the underlying disease. These flags apply to LVH activation/pacing/reference eligibility, RVH references, low-voltage calibration, QT references, disease-specific ST eligibility and pathological/prior-infarct Q interpretation. Plain observed-counterevidence invalidators retain their legacy veto semantics. Supporting observations do not gate placement.

The first-degree pathway now requires `atrial_wave_identity` in addition to PR and 1:1 association. It reads P boundaries, per-lead quality, T/A ambiguity and extraction flags, separately from accepting a PR value or event label. This is an additional assessment, **not an independent raw-waveform measurement**: multiple tools can still share one extractor. Atrial event views explicitly request event IDs, times, association, confidence, source leads, linked QRS IDs and PR. The deterministic resolver validates these observations against both stored beat timelines.

The orchestrator activates raw review on feature conflicts using `attach_waveform_review(pathway, profile)`. This returns a deep copy with a model-owned `raw_measurement_consistency` invalidator and both strict applicability flags. Use `conflict=False` only for an explicitly requested supporting observation review. Repeated calls retain a known conflict, merge different profiles to `all`, and never remove existing definition nodes, even when a targeted seventh node is necessary. These default paths do not force raw review on feature-only records. The new `get_waveform_review(profile='p_av'|'qrs'|'st'|'all')` may supply additional evidence through the orchestrator; a status such as `observations_available` is not proof of any morphology or mechanism, and absent raw data are not a disease-negative result.

## Primary references and version boundaries

The search was targeted at definition/applicability errors, not a systematic review of every possible ECG disease. Sources were checked on the audit date. Publisher search excerpts were used where direct PDF retrieval was blocked; no unavailable document text was claimed as reviewed.

| Reference | Use and boundary |
| --- | --- |

| [AHA/ACCF/HRS ECG standardization, Part IV, 2009](https://www.ahajournals.org/doi/10.1161/CIRCULATIONAHA.108.191096) | ST/T/U and QT measurement context; morphology remains informative when an interval endpoint is unavailable. |
| [AHA/ACCF/HRS ECG standardization, Part V, 2009](https://www.jacc.org/doi/10.1016/j.jacc.2008.12.015) | Component-specific chamber voltage and P-wave criteria; no claim that one voltage formula proves anatomy or is universally applicable. |
| [ACC/AHA/HRS bradycardia and conduction delay guideline, 2018](https://www.ahajournals.org/doi/10.1161/CIR.0000000000000628), [HRS full text](https://www.hrsonline.org/wp-content/uploads/2025/02/2018-ACC-AHA-HRS-Bradycardia-Full-Text.pdf) | Genuine P/AV timing distinguishes AV delay/block. | [Fourth UDMI, 2018](https://www.ahajournals.org/doi/10.1161/CIR.0000000000000617) | Explicitly versioned legacy Q/QS lead-specific route and normal variants; it is **not described as the latest UDMI**. |
| [Fifth UDMI, 2026, full text](https://academic.oup.com/eurheartj/advance-article/doi/10.1093/eurheartj/ehag101/8766309), [ESC publication page](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/universal-definition-myocardial-infarction/) | Published 2026-08-28. | [Smith et al., modified Sgarbossa derivation, 2012](https://pubmed.ncbi.nlm.nih.gov/22939607/) | Named proportional discordance calculation is distinct from original weighted criteria. This is primary research, not a newly validated result for this system. |

| [ESC myocarditis/pericarditis guideline, 2025](https://academic.oup.com/eurheartj/article/46/40/3952/8234483) | PR-segment and widespread ST observations cannot establish inflammatory etiology or replace clinical/imaging assessment. PR interval is not PR-segment displacement. |
| [HRS/EHRA/APHRS inherited arrhythmia consensus, 2013](https://www.hrsonline.org/wp-content/uploads/2025/02/2013-Inherited-Primary-Arrhythmia-Syndromes_Full-Text.pdf), [ESC ventricular-arrhythmia guideline portal, 2022](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/ventricular-arrhythmias-and-the-prevention-of-sudden-cardiac-death/) | Right-precordial type-1 morphology is a screening pattern. The older morphology reference is explicit; no inherited syndrome, provocation result or risk classification is inferred. Full 2022 article retrieval was restricted. |
| [ESC pulmonary embolism guideline, 2019](https://academic.oup.com/eurheartj/article/41/4/543/5556136) | Right-heart strain observations are nonspecific; their absence cannot rule out PE and their presence cannot establish it. |
| [ESC pacing guideline, 2021](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/cardiac-pacing-and-cardiac-resynchronization-therapy/) | Pacing chamber, stimulus/capture timing and device context differ from spike detection alone. No treatment or device programming recommendation is implemented. |

The LVH wide-QRS gate is a deliberately conservative **implementation applicability boundary for the conventional criteria supported here**. It is not a guideline claim that all ECG-LVH assessment is impossible in every BBB. Alternative validated criteria under altered activation have not been added. Likewise, giant/flat T-wave, pediatric voltage and less-standard morphology labels require an explicitly justified reference; this audit does not invent a universal cutoff where none has been established in the available policy.

## Remaining data and implementation limitations

- Feature views still share upstream extraction. Required P-quality review prevents a wholly numeric AV pathway from confirming by itself, but cannot prove that an accepted P detection is real. Conflict-triggered raw review must enforce a specific P identity, QRS boundary or ST baseline question; raw availability alone must not resolve that question.
- Some necessary observations are not exported: terminal-QRS notch location, reliable separate QS identity, PR-segment displacement, pacing settings and stimulus-level timing, serial ECG changes, high/right/posterior lead recordings, and selected pediatric references. Those nodes intentionally remain unknown when the defining observation is unavailable. No new tool argument or pretend remeasurement was added.
- Electrical alternans currently has a QRS-area view. The path now explicitly refuses to equate area with amplitude; adding a validated amplitude series is still needed for an affirmative amplitude-alternans claim.
- `get_diagnostic_overview` now has parent integration into the compact direct-tool compiler/evidence namespaces and exposes the calibration object and output unit. Relevant source fields under `/metadata/input_contract` are `amplitude_calibration/per_lead_normalized`, `amplitude_calibration/amplitudes_diagnostic`, `amplitude_calibration/reason`, `amplitude_input_unit`, `amplitude_output_unit` and `amplitude_scale_to_mv`. The normalization detector returning false, particularly for `too_few_leads_with_signal`, is not independent proof of physical calibration. Missing applicable metadata stays unknown.
- Changed pathways consume additional distinct views. The orchestrator owns batched scheduling, incomplete-coverage reporting and one-shot candidate refresh. This audit does not claim that coverage or recall has improved on a clinical cohort.
- Pattern confirmation is not a calibrated probability. The orchestrator owns the MEDIUM default and correlated-evidence accounting. There is no new sensitivity/specificity estimate, clinical validation, medication advice or treatment recommendation in this work.

## Validation and handoff

`tests/test_ecgagent_v44_pathways.py` exercises production view compilation, actual tool results/visibility and verdict placement with controlled judgments. It covers omitted P identity, unknown/inapplicable LVH criteria, preservation of wide-complex and ST phenotypes, AF with an uninformative RR response, unestablished ectopic origin, pacing-failure definitions, null-only Q evidence, exact extension arguments and pediatric model ownership. It also validates every catalog pathway against registered tool schemas and makes catalog additions without audit entries fail visibly. These are engineering contract tests, not waveform-reader or LLM accuracy tests.

Final targeted validation after the helper and parent overview integration: **33 passed** with `.venv/bin/python -m pytest -q tests/test_ecgagent_v44_pathways.py`. Helper tests additionally exercise strict-versus-supporting missing-review placement, inability of supporting review to replace required evidence, idempotence, monotonic conflict gating, profile validation and preservation of six-node base definitions.

The integrated ECGAgent suite passes **900 tests** (see `ecgagent_v44_review_20260922/test_full.log`). This includes 248 focused fact tests, 48 shared-packing tests, 35 waveform tests, 33 pathway tests and 15 execution tests, alongside existing regressions. These counts describe engineering behavior, not diagnostic accuracy.

All 123 catalog definitions construct successfully and all explicit arguments pass their registered JSON schemas. The accompanying [implementation and validation report](../ecgagent_v44_review_20260922/analysis_zh.md) distinguishes live model timings, deterministic replays and remaining clinical-data limitations.
