# ecgfeat 診断契約 v2026.07.10

このバージョンでは、`docs/流程` の「測定」と「診断」を別々に実装します。診断ゲートが失敗した場合でも、
取得可能な測定値、品質証拠、および失敗の理由は引き続き返されますが、信頼性の低い測定値は否定的または否定的なものとして解釈されなくなりました。
陽性診断。このプロジェクトは依然として研究および補助解釈ツールであり、規制上の検証を受けた医療機器ではありません。

<a id="项目特定例外"></a>
## プロジェクト固有の例外

この実装では、元のサンプリング レートが 500 Hz である必要はありません。

- サポートされる最小入力サンプル レートは 100 Hz のままです。
- 元のサンプリング レートを使用することも、`fs_internal` 経由でリサンプリングすることもできます。
- レポートには、元の/内部サンプル レート、時間量子化解像度、およびそれが 500 Hz 未満かどうかが記録されます。
- 500 Hz 未満では、それ自体は診断停止をトリガーしません。
- ただし、レポートでは、ペーシング ネイルの感度が制限されている可能性があり、「ペーシング ネイルが検出されない」という言葉はペーシングが存在しないと判断するものとして解釈できないことを示しています。

<a id="已实现的输入和质量契约"></a>
## インプットと品質に関する契約を実装

- フル標準の 12 リード、または `lead_names` の 8 独立リードを受け入れます
  `I, II, V1-V6`;後者は、アイントホーフェン/ゴールドベルガーの関係に従って残りの四肢のリードを導き出します。
- 内部でmVに統一されている`mV`、`uV`、`V`および`gain_uv_per_lsb`によるデジタル量をサポートします。
- NaN/Inf、継続時間、フラットライン、飽和、ベースラインドリフト、電源周波数、EMG、
  pSQI、kSQI、bSQI、四肢誘導方程式残差、および誘導配置の異常。
- メインの QRS 検出と独立したマルチリード振幅検出の間の一貫性をチェックします。重大な矛盾がある場合は診断を中止します。
- 診断ゲートのステータスは `pass`、`partial`、または `stop` であり、次の値が与えられます。
  `stop_reasons`、`partial_reasons`、および継続を許可する診断フィールド。
- 3拍未満、8秒未満、重大な品質不良、重度の誘導方程式の不一致、または四肢誘導の疑い
  接続が逆になると診断は停止します。複雑なポリモーフィックな録音では、品質、リズム、異所性ビート分析のみが保持されます。

<a id="新增测量与-finding"></a>
## 測定と結果を追加

- HR 最小/最大、RR 平均/SD/CV、RMSSD、pNN50、ポアンカレ SD1/SD2 および RR エントロピー。
- バゼット、フリデリシア、フラミンガム、ホッジス QTc、JT/JTc 制限はワイド QRS に維持されます。
- QRS-T にはアングルと R/S 変換領域が含まれています。
- U 波振幅、T 波対称性、PR セグメント オフセット、QRS ノッチ/スタッタリング、VAT および ST スロープ。
- 独立した 3 つの状態の調査結果: `TRUE`、`FALSE`、`UNKNOWN`。必須入力が欠落している場合に限ります
  `UNKNOWN` と入力し、`abstentions` と入力すると、サイレントに `FALSE` に変換することはできません。

<a id="诊断与报告"></a>
## 診断とレポート

- 新しいまたは強化された洞調律、約 150 拍/分での 2 対 1 の心房粗動レビュー、ペーシング リズムとデバイスの異常、
  広範囲の QRS 頻脈、重度の QTc、LVH/RVH 拡張基準。
- ST落ち込み、デ・ウィンター、ウェレンス、左メインタイプの追加または強化、オリジナル/改良
  サルボッサ、ブルガダ 1 型、高カリウム血症/低カリウム血症の合図、交互脈、早期再分極、心膜炎、
  右心症、S1Q3T3/右心負荷、ジギタリス効果。
- シーケンス比較のための受信 `prior_features` をサポート: リズム、PR、QRS、QT、ST、ECG 軸、および
  T波の極性が変化します。
- 固定信頼レベル `HIGH/MEDIUM/LOW/UNAVAILABLE`、優先度 `P0-P6` の最終ステートメント、
  `report_statement`、`human_review_required`、証拠、しきい値、抑制理由、および利用可能
  SNOMED CT コード。
- すべてのレポートにはサポート解釈ステートメントが付属しています。高リスク、技術的限界、境界線の結果、および重大な配列変更が必須
  マニュアルレビュー。

```python
    signal,
    fs,
    meta=PatientMeta(
        age=55,
        sex="male",
        amplitude_unit="uV",
        device="device-name",
        acquisition_time="2026-07-28T12:00:00Z",
    ),
    lead_names=["I", "II", "V1", "V2", "V3", "V4", "V5", "V6"],
    prior_features=previous_features,
)

gate = features.metadata["diagnostic_gate"]
analysis = features.metadata["clinical_interpretation"]
```
