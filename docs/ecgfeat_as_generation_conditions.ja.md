# ecgfeat 条件として生成されたフィーチャ ソース - 使いやすさの説明

対象となる用途: **条件付き ECG 生成**の条件付き量を提供する特徴抽出器として ecgfeat を使用します。
ST、リズム、形態、梗塞領域を制御します。これは診断用の要件とは異なり、この記事は生成された基準に照らして再評価されます。

パッケージ: [EDB ST 振幅検証](edb_st_cross_dataset_validation.ja.md)、
[QTDB トレース検証](qtdb_cross_dataset_validation.ja.md)、[診断機能ギャップ登録](%E8%AF%8A%E6%96%AD%E7%89%B9%E5%BE%81%E7%BC%BA%E5%8F%A3%E7%99%BB%E8%AE%B0.ja.md)。

---

<a id="0-一句话结论"></a>
## 0. 一文の結論

**リードバイリードの連続測定は直接使用できます。カテゴリ ラベルには ecgfeat を使用せず、データ セット独自の注釈を使用してください。 **

ecgfeat の価値は、データセット ラベルでは表現できないきめ細かい連続量を提供することにあります。
(「V3 リード ST 低下 80 ms で 0.15 mV」、「QRS 軸 +45°」、「P 波持続時間 110 ms」)、
ラベル自体を再生産するのではなく、ラベル自体の不正確さが生じるだけです。

---

<a id="1-为什么不能照搬诊断结论"></a>
## 1. 診断結果をそのままコピーできないのはなぜですか?

診断評価では「レポートが正確かどうか」が問われますが、生成条件では他に 3 つのことが問われます。

|メトリクス |意味 |生成することが重要な理由 |
|---|---|---|
| **対象範囲** |空でない割合 |特徴が空でないことが必要な場合に、トレーニング サンプルがいくつ残っているか |
| **偏差がありません** |異常なグループ カバレッジ − 正常なグループ カバレッジ | **ゼロ以外はアラームを意味します**。以下を参照してください。
| **劣化** |最も一般的な値の割合 / 変動係数 |ほぼ一定の特性、発電機は「調整」できません。

**ミッシングバイアスは、世代特有の落とし穴です。 ** 特徴を計算できない場合は、診断を控えても安全です。
しかし、異常なレコードでより頻繁に棄権する場合、「特徴が null でないことを要求する」ことは、異常なサンプルを体系的にフィルタリングして除外することと同じです。
ジェネレーターが学習した異常分布を削り落とします。補間も同様に有害であり、何もないところから構造を作成することになります。

## 2. 推奨条件セット

(正常/心筋梗塞/虚血性/AFIB/伝導異常 各 50)、2026 年 8 月 9 日。

<a id="21-逐导联-12-维向量-覆盖-100缺失偏差-000"></a>
### 2.1 リードバイリード 12 次元ベクトル - カバレッジ 1.00、欠落バイアス 0.00

```
ST     st_hybrid_j_mv, st_hybrid_60ms_mv, st_hybrid_80ms_mv,
       st_hybrid_slope_mv_per_ms, st_hybrid_baseline_confidence
形态   p_amp_mv, p_dur_ms, t_amp_mv, t_polarity, qrs_ms,
```

MAE **0.099 mV**、バイアス -0.021 mV、r **0.878** (専門家がラベル付けしたイベント ピーク 215 個)。

<a id="3-禁用清单"></a>
## 3. 無効者リスト

<a id="31-缺失系统性有偏-最危险的一类"></a>
### 3.1 体系的なバイアスの欠如 - 最も危険なタイプ

|特長 |取材範囲 |バイアスの欠落 |
|---|---|---|
| `pr_ms` | 0.59 | **−0.34** |
| `t_axis_deg` | 0.60 | **−0.48** |
| `qrs_t_angle_deg` | 0.49 | **−0.46** |

異常なレコードのカバレッジは通常より 34 ～ 48 パーセント ポイント低くなります。原因は生理的なもの
(心房細動には PR がなく、異常な再分極は T 軸として計算できません)、**これが危険な理由です** - 欠如自体がラベル情報を持ちます。

以下を使用する必要がある場合: **欠落を明示的にモデル化するためにマスク チャネルを追加**、破棄または補間しないでください。
「AF には PR がない」ということはノイズではなく意味のある事実です。

`q_duration_ms` (カバレッジ 0.39、バイアス **+0.16**) はその逆です。バイアスは正です。
病的な Q 波は異常がある場合にのみ現れるため、そのヌルは「検出できない」というよりは「Q 波がない」ことを意味します。
2 つのタイプの null はセマンティクスが異なるため、組み合わせることはできません。

<a id="32-分布退化-与临床含义反相关"></a>
### 3.2 分布低下 + 臨床的意義との逆相関

`st_pattern_class` (フォームの 4 つのカテゴリ)、`st_morphology` (傾斜の 3 つのカテゴリ)。

実際の測定値 (PTB-XL 135、1620 リード、2026 年 8 月 9 日):

- `horizontal` はリードの **49%** を表し、ST80 中央値は **+0.001 mV** ——
  実際には、クラス名が示すように「水平凹み」ではなく「ベースラインフラット」を意味します。
- `downsloping` はリードのわずか 3%、`j_point_elevation` はわずか 0.4%、ほとんどトリガーされません
- 虚血の指標として **AUC 0.38 ～ 0.47 (ランダム以下)**、一方、純粋な「抑制されたリードの割合」は **0.857**
- **パターンと振幅の組み合わせ (0.72) は、振幅のみを使用する場合 (0.86) ほど良くありません** ——パターンはマイナスの寄与です

理由: これらのクラスは、大きさではなく、傾斜/曲率のみによって決定されます。安静時心電図のほとんどの ST セグメントは平坦です。
臨床的に意味のある実体は「水平」ではなく「水平**うつ病**」です。

**結果**: このウェアハウスの形態学的分類は、ほとんどが粗粒度の連続量です。
**ビニングの前に常に連続量を取得してください** —— `st_hybrid_slope_mv_per_ms` は `st_morphology` よりも優れています。
`qrs_axis_deg` は `qrs_axis_class` よりも優れています。

<a id="33-梗死区域-首次评估不通过"></a>
### 3.3 梗塞領域 - 最初の評価、不合格

測定基準: `mi_territory_audit.py`、PTB-XL 各エリアの 50 + 50 は正常です。
PTB-XL の MI コードには、直接比較できる独自の面積 (IMI=下壁、ASMI=前中隔壁、ALMI=前側壁) があります。

|出力 |空でない率 |ヒット真値領域 |空でないサンプルのヒット率 |
|---|---|---|---|
| `q_wave_territories` | 0.85 | 0.55 | 0.64 |
| `mi_statement_candidates.territory` | 0.75 | 0.54 | 0.72 |
| `st_territories_elevated` | **0.05** | 0.02 | — |

混乱 (レコードが複数の領域に割り当てられる可能性があります):

|真の値 | ecgfeat | によって与えられる領域
|---|---|
|下壁 (n=50) |下 **32** / 前部 17 / 前外側 12 / 外側 6 |
|前壁 (n=50) |前部 **24** / 前外側 16 / 下 15 |
| **前外側** (n=50) |前外側 **25** / 前部 24 / 下部 24 / 外側 18 |

**前壁と側壁は基本的に非特異的です** (正解は 25、他の 3 つの領域への誤判定はそれぞれ 24/24/18 で、ランダムに近い)。
そして **通常のレコードの 34% に MI ステートメントが与えられました**、`st_territories_depressed`
正常グループのトリガーは 0.94 で、梗塞グループの 0.64 ～ 0.74 より **高かった**。

<a id="4-为什么类别条件要用数据集标签"></a>
## 4. カテゴリ条件にデータ セット ラベルを使用する必要があるのはなぜですか?

PTB-XL でトレーニングする場合、領域/リズム/診断の注釈自体がグラウンド トゥルースです。
ecgfeat を再推論させると、条件にエラーが挿入されるだけです。

|条件 | ecgfeat のエラー |
|---|---|
|梗塞領域 |命中率 54% |
|心房細動 | 67.3% 検出 |
|心房粗動 | 心房粗動検出率 79.4% |

**2 種類の条件は別々に取得され、それぞれ独自の長所を使用します。**

- カテゴリ/診断/地域 → **データセット ラベル** (エラーゼロ)
・連続形態量 → **ecgfeat**（ラベルで表現できない部分）

<a id="5-q-波与-s-波可用作几何量不可用作病理量"></a>
## 5. Q 波と S 波: 幾何量として使用できますが、病理学的量としては使用できません

測定基準: `qs_wave_probe.py`、PTB-XL NORM / MI / LVH 各 50、1800 リード行。

<a id="51-无真值可对照"></a>
### 5.1 比較する真の値がありません

LUDB および QTDB **Q、R、S を個別にマークするのではなく、QRS の開始点/ピーク/終了点のみをマークします。
したがって、振幅と時間制限**には、チェックするための基準マークがありません**。 `test_mi_qwave.py` はすべて合成単体テストです。

<a id="52-定义是极值而非负向波"></a>
### 5.2 定義は「負の波動」ではなく「極値」

```python
r_amp = max(0, max(seg))        # QRS 内最大正向偏转
q_amp = min(seg[:r_pos + 1])    # R 峰之前的最小值
s_amp = min(seg[r_pos:])        # R 峰之后的最小值
```

r 波で始まり Q 波がまったくない QRS も `q_amp_mv` を取得し、これは正の数にすることができます。

| |測定された比率 |
|---|---|
| `q_amp` はプラスです (このリードには Q 波がありません) | **24.4%** (中央値 -0.044 mV、p90 **+0.037**) |
| `s_amp` は陽性 (S 波なし) | **15.7%** |
| `q_duration_ms` には値があります | 32.1% |

<a id="53-病理判别力等同随机"></a>
### 5.3 病理学的差別はランダムに等しい

|特長 | MI と正常 | LVH vs ノーマル |
|---|---|---|
| `q_amp` | **0.512** | 0.457 |
| `q_r_ratio` | 0.589 | 0.467 |
| `q_dur` | 0.598 | 0.538 |
| `s_amp` | **0.489** | 0.498 |

`significant_q` は **正常リード** で 10.7%、MI グループで 18.7% を引き起こしました (濃縮はわずか 1.75 倍)。

<a id="54-但对生成而言仍然可用"></a>
### 5.4 ですが、引き続きビルド可能です

ジェネレーターは、波形を忠実かつ再現可能に記述するだけで、診断機能を必要としません。
「R ピーク前の最小値」は、条件付き次元として完全に利用できる、決定論的で 100% カバーされる幾何学的量です。

**リスクは純粋に解釈的なものです**:

- 文書および実験の説明では名前を `min_before_R` / `min_after_R` に変更しました。Q 波 / S 波振幅とは呼ばないでください。
- 「病的なQ波の有無」を制御する場合 → データセットMIタグを使用し、`significant_q`を使用しない
- 忠実な Q 波の寸法が必要 → `q_duration_ms` 空ではない **インジケータ ビット**を使用します。
  Q波の有無により振幅を2次元に分割します。 2 つの物理量を同じ軸に詰め込まないでください。

<a id="6-使用须知"></a>
## 6. 使用上の注意

1. **欠落バイアスはデータセットに依存します。 **セクション 3.1 の番号は PTB-XL からのものです。
   コーパスを変更するには、`cond_feature_audit.py` を使用して再テストする必要があります。これはまさに、学習された分布を静かに歪めるプロパティです。

2. **AUC口径。 ** この記事の PTB-XL レコードレベルの注釈と比較した AUC には、ラベル ノイズが含まれています。
   そして、形状はリードごとに変化し、注釈は記録レベルです（虚血は一部のリードのみに影響を与えることが多く、凝集により信号が希釈されます）。
   **相対的な比較を読む必要があります** (例: 形式と純粋な大きさ)、分類器のパフォーマンスとして絶対値を考えないでください。
   EDB の r = 0.878 は、ST 振幅のより明確な尺度です。

3. **空のリストを確認します。 ** 以下は、このリポジトリ内の実際のアノテーションで検証されていません。
   STの4種類の形態、梗塞領域（本稿最初の評価、不合格）、Q/S波の振幅と制限時間、
   12 リード隣接ゾーン ルール (EDB には物理チャネルが 2 ～ 3 つしかなく、構造的に検証できません)。
