# v43：由真实样本 trace 驱动的修复

上一轮 PTB-XL `01000_hr` 运行报告电轴左偏，但参考报告为正常心电图。
核对发现：QRS 限制引用在清洗中消失，计划反证检查未执行，纯程序路径仍占用
模型调用，且失败的公开响应正文没有保存在逐阶段 trace 中。本次修复这些
可由代码和回归用例证实的问题，保持已有临床数值阈值。

| 改动 | 最终行为 | 验证 |
|---|---|---|
| 质量限制解析 | 先解析授权 Qn 引用，生成不带游离数值的可读限制；原始 caveats 单独入审计 | QRS 103/114 ms 回归用例 |
| 有效反证落地 | 每个独立规划候选至多一个固定路径未覆盖的反证模态，编译为必需模型节点后参与完整路径预算；规则模板复用既有路径 | 导联反证节点、预算、缺失结果不能确认 |
| 数值矛盾提前剔除 | 成人、授权、可靠的 QRS 电轴若直接否定候选的原有定义范围，在预算分配前剔除 | 有授权范围检查，接近边界且符合阈值的候选仍保留 |
| 必需证据预算 | 第一层单工具视图优先容纳完整必需 bundle；Qwen 共享证据按实际必需字符数扩展，最高 24,000 字符 | 36 个跨导联原子完整保留；共享包扩展与固定上限模式 |
| 纯程序阶段短路 | 所有预取均为程序专用，且无模型节点、间期任务、补充 review、取证缺口时，完成工具后直接进入程序裁决 | 0 模型调用，仍执行 1 次数值取证；review 存在时禁止短路 |
| 公开响应历史 | 每次响应正文、停止原因、结构错误和修复反馈均保存；不读取隐藏思维内容 | 截断及局部修复两轮记录 |
| vLLM 空白控制 | `structured_outputs` 同时传 `json` schema 和 `disable_any_whitespace=true` | 请求契约用例及真实 vLLM 调用 |
| 报告与 trace 措辞 | 报告不再把有限异常发现称为完整解释；程序专用取证独立标记；缺失 batch 耗时显示 N/A | 报告与 trace 回归用例 |
| 缺失证据语义 | 模型只引用 null 测量时，pass/fail 均归为 unknown，不能用缺失值排除疾病 | Q 波时限缺失回归与冻结输出回放 |
| R/S 符号检查 | ecgfeat 定义的有符号幅度若出现 R<0 或 S>0，转位节点保持 unknown，避免 abs(S) 掩盖上游异常 | 正值 S 不得确认早期转位 |

协议更新为 `ecgagent.diagnostic.v43`，旧产物不会被当作同协议的新结果。
本次没有修改 feature_extraction 中其他正在进行的工作。

验证命令：

```bash
.venv/bin/python -m pytest -q tests/test_ecgagent*.py \
  tests/test_diagnostic_contract_v10.py tests/test_diagnostic_baseline_alignment.py \
  tests/test_webchat_security.py tests/test_batch_medgemma_diagnostics.py
```

结果：521 项通过。另进行了真实复杂样本 `01006_hr` 的两轮本地推理和一次
冻结公开输出的离线回放；最后两项程序校验改动通过回放验证，未宣称为第三轮推理。完整输出、
失败请求记录和测试分析保存在 [复杂样本目录](../ecgagent_complex_review_20260908/)。

本次没有凭单个参考标签改变电轴定义。跨搏电轴误差建模、完善正常节律报告、
增加 review 专属结论结构仍需要独立设计和队列验证。保留一个额外反证节点
会增加部分候选的证据成本，过于保守时可能降低召回，需在固定队列评估。

Qwen 的 `max_retained_evidence_chars` 是可选证据的基本预算；
`max_required_evidence_chars=24000` 控制必需证据触发的扩展。
设置后者为 `None` 可禁用扩展，设置为基本预算可维持固定上限。
复杂样本建议服务端至少提供 24K token 上下文；字符预算不等于 token 预算。
单工具默认扩展最多 24,000 字符，显式调用传入的字符与原子上限仍严格遵守。
更大预算仍可能容纳不下某些必需 bundle；此时审计记录缺失，节点继续为 unknown。
