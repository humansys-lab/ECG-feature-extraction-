# Diagnostic Feature Gap Registry

Entries skipped during diagnostic layer alignment against `docs/心电图诊断规则系统综述.md` due to **missing required feature quantities**.
Each record: Required feature → Current status → Blocking point.

Reference framework: `clinical_rules/sources.py: BASELINE_STANDARD` (AHA/ACCF/HRS 2009 + UDMI 2018).

<a id="一本次实施中直接受影响的缺口"></a>
## I. Gaps Directly Affected in This Implementation

<a id="11-21-房室阻滞文档-174-已探测未发布诊断"></a>
### 1.1 2:1 Atrioventricular Block (Document 17.4) — Detected, but Diagnosis Not Issued

**Required**: An atrial event sequence independent of QRS, capable of proving "1 conducted beat for every 2 P waves" rather than P-wave detection miscounting T waves as P waves.

**Current Status**: `rhythm_rules.detect_pauses_and_av_block` currently sets
`two_to_one_conduction_suspected`, but `av_block_evidence.constant_multiple_atrial_events_requires_validation`
guard still blocks it — when **every** RR interval contains 2 atrial events, it is impossible to distinguish true 2:1 conduction from continuous T-wave misdetection,
therefore `second_degree_avb` remains `None`, and no diagnosis is issued.

**Missing Features**:
- **Multi-lead independent verification** of `atrial_rate_bpm` (currently `GlobalFeatures.atrial_rate_bpm` falls back to ventricular rate when P-wave detection degrades)
- P-wave detection confidence for non-QRST intervals (one confidence score per atrial event, not just a count)

**Conclusion**: Skip for now. Only place the flag into evidence for manual review.

<a id="12-完全性三分支阻滞文档-56-只发-pattern不发诊断"></a>
### 1.2 Complete Trifascicular Block (Document 5.6) — Pattern Issued, but Diagnosis Not Issued

**Required**: Alternating bundle branch block (alternation of RBBB and LBBB within the same recording), or HV interval.

**Current Status**: `CLIN-CONDUCTION-TRIFASCICULAR-01` only issues
`trifascicular_block_pattern` when "bifascicular block + PR > 200 ms" is present, and explicitly states in the text that the block site cannot be localized.

**Missing Features**:
- Beat-to-beat QRS morphology classification results mapped to bundle branch types (`grouping.py` has template clustering, but templates are not labeled as RBBB type/LBBB type)
- A 10-second recording is generally insufficient to observe alternation

**Conclusion**: Implemented at the pattern level; complete trifascicular block is skipped.

<a id="13-r-波递增不良的鉴别项文档-81"></a>
### 1.3 Differential Items for Poor R-Wave Progression (Document 8.1)

**Required**: Electrode position metadata (whether placed in the 2nd–3rd intercostal space), body habitus/gender-related chest wall attenuation estimation.

**Current Status**: `CLIN-MORPH-RPROG-01` places
`high_precordial_electrode_placement` / `body_habitus` into
`confounders_require_review`, but cannot automatically exclude them.

**Missing Features**:
- Electrode position field in acquisition metadata (`PatientMeta` lacks this field)
- BMI / Chest circumference

**Conclusion**: Listed as a confounding factor requiring manual review; no automatic exclusion performed.

## III. Non-Feature Gaps, but Entries Requiring Decisions

- **Congenital Heart Disease (Document Chapter 21)**: Criteria for ASD/VSD/PS/TOF/Ebstein/ccTGA are all calculable from existing feature quantities
  (V1 morphology, electrical axis, P-wave amplitude, transition zone); **no feature gap**. Non-implementation is a scope decision, not a capability limitation.
- **Narrow QRS Tachycardia Differential (Chapter 18)**: Requires RP' interval. P-wave detection reliability at 150–250 bpm is unverified;
  reliability assessment should be performed first before deciding whether to implement.
- **VT vs SVT with Aberrancy Morphology (19.0)**: The
  `rs_interval_ms` (R onset → S nadir) required by the Brugada four-step method **is currently not exported**, representing the single most critical missing quantity for this chapter.

## IV. New Issues Exposed by 100 Real-World Tests (WFDBRecords/01/019)

Results directory: `ecgfeat_diagnosis_01_019/`.

<a id="41-lafb-在-99-条中-0-次匹配-需要复核电轴窗口"></a>
### 4.1 LAFB Matched 0 Times in 99 Cases — Requires Review of Electrical Axis Window

- There is **only 1 record** with an electrical axis ≤ −45° (the current lower bound of the LAFB window), and it did not meet the morphological criteria;
- However, **3 records** have an electrical axis falling between −45° and −30°, and the reference labels include 3 cases of `Axis left shift`.

Document 5.4 notes that "some textbooks use ≤ −30°." The current window is set to −45° to −90° (according to AHA/ACCF/HRS standards).
**Conclusion**: This is not a feature gap, but a choice of threshold criteria. To improve LAFB sensitivity, the
`MorphologyThresholds.lafb_axis_max_deg` should be relaxed to −30° and accompanied by stricter morphological criteria
(add `S(III) > S(II)` and `R(aVL) > R(I)`, which are currently **not implemented** although the required feature quantities are already available).

<a id="42-双分支阻滞-0-次触发-符合预期非缺陷"></a>
### 4.2 Double Bundle Branch Block Triggered 0 Times — As Expected, Not a Defect

Among the 99 cases, the RBBB family matched 7 cases (all `probable_rbbb_pattern`). There was no co-occurrence with LAFB/LPFB, so `bifascicular_block_pattern` was not triggered. The rule itself is already covered by unit tests.

<a id="43-rs-移行区判定曾产生系统性假阳性已修"></a>
### 4.3 R/S Transition Zone Determination Previously Produced Systematic False Positives (Fixed)

In the first round of 100 cases, `counterclockwise_rotation` triggered 24 times. Spot checks revealed that
for JS00956, R(V1)=0.054 mV and S(V1)=−0.028 mV were both at the noise level,
yet they satisfied `R ≥ |S|` and were judged as V1 transition → counter-clockwise rotation, whereas the actual case was
**clockwise rotation + poor R-wave progression** with a QS pattern in V2.

Two constraints have been added (`MorphologyThresholds.transition_min_r_mv` = 0.10 mV
amplitude lower limit + transition must be maintained in the next lead). After re-running,
counter-clockwise cases dropped from 24 to 18, and clockwise cases changed from 11 to 13. JS00956 was correctly classified as clockwise rotation + poor progression.

**Remaining Issue**: The amplitude lower limit is an empirical value and has not been calibrated for low-voltage records. For low-voltage records (all precordial leads < 1.0 mV),
this lower limit may be too high. An **adaptive lower limit relative to the precordial voltage scale of that record** is needed.
The required feature quantities (per-lead QRS peak-to-peak values) already exist but are not implemented.

<a id="44-窦性心动过速召回率-110-根因是快心率下的-p-波检出不是阈值"></a>
### 4.4 Sinus Tachycardia Recall Rate 1/10 — Root Cause is P-Wave Detection at High Heart Rates, Not Thresholds

Out of 10 records labeled with reference `Sinus Tachycardia`, only 1 issued `sinus_tachycardia`.
A case-by-case review of `sinus_mechanism` rule evidence:

| Record | Status | organized_p_ratio | P Axis | HR |
|---|---|---:|---:|---:|
| JS00949 | unavailable | 0.11 | — | 111 |
| JS00960 | not_matched | 0.10 | 29.9° | 130 |
| JS00964 | not_matched | 0.53 | 4.6° | 105 |
| JS00966 | not_matched | 0.05 | 34.8° | 138 |
| JS00978 | not_matched | 0.35 | 74.1° | 102 |
| JS00984 | not_matched | 0.12 | 71.3° | 106 |
| JS00990 | not_matched | 0.24 | 94.8° | 104 |
| JS01008 | not_matched | 0.10 | 46.2° | 126 |
| JS01035 | unavailable | **0.88** | **—** | 107 |

**Root Cause**: The sinus criteria require `organized_p_ratio ≥ 0.70`, but for 8/10 cases at 100–140 bpm,
this value is only 0.05–0.53. The P-axis itself is mostly normal (0–75°). This is exactly the scenario described in Document 18.1
where "at high rates, P may merge with the preceding T" —— **this is a degradation of P-wave detection capability at high heart rates, not that the threshold is set too strictly**.
Lowering the 0.70 threshold would only let false positives in.

**Missing Feature**: P-wave recovery capability in the T-P fusion zone. Needs
(a) re-detection of P waves from residuals after subtracting a per-beat T-wave template (`atrial.py` already has a QRS T-template residual pathway,
but it is only used for f/F wave spectral analysis and has not been fed back into per-beat P-wave detection),
(b) or a P-search window adaptive to RR intervals.

**Another Independent Gap**: JS01035 has a `organized_p_ratio` of 0.88 (good P-wave detection)
but `p_axis_deg` is empty → the rule judges it as unavailable. There is an
availability inconsistency between P-wave detection and P-axis calculation, which needs separate investigation.

## V. Morphological Document Alignment (Supplementary Implementation on 2026-07-29)

After verifying item by item against `docs/morphological` (P/QRS-Q/ST/T/QT/U six sections + 12-lead segmentation),
four types of morphology that were previously completely unimplemented have been added. Each entry records **false positives exposed during testing** and their corrections,
because these corrections are the main content of this implementation —— textbook criteria alone are insufficient for direct deployment.

<a id="51-u-波文档第-6-节-从仅服务于-t-波终点升级为独立诊断特征"></a>
### 5.1 U Wave (Section 6 of Document) — Upgraded from "Serving Only T-Wave End" to an Independent Diagnostic Feature

**Original State**: `u_amp_mv` was `max(|signal − baseline|)` (unsigned window maximum, no peak validation),
serving only `_clamp_t_end_to_tu_nadir` to determine "whether the T-wave end should stop at the T-U valley."
Unsigned ⇒ **inverted U waves are invisible at the data layer**.

**New Addition**: `feature_extraction/ecgfeat/u_wave.py`, re-measuring the U wave as a true local extremum:
signed amplitude, polarity, prominence, duration, T-U isoelectric interval, and beat-by-beat aggregation (`features._u_wave_params`,
determining the majority polarity first and then taking the median; if polarity is tied, reporting is rejected).

**Diagnostic Rules**: `clinical_rules/u_wave.py` → `prominent_u_wave` / `inverted_u_wave`.

**Three Types of False Positives Exposed in Testing (All Fixed)**:

| False Positive | Manifestation | Correction |
|---|---|---|
| Terminal negative lobe of biphasic T wave read as inverted U wave | LUDB 103: prominence 0.19–0.25 mV, U/T≈1.0 | Require a **≥20 ms isoelectric segment** between T and U (not just "touching the baseline," but sustained duration). Biphasic T continues downward after crossing zero ⇒ does not meet criteria |
| Baseline drift read as inverted U wave | LUDB 100/132: prominence only 0.028–0.037 mV | Inverted U uses **prominence ≥0.05 mV** as a gate (amplitude is relative to beat baseline, slow drift can easily gain amplitude) |
| Narrow sharp noise pulses read as U waves | PTB-XL 11072/11076/11088 (all labeled **NORM**): U duration only 27–51 ms | Require **duration ≥60 ms**. U waves are the slowest waves in surface ECG (base 150–250 ms); amplitude/prominence cannot block narrow pulses, only duration can |

After correction, on 120 cases of PTB-XL, `inverted_u_wave` dropped from 3 cases (all labeled NORM) to 0 cases.

**Incidental Correction**: The hypokalemia rule originally used unsigned `u_amp_mv` to judge `u_amp ≥ 0.05`,
Deeply inverted U waves may be mistakenly counted as "prominent upright U waves" in the hypokalemia criteria; a signed field has been adopted instead.

<a id="52-t-波亚型文档-42-超急性期-t-与巨大阴性-t"></a>
### 5.2 T-wave Subtypes (Document 4.2) — Hyperacute T and Giant Negative T

`clinical_rules/t_morphology.py`:

- `hyperacute_t_wave_pattern`: **Amplitude cannot distinguish hyperacute T from hyperkalemic T (both are tall)**,
  so the primary criterion is "disproportionate relative to QRS (T/QRS ≥0.75) + widened base (≥160 ms)",
  with symmetry (0.8–1.2 classified as hyperkalemic-like) used for adjudication within the 160–200 ms overlap zone.
  The engine layer also includes suppression: suppressed when `acute_occlusion_pattern` (ST elevation already present, hyperacute T provides no incremental information)
  or `hyperkalemia_pattern` is present.
- `giant_negative_t_wave`: Precordial leads ≤ −1.0 mV (10 mm) + second lead ≤ −0.5 mV as corroborating evidence.
  **The statement deliberately lists both ischemic deep inversion and apical hypertrophic cardiomyopathy**: When PTB-XL 11006 is triggered, the label is
  ISCIL+ISCAS (ischemia), indicating that the most common cause of deep inversion is ischemia rather than apical HCM;
  listing only HCM would mislead readers toward a rare diagnosis. Confounding factors such as LVH are reported in parallel via `differential_confounders` rather than suppressed.

<a id="53-st-段四型命名文档-34"></a>
### 5.3 Four ST-Segment Types Naming (Document 3.4)

`st_localization.classify_st_pattern`: `j_point_elevation` (J-type) / `slow_upsloping` (SU-type) /
`horizontal` (H-type) / `downsloping` (DS-type). **Not a renaming of `trend`**: The J-type spans the trend
(J-point elevation with notch/sloping, followed by flat or upsloping); separating it from ordinary upsloping types is key to avoiding benign early repolarization
being misread as ischemic ST-segment changes. Downsloping type has the highest priority — a downsloping ST segment is never classified as early repolarization, regardless of how much the J-point resembles a fishhook.
Output per lead to `leads[*].st.hybrid_robust.pattern_class`.

<a id="54-心房激动起源与多源性文档-12"></a>
### 5.4 Atrial Activation Origin and Multifocality (Document 1.2)

`clinical_rules/atrial_rhythm.py`:

- `junctional_rhythm_pattern` / `ectopic_atrial_rhythm_pattern`: Inverted P in inferior leads + PR boundary
  (<120 ms junctional, ≥120 ms low ectopic atrial). **Limb lead reversal is a typical false positive for this rule** (reversal also inverts inferior P waves),
  and has been listed as a suppression item. Suppressed globally when sinus mechanism is confirmed — sinus criteria use multi-lead P axis + organized_p_ratio,
  which provide stronger evidence than the 2–3 lead amplitudes used in this rule.
- `multifocal_atrial_rhythm` / `multifocal_atrial_tachycardia`: Beat-to-beat P morphology clustering in lead II
  (amplitude 0.06 mV / duration 30 ms tolerance, each cluster ≥2 beats to prevent noise from splitting one focus into three) + PR variability + irregular RR.

**False positives exposed in practice**: PTB-XL 11026 (label **AFIB**) previously met all textbook criteria.
Atrial fibrillation is the true differential diagnosis, and textbook criteria do not exclude it — f waves cluster into "multiple morphologies" just as easily as true P waves.
Therefore, a hard criterion **`organized_p_ratio ≥ 0.60`** was added: The true distinction between MAT and AF is "a discrete P wave before almost every QRS",
rather than morphology counting. After this addition, this case no longer triggers. Relying solely on the `probable_af` flag is insufficient because it depends on a detector that may miss detections.

<a id="55-仍未实现-刻意不做"></a>
### 5.5 Not Yet Implemented / Deliberately Not Done

| Item | Reason |
|---|---|
| Direct analysis of RV V4R, posterior V7–V9 | Standard 12-lead ECG does not include these leads (data source limitation, not algorithm defect); V1–V3 mirror pathway already exists |
| "Normality" judgment of U-wave and T-wave direction consistency | Polarity data exists, but normal/abnormal boundaries have not been defined; avoiding setting thresholds without empirical support |

**Rule Availability Design**: New rhythm / ischemia domain rules are set to `normality_role="supporting"`
(following the existing precedent of 2:1 atrial flutter screening in `basic_rhythm`), so when data is insufficient and `unavailable`,
the entire domain will **not** be marked as unevaluated, thereby preventing normal records from being downgraded to `incomplete`. Empirical testing on 30 records confirmed that no domain unavailability was caused by the new rules. The repolarization domain was not within `REQUIRED_DOMAINS` to begin with.
