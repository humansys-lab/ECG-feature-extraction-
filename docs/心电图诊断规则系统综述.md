# 第 0 章 基础事项（判读前必须掌握）

## 0.1 心电图的原理

- 心肌除极/复极产生的电位差，通过体表电极记录为电压-时间曲线。
- **核心规则**：除极波**朝向**某导联正极 → 该导联记录**向上（正向）**波；**背离**正极 → **向下（负向）**波；与导联轴**垂直** → 双向或等电位。
- 复极方向在正常心室与除极方向**相反**（心外膜先复极），因此正常 T 波与 QRS 主波**同向**。
- 心电图反映的是**瞬时综合向量（合成向量）**在各导联轴上的投影。

## 0.2 心电计的操作与记录条件

| 项目 | 标准值 | 说明 |
|---|---|---|
| 走纸速度 | **25 mm/s** | 1 小格（1 mm）= **0.04 s**；1 大格（5 mm）= **0.20 s** |
| 增益（标准电压） | **10 mm/mV** | 1 小格 = 0.1 mV；定标方波高 10 mm |
| 低频截止（时间常数） | ≥ 3.2 s（0.05 Hz） | 过短会造成假性 ST 偏移 |
| 高频截止 | 100–150 Hz（成人 ≥150 Hz） | 过低会削低 R 波、掩盖切迹 |
| 交流滤波（Hz 滤波） | 尽量不用 | 会使 QRS 变形，掩盖 δ 波、J 波 |

**记录条件必须先确认**：若走纸 50 mm/s，则所有时间读数需 ÷2；若增益 5 mm/mV（半标准），则电压需 ×2。**很多"左室高电压"和"低电压"的误判来自未确认定标。**

### 电极位置（必须记忆）

- **肢体导联**：右腕（红）、左腕（黄）、左踝（绿）、右踝（黑，接地）
- **胸导联**：
  - V1：胸骨右缘第 4 肋间
  - V2：胸骨左缘第 4 肋间
  - V3：V2 与 V4 连线中点
  - V4：左锁骨中线第 5 肋间
  - V5：V4 水平、腋前线
  - V6：V4 水平、腋中线
  - **V7–V9**（后壁）：V6 水平的腋后线 / 肩胛下角线 / 脊柱旁线
  - **V3R–V6R**（右室）：V3–V6 的右胸对称位置（V4R 最常用）

## 0.3 波形名称与测量法

| 波/间期 | 定义 | 反映 |
|---|---|---|
| **P 波** | 心房除极 | 前半＝右房，后半＝左房 |
| **PQ（PR）间期** | P 起点 → QRS 起点 | 房室传导时间（含房内、AVN、His-Purkinje） |
| **QRS 群** | 心室除极 | 心室内传导 |
| **J 点** | QRS 终点 = ST 起点 | ST 偏移的测量基准点 |
| **ST 段** | J 点 → T 波起点 | 心室复极早期（平台期） |
| **T 波** | 心室复极 | |
| **QT 间期** | QRS 起点 → T 波终点 | 心室总电活动时间 |
| **U 波** | T 后的小波 | 浦肯野纤维 / 乳头肌复极（学说未定） |

### 测量要点

- **基线（等电位线）**：以 **TP 段**为准（心动过速时用 PR 段）。
- **ST 偏移测量点**：**J 点后 0.06–0.08 s**（日本教材多用 J 点后 0.08 s；ST 抬高的诊断则在 **J 点**测量）。
- **QT 终点**：T 波下降支切线与基线交点（切线法）。有 U 波时不含 U 波；T-U 融合时取 T 与 U 谷底。
- **QT 间期用 II 导联或 V5，取最长者**。
- **心率计算**：
  - 规则：`HR = 300 ÷ (RR 大格数)` 或 `1500 ÷ (RR 小格数)`
  - 不规则（如房颤）：数 **6 秒（30 大格）内 QRS 数 × 10**
- **QT 校正（QTc）**：
  - Bazett：`QTc = QT / √RR(s)` —— 最常用，但心率过快/过慢时误差大
  - Fridericia：`QTc = QT / RR^(1/3)` —— 心动过速时更可靠

## 0.4 QRS 波形的命名规则

- **Q 波**：QRS 的**第一个向下**波，其前无向上波
- **R 波**：**任何向上**波（第 2 个向上波记为 R'）
- **S 波**：R 波**之后向下**的波
- **QS 波**：整个 QRS 群**只有一个向下**波
- **大小写**：振幅**≥ 5 mm（0.5 mV）用大写**（Q、R、S），**< 5 mm 用小写**（q、r、s）

例：`rSr'`（V1 的不完全右束支阻滞型）、`qR`、`RS`、`QS`、`rsR'`（M 型）

## 0.5 各导联的"观察方向"（定位诊断的根本）

| 导联组 | 观察部位 | 对应冠脉 |
|---|---|---|
| **II, III, aVF** | **下壁（膈面）** | RCA（多数）/ LCX |
| **I, aVL** | **高侧壁** | LCX 或 LAD 对角支 |
| **V1, V2** | **前间壁（室间隔）**、亦朝向右室 | LAD 近端间隔支 |
| **V3, V4** | **前壁** | LAD |
| **V5, V6** | **侧壁（左室下侧壁）** | LCX / LAD 远端 |
| **V1–V6 全部** | **广泛前壁** | LAD 近端 |
| **V7–V9** | **后壁（正后壁）** | LCX / RCA |
| **V3R–V6R（V4R）** | **右室** | RCA 近端 |
| **aVR** | 右上方 / 心腔内 | 抬高提示左主干或三支病变 |

**"相邻导联"的定义**（诊断 MI 必需的"≥2 个相邻导联"）：
`V1-V2-V3-V4-V5-V6` 顺序相邻；`aVL-I-(-aVR)-II-aVF-III` 顺序相邻。

## 0.6 平均电轴（QRS 电轴）

**求法（目视法）**：
1. 找肢体导联中 QRS 代数和最接近 0 的导联 → 电轴与该导联轴**垂直**
2. 再看与之垂直的导联主波方向 → 确定是垂直方向的哪一侧
3. 简易判断：**I 与 aVF 均为正 → 0°～+90°（正常）**

| 电轴 | 范围 | 常见原因 |
|---|---|---|
| 正常 | **−30° ～ +90°**（宽松 −30°～+110°） | |
| **左偏** | −30° ～ −90° | 左前分支阻滞、下壁 MI、LVH、横位心、肥胖、妊娠 |
| **右偏** | +110° ～ +180° | RVH、左后分支阻滞、侧壁 MI、垂位心、COPD、肺栓塞 |
| **不确定轴（西北轴）** | −90° ～ ±180° | 严重心脏病、室速、高钾、右位心、电极接错 |

## 0.7 术语约定

- **"性" vs "样"**：形态学描述用「…型（pattern）」，如 "RBBB 型"，不等于真正的束支阻滞。
- **原发性 ST-T 改变**：QRS 正常，ST-T 本身异常（缺血、电解质、药物）。
- **继发性 ST-T 改变**：因 QRS 异常（束支阻滞、肥大、预激、起搏）而"顺带"出现的 ST-T 改变。
- **"疑似 / 提示 / 符合"**：心电图诊断多为**概率性**表述，除少数（房颤、完全性 AVB、预激等）外，不宜断言病理诊断。

# 第 1 章 正常心电图与判读顺序

## 1.0 判读的固定顺序（务必按此顺序，防漏诊）

1. **记录条件确认**（走纸速度、增益、有无伪差、电极是否接错）
2. **节律（rhythm）** —— 是否窦性？规则否？
3. **心率（rate）**
4. **P 波** —— 有无、形态、大小、每个 P 后是否跟 QRS
5. **PQ 间期**
6. **QRS**：时限 → 电轴 → 振幅 → 有无异常 Q → 胸导 R 波递增
7. **ST 段**：抬高 / 压低 / 形态
8. **T 波**：方向、振幅、对称性
9. **QT 间期（QTc）**
10. **U 波**
11. **与既往心电图对比**（最重要的一步！）

## 1.1 节律、心率、P 波、PQ

### 窦性心律的诊断标准（4 条全部满足）

1. **P 波在 II、III、aVF 直立**，**aVR 倒置**
2. 每个 P 波后跟随一个 QRS（PQ 恒定，0.12–0.20 s）
3. **PP 间期规则**（变动 < 0.16 s；> 0.16 s 为窦性心律不齐）
4. 频率 **50/60–100 次/分**

### 正常 P 波

| 项目 | 正常值 | 最佳观察导联 |
|---|---|---|
| 时限 | **< 0.12 s（< 3 小格）** | II |
| 振幅 | **< 0.25 mV（< 2.5 mm）** | II, III, aVF |
| 形态 | 圆钝单峰；V1 可呈正负双相 | II, V1 |
| V1 终末负向部分（Ptf） | 面积 > −0.04 mm·s（即 深度 <1 mm 或 宽度 <0.04 s） | V1 |

### 正常 PQ（PR）间期

- **0.12 – 0.20 s**（儿童/心动过速时可稍短，老年/心动过缓可达 0.21 s）
- 测量应取**最长的 PQ**（在 II 或 V1）

## 1.2 QRS 群的检查点

| 项目 | 正常标准 |
|---|---|
| **时限** | **< 0.10 s**（0.10–0.11 s 为轻度延长；**≥ 0.12 s 为宽 QRS**） |
| **电轴** | −30° ～ +90° |
| **正常 q 波（间隔 q）** | I, aVL, V5, V6 可有小 q：**宽度 < 0.04 s 且 深度 < 同导联 R 波的 1/4** |
| **aVR** | 正常呈 QS 或 rS（主波向下） |
| **V1** | 正常可呈 QS 或 rS；**V1 有 q 波则异常** |
| **胸导 R 波递增** | V1→V5 逐渐增高；**V1 的 R < S**，**V6 的 R > S** |
| **移行区（R=S）** | **V3 – V4**（V2 或更右＝逆钟向转位；V5 或更左＝顺钟向转位） |
| **室壁激动时间 VAT（类本位曲折）** | V5, V6 **< 0.05 s**；V1, V2 **< 0.03 s** |
| **振幅（不过低）** | 肢体导联至少 1 个 ≥ 0.5 mV，胸导至少 1 个 ≥ 1.0 mV |

## 1.3 ST 段的检查点

- 正常 ST 段与基线（TP 段）**齐平**，为**平滑上凹**曲线。
- 允许范围：
  - **抬高**：肢体导联 **< 0.1 mV**；V1–V3 **< 0.2 mV（男 ≥40 岁）/ < 0.25 mV（男 <40 岁）/ < 0.15 mV（女）**
  - **压低**：**< 0.05 mV**（任何导联）
- **早期复极（正常变异）**：J 点抬高伴 J 波（切迹/顿挫），ST 呈**上凹**，T 波高耸直立，多见于 V2–V5 及下壁，年轻男性、运动员。**关键是形态上凹 + 无动态演变 + 无对应导联压低**。

## 1.4 T 波的检查点

- 方向：**与 QRS 主波同向**
  - I, II, V3–V6：**直立**
  - aVR：**倒置**
  - III, aVL, V1, V2：**可以倒置（正常变异）**；V1 倒置在女性尤为常见
- 形态：**不对称**（升支缓、降支陡）
- 振幅：肢体导联 < 0.5 mV，胸导 < 1.0–1.5 mV；一般 **≥ 同导联 R 波的 1/10**（过低为 T 波低平）
- **持续性幼稚型 T 波（persistent juvenile T）**：年轻女性 V1–V3 T 倒置，为正常变异

## 1.5 QT 间期与 U 波

| 项目 | 正常值 |
|---|---|
| **QTc（Bazett）** | 男 **≤ 0.44 s**，女 **≤ 0.46 s**（≥0.48 s 明确延长；≤0.34–0.36 s 为缩短） |
| **简易判断** | **QT < RR 的一半**（心率 60–100 时适用） |
| **U 波** | 与 T 同向（直立），振幅 **< T 波的 1/2**（一般 < 0.1–0.2 mV），V2–V3 最明显 |

**U 波倒置在任何导联都是异常**（除 aVR）。

# 第 2 章 P-QRS 关系异常：基本节律异常（非心动过速）

> **切入点**：找不到正常的 P 波，或 P 与 QRS 不对应。

## 2.1 心房颤动〈AF / Af〉

| 诊断要素 | 具体标准 | 最佳导联 |
|---|---|---|
| **P 波消失** | 代之以**细颤波 f 波**，频率 **350–600 次/分**，振幅形态不规则 | **V1**（f 波最清楚）、II |
| **RR 间期绝对不整** | 无任何规律（"绝对不整 absolutely irregular"） | 任意 |
| **QRS 形态** | 通常正常（窄）；伴束支阻滞或差异传导时变宽 | |

**补充判读**：
- **心室率分类**：< 50 次/分＝慢心室率型（提示 AVN 传导障碍或药物过量）；50–100＝控制良好；> 100＝快心室率型
- **粗颤波（coarse AF）**：f 波 ≥ 0.1 mV，常见于二尖瓣狭窄、左房显著扩大
- **Ashman 现象**：长 RR 后的短 RR 出现宽 QRS（多为 RBBB 型），是**差异传导**而非 PVC
- **AF + 规则的缓慢心室率** → **完全性房室阻滞合并 AF**（重要！不可漏诊）
- **AF + 规则的快速心室率（>100，规则）** → 交界性心动过速 / 洋地黄中毒
- **AF + 极快（>200）不规则宽 QRS** → **预激伴 AF（pseudo-VT）**，禁用洋地黄/维拉帕米

## 2.2 心房扑动〈AFL〉

| 诊断要素 | 具体标准 | 最佳导联 |
|---|---|---|
| **F 波（锯齿波 saw-tooth）** | 频率 **250–350 次/分**（典型 ~300） | **II, III, aVF**（典型型呈负向锯齿）、**V1**（呈正向直立 P 样） |
| **无等电位线** | F 波连续，基线呈连续波浪状 | II, III, aVF |
| **房室传导比** | 2:1（心室率 ~150）、3:1（~100）、4:1（~75）；比例固定则 RR 规则，不固定则不整 | |
| **QRS** | 通常窄 | |

**要点**：
- **心室率恒定 150 次/分左右的规则窄 QRS 心动过速 → 首先怀疑 2:1 AFL**（F 波藏在 QRS 和 T 中）
- 显露方法：颈动脉窦按摩或腺苷 → 房室传导比增加，F 波暴露
- **典型型（common/counterclockwise）**：II/III/aVF 负向锯齿、V1 正向
- **非典型型（reverse typical）**：II/III/aVF 正向、V1 负向

## 2.3 房室交界区节律 / 加速性交界区节律

| 类型 | 频率 | 定义 |
|---|---|---|
| **交界性逸搏心律** | **40–60 次/分** | 窦房结功能低下或 AV 阻滞时的被动逸搏 |
| **加速性交界区节律** | **60–100 次/分** | 交界区自律性增高（洋地黄中毒、下壁 MI、心肌炎、心脏术后） |
| **交界性心动过速** | > 100 次/分 | |

**诊断要素**：
1. **QRS 窄**（除非合并束支阻滞）
2. **P 波逆行**：**II、III、aVF 倒置**，**aVR 直立**
3. P 与 QRS 的位置关系（决定于逆传与前传的相对速度）：
   - **P 在 QRS 之前**：PR **< 0.12 s**（"上部交界区"）
   - **P 埋没于 QRS 中**：看不到 P（最常见）
   - **P 在 QRS 之后**：RP **< 0.20 s**（"下部交界区"）
4. RR 间期规则

## 2.4 心室固有节律 / 加速性心室固有节律〈AIVR〉

| 类型 | 频率 | 意义 |
|---|---|---|
| **心室固有（逸搏）节律** | **20–40 次/分** | 完全性 AVB、濒死心律；极危险 |
| **加速性心室固有节律 AIVR** | **60–100（~120）次/分** | **急性 MI 再灌注的标志**；多为一过性、良性 |

**诊断要素**：
1. **宽大畸形 QRS ≥ 0.12 s**，T 波与 QRS 主波方向相反
2. **无相关的 P 波**（或存在房室分离）
3. 节律**规则或大致规则**
4. **开始与终止呈渐进性**（"warm-up / cool-down"）——与室速的突发突止不同
5. 常见**融合波（fusion beat）与夺获波**，因为频率与窦律接近

**AIVR vs VT**：AIVR 频率 < 120、渐起渐止、血流动力学稳定；VT ≥ 100（通常 >130）、突发突止。

## 2.5 心房静止〈AS〉/ 窦室传导

**心房静止（atrial standstill）**：
- **完全无 P 波**（各导联均无，包括 V1）
- 规则的交界性或室性逸搏心律
- 原因：高钾血症、洋地黄中毒、心房肌病变（心房麻痹）、终末期心脏病

**窦室传导（sino-ventricular conduction）—— 高钾血症的特征性表现**：
1. **P 波消失**（心房肌不能除极，但窦房结冲动经结间束传至心室）
2. **QRS 显著增宽**（正弦波样，无法区分 QRS 与 T）
3. **T 波高尖**
4. 节律规则
> 血钾常 > 8 mEq/L，为**紧急状态**（钙剂 + 葡萄糖胰岛素 + 透析）

# 第 3 章 P 波形态、大小异常

> **P 波看 II 导联（时限、振幅）+ V1 导联（双相成分）**，这两个导联是 P 波诊断的主战场。

## 3.1 左房扩大（P mitrale）

| 标准 | 数值 | 导联 |
|---|---|---|
| **P 波时限延长** | **≥ 0.12 s（≥ 3 小格）** | **II**（或 I, aVL） |
| **双峰 P（notched）** | 两峰间距 **≥ 0.04 s** | **II** |
| **P 波终末电势（Ptf-V1）** | **≤ −0.04 mm·s**（即 终末负向波 **深 ≥ 1 mm 且 宽 ≥ 0.04 s**） | **V1** |

- 病因：**二尖瓣狭窄/关闭不全**、左室肥大/心衰导致的左房负荷、高血压
- 注意：Ptf-V1 异常是**最敏感**的指标，也可见于左室舒张功能不全（不一定真有左房扩大）

## 3.2 右房扩大（P pulmonale）

| 标准 | 数值 | 导联 |
|---|---|---|
| **P 波高尖** | **≥ 0.25 mV（≥ 2.5 mm）** | **II, III, aVF** |
| **V1 起始正向部分增高** | **≥ 0.15 mV（≥ 1.5 mm）** | **V1**（或 V2） |
| **P 波时限** | **正常（< 0.12 s）** —— 是与左房扩大的关键区别 | II |
| 电轴 | P 电轴右偏（> +75°） | |

- 病因：**COPD / 肺心病、肺动脉高压、三尖瓣疾病、先天性心脏病（PS、ASD、TOF、Ebstein）**
- **双心房扩大**：II 导联 P 既高（≥2.5 mm）又宽（≥0.12 s）+ V1 双向 P 的正负成分均增大

## 3.3 异位心房节律（冠状窦节律 / 左房节律）

**共同点**：P 波形态异常但 **PQ ≥ 0.12 s**（与交界性节律的关键鉴别）

| 类型 | 特征 | 导联 |
|---|---|---|
| **冠状窦节律** | **II, III, aVF 的 P 倒置**，**PQ ≥ 0.12 s**；I、V5–V6 P 直立 | II, III, aVF |
| **左房节律** | **I 和/或 aVL 的 P 倒置**（关键！）；V1 呈 **"dome and dart"（圆顶与尖顶）**样 P | **I, aVL, V1** |
| **右房下部节律** | II, III, aVF P 倒置，I 直立 | |

> **口诀**：P 倒置 + PQ ≥ 0.12 s → 异位房性；P 倒置 + PQ < 0.12 s → 交界性。

## 3.4 游走性起搏点（wandering pacemaker）

**诊断要素（同一导联，通常看 II）**：
1. **P 波形态有 ≥ 3 种**，逐搏渐变（直立→低平→倒置→再直立）
2. **PQ 间期随之变化**（0.12 s 以上到 0.12 s 以下）
3. **PP 间期轻度不规则**
4. 心率通常正常或偏慢（**若 > 100 次/分 → 称"多源性房性心动过速 MAT"**，多见于严重 COPD）

- 机制：起搏点在窦房结 ↔ 心房 ↔ 交界区之间游走
- 多为迷走张力增高所致的**生理现象**（运动员、青年、睡眠中）

# 第 4 章 PQ（PR）间期缩短与延长

## 4.1 WPW 综合征（心室预激）

### 诊断三联征

| # | 标准 | 数值 |
|---|---|---|
| 1 | **PQ 间期缩短** | **< 0.12 s** |
| 2 | **δ（delta）波** | QRS 起始部粗钝、顿挫；使 QRS 起始 0.03–0.05 s 缓慢 |
| 3 | **QRS 增宽** | **≥ 0.12 s**（PQ + QRS 之和恒定，因为 PJ 间期正常 ≤ 0.26 s） |
| 附 | **继发性 ST-T 改变** | ST-T 方向与 δ 波/QRS 主波相反 |

### 分型（依据 V1 的 δ 波/QRS 主波极性）

| 型 | V1 的 QRS 主波 | 旁路位置 | 易被误诊为 |
|---|---|---|---|
| **A 型** | **正向（R 或 Rs）** | **左侧壁 / 左后** | **RBBB、后壁 MI、RVH** |
| **B 型** | **负向（rS 或 QS）** | **右侧壁 / 右前** | **LBBB、前间壁 MI** |
| **C 型** | V1–V4 正向、V5–V6 负向 | 左后间隔 | 罕见 |

**重要陷阱**：
- 预激可产生**假性 Q 波**（δ 波向下时），被误诊为陈旧 MI（尤其下壁）
- 预激的 ST-T 改变是**继发性**的，不可诊断为缺血
- **WPW + 房颤 = pseudo-VT**（极快、不规则、宽 QRS）→ **禁用洋地黄、维拉帕米、β 阻滞剂**（会加速旁路传导 → VF）
- **间歇性预激**（δ 波时有时无）提示旁路不应期长，猝死风险低

## 4.2 LGL 综合征

| 标准 | |
|---|---|
| **PQ < 0.12 s** | ✅ |
| **无 δ 波** | ✅ |
| **QRS 时限正常（< 0.10 s）** | ✅ |
| 伴发作性室上速病史 | 诊断"综合征"所需 |

- 机制假说：James 束（房-结旁路）或 AVN 内快速传导通路
- 若无心动过速发作，仅描述为"**短 PQ（PR）间期**"

## 4.3 I 度房室阻滞

| 标准 | 数值 |
|---|---|
| **PQ 间期延长** | **> 0.20 s**（老年可放宽至 > 0.22 s；儿童 > 0.18 s） |
| **每个 P 波后均有 QRS** | 无脱落（这是与 II 度的区别） |
| PQ 恒定 | |

**阻滞部位的推断**：
- **QRS 窄 + PQ 延长** → 阻滞多在 **AVN 内**（良性，阿托品可改善）
- **QRS 宽（束支阻滞）+ PQ 延长** → 阻滞可能在 **His 束以下**（需警惕进展为高度 AVB）
- PQ **> 0.30 s** 称"显著 I 度 AVB"，可致房室不同步（"起搏器综合征"样症状）
- 病因：迷走张力增高、运动员、洋地黄/β 阻滞剂/钙拮抗剂、下壁 MI、心肌炎（尤其莱姆病）、老年传导系统退行性变

# 第 5 章 QRS 增宽与电轴异常

> **切入点**：QRS ≥ 0.12 s 时，先看 **V1 的形态**（正向＝RBBB 型，负向＝LBBB 型），再看电轴。

## 5.1 完全性右束支阻滞〈CRBBB〉

| # | 标准 | 导联 |
|---|---|---|
| 1 | **QRS ≥ 0.12 s** | 任意 |
| 2 | **V1（V2）呈 rsR'、rSR'、M 型**（"兔耳"），R' > r | **V1, V2** |
| 3 | **I、aVL、V5、V6 出现宽而顿挫的 S 波**（S 宽度 > R 宽度或 > 0.04 s） | **I, aVL, V5, V6** |
| 4 | **V1 的 VAT（类本位曲折）> 0.05 s** | V1 |
| 5 | **继发性 ST-T 改变**：V1–V2 ST 压低、T 倒置 | V1, V2 |

- **不完全性 RBBB（IRBBB）**：形态相同但 **QRS 0.10–0.12 s**。常见于正常年轻人、**ASD（重要！）**、右室容量负荷。
- **RBBB 不妨碍 MI 诊断**：因为 QRS 起始向量（间隔除极）正常，Q 波仍可判读。
- V1 呈 **qR** 型的 RBBB → 提示合并**前间壁 MI** 或右室肥大。

## 5.2 完全性左束支阻滞〈CLBBB〉

| # | 标准 | 导联 |
|---|---|---|
| 1 | **QRS ≥ 0.12 s** | 任意 |
| 2 | **V5、V6、I、aVL 呈宽大、顿挫或平顶的 R 波**，**无 q 波**（间隔 q 消失） | **I, aVL, V5, V6** |
| 3 | **V1、V2 呈 rS 或 QS**（r 极小或缺如） | **V1, V2** |
| 4 | **V5、V6 的 VAT > 0.06 s** | V5, V6 |
| 5 | **继发性 ST-T 改变**：I、aVL、V5、V6 ST 压低 + T 倒置；V1–V3 ST 抬高 + T 直立 | |
| 6 | 电轴常左偏 | |

**临床要点**：
- CLBBB 几乎总是**器质性心脏病**的标志（缺血性心肌病、高血压、扩张型心肌病、主动脉瓣病变），与 RBBB 不同。
- **CLBBB 掩盖 MI 诊断** → 使用 **Sgarbossa 标准**判断急性 MI：
  - ST 抬高 **≥ 1 mm 且与 QRS 主波同向（concordant）** —— 5 分
  - V1–V3 ST 压低 **≥ 1 mm 且与 QRS 主波同向** —— 3 分
  - ST 抬高 **≥ 5 mm 且与 QRS 主波反向（discordant）** —— 2 分
  - （修正版 Smith 标准：ST/S 比值 ≤ −0.25）
  - **≥ 3 分**提示急性 MI
- **新出现的 LBBB + 胸痛** 按 STEMI 等同处理。
- LBBB 时**不能诊断左室肥大、MI、缺血**（继发改变干扰）。

## 5.3 非特异性室内传导障碍〈nonspecific IVCD〉

| 标准 |
|---|
| **QRS ≥ 0.11–0.12 s** |
| **不符合典型 RBBB 也不符合典型 LBBB 的形态** |
| 常呈弥漫性 QRS 增宽、粗钝、切迹 |

- 病因：**高钾血症、Ia/Ic 类抗心律失常药（氟卡尼等）、三环类抗抑郁药中毒、严重心肌病变、心肌纤维化、高度心肌缺血**
- 见到 IVCD 应立即查**血钾**和**用药史**。

## 5.4 左前分支阻滞〈LAH / LAFB〉

| # | 标准 | 导联 |
|---|---|---|
| 1 | **电轴显著左偏：−45° ～ −90°**（部分教材用 ≤ −30°） | 肢体导联 |
| 2 | **II、III、aVF 呈 rS 型**，且 **S(III) > S(II)** | II, III, aVF |
| 3 | **I、aVL 呈 qR 型**，**R(aVL) > R(I)** | I, aVL |
| 4 | **QRS 时限正常或轻度延长（< 0.12 s）** | |
| 5 | aVL 的 VAT ≥ 0.045 s | aVL |
| 6 | 需**排除**下壁 MI、LVH、垂位心、肺气肿等其他左偏原因 | |

- 是最常见的分支阻滞。可造成 **V1–V3 R 波递增不良**（假性前间壁 MI）和 **aVL 假性 Q 波**。

## 5.5 左后分支阻滞〈LPH / LPFB〉

| # | 标准 | 导联 |
|---|---|---|
| 1 | **电轴右偏：+90° ～ +180°**（多数要求 ≥ +110°） | 肢体导联 |
| 2 | **I、aVL 呈 rS 型** | I, aVL |
| 3 | **II、III、aVF 呈 qR 型**，且 **R(III) > R(II)** | II, III, aVF |
| 4 | **QRS < 0.12 s** | |
| 5 | **必须排除**：右室肥大、垂位心（瘦长体型）、侧壁 MI、肺气肿、肺栓塞 | |

- 左后分支粗且双重供血 → **单独 LPH 罕见**，出现时提示广泛病变、预后差。
- **诊断 LPH 是排除性诊断**，务必先排除 RVH。

## 5.6 双分支阻滞与三分支阻滞

| 类型 | 心电图组合 |
|---|---|
| **双分支阻滞（bifascicular block）** | ① **RBBB + LAH**（最常见：V1 rsR' + 电轴 ≤−45°）<br>② **RBBB + LPH**（V1 rsR' + 电轴 ≥+110°，预后较差）<br>③ 单独 CLBBB（视为左前+左后同时受累） |
| **三分支阻滞（trifascicular block）** | 双分支阻滞 **+ I 度 AVB（PQ 延长）**（"不完全三分支"）<br>或 双分支阻滞 **+ 交替出现的另一种分支阻滞**<br>或 双分支阻滞 **+ II 度/III 度 AVB**（"完全三分支"＝完全性 AVB） |

- 双分支阻滞 + 晕厥 → 强烈提示间歇性完全性 AVB，**起搏器适应证评估**。

## 5.7 双侧束支阻滞、交替性束支阻滞

- **交替性束支阻滞（alternating BBB）**：同一份或连续记录中，**RBBB 与 LBBB 交替出现**，或 RBBB+LAH 与 RBBB+LPH 交替 → **双侧束支病变，极高危，永久起搏器 I 类适应证**。
- **双侧束支阻滞**：表现为**完全性房室阻滞 + 宽 QRS 逸搏**，阻滞部位在 His 束以下（逸搏频率 < 40，对阿托品无反应）。

# 第 6 章 左室电位过高 / 过低

## 6.1 左室高电压（high voltage）

> 仅电压增高、**无 ST-T 改变**时，只能诊断"左室高电压"，不能诊断左室肥大。

| 标准名称 | 公式 | 导联 |
|---|---|---|
| **Sokolow-Lyon（胸导）** | **S(V1) + R(V5 或 V6) ≥ 3.5 mV（35 mm）** | V1, V5, V6 |
| **R(V5) 或 R(V6)** | **≥ 2.6 mV（26 mm）** | V5, V6 |
| **Sokolow-Lyon（肢导）** | **R(I) + S(III) ≥ 2.5 mV** | I, III |
| **R(aVL)** | **≥ 1.1 mV（1.2 mV）** | aVL |
| **Cornell 电压** | **R(aVL) + S(V3) > 2.8 mV（男）/ > 2.0 mV（女）** | aVL, V3 |
| **Cornell 乘积** | (Cornell 电压 + 女性 0.6 mV) × QRS 时限 > 2440 mm·ms | |

**注意**：青年、瘦体型、运动员常有假阳性；肥胖、肺气肿、心包积液常有假阴性。

## 6.2 左室肥大〈LVH〉

诊断 = **电压标准 + 支持性所见**：

| 支持性所见 | 具体描述 | 导联 |
|---|---|---|
| **① ST-T 劳损型（strain pattern）** | ST 段**下斜型压低** + **非对称性倒置 T**（降支陡、升支缓，呈"鱼钩"反向） | **V5, V6, I, aVL** |
| ② 左房扩大 | Ptf-V1 ≤ −0.04 mm·s | V1 |
| ③ 电轴左偏 | ≤ −15° ～ −30° | |
| ④ QRS 时限轻度延长 | 0.09–0.11 s | |
| ⑤ VAT 延长 | V5, V6 **> 0.05 s** | V5, V6 |
| ⑥ V1–V3 R 波递增不良 | | V1–V3 |

**Romhilt-Estes 积分法（≥ 5 分＝确诊，4 分＝可能）**

| 项目 | 分 |
|---|---|
| 任一肢导 R 或 S ≥ 2.0 mV，或 S(V1,V2) ≥ 3.0 mV，或 R(V5,V6) ≥ 3.0 mV | 3 |
| ST-T 劳损型（未用洋地黄） | 3（用洋地黄时 1） |
| 左房扩大（Ptf-V1 ≤ −0.04 mm·s） | 3 |
| 电轴左偏 ≤ −30° | 2 |
| QRS 时限 ≥ 0.09 s | 1 |
| VAT(V5/V6) ≥ 0.05 s | 1 |

- 病因：高血压、主动脉瓣狭窄、肥厚型心肌病、主动脉缩窄

## 6.3 左室容量（舒张期）负荷

> 与"压力负荷（劳损型）"相对，形态学上相反。

| 特征 | 描述 | 导联 |
|---|---|---|
| **深而窄的 q 波** | 间隔 q 增大（但宽度 < 0.04 s） | **V5, V6, I, aVL** |
| **高 R 波** | 电压增高 | V5, V6 |
| **ST 段抬高（轻度）或齐平** | 不是压低 | V5, V6 |
| **T 波高耸直立** | 与劳损型的倒置 T 相反 | V5, V6 |

- 病因：**主动脉瓣关闭不全、二尖瓣关闭不全、VSD、PDA、动静脉瘘、贫血/甲亢等高排量状态**
- 记忆：压力负荷 → ST-T 劳损（倒置 T）；容量负荷 → 深 q + 高 T。

## 6.4 肥厚型心肌病〈HCM〉

### 一般型（非对称性室间隔肥厚）

| 特征 | 描述 | 导联 |
|---|---|---|
| **左室高电压** | 常显著 | V4–V6 |
| **异常 Q 波（假性梗死型）** | **窄（< 0.04 s）而深**的 Q 波，源于室间隔肥厚 | **II, III, aVF, V4–V6, I, aVL** |
| ST-T 改变 | 倒置 T、ST 压低 | 侧壁导联 |
| 左房扩大 | | V1, II |

- **关键鉴别点**：HCM 的 Q 波**窄而深**（<0.04 s），MI 的 Q 波**宽**（≥0.04 s）。

### 心尖肥厚型（APH，日本多见）

| 特征 | 数值 | 导联 |
|---|---|---|
| **巨大倒置 T 波〈GNT〉** | **深度 > 1.0 mV（10 mm）**，最深常在 V4 | **V3–V5**（V4 最深） |
| **左室高电压** | R(V4–V5) 增高，常 ≥ 2.6 mV | V4, V5 |
| ST 压低 | 伴随 | V4–V6 |
| **无异常 Q 波** | 与 MI 鉴别 | |

- 心脏超声/MRI 见心尖部"黑桃 A（spade）"样左室腔。

## 6.5 低电压（low voltage）

| 标准 | 数值 |
|---|---|
| **肢体导联低电压** | **全部 6 个肢体导联的 QRS 振幅（R+S 绝对值之和）< 0.5 mV（5 mm）** |
| **胸导联低电压** | **全部 6 个胸导联 QRS 振幅 < 1.0 mV（10 mm）** |
| **广泛低电压** | 二者兼有 |

**病因鉴别**：

| 机制 | 疾病 |
|---|---|
| 心脏与电极间绝缘/短路 | **心包积液（+ 电交替 → 心脏压塞）**、胸腔积液、**肺气肿/COPD**、气胸、肥胖、皮下水肿 |
| 心肌本身电活动减少 | **心肌淀粉样变（低电压 + 假性梗死 Q 波，重要！）**、广泛心肌梗死、扩张型心肌病末期、**黏液性水肿（甲减）**、限制型心肌病 |
| 其他 | 缩窄性心包炎、硬皮病 |

- **电交替（electrical alternans）**：QRS 振幅逐搏高低交替 → **心脏压塞**的特异性表现（心脏在心包液中摆动）。

# 第 7 章 异常 Q 波

## 7.1 心肌梗死〈MI〉

### 异常 Q 波（病理性 Q 波）的标准

| # | 标准 |
|---|---|
| 1 | **宽度 ≥ 0.04 s**（V2–V3 用 ≥ 0.02 s 且呈 Q 或 QS） |
| 2 | **深度 > 同导联 R 波的 1/4**（有的教材用 > 1/3） |
| 3 | **出现在 ≥ 2 个相邻导联** |
| 4 | 常伴 R 波振幅减低、切迹 |

> **例外**：aVR 的 Q/QS 是正常的；III 和 V1 的孤立 Q 波常无意义（III 导联 Q 在深吸气时消失＝生理性）。

### 定位诊断（关键表）

| 梗死部位 | 出现异常 Q / ST 抬高的导联 | 对应（镜像）导联 | 罪犯血管 |
|---|---|---|---|
| **前间壁** | **V1, V2 (V3)** | — | LAD 间隔支 |
| **前壁** | **V3, V4** | — | LAD |
| **广泛前壁** | **V1–V6, I, aVL** | II, III, aVF | **LAD 近端（高危）** |
| **侧壁（高侧壁）** | **I, aVL (V5, V6)** | II, III, aVF | LCX / 对角支 |
| **下壁** | **II, III, aVF** | I, aVL (V1–V3) | **RCA（~80%）/ LCX** |
| **正后壁** | **V7–V9 的 Q**；**V1–V2 出现高 R、R/S ≥ 1、ST 压低、T 直立** | V1–V3（镜像） | LCX / RCA |
| **右室** | **V4R（V3R–V6R）ST 抬高 ≥ 0.1 mV** | — | **RCA 近端** |
| 左主干 | **aVR ST 抬高 > V1 的 ST 抬高**，广泛导联 ST 压低（≥6 个导联） | | LMT |

### MI 的时相演变（用于判断新旧）

| 分期 | 时间 | 心电图 |
|---|---|---|
| **超急性期** | 数分~数十分 | **T 波高尖增宽（hyperacute T）**，ST 开始抬高，尚无 Q |
| **急性期** | 数小时~数日 | **ST 显著抬高（凸面向上、单向曲线 monophasic）**，**异常 Q 出现**，对应导联 ST 压低 |
| **亚急性期（近期）** | 数日~数周 | ST 逐渐回落，**T 波倒置加深（冠状 T）**，Q 波固定 |
| **陈旧期** | 数周~数月以后 | **ST 回到基线**，T 可恢复直立或维持倒置，**异常 Q 波持续存在** |

**若 ST 抬高持续 > 4–6 周不回落 → 怀疑室壁瘤**（见 10.4）。

### 下壁 MI 的必查项
1. **加做 V4R** → 排除右室梗死（**右室梗死禁用硝酸酯类、利尿剂，需大量补液**）
2. **加做 V7–V9** → 排除后壁受累
3. 注意 **II、III、aVF 中 ST 抬高 III > II 且 V1 ST 抬高** → RCA 近端；**I、aVL ST 压低** 支持 RCA

## 7.2 左右电极接错（lead reversal）

**最常见：左右腕（LA/RA）互换**

| 特征 | 表现 |
|---|---|
| **I 导联**：P、QRS、T **全部倒置** | ✅ 关键 |
| **aVR 直立**（P 与 QRS 向上） | ✅ 关键 |
| II 与 III 互换，aVL 与 aVR 互换 | |
| **胸导联完全正常**（R 波递增正常） | ✅ **与右位心的关键区别** |

**其他接错**：
- **右腿（黑）与其他肢体互换** → 某个肢体导联呈**近乎平线（振幅极低）**
- 胸导电极顺序错 → R 波递增出现"断层"（如 V3 > V4）

## 7.3 右位心（dextrocardia）

| 特征 | 表现 |
|---|---|
| **I 导联** P、QRS、T **全部倒置** | 与电极接错相同 |
| **aVR 直立** | 与电极接错相同 |
| **胸导联 R 波从 V1 到 V6 逐渐减小**（"R 波递减"），V5–V6 呈极小 rS 或 QS | ✅ **决定性区别** |
| 电轴右偏 | |

**确认方法**：将肢体导联左右互换 + 胸导联置于右胸（V1R–V6R） → 记录出正常心电图，即可确诊镜像右位心。

# 第 8 章 胸导联 R 波递增不良

## 8.1 R 波递增不良〈poor R progression, PRP〉

| 标准（满足其一） |
|---|
| **R(V3) ≤ 0.3 mV（3 mm）** |
| **R(V1) ≤ R(V2) ≤ R(V3) ≤ R(V4)** 未按正常方式递增 |
| V1–V4 的 R 波振幅无明显增长 |

**鉴别诊断（重要，因为常被误报为"前壁陈旧梗死"）**：

| 原因 | 鉴别线索 |
|---|---|
| **前壁/前间壁陈旧 MI** | 伴 QS 或异常 Q、T 倒置、既往病史 |
| **左室肥大** | V5–V6 高电压、劳损型 ST-T |
| **左束支阻滞 / 左前分支阻滞** | QRS 宽或电轴左偏 |
| **COPD / 肺气肿** | 低电压、电轴右偏、P 肺型、顺钟向转位 |
| **扩张型心肌病** | 广泛低电压、心脏扩大 |
| **电极位置过高**（放在第 2–3 肋间） | 重新贴片后恢复；深吸气时改善 |
| **WPW（B 型）** | δ 波、短 PQ |
| 肥胖、女性乳房 | |

## 8.2 反向 R 波递增〈reversed r progression〉

- **R 波从 V1 向 V4 反而逐渐变小**（V1 > V2 > V3…）
- 意义与 PRP 相同但更强烈提示**前壁大面积梗死**或**右位心/电极错位**。

## 8.3 顺钟向转位（clockwise rotation）

| 标准 | 说明 |
|---|---|
| **移行区（R = S 处）右移至 V5、V6 或更左** | 正常在 V3–V4 |
| V1–V4（甚至 V5）均呈 **rS 型** | |
| 常伴电轴右偏 | |

- 意义：从心尖向上看，心脏沿长轴**顺时针**旋转，右室转向前方。
- 病因：**右室肥大、COPD/肺气肿、垂位心（瘦长体型）、肺栓塞**；也见于正常人。

# 第 9 章 右胸导联 R 波增高 / I、左侧胸导联 S 波加深

> **切入点**：V1 出现"高 R 波"（R/S ≥ 1）时的 6 大鉴别 —— **① 逆钟向转位 ② 后壁梗死 ③ 右室肥大 ④ RBBB ⑤ WPW A 型 ⑥ 正常变异/儿童**

## 9.1 逆钟向转位（counterclockwise rotation）

| 标准 |
|---|
| **移行区左移至 V2 或更右**（V1 就已呈 Rs） |
| V5、V6 呈 qR，无深 S |

- 病因：左室肥大、横位心（肥胖、妊娠、腹水）、正常变异。
- **是良性所见**，需与后壁梗死、RVH 鉴别。

## 9.2 后壁（正后壁）梗死

| # | 标准 | 导联 |
|---|---|---|
| 1 | **R/S ≥ 1**（R 波增高） | **V1, V2** |
| 2 | **R 波时限 ≥ 0.04 s** | V1, V2 |
| 3 | **ST 段压低**（急性期，为后壁 ST 抬高的镜像） | V1–V3 |
| 4 | **T 波直立、高耸**（为后壁倒置 T 的镜像） | V1, V2 |
| 5 | **确诊：加做 V7–V9，出现 ST 抬高 ≥ 0.05 mV（男<40岁 ≥0.1 mV）及/或异常 Q 波** | **V7, V8, V9** |
| 6 | 常合并下壁（II, III, aVF）或侧壁改变 | |

> 记忆法：把 V1–V2 的心电图**上下颠倒 + 左右翻转**看，就是后壁的"ST 抬高 + Q 波"。

## 9.3 右室肥大〈RVH〉

| # | 标准 | 导联 |
|---|---|---|
| 1 | **R/S ≥ 1**，或 **R ≥ 0.7 mV（7 mm）** | **V1** |
| 2 | **R(V1) + S(V5 或 V6) ≥ 1.05 mV（10.5 mm）** | V1, V5, V6 |
| 3 | **电轴右偏 ≥ +110°** | 肢体导联 |
| 4 | **V5、V6 出现深 S 波**（R/S ≤ 1） | V5, V6 |
| 5 | **ST-T 劳损型**：V1–V3 ST 压低 + T 倒置 | **V1–V3** |
| 6 | 常伴**右房扩大**（P ≥ 0.25 mV in II）、不完全性 RBBB | II, V1 |
| 7 | V1 的 VAT > 0.035 s | V1 |

**V1 高 R 的类型学**：
- **qR 型 in V1** → 提示重度 RVH（右房扩大压迫）或前间壁 MI
- **rSR' 型** → 右室容量负荷（ASD）
- **纯 R 或 Rs 型** → 右室压力负荷（PS、原发性肺高压、TOF）
- **rS 型持续到 V6** → 慢性肺心病型（COPD）

## 9.4 右束支阻滞〈RBBB〉

（诊断标准见 5.1）—— 在本章的意义：**RBBB 是 V1 高 R 波（R'）最常见的原因**。
- 鉴别关键：RBBB 的 V1 高波是**第二个 R（R'）**，且 QRS **≥ 0.12 s**，I 和 V6 有宽 S 波。
- **RBBB + 电轴右偏 + 右房扩大** → 提示合并 RVH。

## 9.5 急性肺源性心脏病（急性肺栓塞）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **S1Q3T3 型**：I 导联出现 S 波、III 导联出现 Q 波和倒置 T 波 | **I, III** |
| 2 | **右胸导联 T 波倒置**（最敏感的所见之一） | **V1–V4** |
| 3 | **新出现的完全性/不完全性 RBBB** | V1 |
| 4 | **电轴右偏**、顺钟向转位（移行区左移） | |
| 5 | **P 肺型**（右房负荷） | II, III, aVF |
| 6 | **窦性心动过速**（最常见的所见，但无特异性） | |
| 7 | 房颤/房扑等房性心律失常 | |
| 8 | V1–V3 ST 抬高（少见，易误诊为前间壁 MI） | |

> **注意**：肺栓塞的心电图**正常者也不少见（约 20–30%）**，心电图正常不能排除。S1Q3T3 只见于约 20%。**动态变化（与既往对比）价值最大。**

# 第 10 章 ST 段抬高

> **切入点**：见到 ST 抬高，依次判断 —— ① **形态**（凸面向上 vs 凹面向上）② **分布**（局限于某支冠脉区域 vs 广泛）③ **有无对应导联的镜像压低** ④ **有无动态演变** ⑤ **有无异常 Q 波**

| 鉴别要点速查 | AMI | 心包炎 | 早期复极 | Brugada | 室壁瘤 |
|---|---|---|---|---|---|
| 形态 | **凸面向上**（弓背） | **凹面向上** | 凹面向上 + J 波 | **coved（穹窿）** | 凸面，固定 |
| 分布 | 冠脉支配区（局限） | **广泛（除 aVR、V1）** | V2–V5、下壁 | **V1–V3** | 原梗死部位 |
| 镜像压低 | **有** | **无**（aVR 除外） | 无 | 无 | 无 |
| PR 段 | 正常 | **压低（aVR 抬高）** | 正常 | 正常 | 正常 |
| 演变 | **有（数小时~日）** | 有（数日~周，4 期） | **无（长期不变）** | 可变动（药物诱发） | **无（>6 周不变）** |
| Q 波 | 有 | 无 | 无 | 无 | **有（QS）** |

## 10.1 急性心肌梗死〈AMI / STEMI〉

### ST 抬高的诊断阈值（第四版心肌梗死通用定义）

| 导联 | 阈值（在 **J 点**测量，≥ 2 个相邻导联） |
|---|---|
| **V2, V3** | 男 ≥40 岁：**≥ 0.2 mV**；男 <40 岁：**≥ 0.25 mV**；女：**≥ 0.15 mV** |
| **其他所有导联** | **≥ 0.1 mV** |
| **V3R, V4R（右室）** | 男 ≥30 岁：≥ 0.05 mV；男 <30 岁：≥ 0.1 mV；女：≥ 0.05 mV |
| **V7–V9（后壁）** | **≥ 0.05 mV**（男 <40 岁 ≥ 0.1 mV） |

### 其他要素
- **形态**：ST 段**凸面向上（弓背向上）**，与 T 波融合成"**单向曲线（monophasic curve）/ 墓碑样**"
- **对应导联镜像性 ST 压低**（reciprocal change）—— 强烈支持 AMI 而非心包炎
- **动态演变**（见 7.1 表）
- **定位**（见 7.1 定位表）

### 高危征象
- **aVR ST 抬高 ≥ 0.1 mV + 广泛导联 ST 压低** → 左主干/三支病变
- **de Winter 型**：V1–V6 J 点压低 + 上斜型 ST 压低 + **T 波高尖对称**，aVR 轻度 ST 抬高 → **LAD 近端闭塞等同**
- **Wellens 综合征**：胸痛缓解期 **V2–V4 T 波双相或深倒置**，R 波保留、无 Q 波 → **LAD 近端严重狭窄**，禁忌运动试验

## 10.2 右室梗死〈RV infarction〉

| # | 标准 | 导联 |
|---|---|---|
| 1 | **V4R（V3R–V6R）ST 抬高 ≥ 0.05–0.1 mV**（最特异，但持续时间短，**发病 12 h 内必须记录**） | **V4R** |
| 2 | 合并**下壁 MI**（II, III, aVF ST 抬高） | II, III, aVF |
| 3 | **ST 抬高 III > II** | II, III |
| 4 | **V1 ST 抬高**（V1 是标准 12 导联中唯一朝向右室的导联）；V1 抬高 + V2 压低更提示 | V1, V2 |
| 5 | 常伴房室阻滞、心房梗死（PR 段偏移） | |

**临床意义（必须记住）**：三联征＝**低血压 + 颈静脉怒张 + 肺野清晰**；治疗上**禁用硝酸酯类、利尿剂、吗啡**，需**大量补液**。

## 10.3 变异型（Prinzmetal）心绞痛〈VAP〉

| # | 特征 |
|---|---|
| 1 | **发作性、一过性的 ST 段抬高**（凸面向上，与 AMI 相同形态），伴胸痛 |
| 2 | **发作缓解后 ST 完全恢复正常**（数分钟~数十分钟）—— 关键 |
| 3 | 发作时可见 **T 波高尖增宽、R 波增高增宽、S 波消失** |
| 4 | 对应导联镜像压低 |
| 5 | 常伴**发作时的室性心律失常（PVC、VT、VF）或房室阻滞** —— 猝死原因 |
| 6 | 好发于**夜间~清晨、静息时**；心肌酶不升高（除非持续痉挛致梗死） |

- 诊断：Holter 捕捉、乙酰胆碱/麦角新碱激发试验。
- 若仅有 **ST 压低或 T 波变化**的一过性发作 → 非 ST 抬高型冠脉痉挛。

## 10.4 室壁瘤（ventricular aneurysm）

| # | 标准 |
|---|---|
| 1 | 有陈旧 MI 病史 |
| 2 | **ST 段抬高持续 ≥ 4–6 周不回落**（"固定性 ST 抬高"） |
| 3 | 同导联存在 **QS 波或深 Q 波** |
| 4 | 常伴 T 波倒置 |
| 5 | 无胸痛、无心肌酶升高、**无动态变化** |
| 6 | 好发部位：**V1–V4（前壁心尖部）** |

## 10.5 急性心包炎

| # | 标准 | 导联 |
|---|---|---|
| 1 | **广泛导联的 ST 抬高（凹面向上）**：I, II, aVF, V2–V6 等 | 广泛 |
| 2 | **aVR（常还有 V1）ST 压低** —— 唯一的"镜像" | aVR, V1 |
| 3 | **PR（PQ）段压低**，而 **aVR 的 PR 段抬高** —— 最特异的所见 | II, V5, V6 / aVR |
| 4 | **无异常 Q 波**、R 波振幅保持 | |
| 5 | **ST/T 比值 > 0.25**（V6，用于与早期复极鉴别） | V6 |
| 6 | 常伴窦性心动过速；心包积液时低电压 + 电交替 | |

**4 期演变（Spodick）**：
- **I 期**：广泛 ST 抬高 + PR 压低（数日）
- **II 期**：ST 回到基线，T 波变平（1–3 周）
- **III 期**：**广泛 T 波倒置**（3–数周）
- **IV 期**：恢复正常（数周~数月，也可长期遗留 T 倒置）

> 与 AMI 的关键区别：心包炎的 **ST 抬高与 T 倒置不同时出现**（AMI 中 ST 尚抬高时 T 已开始倒置）。

## 10.6 脑血管障碍（尤其蛛网膜下腔出血 SAH）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **巨大倒置 T 波〈GNT〉**：宽大、深（可 > 1.0 mV）、对称，常称"**cerebral T**" | **广泛，尤 V2–V6** |
| 2 | **QT 间期显著延长**（QTc 可 > 0.60 s） → **TdP 风险** | II, V5 |
| 3 | **U 波增高**（明显） | V2–V4 |
| 4 | ST 抬高或压低（可类似 MI，"**神经源性心肌顿抑**"） | |
| 5 | **窦性心动过缓**、各种心律失常 | |

- 机制：交感神经风暴 → 儿茶酚胺心肌损伤。心肌酶可轻度升高（易误诊 AMI，**误用抗凝/溶栓可致命**）。

## 10.7 Takotsubo（应激性）心肌病

| 阶段 | 心电图 |
|---|---|
| **急性期（数小时）** | **广泛前壁导联（V2–V6, I, aVL）ST 抬高**，但 **aVR 常 ST 压低**；**对应导联镜像压低不明显**；抬高幅度小于同范围的 AMI |
| **亚急性期（2–5 日）** | **巨大倒置 T 波（GNT）+ 显著 QT 延长（QTc 常 > 0.50 s）** |
| **恢复期（数周~数月）** | 逐渐恢复 |

**与前壁 AMI 的鉴别线索**：
- **无异常 Q 波**，或仅一过性 Q 波（R 波保留）
- **ST 抬高范围广于单支冠脉支配区**，且 **aVR ST 压低 + V1 无抬高**
- 心肌酶升高幅度**与 ST 抬高范围不成比例（偏低）**
- 诱因：**强烈情绪/躯体应激**，好发**老年女性**
- 确诊靠左室造影/超声：心尖部球形扩张（"章鱼壶"）

## 10.8 Brugada 综合征

### 心电图分型（V1–V3，尤其 V1、V2）

| 型 | J 点抬高 | ST 形态 | T 波 |
|---|---|---|---|
| **1 型（coved / 穹窿型）** | **≥ 0.2 mV（2 mm）** | **下斜型（coved），与 T 波连续** | **倒置** |
| **2 型（saddleback / 马鞍型）** | ≥ 0.2 mV | 谷底 ST 抬高 **≥ 0.1 mV**，上斜型 | 直立或双相 |
| **3 型** | 马鞍或穹窿型，但 ST 抬高 **< 0.1 mV** | | |

- **只有 1 型具有诊断意义**（"Brugada 型心电图"）；2/3 型需药物（钠通道阻滞剂：匹西卡尼、氟卡尼、阿义马林）诱发转为 1 型。
- **诊断敏感化技巧**：将 **V1、V2 电极上移至第 3 或第 2 肋间**记录 → 检出率显著提高。
- 心电图可**自发波动**（迷走张力增高、发热、饱餐、饮酒后加重）。
- 常伴 **V1 的 rSR' 样形态（易误为不完全性 RBBB）**，但 I、V6 无宽 S 波是区别点。
- **Brugada 综合征** = Brugada 型心电图（1 型）+ 以下之一：VF/多形性 VT 记录、心脏骤停幸存、家族史（<45 岁猝死）、家族成员 1 型心电图、诱发性 VF、夜间濒死呼吸/晕厥。
- 好发：**东亚成年男性、夜间/睡眠中猝死**。

## 10.9 低体温（hypothermia）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **Osborn 波（J 波）**：QRS 终末部与 ST 交界处出现的**圆顶状正向偏转**，体温越低越大 | **V4–V6, II**（左侧导联明显） |
| 2 | **窦性心动过缓** | |
| 3 | **PR、QRS、QT 间期均延长** | |
| 4 | **肌肉震颤（寒战）造成的基线伪差** | 肢体导联 |
| 5 | 进展：房颤 → 交界性节律 → VF（< 28℃）→ 心停 | |

- **鉴别 J 波的其他原因**：早期复极、高钙血症、SAH、Brugada 综合征、败血症。

# 第 11 章 T 波增高

## 11.1 高钾血症〈hyperkalemia〉

### 血钾浓度与心电图的对应（记忆重点）

| 血钾 (mEq/L) | 心电图变化 |
|---|---|
| **5.5 – 6.5** | **T 波高尖（tented T）**：**窄基底、对称、尖锐**，QT 缩短。最明显于 **V2–V4** |
| **6.5 – 8.0** | **P 波振幅降低、变宽 → 最终消失**；**PR 延长**；**QRS 开始增宽** |
| **8.0 – 10** | **QRS 显著增宽**，与 T 融合 → **正弦波（sine wave）**；**窦室传导** |
| **> 10** | **心室颤动 / 心室停搏** |

**高尖 T 波的鉴别**：

| 原因 | 特征 |
|---|---|
| **高钾** | **基底窄、对称、尖锐**，QT 缩短，同时 P 波变化 |
| **超急性期 MI** | **基底宽**、不对称，伴 ST 抬高，局限于冠脉支配区 |
| **早期复极** | 伴 J 波、ST 上凹抬高，R 波高 |
| 正常变异 / 迷走张力高 | 振幅高但形态正常 |
| 左室容量负荷 | 伴深 q、高 R |
| **de Winter 型** | 伴 J 点压低 + 上斜 ST 压低 |

> **低钾血症**见 12.6（T 低平 + U 波增高），与高钾恰好相反。

# 第 12 章 ST 压低、T 波低平 / 倒置

> **切入点**：先判断是**原发性**（QRS 正常）还是**继发性**（QRS 异常：束支阻滞/肥大/预激/起搏）。

## 12.1 心肌缺血（劳力性心绞痛 / 运动负荷试验）

### ST 压低的形态学分类

| 类型 | 形态 | 意义 |
|---|---|---|
| **水平型（horizontal）** | ST 段与基线平行下移 | **缺血（有意义）** |
| **下斜型（downsloping / sagging）** | 从 J 点向下倾斜 | **缺血（意义最大）** |
| **上斜型（upsloping）** | J 点压低但 ST 迅速上升 | 多为**生理性**（心动过速、Ta 波）；仅当**缓慢上斜且 J 点后 0.08 s 仍 ≥ 0.1 mV** 时有意义 |
| **盆状（sagging / scooped）** | 鱼钩样 | **洋地黄效应** |

### 定量标准

| 场合 | 阳性标准 |
|---|---|
| **静息心电图** | J 点后 **0.06–0.08 s** 处，**水平或下斜型压低 ≥ 0.05–0.1 mV** |
| **运动负荷试验** | **水平或下斜型 ST 压低 ≥ 0.1 mV（1 mm）**，持续 ≥ 0.08 s，出现在 ≥ 2 个相邻导联 |
| **强阳性（高危）** | 压低 ≥ 0.2 mV；低负荷即出现；恢复期持续 > 5 min；多导联受累；运动中**血压下降**；运动诱发 VT |
| **运动中 ST 抬高** | 提示**透壁缺血/冠脉痉挛/严重狭窄**，比压低更危险 |

- 最常出现于 **V4–V6、II、aVF**。
- **ST 压低不能定位缺血部位**（与 ST 抬高不同）；**aVR ST 抬高 + 广泛压低** → 左主干/三支。

### 缺血性 T 波改变
- **冠状 T（coronary T）**：**深、对称、箭头样倒置** —— 提示心内膜下损伤/缺血
- **假性正常化（pseudonormalization）**：原本倒置的 T 在缺血发作时**变为直立** → 是缺血的表现！

## 12.2 心内膜下梗死（非 Q 波心肌梗死 / NSTEMI）

| # | 标准 |
|---|---|
| 1 | **持续性 ST 压低**（水平/下斜型）和/或 **深对称倒置 T 波**，持续数日 |
| 2 | **无异常 Q 波**（R 波保持），**无 ST 抬高** |
| 3 | **心肌坏死标志物（肌钙蛋白）升高** —— 与不稳定性心绞痛的唯一区别 |
| 4 | 有动态演变（与慢性 ST-T 改变区别） |

- **UA vs NSTEMI vs STEMI**：ST 抬高 → STEMI；无 ST 抬高 + 肌钙蛋白升高 → NSTEMI；无 ST 抬高 + 肌钙蛋白正常 → 不稳定性心绞痛。

## 12.3 继发性 ST-T 改变

| 定义 | 因**心室除极（QRS）异常**而必然伴随出现的复极异常 |
|---|---|
| **判定法** | **ST-T 的方向与 QRS 主波方向相反**（discordant） |
| **常见原因** | **束支阻滞（LBBB、RBBB）、心室肥大（劳损型）、WPW 预激、心室起搏、PVC、室速** |
| **临床含义** | **不可解读为心肌缺血** |

- 例：LBBB 时 V5–V6（R 波向上）→ ST 压低 + T 倒置；V1–V2（S 波向下）→ ST 抬高 + T 直立。这是"应该有"的表现。
- **原发性 ST-T 改变叠加**的线索：ST-T 方向与预期相反（concordant）→ 用 Sgarbossa 标准评估。

## 12.4 非特异性 ST-T 改变

| 描述 | 轻度 ST 压低（< 0.1 mV）、T 波低平（< R 波的 1/10）、轻度 T 倒置，不符合任何特定模式 |
|---|---|
| **可能原因** | 自主神经张力（过度换气、体位、餐后、焦虑、寒冷）、女性、贫血、发热、感染、甲功异常、电解质轻度紊乱、药物、陈旧性心肌病变、轻度缺血 |
| **判读原则** | **必须与既往心电图对比**；单次记录的非特异改变价值有限，需结合临床 |

**体位/生理性 T 波变化的确认**：深吸气后 III 导联 Q/T 变化、站立位 T 变化、过度换气试验、β 阻滞剂试验。

## 12.5 洋地黄效应（digitalis effect）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **盆状（鱼钩样 / sagging）ST 压低** —— 特征性 | **V5, V6, II**（R 波为主的导联） |
| 2 | **T 波低平、双向或倒置**（T 的起始部被 ST 拉低） | V5, V6 |
| 3 | **QT 间期缩短** —— 关键点 | |
| 4 | U 波振幅增高 | |
| 5 | PR 间期轻度延长 | |

> **"洋地黄效应"≠"洋地黄中毒"**。效应是治疗浓度下的正常表现。

**洋地黄中毒的心电图**（另一回事）：
- **房性心动过速伴房室阻滞（PAT with block）** —— 最典型
- **双向性室性心动过速（bidirectional VT）** —— 高度特异
- 加速性交界区节律、房颤伴规则缓慢心室率（＝完全 AVB）
- 各种 PVC（二联律）、II 度/III 度 AVB、窦房阻滞

## 12.6 低钾血症〈hypokalemia〉

| 血钾 | 心电图 |
|---|---|
| **< 3.5** | **T 波振幅降低、低平**；**U 波增高** |
| **< 3.0** | **U 波 > T 波**（V2–V3 最明显）；**ST 段压低**；T-U 融合 → 看似"QT 延长"（实为 **QU 延长**） |
| **< 2.5** | T 倒置，U 波显著，**QU 显著延长 → torsade de pointes**；PR 延长、P 波增高、QRS 增宽 |

- 最佳观察导联：**V2, V3**（U 波最明显）
- 促发：利尿剂、呕吐/腹泻、原醛症、Cushing、胰岛素、β 激动剂
- **低镁血症**表现相似，且低钾常合并低镁（补钾无效时须补镁）

## 12.7 巨大倒置 T 波〈GNT / giant negative T〉

**定义**：T 波倒置深度 **> 1.0 mV（10 mm）**

**鉴别诊断（5 大原因）**：

| 疾病 | 鉴别线索 |
|---|---|
| **心尖肥厚型心肌病（APH）** | **V4 最深** + **左室高电压** + **无 QT 延长（或轻度）** + 无 Q 波；日本人多见 |
| **Takotsubo 心肌病** | **显著 QT 延长**、有强烈应激诱因、前期有 ST 抬高、心尖部无运动 |
| **脑血管障碍（SAH、脑出血、脑梗）** | **极度 QT 延长 + 显著 U 波** + 窦缓；有神经系统症状 |
| **心肌缺血 / Wellens 综合征** | **V2–V4** 双相或深倒置 T，R 波保留，胸痛病史 → LAD 近端病变 |
| **完全性房室阻滞 / 起搏后（心脏记忆 cardiac memory）** | 恢复窦律后 T 波仍倒置一段时间，方向与既往起搏 QRS 一致 |

其他：嗜铬细胞瘤、大量心包积液后、急性肺栓塞、间歇性 LBBB 后。

# 第 13 章 QT 延长与缩短

## 13.0 QT 的测量与判定

- 测量导联：**II、V5（取最长者）**；避免有 U 波干扰的导联
- **QTc（Bazett）= QT / √RR(s)**
- **正常上限**：男 0.44 s，女 0.46 s；**≥ 0.48 s（男）/ 0.48 s（女）明确延长**；**≥ 0.50 s 高危**
- **缩短**：QTc **≤ 0.34–0.36 s**
- **QT 离散度（QT dispersion）**：12 导联中最长 QT − 最短 QT，> 0.06–0.08 s 提示复极不均一（心律失常风险）

## 13.1 低钙血症〈hypocalcemia〉

| 特征 |
|---|
| **ST 段延长（平坦、被拉长）** → **QT 间期延长** |
| **T 波形态、宽度正常**（关键：延长的是 ST 而非 T） |
| 严重时可有 T 波低平/倒置 |

- 病因：甲状旁腺功能减退、慢性肾衰、维生素 D 缺乏、大量输血（枸橼酸）、急性胰腺炎
- 与其他 QT 延长的鉴别：**低钙 = ST 延长型；药物/LQTS = T 波增宽型**

## 13.2 高钙血症〈hypercalcemia〉

| 特征 |
|---|
| **ST 段缩短或消失**（T 波紧接 QRS 之后）→ **QT 间期缩短** |
| 严重时 T 波增宽、振幅增高；可出现 **J 波（Osborn 波）** |
| 极重度：PR 延长、QRS 增宽、房室阻滞、心停 |

- 病因：甲状旁腺功能亢进、恶性肿瘤骨转移/PTHrP、结节病、维生素 D 中毒、噻嗪类

## 13.3 先天性 QT 延长综合征〈congenital LQTS〉

### 诊断要素

| # | 项目 |
|---|---|
| 1 | **QTc 延长**：≥ 0.48 s 明确；0.46–0.47 s 可疑 |
| 2 | **T 波形态异常**（见下表）、**T 波电交替（T-wave alternans）** —— 高度提示 |
| 3 | **TdP / 晕厥 / 心脏骤停**发作史 |
| 4 | **家族史**（LQTS 或 < 30 岁不明原因猝死） |
| 5 | 心动过缓（相对于年龄） |
| ※ | **Schwartz 评分 ≥ 3.5 分**可诊断 |

### 主要基因型的心电图与诱因

| 型 | 基因/通道 | T 波形态 | 典型诱因 |
|---|---|---|---|
| **LQT1（~45%）** | KCNQ1（IKs↓） | **基底宽、平滑的宽大 T 波** | **运动，尤其游泳**；交感兴奋 |
| **LQT2（~40%）** | KCNH2/HERG（IKr↓） | **低振幅、有切迹（notched）/ 双峰 T 波** | **突发声音刺激（闹钟、电话）**、情绪、产后 |
| **LQT3（~8%）** | SCN5A（INa 晚期↑） | **ST 段长而平坦，其后出现迟发的尖锐 T 波** | **睡眠中、心动过缓时** |

- **Jervell-Lange-Nielsen 综合征**：常染色体隐性 + **先天性耳聋**，QT 极度延长
- **Romano-Ward 综合征**：常染色体显性，听力正常

## 13.4 药物性 QT 延长〈drug-induced LQT〉/ 获得性 LQTS

### 主要致病药物

| 类别 | 代表药 |
|---|---|
| **抗心律失常药 Ia 类** | 奎尼丁、丙吡胺、西苯唑啉 |
| **抗心律失常药 III 类** | 索他洛尔、胺碘酮（QT 延长明显但 TdP 少）、尼非卡兰、多非利特 |
| **抗精神病药 / 抗抑郁药** | 氟哌啶醇、硫利达嗪、氯丙嗪、三环类（阿米替林等） |
| **抗菌药** | **大环内酯类（红霉素、克拉霉素）**、氟喹诺酮类（莫西沙星等）、喷他脒 |
| **抗真菌药** | 唑类（伊曲康唑、氟康唑） |
| **消化系统药** | 西沙必利（已撤市）、多潘立酮、昂丹司琼 |
| **其他** | 砷剂、酪氨酸激酶抑制剂、羟氯喹、美沙酮 |

### 促发 TdP 的危险因素（"叠加"效应）
**低钾、低镁、低钙**；**心动过缓**（尤其完全性 AVB、窦停后）；女性；心衰/左室肥大；**药物相互作用（CYP3A4 抑制）**；肝肾功能不全；快速静脉给药；**长-短 RR 序列**。

### TdP 的先兆心电图
- QTc 进行性延长（> 0.50 s）
- **T-U 波变形、U 波增大、T 波电交替**
- **"短-长-短"序列**（PVC → 代偿间歇 → 下一搏 QT 更长 → R on T）

# 第 14 章 U 波增高与倒置

## 14.0 U 波的基础
- 正常：与 T 同向（直立），振幅 **< T 的 1/2**，**V2–V3 最明显**
- **U 波增高**：> 0.1–0.2 mV，或 **U > T**
- **U 波倒置（陰転）**：**除 aVR 外任何导联的 U 波倒置均为异常**

| 分类 | 病因 |
|---|---|
| **U 波增高** | **低钾血症（最常见）**、低镁、心动过缓、洋地黄、Ia/III 类抗心律失常药、LQTS、SAH/脑血管障碍、甲亢、运动员（生理性）、**后壁心肌缺血** |
| **U 波倒置** | **心肌缺血（尤其前壁 / 左主干、LAD 病变）**、**高血压/左室肥大**、主动脉瓣关闭不全、二尖瓣关闭不全、高钾（罕见） |

## 14.1 心肌缺血 — 前壁缺血（U 波倒置）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **U 波倒置** | **V4–V6, I, aVL（左侧胸导联）** |
| 2 | **运动负荷试验中/后新出现的 U 波倒置** → **对 LAD 病变高度特异**（特异度 > 90%） | V4–V6 |
| 3 | 可在 ST 段无变化时单独出现 —— 唯一线索 | |
| 4 | 静息时出现的 U 倒置也提示严重左前降支狭窄或左主干病变 | |

## 14.2 心肌缺血 — 后壁缺血（U 波增高）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **U 波振幅增高（直立）** | **V1–V3（右侧胸导联）** |
| 2 | 机制：后壁的 U 波倒置在右胸导联表现为**镜像的直立增高** | |
| 3 | 提示 **RCA 或 LCX（后壁供血血管）病变** | |

> 记忆：**左侧导联 U 倒置 = 前壁缺血；右侧导联 U 增高 = 后壁缺血**（互为镜像）。

# 第 15 章 提前出现的 P 或 QRS（期前收缩）

> **第一判断点**：提前的 QRS **是宽的还是窄的**？其前**有没有提前的 P'**？

## 15.1 心室期前收缩〈PVC / VPC〉

| # | 标准 |
|---|---|
| 1 | **提前出现的宽大畸形 QRS，时限 ≥ 0.12 s** |
| 2 | **其前无相关的 P 波**（可有窦性 P 落入但不相关） |
| 3 | **继发性 ST-T 改变**：ST-T 方向与 QRS 主波**相反** |
| 4 | **多有完全性代偿间歇**（PVC 前后两个窦性 R 的间距 = 2 倍正常 RR） |
| 5 | 常有固定的**联律间期（coupling interval）** |

**起源部位的推定**：

| V1 形态 | 起源 |
|---|---|
| **LBBB 型（V1 主波向下）** | **右室**（或室间隔左侧近处） |
| **RBBB 型（V1 主波向上）** | **左室** |
| **下壁导联（II, III, aVF）高 R + 电轴向下** | **流出道（RVOT / LVOT）** |
| **下壁导联主波向下（电轴向上）** | 心尖部 / 下壁 |
| 移行区 ≤ V2 | LVOT / 主动脉窦 |

## 15.2 插入性 PVC 与伴代偿间歇的 PVC

| 类型 | 定义 | 意义 |
|---|---|---|
| **完全代偿间歇（compensatory pause）** | PVC 前后的两个窦性 QRS 间距 **= 2 × 正常 RR**。因为逆传冲动在 AVN 内被阻，窦房结未被重整 | PVC 的典型表现 |
| **插入性（interpolated）PVC** | PVC **夹在两个正常窦性搏动之间，无代偿间歇**，总 RR 不变；常见于心动过缓时 | PVC 后的窦性搏动常有 **PR 延长**（隐匿性逆传致 AVN 不应） |
| **不完全代偿间歇** | 间距 < 2 × RR。见于**房性/交界性期前收缩**（逆传重整窦房结） | 提示为室上性起源 |

## 15.3 PVC 的分类

### 形态学与配布

| 分类 | 定义 |
|---|---|
| **单源性（单形性）** | 同一导联中形态相同、联律间期固定 |
| **多源性（多形性）** | 形态 ≥ 2 种，联律间期不固定 |
| **二联律（bigeminy）** | 每 1 个窦性搏动后跟 1 个 PVC |
| **三联律（trigeminy）** | 每 2 个窦性搏动后跟 1 个 PVC |
| **成对（couplet / pair）** | 连续 2 个 PVC |
| **非持续性 VT** | 连续 ≥ 3 个 PVC，持续 < 30 s |
| **R on T 现象** | PVC 落在前一心搏 T 波的顶峰附近（易损期）→ **可诱发 VF / TdP** |

### Lown 分级（急性 MI 中的危险度分层，现代已较少用于非缺血患者）

| 级 | 内容 |
|---|---|
| 0 | 无 PVC |
| 1 | 偶发，< 30 次/小时 |
| 2 | 频发，≥ 30 次/小时 |
| 3 | 多源性（多形性） |
| **4a** | **成对（2 连发）** |
| **4b** | **3 连发以上（非持续性 VT）** |
| **5** | **R on T** |

> 现代观点：**有无器质性心脏病（尤其左室功能）比 Lown 分级更决定预后**。无器质性心脏病的频发 PVC 多为良性，但 PVC 负荷 > 10–20% 可致 PVC 诱导性心肌病。

**"良性 PVC"的提示**：运动后减少/消失、单形性、联律间期固定、无器质性心脏病、QRS 时限相对窄（< 0.14 s）、RVOT 起源形态。

## 15.4 并行心律（parasystole）

| # | 三大诊断标准 |
|---|---|
| 1 | **联律间期不固定**（异位搏动与前一窦性搏动的间距变化 > 0.08–0.1 s） |
| 2 | **异位搏动之间的间期（异位间期）存在最大公约数**（所有异位间期是最短间期的整数倍） |
| 3 | **出现融合波（fusion beat）** |

- 机制：异位起搏点周围存在**传入阻滞（entrance block）**，不受窦律重整，独立发放。
- 可以是心室性（最常见）、房性、交界性。
- 一般预后良好，对抗心律失常药反应差。

## 15.5 室上性期前收缩〈SVPC / PAC〉

| # | 标准 |
|---|---|
| 1 | **提前出现的 P' 波，形态与窦性 P 不同**（提前越早，形态差异越大；常藏在前一 T 波中 → **仔细看 T 波形态是否变形**） |
| 2 | **P'R 间期 ≥ 0.12 s**（房性）；PR 可较窦性长（AVN 部分不应） |
| 3 | **QRS 形态与窦性相同（窄）** |
| 4 | **不完全代偿间歇**（逆传重整窦房结） |
| 5 | 例外：**差异性传导（aberrant conduction）** 时 QRS 变宽，多呈 **RBBB 型（V1 rsR'）**，因右束支不应期最长 |

**SVPC 伴差传 vs PVC 的鉴别**：

| 项目 | SVPC 伴差传 | PVC |
|---|---|---|
| 提前的 P' | **有**（藏在前 T 波中） | 无 |
| QRS 形态 | **多为 RBBB 型（V1 呈 rsR'，三相波）** | 常为单相/双相，形态更怪异 |
| QRS 起始向量 | **与窦性相同** | 与窦性不同 |
| 代偿间歇 | **不完全** | 完全 |
| 前一 RR | **长 RR 之后出现（Ashman 现象）** | 无此规律 |

## 15.6 室上性期前收缩的分类

| 分类轴 | 类别 |
|---|---|
| **起源部位** | **房性（PAC）**：P' 直立或形态异常，P'R ≥ 0.12 s<br>**交界性（PJC）**：P' 逆行（II/III/aVF 倒置）或缺如，P'R < 0.12 s |
| **传导结果** | **正常传导**：窄 QRS<br>**差异传导（aberrant）**：宽 QRS（多 RBBB 型）<br>**非传导（blocked / 未下传）**：P' 后无 QRS |
| **配布** | 散发 / 二联律 / 三联律 / 成对 / **短阵房性心动过速（≥ 3 连发）** |
| **临床意义** | 频发 PAC（> 100–500 次/日）是**新发房颤的独立预测因子** |

# 第 16 章 该出现的 P 或 QRS 没有出现（漏搏）

> **铁律：见到"长间歇"，第一件事是看前一个 T 波里有没有藏着提前的 P'（未下传的 SVPC 是最常见原因）。**

## 16.1 窦性停搏（sinus arrest / sinus pause）

| # | 标准 |
|---|---|
| 1 | **P 波与 QRS 同时缺失**，出现长间歇 |
| 2 | **长间歇不是基本 PP 间期的整数倍** —— 与窦房阻滞的关键区别 |
| 3 | 停搏 **≥ 3.0 s** 有临床意义（清醒时） |
| 4 | 长间歇后可出现交界性/室性逸搏 |

## 16.2 窦房阻滞〈SA block〉

| 型 | 标准 |
|---|---|
| **I 度 SA 阻滞** | 心电图**无法诊断**（窦房结电位不可见） |
| **II 度 Mobitz I 型（文氏型）** | **PP 间期逐渐缩短**，然后出现长间歇；**长间歇 < 2 倍最短 PP** |
| **II 度 Mobitz II 型** | PP 恒定，**长间歇恰好 = 基本 PP 的整数倍（2 倍、3 倍…）** —— 决定性标准 |
| **III 度（完全性）SA 阻滞** | P 波完全消失，与窦性停搏无法区分 |

## 16.3 Mobitz II 型 II 度房室阻滞

| # | 标准 |
|---|---|
| 1 | **PR 间期恒定不变**（下传的搏动） |
| 2 | **突然出现 P 波后无 QRS**（无预兆） |
| 3 | PP 间期规则（含脱落处） |
| 4 | **QRS 常增宽（合并束支阻滞）** —— 提示阻滞部位在 **His 束以下（希浦系统）** |

**临床意义**：**高危**！易进展为完全性房室阻滞和阿-斯综合征 → **永久起搏器适应证（即使无症状）**。阿托品**无效甚至加重**。

## 16.4 Wenckebach 型（Mobitz I 型）II 度房室阻滞

| # | 标准 |
|---|---|
| 1 | **PR 间期逐搏延长**，直至一个 P 波未下传（QRS 脱落） |
| 2 | **PR 增量逐渐减小** → **RR 间期逐渐缩短** |
| 3 | **含脱落的长 RR < 2 倍最短 RR** |
| 4 | 脱落后的第一个 PR 最短（周期重新开始） |
| 5 | **QRS 多为窄** —— 阻滞部位在 **AVN 内** |
| 6 | 传导比表示为 4:3、3:2 等 |

**临床意义**：**多为良性**（迷走张力增高、运动员、睡眠中、下壁 MI、药物）。运动或阿托品可改善。无症状者一般不需起搏器。

## 16.5 未下传（阻滞型）室上性期前收缩〈blocked SVPC〉

| # | 标准 |
|---|---|
| 1 | 长间歇之前的 **T 波形态与其他 T 波不同**（变尖、变高、出现切迹）→ **其中藏着提前的 P'** |
| 2 | 该 P' 后**无 QRS**（因过早，落在 AVN 绝对不应期） |
| 3 | 长间歇后恢复窦律 |

> **临床价值最高的鉴别点**：这是"漏搏"最常见的原因，**完全良性**，但极易被误诊为 II 度房室阻滞或窦性停搏而导致不必要的起搏器植入。**必须逐一比对 T 波形态！**

# 第 17 章 心动过缓

## 17.1 窦性心动过缓（sinus bradycardia）

| 标准 | 窦性心律（P 波正常）+ **心率 < 50–60 次/分** |
|---|---|
| 生理性 | 运动员、睡眠中、迷走张力高的年轻人 |
| 病理性 | 甲状腺功能减退、低体温、颅内压增高、黄疸、**下壁 MI**、SSS |
| 药物性 | **β 阻滞剂、钙拮抗剂（维拉帕米/地尔硫䓬）、洋地黄、胺碘酮、抗胆碱酯酶药** |

## 17.2 窦房结功能不全综合征〈SSS〉

**Rubenstein 分型**：

| 型 | 心电图 |
|---|---|
| **I 型** | **持续性显著窦性心动过缓**（< 50 次/分），非药物性 |
| **II 型** | **窦性停搏 和/或 窦房阻滞**（长间歇） |
| **III 型** | **徐脉-频脉综合征**（见 17.3） |

- 诊断辅助：**心率变异性消失、运动时心率不上升（变时性功能不全，最大心率 < 100–120）**、阿托品试验（心率上升 < 25% 或 < 90 次/分为阳性）、电生理检查（SNRT > 1500 ms，CSNRT > 550 ms）
- 有**症状（晕厥、头晕、心衰、易疲劳）** + 心动过缓的**因果关系确认** → 起搏器适应证

## 17.3 徐脉-频脉综合征（brady-tachy syndrome）

| # | 标准 |
|---|---|
| 1 | **快速性房性心律失常（房颤、房扑、房速）发作** |
| 2 | 其**终止后出现长时间的窦性停搏（洞停止）** —— "**过度抑制（overdrive suppression）**" |
| 3 | 长间歇常 > 3–5 s → **晕厥（Adams-Stokes 发作）** |

- 治疗困境：抗心律失常药会加重心动过缓 → **常需起搏器 + 抗心律失常药/消融并用**。

## 17.4 2:1 房室阻滞

| # | 标准 |
|---|---|
| 1 | **每 2 个 P 波中有 1 个下传**（P 数 = QRS 数 × 2） |
| 2 | 下传搏动的 **PR 恒定** |
| 3 | **无法单凭 2:1 判断是 Mobitz I 还是 II 型**（因为看不到 PR 的连续变化） |

**推定阻滞部位的线索**：

| 提示 AVN 内（I 型样，较良性） | 提示 His 束以下（II 型样，高危） |
|---|---|
| **QRS 窄** | **QRS 宽（束支阻滞）** |
| **PR 明显延长（> 0.30 s）** | PR 正常 |
| 运动/阿托品后传导**改善** | 运动/阿托品后**恶化** |
| 颈动脉窦按摩后传导**恶化** | 按摩后**改善** |
| 常伴下壁 MI、洋地黄、迷走张力 | 常伴前壁 MI、传导系统退变 |

## 17.5 高度房室阻滞（advanced / high-grade AVB）

| 标准 | **连续 ≥ 2 个 P 波未下传**（传导比 ≥ 3:1，如 3:1、4:1） |
|---|---|
| 特征 | 仍有部分 P 下传（PR 固定）→ 与完全性 AVB 的区别 |
| 常伴 | 交界性/室性逸搏搏动、逸搏-夺获二联律 |
| 意义 | **高危，起搏器适应证** |

## 17.6 完全性房室阻滞（III 度 AVB）

| # | 标准 |
|---|---|
| 1 | **P 波与 QRS 完全无关（房室分离）** —— PR 间期毫无规律地变化 |
| 2 | **PP 间期规则**（心房率 > 心室率） |
| 3 | **RR 间期规则**（逸搏节律，比 PP 慢） |
| 4 | P 波数 > QRS 数 |

**逸搏节律的水平决定预后**：

| 逸搏起源 | QRS | 频率 | 危险度 |
|---|---|---|---|
| **AVN / His 束（交界性）** | **窄（< 0.12 s）** | **40–60 次/分** | 相对稳定，阿托品可能有效 |
| **His 束以下（心室性）** | **宽（≥ 0.12 s）** | **20–40 次/分** | **高危**（易发生心停、TdP），阿托品无效 |

**特殊情形**：
- **房颤 + 规则的缓慢 RR** → **房颤合并完全性 AVB**（常为洋地黄中毒）
- **先天性完全性 AVB**：多为交界性逸搏、窄 QRS、频率较快（50–60），预后相对好
- **完全性 AVB + QT 延长 → TdP（"心停发作"）**，需注意

**房室分离 ≠ 完全性 AVB**：若心室率 > 心房率（如加速性交界区节律、VT），称"干扰性房室分离"，机制完全不同。

# 第 18 章 心动过速：窄 QRS、规则

> **分析流程**：① 心率是多少？② 能否找到 P'波？③ **P' 在哪里（RP' 间期）**？④ 迷走刺激/腺苷的反应？

## 18.0 窄 QRS 心动过速的鉴别流程

```
窄 QRS 心动过速（QRS < 0.12 s）
├── 不规则 → 房颤 / 房扑伴不等比传导 / 多源性房速
└── 规则
    ├── 有正常窦性 P（P 在 QRS 前，形态同窦性）
    │   ├── 心率 100–180，渐起渐止 → 窦性心动过速
    │   └── 突发突止 → 窦房结折返性心动过速（SANRT）
    ├── 找不到 P（藏在 QRS 内）→ AVNRT（典型型）
    ├── P' 在 QRS 之后、ST 段上（RP' 短，< 1/2 RR）
    │   ├── RP' < 70 ms → AVNRT
    │   └── RP' > 70 ms → AVRT（顺向型）
    ├── P' 在 T 波附近（RP' 长，> 1/2 RR）→ 房速 / 非典型 AVNRT / PJRT
    └── 锯齿状 F 波，心率 ≈150 → 2:1 心房扑动
```

**腺苷（ATP）/ 迷走刺激的反应**：
- **突然终止** → AVNRT 或 AVRT（AVN 是折返环的一部分）
- **暂时减慢后恢复** → 窦速、房速
- **房室传导比增加、暴露 F/P' 波** → 房扑、房速

## 18.1 窦性心动过速（sinus tachycardia）

| # | 标准 |
|---|---|
| 1 | 窦性 P 波（II、III、aVF 直立，aVR 倒置），形态与静息时相同 |
| 2 | **心率 100–180 次/分**（上限 ≈ 220 − 年龄） |
| 3 | **渐进性开始、渐进性终止**（warm up / cool down） |
| 4 | 心率随呼吸/体位/情绪轻微波动 |
| 5 | 快时 P 可与前一 T 融合 → 注意"驼峰状 T" |

- 病因：发热、贫血、脱水、疼痛、焦虑、甲亢、心衰、休克、肺栓塞、咖啡因/儿茶酚胺/药物
- **是一种"症状"而非疾病** → 找原因，不要盲目用 β 阻滞剂

## 18.2 阵发性室上性心动过速 — 房室折返性心动过速〈AVRT〉

| # | 标准 |
|---|---|
| 1 | 心率 **150–250 次/分**，节律**绝对规则** |
| 2 | **突发突止（paroxysmal）** |
| 3 | **顺向型（orthodromic，90%）：窄 QRS**（经 AVN 前传，经旁路逆传） |
| 4 | **逆行 P'（II/III/aVF 倒置）位于 QRS 之后的 ST 段上**，**RP' > 70 ms**，且 **RP' < P'R** |
| 5 | **QRS 电交替（QRS alternans）** —— 相对特异于 AVRT |
| 6 | 窦律时可见 **δ 波（显性 WPW）**；隐匿性旁路时窦律正常 |
| 7 | **逆向型（antidromic，5–10%）：宽 QRS**（经旁路前传）→ 见第 19 章 |
| 8 | 心动过速中出现**束支阻滞（与旁路同侧）时周期延长 ≥ 35 ms** → 高度提示 AVRT |

## 18.3 阵发性室上性心动过速 — 房室结折返性心动过速〈AVNRT〉

| # | 标准 |
|---|---|
| 1 | 心率 **150–250 次/分**（常 180 左右），绝对规则 |
| 2 | 突发突止；常由 **PAC 伴 PR 突然跳跃延长（jump up）** 诱发 |
| 3 | **典型（slow-fast，90%）：P' 埋没于 QRS 之内，看不到**；或紧随 QRS 之后，**RP' < 70 ms** |
| 4 | **假性 r' 波（pseudo-r'）：V1** 出现窦律时没有的小 r'（窦律时无） |
| 5 | **假性 S 波（pseudo-s）：II、III、aVF** 出现窦律时没有的终末小 s |
| 6 | **非典型（fast-slow / slow-slow，10%）**：**RP' 长**，P' 在 T 波之前，II/III/aVF 深倒置 → 易与房速混淆 |
| 7 | 是**最常见的 PSVT**（约 60%），好发中年女性 |

**AVNRT vs AVRT 速查**：

| 项目 | AVNRT | AVRT（顺向型） |
|---|---|---|
| RP' | **< 70 ms** | **> 70 ms** |
| P' 位置 | 埋在 QRS 内 / 紧邻 | ST 段上，清晰可见 |
| 假性 r'(V1)、假性 s(下壁) | **有** | 无 |
| QRS 电交替 | 少 | **较多** |
| 窦律时 δ 波 | 无 | 可有（显性 WPW） |
| 好发年龄 | 中年、女性多 | 年轻、男性多 |

## 18.4 阵发性室上性心动过速 — 窦房结折返性心动过速〈SANRT / SART〉

| # | 标准 |
|---|---|
| 1 | **P 波形态与窦性完全相同或极为相似**（折返环在窦房结内/周围） |
| 2 | **突发突止** —— 与窦速的**决定性区别** |
| 3 | 心率相对较慢：**100–150 次/分** |
| 4 | PR 间期正常或略延长（与心率相符） |
| 5 | 可被 PAC 诱发和终止；迷走刺激可终止 |
| 6 | 罕见（占 PSVT < 5%） |

## 18.5 房性心动过速〈AT〉

| # | 标准 |
|---|---|
| 1 | **P' 波形态与窦性 P 不同**（异位起源） |
| 2 | **心房率 100–250 次/分**（多 150–200） |
| 3 | **P' 波之间有等电位线** —— 与房扑（无等电位线）的区别 |
| 4 | **P'R 间期正常或延长**，且 **RP' > P'R（长 RP' 型）** |
| 5 | **可伴房室阻滞（2:1 等）而心动过速不终止** —— 与 AVNRT/AVRT 的决定性区别（后者 AVN 是折返环必需部分） |
| 6 | 起始常有 **"温醒（warm-up）"现象**（自律性机制） |

- **多源性房性心动过速（MAT）**：P' 形态 ≥ 3 种、PP/PR 不等、心率 > 100 → **重症 COPD、茶碱中毒、低钾**
- **房速伴房室阻滞（PAT with block）** → **首先怀疑洋地黄中毒**

## 18.6 2:1 传导的心房扑动

| # | 标准 |
|---|---|
| 1 | **心室率恒定在 ~150 次/分（140–160）** —— **凡见此心率的规则窄 QRS 心动过速，必须先排除 2:1 房扑** |
| 2 | F 波频率 ~300 次/分，其中一半藏在 QRS 或 T 波中 |
| 3 | 观察 **II、III、aVF 的锯齿状基线** 和 **V1 的直立 P 样波** |
| 4 | **心率变化呈"跳跃式"**（150 → 100 → 75，对应 2:1 → 3:1 → 4:1）而非连续变化 |
| 5 | **确认方法**：颈动脉窦按摩 / 腺苷 → 房室比增加，F 波完全暴露 |

# 第 19 章 心动过速：宽 QRS、规则

> **原则：宽 QRS 心动过速在确诊之前，一律按室性心动过速（VT）处理。** 在急诊，VT 占宽 QRS 心动过速的 **80%**（有陈旧心梗史者 > 95%）。
> **禁忌**：不明宽 QRS 心动过速禁用维拉帕米（可致血流动力学崩溃）。

## 19.0 VT vs SVT 伴差传的鉴别标准

### 支持 VT 的决定性所见（"三大法宝"）

| # | 所见 | 说明 |
|---|---|---|
| 1 | **房室分离（AV dissociation）** | 独立的 P 波以自己的频率出现，与 QRS 无关。**最特异（特异度 ~100%）**，但仅约 20–30% 可见。查 II、V1、食管导联 |
| 2 | **心室夺获（capture beat）** | 心动过速中突然出现 1 个**窄 QRS**（窦性冲动下传）→ 确诊 VT |
| 3 | **融合波（fusion beat）** | 窦性与室性冲动同时激动心室，QRS 形态介于两者之间 → 确诊 VT |

### 其他支持 VT 的所见

| 所见 | 内容 |
|---|---|
| **QRS 极度增宽** | RBBB 型 > 0.14 s；LBBB 型 > 0.16 s |
| **胸导联同向性（concordance）** | **V1–V6 的 QRS 主波全部向上或全部向下**（全部向下＝阴性同向性，几乎确诊 VT） |
| **电轴极度偏移（"无人区轴"）** | −90° ～ ±180°（北西轴） |
| **无 RS 型（Brugada 第 1 步）** | 所有胸导联均无 RS 形态 → VT |
| **RS 间期 > 100 ms（Brugada 第 2 步）** | 任一胸导联 R 起点到 S 最低点 > 100 ms → VT |
| **aVR 起始 R 波（Vereckei 标准）** | aVR 呈起始 R 波 → VT |
| **V1 形态（RBBB 型时）** | 单相 R、**qR**、**Rsr'（左耳 > 右耳，"兔耳征"）** → VT；三相 rsR'（右耳>左耳）→ SVT |
| **V6 形态（RBBB 型时）** | **R/S < 1**、QS、qR → VT |
| **V1/V2 形态（LBBB 型时）** | **r 波宽度 > 30 ms**、S 波降支有切迹、**QRS 起点到 S 底 > 60 ms** → VT |
| **V6 有 Q 波（LBBB 型时）** | qR 或 QS → VT |
| **临床线索** | **陈旧性心肌梗死病史、心功能低下、年龄 > 35 岁** → 强烈提示 VT |

### 支持 SVT 伴差异传导的所见
- **典型的 RBBB 或 LBBB 形态**（V1 呈三相 rsR'，V6 有 qRs）
- **QRS 起始向量与窦性心律时相同**
- 与既往窦律心电图中已有的束支阻滞形态**完全一致**
- 腺苷可终止
- 心动过速起始由提前的 P' 波诱发

## 19.1 心室心动过速〈VT〉

| # | 标准 |
|---|---|
| 1 | **连续 ≥ 3 个（一般定义 ≥ 3 或 ≥ 5 个）室性搏动**，频率 **> 100（多 130–250）次/分** |
| 2 | **QRS ≥ 0.12 s（多 > 0.14 s），宽大畸形** |
| 3 | 节律**大致规则**（RR 变动 < 0.02–0.04 s） |
| 4 | **房室分离 / 夺获波 / 融合波**（见上） |
| 5 | ST-T 方向与 QRS 主波相反 |

**分类**：
- **持续性（sustained）**：持续 ≥ 30 s 或因血流动力学不稳而需终止
- **非持续性（non-sustained, NSVT）**：< 30 s 且自行终止
- **单形性（monomorphic）**：QRS 形态恒定 —— 多有器质基础（陈旧 MI 瘢痕折返）
- **多形性（polymorphic）**：形态多变 —— 急性缺血、LQTS（→TdP）、Brugada、CPVT
- **双向性（bidirectional）**：QRS 电轴逐搏交替 —— **洋地黄中毒、CPVT**

## 19.2 特发性室性心动过速（左室、左后分支起源）

**别名**：分支性 VT（fascicular VT）、**维拉帕米敏感性 VT**、Belhassen 型

| # | 特征 | 导联 |
|---|---|---|
| 1 | **RBBB 型**（V1 主波向上） | V1 |
| 2 | **电轴左偏（左后分支起源，最常见）** | 肢体导联 |
| 3 | **QRS 相对较窄（0.12–0.14 s）** —— 因起源于希浦系统 | |
| 4 | 若为**左前分支起源** → RBBB 型 + **电轴右偏** | |
| 5 | 心率 150–200，多见于**无器质性心脏病的年轻男性** | |
| 6 | **对维拉帕米有效**（对腺苷、利多卡因无效）；预后良好，消融成功率高 | |

## 19.3 特发性室性心动过速（右室流出道起源，RVOT-VT）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **LBBB 型**（V1 主波向下，呈 rS/QS） | V1, V2 |
| 2 | **下壁导联高大直立 R 波（电轴向下，约 +90°）** | **II, III, aVF** |
| 3 | **移行区在 V3–V4**（若 ≤ V2 → 提示左室流出道/主动脉窦起源） | V1–V6 |
| 4 | I 导联多呈 rS 或 QS（游离壁起源）/ R（间隔起源） | I |
| 5 | 常由运动、精神紧张诱发（儿茶酚胺依赖）；多见于青中年、无器质性心脏病 | |
| 6 | **对腺苷、β 阻滞剂、维拉帕米有效**；预后良好 | |

> **重要鉴别：致心律失常性右室心肌病（ARVC）** 也呈 LBBB 型 VT，但窦律时有 **V1–V3 的 ε 波、T 波倒置、QRS 终末激动延迟 ≥ 55 ms**，且多形性、有家族史 → 预后完全不同。

## 19.4 伴束支阻滞（差异传导）的 PSVT

| # | 特征 |
|---|---|
| 1 | 心率 150–250，绝对规则 |
| 2 | **QRS 呈典型的 RBBB 或 LBBB 形态**（V1 三相 rsR'；V6 有 qRs、R/S > 1） |
| 3 | **无房室分离、无夺获波、无融合波** |
| 4 | **QRS 起始向量与窦律时相同** |
| 5 | 与既往窦律时已存在的束支阻滞形态一致（"既存性束支阻滞"）；或仅在快心率时出现（"频率依赖性/3 相阻滞"） |
| 6 | 腺苷/迷走刺激可终止 |

## 19.5 经旁路前传的 PSVT（逆向型 AVRT / 预激性心动过速）

| # | 特征 |
|---|---|
| 1 | **QRS 宽大畸形（完全预激波形）**，因心室全部由旁路激动 |
| 2 | 规则、心率 150–250 |
| 3 | 窦律时心电图有 **δ 波（显性 WPW）**，且**心动过速时的 QRS 形态是窦律 δ 波形态的"放大版"** —— 关键线索 |
| 4 | 逆行 P' 位于 QRS 之后（RP' 长） |
| 5 | 与 VT 极难鉴别 → **不确定时按 VT 处理** |
| 6 | 治疗：**普鲁卡因胺 / 伊布利特 / 电复律；禁用洋地黄、维拉帕米、腺苷（可致 VF）** |

# 第 20 章 心动过速：不规则（窄或宽 QRS）

## 20.1 心室颤动〈VF / Vf〉

| # | 标准 |
|---|---|
| 1 | **完全无法辨认 P、QRS、T 的杂乱波形** |
| 2 | **振幅、频率、间期均不规则**，频率 150–500 次/分 |
| 3 | **粗颤（coarse VF）**：振幅 ≥ 0.5 mV，除颤成功率较高 |
| 4 | **细颤（fine VF）**：振幅 < 0.2–0.3 mV，接近心停，需先 CPR/肾上腺素 |
| 5 | 临床上必然伴意识丧失、脉搏消失 |

**必须排除的伪差（artifact）**：肌电、体动、电极接触不良、CPR 按压 —— **看患者，不要只看监护仪**！伪差时常能在杂乱波中看到规则的 QRS "透出"。

## 20.2 尖端扭转型室速〈torsade de pointes, TdP〉

| # | 标准 |
|---|---|
| 1 | **多形性 VT，QRS 的极性/振幅围绕基线呈螺旋状"扭转"**，每 5–20 个搏动翻转一次 |
| 2 | **频率 200–250 次/分** |
| 3 | **发作前的基础心律存在 QT 延长（QTc > 0.50 s）+ 显著 U 波** —— 诊断必需 |
| 4 | **由"短-长-短（short-long-short）"序列启动**：PVC → 长代偿间歇 → 下一搏 QT 更长 → **R on T 型 PVC** 触发 |
| 5 | 多为**自限性（数秒~数十秒）**，反复发作 → 晕厥；可蜕变为 **VF** |

**病因**：
- **获得性**：药物性 LQT（见 13.4）、**低钾/低镁/低钙**、**心动过缓（完全性 AVB、窦停）**、饥饿/极端节食、脑血管障碍、心肌炎
- **先天性**：LQTS（见 13.3）

**治疗**：**硫酸镁静注（首选，即使血镁正常）**、纠正电解质、停用致病药、**提高心率（异丙肾上腺素或临时起搏 overdrive pacing）**；**禁用 Ia/III 类抗心律失常药**。
> 注意：**短 QT 基础上的多形性 VT 不叫 TdP**（如 Brugada、CPVT、缺血），治疗策略不同（Brugada 用异丙肾上腺素/奎尼丁，CPVT 用 β 阻滞剂）。

## 20.3 假性室速〈pseudo-VT〉

### ① 预激综合征合并心房颤动（WPW + AF）—— 最重要的"真病"

| # | 特征 |
|---|---|
| 1 | **极快的心室率（常 > 200，可达 300 次/分）** |
| 2 | **RR 间期绝对不整** —— 与 VT 的关键区别 |
| 3 | **QRS 宽大畸形，且形态逐搏变化**（预激程度不同：完全预激、部分预激、正常传导的融合） |
| 4 | 最短 RR **< 250 ms** → **VF 高危** |
| 5 | 窦律恢复后可见 δ 波 |
| 6 | **治疗：立即电复律；药物用普鲁卡因胺/伊布利特。绝对禁用洋地黄、维拉帕米、地尔硫䓬、腺苷、β 阻滞剂**（阻断 AVN 会使全部冲动经旁路下传 → VF） |

### ② 伪差（artifact）造成的假性 VT

| 线索 |
|---|
| 杂乱波形中**可辨认出规则的窦性 QRS"穿透"其间**（"sinus spikes"） |
| 波形**仅出现在部分导联**（对应某一个电极） |
| 起止**突兀**，前后 RR 完全不受影响 |
| **患者状态良好、脉搏正常** |
| 常见原因：帕金森病震颤、刷牙/搔抓、电极松脱、寒战 |

### ③ 其他易误认为 VT 的情形
- **高钾血症的正弦波**（宽 QRS + 无 P 波）
- **起搏器介导性心动过速（PMT）**：起搏 QRS 宽，频率恒定在上限跟踪频率（如 120–130）
- 严重 IVCD（Ic 类药物中毒）+ 窦速

# 第 21 章 先天性心脏病

> 先天性心脏病心电图的核心逻辑：**血流动力学负荷类型（容量 vs 压力）× 受累心腔（左 vs 右）→ 特征性心电图**。

## 21.1 心房间隔缺损〈ASD〉

### 继发孔型（secundum ASD，最常见）

| # | 特征 | 导联 |
|---|---|---|
| 1 | **不完全性右束支阻滞（rsR' 型）** —— **最具特征**（右室容量负荷） | **V1** |
| 2 | **电轴右偏（+90° ～ +150°）** | 肢体导联 |
| 3 | **右房扩大**（P 高尖 ≥ 0.25 mV） | II, III, aVF |
| 4 | **I 度房室阻滞**（PR 延长，约 20%） | |
| 5 | **Crochetage 征**：下壁导联 R 波升支上的切迹（特异性高） | **II, III, aVF** |
| 6 | 年长后：房颤/房扑；肺高压时呈真正的 RVH（V1 高 R + ST-T 劳损） | |

### 原发孔型（primum ASD / 房室间隔缺损）

| # | 特征 |
|---|---|
| 1 | **电轴左偏（−30° ～ −90°）＝左前分支阻滞型** —— **决定性鉴别点**（传导系统移位） |
| 2 | 不完全性 RBBB（同样存在） |
| 3 | I 度房室阻滞更常见 |
| 4 | 常合并二尖瓣裂缺 → 左室容量负荷 |

> **口诀：ASD + 电轴右偏 = 继发孔型；ASD + 电轴左偏 = 原发孔型。**

## 21.2 心室间隔缺损〈VSD〉/ 动脉导管未闭〈PDA〉

| 分流量 | 心电图 |
|---|---|
| **小分流（Roger 病）** | **正常心电图** |
| **中等分流** | **左室容量负荷型**：V5–V6 **深而窄的 q 波 + 高 R 波 + 高耸直立 T 波**；左房扩大 |
| **大分流（肺高压前）** | 左室容量负荷 + 右室负荷 → **双心室肥大** |
| **Katz-Wachtel 现象** | **中间胸导联（V2–V4）出现高大的双向 QRS（R 与 S 均 > 5 mm，"RS 巨大"）** → 双心室肥大的标志 |
| **Eisenmenger 化后** | 转为**纯右室肥大型**：V1 高 R、电轴右偏、右房扩大、V1–V3 ST-T 劳损；左室征象消失 |

- **PDA** 与 VSD 的心电图基本相同（均为左室容量负荷 + 肺血流增加）。

## 21.3 肺动脉瓣狭窄〈PS〉

**核心：纯粹的右室压力负荷，其程度与狭窄严重度平行**（是心电图能"定量"评估的少数疾病）。

| 严重度 | 心电图 |
|---|---|
| **轻度**（跨瓣压差 < 50 mmHg） | 正常或轻度电轴右偏、V1 rsR' |
| **中度**（50–80 mmHg） | **V1 的 R ≥ 1.0 mV**、电轴右偏 +90°～+120° |
| **重度**（> 80–100 mmHg） | **V1 呈高大单相 R 波（≥ 2.0 mV）或 qR 型**、**V1–V3 ST 压低 + T 倒置（劳损型）**、**电轴 > +120°**、**右房扩大（P 高尖）** |

- **V1 的 R 波振幅（mm）× 5 ≈ 右室收缩压（mmHg）** 的经验估算。
- **V1 出现 q 波（qR）→ 提示重度右室肥大**。

## 21.4 法洛四联症〈TOF〉

| # | 特征 | 导联 |
|---|---|---|
| 1 | **显著右室肥大**：V1 呈**高大单相 R 波或 qR** | **V1** |
| 2 | **移行突然（abrupt transition）**：从 V1 的高 R **骤然**变为 V2 的 rS —— 特征性 | **V1 → V2** |
| 3 | **电轴右偏（+90° ～ +150°）** | 肢体导联 |
| 4 | **右房扩大**（P 高尖），但通常不如 PS 显著 | II, V1 |
| 5 | V1 的 T 波直立（新生儿期后 T 直立＝RVH 的敏感指标） | V1 |
| 6 | **术后**：几乎必然出现 **完全性 RBBB**（右室切开/流出道补片）；**QRS 时限 ≥ 180 ms 是术后猝死/持续性 VT 的强预测因子** | V1 |

## 21.5 Ebstein 畸形

| # | 特征 | 导联 |
|---|---|---|
| 1 | **巨大的 P 波（"喜马拉雅 P 波 / Himalayan P wave"）**：高度可 > 0.5 mV，宽度也增加 —— 极度右房扩大 | **II, V1** |
| 2 | **完全性或不完全性 RBBB，但 V1 的 QRS 振幅极低、呈碎裂多相波（低电压、粗钝）** —— 与普通 RBBB 的关键区别（房化右室是薄壁无效心肌） | **V1, V2** |
| 3 | **PR 间期延长（I 度房室阻滞）** | |
| 4 | **合并 WPW（B 型，右侧旁路）的比例高（约 20%）** → 短 PR + δ 波，可掩盖上述表现 | V1 |
| 5 | 常有房性心律失常（房扑、房颤、PSVT） | |
| 6 | 电轴可右偏或正常 | |

## 21.6 矫正型大动脉转位（先天性矫正型 TGA / ccTGA）

**核心机制：室间隔的激动方向逆转（从右向左变为从左向右）** —— 因传导系统与心室的解剖关系反转。

| # | 特征 | 导联 |
|---|---|---|
| 1 | **右侧胸导联出现 q 波（V1、V2 呈 qR 型）** —— 特征性 | **V1, V2** |
| 2 | **左侧胸导联的间隔 q 波消失（V5、V6 无 q）** —— 特征性 | **V5, V6** |
| 3 | 下壁导联（II, III, aVF）可出现 Q 波（假性下壁梗死） | II, III, aVF |
| 4 | **各种程度的房室阻滞（I 度 → 完全性）**，发生率随年龄增加（**每年约 2% 进展为完全性 AVB**） | |
| 5 | 电轴左偏（PQ 轴异常）；可有异位心房节律 | |
| 6 | 常合并 VSD、肺动脉狭窄、Ebstein 样三尖瓣畸形 → 叠加相应表现 | |

> **口诀：V1 有 q、V5–V6 无 q + 房室阻滞 → 想到矫正型大血管转位。**

# 附录 B 从异常出发的鉴别流程（速查）

## B.1 「宽 QRS」的鉴别

```
QRS ≥ 0.12 s
├── 有提前的窦性/房性 P 且 PR 正常
│   ├── V1 呈 rsR'、I/V6 有宽 S → 右束支阻滞
│   ├── V1 呈 rS/QS、V5-V6 宽顿挫 R 无 q → 左束支阻滞
│   └── 都不像 → 非特异性 IVCD（查血钾、查药物！）
├── PR < 0.12 s + δ 波 → WPW 综合征
├── 无 P 波，规则，20-40/min → 心室固有节律
├── 无 P 波，规则，60-100/min → AIVR
├── 无 P 波，> 100/min → 室性心动过速（或 SVT 伴差传，见 19.0）
├── 无 P，QRS 与 T 无法区分，T 高尖 → 高钾血症
└── 有起搏钉（spike）→ 心室起搏心律
```

## B.2 「V1 出现高 R 波」的鉴别（6 大原因）

| 原因 | 关键鉴别点 |
|---|---|
| **右束支阻滞** | QRS ≥ 0.12 s，V1 呈 rsR'，I/V6 宽 S |
| **右室肥大** | 电轴右偏 ≥ +110°，V1 ST-T 劳损，右房扩大，V5-V6 深 S |
| **后壁梗死** | V1-V2 ST 压低 + 高 T，V7-V9 有 Q/ST 抬高，常伴下壁改变 |
| **WPW（A 型）** | PR < 0.12 s，δ 波 |
| **逆钟向转位** | 移行区左移至 V2，其余正常 |
| **正常变异 / 儿童 / 瘦体型** | 无其他异常 |

## B.3 「电轴左偏」的鉴别

左前分支阻滞 / 下壁陈旧 MI（II、III、aVF 有异常 Q）/ 左室肥大 / LBBB / 横位心（肥胖、妊娠、腹水）/ 原发孔型 ASD / WPW / 高钾 / 起搏心律

## B.4 「电轴右偏」的鉴别

右室肥大 / 左后分支阻滞（排除性诊断）/ 侧壁 MI（I、aVL 有 Q）/ 垂位心（瘦长）/ COPD・肺气肿 / 急性肺栓塞 / 继发孔型 ASD / 右位心・电极接错 / 婴幼儿（生理性）

## B.5 「长间歇（漏搏）」的鉴别顺序

```
1. 看长间歇前的 T 波形态 → 有变形？→ 未下传的 SVPC（最常见，良性）
2. 长间歇是基本 PP 的整数倍？→ 是：II 度 SA 阻滞（Mobitz II 型）
                                → 否：窦性停搏
3. 有 P 波但后面没 QRS？→ II 度房室阻滞
   ├── PR 逐渐延长后脱落 → Wenckebach（良性，AVN 内）
   └── PR 固定后突然脱落 → Mobitz II（高危，His 以下）
4. P 与 QRS 完全无关 → 完全性房室阻滞
5. 房颤 + 长间歇 → 药物过量 / 合并 AVB
```

## B.6 「窄 QRS 心动过速（心率 ~150）」必查

**一律先排除 2:1 心房扑动**（看 II/III/aVF 的锯齿基线、V1 的直立 F 波；必要时腺苷/迷走刺激）。

## B.7 「ST 抬高」的 5 秒判断

**凸面向上 + 局限在冠脉支配区 + 有镜像压低 + 有动态演变 = STEMI，立即启动再灌注流程。**
