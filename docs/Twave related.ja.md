<a id="1-前处理"></a>
## 1. 前処理

前処理の系統誤差は通常、アルゴリズムの違いそのものよりも大きくなります。 T エンドポイントの合計エラー バジェットは約 ±30 ms ですが、前処理が適切に行われていない場合、このうち 15 ms 以上が単独で消費される可能性があります。

<a id="11-采样率"></a>
### 1.1 サンプリングレート

|目的 |最小 |おすすめ |
|---|---|---|
|従来の T 境界 | 500Hz | 500Hz |
| QT精密測定 / TpTe | 500Hz | 1000Hz |
| STレベル | 250Hz | 500Hz |

生の 250 Hz 以下の信号は、まず 3 次スプラインまたはポリフェーズ FIR を使用して 1000 Hz に補間することをお勧めします。これにより情報量は増加しませんが、サンプル ポイント グリッドによって引き起こされる ±2 ms の量子化誤差が除去されます。これは、TpTe (通常 80 ～ 100 ミリ秒) などの小さな相対誤差に大きな影響を与えます。

<a id="12-基线漂移去除对-st-影响最大的一步"></a>
### 1.2 ベースラインドリフトの除去 (ST に最も大きな影響を与えるステップ)

**推奨: カスケード メディアン フィルター** (PhysioNet 規約)

```
y1 = medfilt(x,  W1)     # W1 = 200 ms → 101 样点 @500Hz（201 @1000Hz）
y2 = medfilt(y1, W2)     # W2 = 600 ms → 301 样点 @500Hz（601 @1000Hz）
out = x - y2
```

ウィンドウの長さは奇数のサンプルでなければなりません。 W1 は最も幅の広い QRS (約 120 ミリ秒をカバー) よりも大きい必要があり、W2 は最も幅の広い QRS+ST+T よりも大きい必要があります。

**代替案 A: 等電点 3 次スプライン**
- ノード位置: 各ビートの `QRSon − 30 ms` (PQ セグメントの中点)、この点の ±10 ms ウィンドウの中央値をノード縦座標として取得します。
- 心拍数が 100 bpm を超える場合、PR セグメントが短すぎるため、代わりに `QRSon − 20 ms` で ±6 ms ウィンドウを使用してください
- ノードが欠落している場合（識別不能な P 波、心房細動）、メディアン フィルタリングに縮退します。

**代替案 B: ゼロフェーズ クアルコム**
- バターワース 4 次、`fc = 0.05 Hz`、`filtfilt` の前方および後方フィルタリング

**❌ 禁止**: `fc = 0.5 Hz` の単方向 IIR クアルコム。実際の測定では、ST セグメントに 50 ～ 100 µV の誤った上昇/下降が発生する可能性があります。その方向は QRS 極性に関連しており、ST 特性における系統誤差の最も危険な原因です。

<a id="13-工频干扰"></a>
### 1.3 電源周波数の干渉

- 優先順位: 適応ノッチ、中心周波数 50/60 Hz、`Q ≈ 35` (−3 dB 帯域幅 ≈ 1.4 Hz)、ゼロ位相実装
- T/ST 解析のみを実行する場合: 直接のローパス 40 Hz が完全にカバーされ、別個のノッチは必要ありません

<a id="14-分支滤波关键设计"></a>
### 1.4 分岐フィルタリング (主要な設計)

**異なるタスクは異なるフィルタ ブランチを使用し、プロセス全体で同じフィルタ チェーンを共有することは禁止されています。 **

|支店 |フィルター |目的 |
|---|---|---|
| `x_qrs` |バンドパス 5 ～ 15 Hz (パントンプキンス) または 8 ～ 20 Hz | QRS 検出、ビート調整 |
| `x_fid` |ゼロ位相ローパス 40 Hz、FIR 等リップル、次数 ≈ 0.1・fs | QRSon / J 点位置決め (QRS 端の高周波を保持する必要があります) |
| `x_t` |ゼロ位相ローパス **20 ～ 25 Hz**、FIR | T 波の境界と形態 (T エネルギー <10 Hz) |
| `x_amp` |ゼロ相ローパス 40 Hz | STレベル、T振幅、その他の振幅測定 |

`x_t` 15 Hz ローパスを使用すると、耐ノイズ性はさらに向上しますが、T-U 融合は悪化するため、§4.7 の U 波識別と連携する必要があります。

<a id="15-伪迹与无效段标记"></a>
### 1.5 アーティファクトと無効なセグメント マーカー

|現象 |基準 |廃棄 |
|---|---|---|
|ペーシングパルス |幅 <2 ms 且幅度 >2 mV の狭いスパイク |検出後の線形補間パディング |
| ADCの飽和 |フルスケールで ≥8 連続サンプル ±1 LSB |このセグメント フラグは無効です |
|電極オフ | 50 ms 以内のピークツーピーク、スライディング ウィンドウ <10 μV |リード全体が削除されました |
|ジャンプアーティファクト |単一のサンプルが 1 mV を超えてジャンプし、隣接するサンプルが継続しません。中央値置換 |

<a id="16-中位拍representative-beat构建"></a>
### 1.6 中央ビート (representative beat) の構築

**T 区切りは中央拍で実行する必要があります**。拍ごとの区切りは拍ごとの変動 (TWA、QT 変動) が必要な場合にのみ使用され、中央拍の結果を事前検索として使用する必要があります。

```
1) QRS 对齐：在 x_qrs 上以模板互相关，搜索范围 ±30 ms，
   峰值处做三点抛物线插值 → 亚样点对齐精度
2) 形态聚类：
   - 相关系数 ρ ≥ 0.90 且 QRS 宽度差 ≤ 25 ms  → 归入同簇   【工程】
   - ρ < 0.85 或宽度差 > 25 ms                 → 新建簇（PVC/差传）
3) 主簇选取：拍数最多且平均 RR 变异最小的簇
4) 逐样点取【中位数】（不是均值，抗离群拍）
5) 输出窗：R − 250 ms  到  R + min(500 ms, 0.70·RR_median)
6) 置信门限：簇内拍数 ≥ 8 才输出高置信中位拍；3–7 拍降级；<3 拍不输出
```

SNR の改善は約 √N です。 8 拍の中央値により、T エンドポイントのランダム誤差が ±20 ミリ秒から ±7 ミリ秒程度に減少します。

<a id="2-基准点与等电位基线"></a>
## 2. 基準点と等電位ベースライン

<a id="21-qrson-与-j-点"></a>
### 2.1 QRSon と J ポイント

**ウェーブレット法 (推奨)**: 2 次スプライン ウェーブレット スケール 2¹、2² に配置します。 QRS は、これら 2 つのスケールで最もエネルギーが集中しています。

- `QRSon`: R ピーク前の最初のモード最大値の前に、`|w₂|` が初めて `0.05 × max|w₂|` に低下します [文学]
- `J`: R/S 後の最後のモジュラー最大値の後、`|w₂|` は `0.125 × 该模极大值` に低下します [文献]

**スロープリファインメント (J ポイント)**: R ピークから逆方向に検索し、**連続 8 ms** で初めて `|dy/dt|` が QRS セグメントの最大スロープよりも 5% 低くなる瞬間を取得します [エンジニアリング]。

**信頼性の低いマーク**: QRS 幅が > 120 ms、デルタ波が存在する、または束分岐ブロック形態が存在する場合、J ポイントの位置決め誤差は 20 ms 以上に達する可能性があるため、低い信頼性マークを設定する必要があり、ST 測定点は一律に後方に移動する必要があります。

<a id="22-等电位基线-b"></a>
### 2.2 等電位ベースライン `B`

|優先順位 |ウィンドウ |追加条件 |
|---|---|---|
| 1 | PR セグメント: `[QRSon − 40 ms, QRSon − 10 ms]` |ウィンドウ内のピークツーピーク値 < 30 µV [エンジニアリング] |
| 2 | PR セグメントで最も平坦なサブウィンドウ: 上のウィンドウ内で 20 ミリ秒のサブウィンドウをスライドさせ、最小の分散を持つサブウィンドウを選択します。心拍数 <100bpm |
| 3 |短い PR: `[QRSon − 26 ms, QRSon − 6 ms]` | RR < 600 ミリ秒 |
| 4 | TP セグメント: `[Toff + 40 ms, Pon − 20 ms]` | Toff を知る必要があります (2 回目の反復) |

`B` は、平均値の代わりにウィンドウ内の **中央値** を取得します。

**`B`** はリードごとに個別に計算され、リード間で共有することはできません。

<a id="3-t-波搜索窗"></a>
## 3. T波検索ウィンドウ

検索ウィンドウの定義は、見逃し検出率と誤検出率を直接決定します。

```
Twin_start = J + max(60 ms, 0.04·RR)
Twin_end   = J + min(0.62·RR, 500 ms)          【工程】
```

心拍数の実際の値によると (RR は前の心拍の RR です):

|心拍数 (bpm) | RR (ミリ秒) |ツインスタート (J+) |ツインエンド (J+) |備考 |
|---|---|---|---|---|
| 50 | 1200 | 60ミリ秒 | 500ミリ秒 |上限が有効です |
| 60 | 1000 | 60ミリ秒 | 500ミリ秒 |上限が有効です |
| 75 | 800 | 60ミリ秒 | 496ミリ秒 | |
| 100 | 600 | 60ミリ秒 | 372ミリ秒 | |
| 120 | 500 | 60ミリ秒 | 310ミリ秒 | P-on-T が必要です |
| 150 | 400 | 60ミリ秒 | 248ミリ秒 | T と P は高度に重複しており、信頼性が低下します。

**RR 平滑化**: 最初の 5 拍の RR の中央値を使用して、単一の早すぎる拍によってウィンドウが崩壊するのを防ぎます。

**P-on-T 保護**: `Twin_end` が次のビート `QRSon` から 120 ミリ秒未満の場合、`Twin_end` を `nextQRSon − 120 ms` に切り捨て、「T-P オーバーラップ」をマークします。

<a id="4-单导联-t-定界方法"></a>
## 4. 単一リード T 区切り方法

<a id="41-小波模极大值法主力方法"></a>
### 4.1 ウェーブレット係数最大化法 (メイン法)

**ウェーブレットの選択**: マラー 2 次スプライン ウェーブレット (一次導関数タイプ)、フィルター `h = [1,3,3,1]/8`、`g = [2,−2]`、トラス アルゴリズム (デシメーションなし、時間調整を維持) を使用。

**スケールの選択**:

| FS | T 波使用スケール |等価通過帯域 |
|---|---|---|
| 250Hz | 23 | ～3 ～ 11 Hz |
| 500Hz | 2⁴ | ~3 ～ 10 Hz |
| 1000Hz | 2⁵ | ~3 ～ 10 Hz |

**手順**:

```
1) 在搜索窗内计算 w4，噪声门限
     ε_T = max( 0.25 · RMS(w4 | Twin) ,  0.125 · max|w4 | Twin| )   【文献】

2) 提取所有 |w4| > ε_T 的模极大值，按时间排序

3) 形态判定与 T 峰定位：
   - 2 个异号模极大值        → 单相 T，两者之间的过零点 = Tpk
                               （模极大值对的符号顺序决定 T 的极性）
   - 3 个交替符号模极大值     → 双相 T，2 个过零点 = 两个峰
   - 4 个及以上              → 切迹/多相 T，取幅度最大的两个相邻异号极大值定主峰
   - 0 或 1 个               → T 波不可辨，返回 NaN 并标记

4) 边界定位：
   Ton  = 第一个模极大值【之前】，|w4| 首次降到 ξ_on · |第一模极大值| 的时刻
   Toff = 最后一个模极大值【之后】，|w4| 首次降到 ξ_off · |末模极大值| 的时刻

   参考阈值                                          【文献】
     ξ_on  = 0.25
     ξ_off = 0.40
   低幅 T（|Tpk − B| < 200 µV）建议 ξ_off = 0.50     【工程】

5) 兜底：若在最大搜索距离内未降到阈值，取 |w4| 的第一个局部最小点
     最大搜索距离：Toff 距末模极大值 ≤ 160 ms，Ton 距首模极大值 ≤ 120 ms  【工程】
```

**パフォーマンス参照**: このメソッドには、CSE ライブラリで約 **0.8 ± 18 ms** の T エンドポイント誤差があります (CSE では 30.6 ms の 2SD 許容誤差が許容されます) [文献]。

**利点**: 順方向、逆方向、および二相 T を同等に扱います。マルチスケールの自然ノイズ耐性。同等のワイヤに依存しません。
**弱点**: 非常に低い振幅 T (<80 µV) では、モード最大値がノイズしきい値に飲み込まれます。最終モードの最大値は、T-U 融合中に U 波に当たる可能性があります。

<a id="42-梯形面积法低幅-t-的主力"></a>
### 4.2 台形領域法（低振幅Tの主力）

Zhangらによって提案された台形領域法。等電位線に依存しないため、残留ベースラインドリフトの影響を受けません。

```
输入：x_t（低通 20–25 Hz），T 峰位置 Tpk

1) 在 [Tpk, Tpk + 200 ms] 内求一阶导数绝对值最大点 → (x_m, y_m)
   （即降支最大斜率点；一阶导数用 Savitzky-Golay，2 阶多项式、9 点窗）

2) 设参考点横坐标  x_r = x_m + 160 ms        【工程，范围 120–200 ms】

3) 对每个候选 x_i ∈ [x_m + 10 ms, x_r − 10 ms]，计算梯形面积：
       A(x_i) = 0.5 · |y_m − y(x_i)| · (2·x_r − x_i − x_m)

4) Toff = argmax_i A(x_i)
```

面積関数 `A` は実際の T の終点で最大値を取ります。`|y_m − y_i|` は終点の前でまだ増加しており、`(2x_r − x_i − x_m)` は終点の後に急速に減衰します。

**パラメータ感度**: `x_r` の値は、結果に約 ±5 ミリ秒影響します。 160 ms に固定し、自分のデータで一度校正することをお勧めします。

**利点**: 低振幅 T では、接線法や閾値法よりも大幅に優れています。ベースラインのドリフトに耐えます。実装は簡単で、反復は必要ありません。
**弱点**: 正しい `Tpk` が必要です。二相 T の場合、最初に下降ブランチのどのフェーズを使用するかを決定する必要があります。

<a id="43-切线法临床对齐用"></a>
### 4.3 タンジェント法 (臨床的アライメント用)

これは手動による解釈の習慣と最も一致しており、臨床ベンチマークを行うときに実装する必要があります。

```
1) 降支最大斜率点 (x_s, y_s)：一阶导数极值
   （Savitzky-Golay 2 阶 / 9 点，或 5 点中心差分 + 3 点平滑）
2) 斜率 k = dy/dt |_{x_s}
3) Toff = x_s + (B − y_s) / k
```

**使用の前提条件 (必ず確認してください)** [プロジェクト]:
- `|Tpk − B| ≥ 100 µV`、それ以外の場合、エラーは 40 ミリ秒を超える可能性があり、無効になります
・`Toff ≤ x_s + 200 ms`を取得し、それ以外の場合は失敗と判断します。
- `|k| ≥ 0.8 µV/ms`、勾配が遅すぎると外挿が不安定になります

**体系的なバイアスのヒント**: タンジェント法は、**閾値法/ウェーブレット法よりも体系的に**早く T エンドポイントを与えます。通常の差は **10 ～ 20 ms** で、T 波の対称性に応じて変化します。長期的な追跡調査や薬物試験を実施する場合、同じ方法とパラメータのセットを全体を通して固定する必要があります。

<a id="44-阈值法快速备用"></a>
### 4.4 閾値方式（クイックバックアップ）

```
Toff = Tpk 之后，|y − B| 首次 < max( 0.10 · |Tpk − B| , 15 µV ) 的时刻   【工程】
去抖：需连续 3 个样点（6 ms @500Hz）满足才确认
```

最も高速ですが、ベースラインに対する感度が最も高く、相互検証の 3 番目の方法として、または極端な場合のカバーとしてのみ使用されます。

<a id="45-累积面积法"></a>
### 4.5 累積面積法

```
S_total = Σ |y(i) − B|,  i ∈ [Ton, Twin_end]
Toff = 累积面积首次达到 0.98 · S_total 的位置      【工程，0.97–0.985】
```

ノイズに対して自然な平滑化効果がありますが、検索ウィンドウの右端の影響を受けやすくなります。

<a id="46-曲线拟合法同时给出形态参数"></a>
### 4.6 カーブフィッティング法 (形態パラメータも与えられます)

非線形最小二乗法 (Levenberg–Marquardt) を使用してパラメトリック モデルを近似し、1 回の近似で境界量と形態量を同時に取得します。 **これは決定論的な曲線フィッティングであり、機械学習ではありません。 **

**ダブル ガウス モデル** (単相および二相 T に適合):

```
T(t) = Σ_{j=1..J} a_j · exp( −(t − µ_j)² / (2σ_j²) )
J = 1（单相）或 2（双相/切迹）
```

- 初期値：`a₁ = Tpk − B`、`µ₁ = Tpk`、`σ₁ = (Toff_wavelet − Ton_wavelet)/5`
- 境界解析定義: `Ton = µ₁ − 2.5σ₁`、`Toff = µ_J + 2.5σ_J` [エンジニアリング、k = 2.0–3.0 はキャリブレーションが必要]
- 適合度のしきい値: `R² ≥ 0.95` が受け入れられます。それ以外の場合は、ウェーブレットの結果 [プロジェクト] に戻ります。

**歪んだガウス** (T 波の固有の非対称性に適しています):

```
T(t) = a · exp(−(t−µ)²/(2σ²)) · [1 + erf( α(t−µ)/(σ√2) )]
```

パラメータ `α` は、非対称性の直接の特性です。正常な洞 T の `α` は、通常 **−1.5 ~ -0.5** (下行脚は上行脚より急勾配です) [工学]。

<a id="47-u-波判别与-tu-融合处理"></a>
### 4.7 U波の識別とT-U融合処理

**T エンドポイントにおける最大の単一エラー原因。 **

**独立した U 波基準** [エンジニアリング]:
- `[Toff + 60 ms, Toff + 200 ms]`の範囲内
- 振幅 **20 ～ 150 μV** のバンプの存在
- ローパス 15 Hz 信号では、その一次導関数は完全な「正→ゼロクロス→負」のシーケンスで表示されます。
- 上記を満たす → 独立したU波と判定され、Toffには影響しない

**T-U 融合基準** [プロジェクト]:
- ウェーブレット法で得られた `Toff`、`|dy/dt| > 5 µV/ms` (つまり、>10 µV/サンプル @500 Hz)
- または、`w4` が `Toff` 後 40 ミリ秒以内にノイズしきい値を下回らない場合
- 上記を満たす → 「T-U fusion」をマークし、信頼度を下げます

**融合中の廃棄**:
`[x_s, x_s + 200 ms]` 内の二次導関数 `d²y/dt²` (Savitzky-Golay 2 次 / 11 ポイント) を計算し、**曲率最大点** (`d²y/dt²` の最初の有意な正の最大値) を `Toff` の上限として取得します。この点は、下降する T 分岐の「平坦化」位置に対応し、通常は U 波の開始よりも早いです。

**高リスクシナリオ**: 低カリウム血症、QT 延長症候群、顕著な U 波を伴う徐脈 (HR <50)、融合検出は必須である必要があります。

<a id="48-方法选择决策树"></a>
### 4.8 手法選択デシジョンツリー

```
读取 A = |Tpk − B|，形态类别 M，U 波标记 U

if T 波不可辨（小波模极大值 < 2 个）:
        → 返回 NaN，导联剔除

elif M == 双相 或 M == 切迹:
        → 小波法（唯一可靠）
        → 若拟合 R² ≥ 0.95，用双高斯结果交叉校验

elif U == 融合:
        → 曲率上界法 (§4.7) 与 梯形法 取【较早】者
        → 置信度降一级

elif A ≥ 200 µV:
        → 主：小波法
        → 校验：切线法。若两者差 > 25 ms → 置信降级
        → 输出：小波法结果

elif 100 µV ≤ A < 200 µV:
        → 小波法 + 梯形法，取两者【中位】（此时即中点）
        → 若两者差 > 30 ms → 置信降级

else  (A < 100 µV):
        → 梯形面积法（唯一可用）
        → 禁用切线法与阈值法
        → 置信度设为最低档；若 A < 50 µV 直接剔除该导联
```

## 5. マルチリード: 信頼性の高いリードスクリーニングと堅牢な融合

<a id="51-派生全局导联"></a>
### 5.1 「グローバルリード」を導き出す

元のリードに加えて、融合クロスチェックとして独立した境界設定のために 3 つの追加の派生リードが構築されます。

**(a) RMS リード**

```
对 8 个独立导联 (I, II, V1..V6)，各自先减去自身基线 B_l：
    RMS(k) = sqrt( (1/8) · Σ_l [x_l(k) − B_l]² )
```

RMS リードの T 波は常に正で、単一の形状を持ち、境界設定において最も安定しています。 §4.1 ウェーブレット法、`ξ_off = 0.40` によって処理されます。

**(b) PCA 第一主成分**

```
1) 取 T 窗矩阵 X ∈ R^{8×N}，N = Twin 内样点数
2) 逐导联去均值（减自身在该窗内的均值）
3) SVD: X = UΣVᵀ
4) PC1 = U[:,0]ᵀ · X   → 1×N 时间序列
5) 在 PC1 上定界
```

PC1 は通常、T ウィンドウ内のエネルギーの 85 ～ 95% を伝送し、元のリードよりも大幅に優れた SNR を実現します。
副産物 `λ₂/λ₁ = (σ₂/σ₁)²` は T 波の複雑さの特性 (§6) です。

**(c) VCG 空間速度**

まず、12 リードから XYZ を再構成します。 **逆ダワー変換行列**:

```
X = −0.172·V1 − 0.074·V2 + 0.122·V3 + 0.231·V4 + 0.239·V5 + 0.194·V6 + 0.156·I − 0.010·II
Y =  0.057·V1 − 0.019·V2 − 0.106·V3 − 0.022·V4 + 0.041·V5 + 0.048·V6 − 0.227·I + 0.887·II
Z = −0.229·V1 − 0.310·V2 − 0.246·V3 − 0.063·V4 + 0.055·V5 + 0.108·V6 + 0.022·I + 0.102·II
```

> ほとんどの研究において、Kors 回帰変換は Inverse Dower よりも優れています (特に QRS-T には角度特徴が含まれています)。実装するときは、オリジナルの Kors テキストから直接係数を確認し、二次ソースからコピーしないことをお勧めします。

空間速度:

```
SV(k) = sqrt( (dX/dt)² + (dY/dt)² + (dZ/dt)² )
导数用 Savitzky-Golay 2 阶 / 9 点

Toff_SV = SV 在 T 峰之后降到 0.15 · max(SV | T窗) 的时刻      【工程，0.10–0.20】
或取 T 波之后 SV 的第一个显著局部极小
```

SV 法は、「全体的な再分極の終わり」の生理学的定義に最もよく適合します。

<a id="54-稳健融合算法"></a>
### 5.4 堅牢な融合アルゴリズム

**前提条件**: 各リードの `Toff_l` が同じ時間軸に位置するように、最初にすべてのリードを **同じグローバル R ピーク**に従って位置合わせする必要があります。 Fusion は、R ピーク `d_l = Toff_l − R` からのオフセットです。

```
输入：{ d_l }, { w_l },  l ∈ 保留导联集 L

Step 1  初始估计
        m₀ = weighted_median(d, w)

Step 2  稳健尺度
        MAD = 1.4826 · median( |d_l − m₀| )
        σ̂  = max(MAD, 3 ms)                      # 下限防退化

Step 3  内点判定
        Inliers = { l : |d_l − m₀| ≤ max(3·σ̂, 15 ms) }      【工程】

Step 4  Huber IRLS（仅用内点），c = 1.345·σ̂
        repeat (最多 5 次，或位移 < 0.5 ms 时停):
            r_l  = d_l − m
            u_l  = w_l · (1 if |r_l| ≤ c else c/|r_l|)
            m    = Σ u_l·d_l / Σ u_l

Step 5  输出
        Toff_global = R + m
        标准误 SE   = σ̂ / sqrt( Σ_{Inliers} w_l )
        95% CI      = ± 1.96 · SE
```

**「グローバル T エンドポイント」の 2 つの定義** - ドキュメント内で明示的に選択して修正する必要があります。

|定義 | Calculation |該当 |
|---|---|---|
| **堅牢なセンター** |上記の IRLS 結果 `m` |人間による解釈（II/V5）との整合、アルゴリズム評価、従来の特徴抽出 |
| **最新の再二極化** |内部点セット内の `d_l` の **P85 分位値** (**max は使用しないでください**) | 「グローバル QT = 初期の脱分極 → 最後の再分極」という生理学的/標準的な定義に沿っています。

`max` を直接取得することは、単一のノイズの多いリード線に非常に敏感であり、エンジニアリングでは利用できません。 P85 は、精度と生理学的定義の間の実際的な妥協点です。

同様に、グローバル `QRSon` は内点の **P15 分位数** (最小値ではない) を取得し、グローバル `J` は内点の **P85 分位数** を取得します。

<a id="65-逐拍动态特征需逐拍定界"></a>
### 6.5 ビートごとの動的特性 (ビートごとの区切りが必要)

**T 波交流 (TWA) - スペクトル法**:

```
1) 取连续 128 拍（必须窦性、RR 变异 < 10%）
2) 对 T 窗内每个时间样点，构造跨拍序列（长度 128）
3) 加 Hanning 窗，FFT
4) TWA 幅度 = 0.5 Hz 处（Nyquist，即每两拍交替）的谱峰
5) 噪声估计 = 0.43–0.47 Hz 频段的平均功率
6) K-score = (峰值 − 噪声均值) / 噪声标准差
   判阳性：K ≥ 3.0 且 TWA 电压 ≥ 1.9 µV        【文献】
```

**MMA (修正移動平均) 法**: 奇数拍と偶数拍の指数移動平均をそれぞれ実行し、係数 **1/8** を更新します (つまり、新しい拍の重みは 12.5% です) [文献]、TWA = ST-T セグメントの奇数平均拍と偶数平均拍の最大絶対差。耐ノイズ性はスペクトル法よりも優れており、厳密な正弦波の法則は必要ありません。

**QT 変動**: `QTVI = log10[ (QTv/QTm²) / (RRv/RRm²) ]`、正常は約 **−1.9 ~ -0.9** [文献]。

## 7. STセグメントの特性

<a id="71-测量点定义"></a>
### 7.1 測定点の定義

すべての ST レベルは、同じ拍動の等電点ベースライン `B` を基準としています (§2.2)。

```
STj   = y(J)        − B
ST20  = y(J + 20ms) − B
ST40  = y(J + 40ms) − B
ST60  = y(J + 60ms) − B
ST80  = y(J + 80ms) − B
```

**心拍数アダプティブ測定ポイント** (運動テストの実践) [文献]:

|心拍数 (bpm) |主な測定箇所 |
|---|---|
| < 100 | J + 80 ミリ秒 |
| 100–110 | J + 72 ミリ秒 |
| 110–120 | J + 64 ミリ秒 |
| > 120 | J + 60 ミリ秒 |

または、連続式 `t_meas = J + min(80 ms, 0.10·RR)` を使用します。

**安全マージン**: `t_meas` は `Ton − 20 ms` よりも前でなければなりません。そうでない場合は、ST セグメントの代わりに T 波の上行枝が測定されます。心拍数が速すぎる場合、時間は J+40 ミリ秒に短縮され、最初にマークされます。

<a id="72-斜率与形状"></a>
### 7.2 傾斜と形状

**ST 傾き**: `[J + 20 ms, J + 80 ms]` に対して最小二乗線形回帰を実行し、傾き `k_ST` (μV/ms、mV/s に相当) を取得します。

分類しきい値 [プロジェクト]:

|フォーム | `k_ST` |
|---|---|
|立ち上がりスロープタイプ | > +0.5 μV/ms |
|横型 | −0.5〜+0.5μV/ms |
|ダウンスロープタイプ | < -0.5 μV/ms |

**ST 曲率 (凹/凸)**: `[J, J + 100 ms]` 上の 2 次フィット `y = a·t² + b·t + c`

- `a > 0`: 上に凹んだ状態 - 初期の再分極と心膜炎の典型的な形態
- `a < 0`: 上に凸 - 急性心筋損傷の典型的な形態
- 判定閾値：`|a| > 0.02 µV/ms²`を使用して形状を判定し、それ以外の場合は線形と判定します [エンジニアリング]

**STエリア**：`ST_area = Σ (y(i) − B) / fs`、`i ∈ [J, Ton]`、単位：μV・s。

**ST-T 合計数量**:
- `ST_T_area`: `[J, Toff]` ポイント
- `ST_T_ratio = STj / T_amp`
- `ST_integral_norm = ST_area / (Ton − J)` (平均STレベル)

<a id="73-临床参考阈值仅作特征标定参考不作诊断输出"></a>
### 7.3 臨床基準閾値 (機能校正基準のみ、診断出力には適用されません)

**ST 上昇** (J 点では、解剖学的に隣接する 2 本以上のリードが必要) [心筋梗塞の臨床第 4 版の普遍的定義]:

|リード |人口 |しきい値 |
|---|---|---|
| V2～V3 |男性 40歳以上 | ≧200μV |
| V2～V3 |男性 <40歳 | ≧250μV |
| V2～V3 |女性（全年齢） | ≥ 150 μV |
|他のすべての見込み客 |すべて | ≥ 100 μV |
| V3R–V4R |すべて | ≥ 50 μV (30 歳未満の男性 ≥100 μV) |

**ST 低下**: 新しい水平型または下降型型 **≥50 μV**、隣接するリードが 2 つ以上ある [臨床]。運動テストで一般的に使用される閾値は、**≥ 100 μV** 水平/下り坂タイプです。

<a id="74-st-向量vcg-域"></a>
### 7.4 ST ベクター (VCG ドメイン)

```
ST 向量 = [X(t_meas), Y(t_meas), Z(t_meas)] − [X_B, Y_B, Z_B]

幅值   = |v_ST|
方位角 azimuth   = atan2(Z, X) · 180/π      # 水平面
仰角   elevation = atan2(Y, sqrt(X²+Z²)) · 180/π
```

虚血領域の位置を特定するための ST ベクトル方向の情報量は、単一誘導の閾値判定よりもはるかに高くなります。

<a id="75-多导联-j-点融合"></a>
### 7.5 マルチリード J ポイント融合

J ポイント誤差はすべての ST フィーチャに **線形に伝播**し、ST 解析における誤差の主な原因となります。

- 各リードは個別に `J_l` (§2.1) を決定し、グローバル R ピーク時間軸に統合
- §5.4 と同じ堅牢なプロセスを使用しますが、内点の **P85 分位数を出力**します (異なるリード QRS の終了時間は異なり、グローバル J は最新のものに対応する必要があります)
- 品質管理: 内部ポイント範囲 > 15 ms → すべての ST 機能がダウングレードされます

## 11. 完全なプロセス疑似コード

```python
def delineate_12lead(sig12, fs):
    # ---------- 1. 前处理 ----------
    if fs < 500: sig12 = resample(sig12, 1000); fs = 1000
    x = remove_baseline_median(sig12, fs, w1=0.200, w2=0.600)
    x = remove_artifacts(x, fs)                  # 起搏尖峰/饱和/平线
    x_qrs = bandpass(x, 5, 15, fs)
    x_fid = lowpass_zerophase(x, 40, fs)
    x_t   = lowpass_zerophase(x, 22, fs)
    x[aVR] *= -1                                 # 极性归一

    # ---------- 2. 全局 R 峰 ----------
    R = fuse_qrs_detections(x_qrs, fs)           # 多导联投票
    RR = median_filter(diff(R), 5)

    # ---------- 3. 中位拍 ----------
    clusters = cluster_beats(x_qrs, R, rho=0.90, dwidth=0.025)
    med = {l: median_beat(x_t[l], clusters.main) for l in LEADS}
    if len(clusters.main) < 8: flag('LOW_BEAT_COUNT')

    # ---------- 4. 基准点与基线 ----------
    QRSon = {l: wavelet_qrs_onset(x_fid[l]) for l in LEADS}
    J     = {l: wavelet_j_point(x_fid[l])   for l in LEADS}
    B     = {l: isoelectric(x[l], QRSon[l], RR) for l in LEADS}
    QRSon_g = robust_quantile(QRSon, weights, q=0.15)
    J_g     = robust_quantile(J,     weights, q=0.85)

    # ---------- 5. 派生导联 ----------
    rms  = rms_lead(x_t, B, INDEP8)
    pc1  = pca_first_component(x_t, INDEP8, T_window)
    svel = spatial_velocity(inverse_dower(x_t), fs)

    # ---------- 6. 逐导联定界 ----------
    res = {}
    for l in LEADS + ['RMS', 'PC1', 'SV']:
        win  = t_search_window(J[l], RR)
        wav  = wavelet_delineate_T(med[l], win, fs,
                                   xi_on=0.25, xi_off=0.40)
        if wav is None: res[l] = None; continue
        A_T  = abs(wav.Tpk_amp - B[l])
        U    = detect_u_wave(med[l], wav.Toff, fs)
        res[l] = select_method(wav, med[l], B[l], A_T, U, fs)   # §4.8
        res[l].sqi = compute_sqi(x[l], med[l], A_T, fs)

    # ---------- 7. 筛选 + 稳健融合 ----------
    keep = [l for l in res
            if res[l] and res[l].sqi.pass_all
            and res[l].A_T >= 50 and res[l].snr_T >= 6]
    if len(keep) < 4: return FAIL('INSUFFICIENT_LEADS')

    w = {l: w_prior[l] * res[l].sqi.score
            * min(1, res[l].A_T/200)
            * consistency_weight(res[l]) for l in keep}

    Toff_g, ci, inliers = robust_fuse([res[l].Toff for l in keep], w)   # §5.4
    Ton_g,  _,  _       = robust_fuse([res[l].Ton  for l in keep], w)

    # ---------- 8. 质控 ----------
    qc = quality_check(inliers, Toff_g, res['RMS'], res['PC1'], res['SV'])

    # ---------- 9. 特征提取 ----------
    feats = {}
    feats.update(t_morphology(med, B, Ton_g, Toff_g, res))       # §6
    feats.update(spatial_features(inverse_dower(x_t), QRSon_g,
                                  J_g, Ton_g, Toff_g))          # §6.4
    feats.update(st_features(med, B, J, RR, Ton_g))              # §7

    return Result(QRSon_g, J_g, Ton_g, Toff_g, feats, ci, qc)
```

<a id="12-实施建议"></a>
## 12. 実装に関する推奨事項

1. **最初にベースライン バージョンを作成します**: メディアン ビート + ウェーブレット区切り + SQI 加重メディアン フュージョン。 LUDB および QTDB のエラー分布を定量化します (層別レポート)。このステップにより、T offset SD ≈ 15 ms を達成できます。
2. **台形法と決定木を追加**: 低振幅 T が、残存する大きな誤差の主な原因です。 §4.2 と §4.8 を追加すると、SD は通常 12 ms 未満に短縮できます。
3. **最後に U 波処理と導出リードのクロスチェックを追加**: 主な貢献はロングテール (50 ミリ秒を超える大きな誤差) の抑制であり、これにより SD の改善は限定的ですが、最悪の場合には大幅な改善が見られます。
4. **すべての `【工程】` しきい値は、独自のデータに基づいて再調整する必要があります**。特に、リード事前重み、SQI しきい値、`ξ_off`、および台形法 `x_r`。収集装置、電極の位置、群衆の構成が異なると、これらの最適値は大幅に変化します。
5. **パラメータは一度決定すると途中で変更できません**。変更が必要な場合は、すべての履歴データを再計算する必要があります。再計算しないと、縦方向の比較が無効になります。
