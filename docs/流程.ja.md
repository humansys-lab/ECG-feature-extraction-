# 12 誘導心電図自動解釈システム - 設計および実装仕様

**バージョン** v1.0 | **技術ロードマップ** 決定論的信号処理 + 明示的なルール推論 (機械学習を除く)

---

<a id="0-文档说明"></a>
## 0. 文書の説明

### 0.1 目的

この文書は、生のサンプリング データから構造化された解釈レポートまでのすべての処理リンクをカバーする、12 誘導安静時心電図自動解釈システムの一連の完全なエンジニアリング仕様を定義します。このドキュメントは、アルゴリズム エンジニアおよびシステム アーキテクトを対象としています。各セクションでは、コーディングに直接入力できるパラメーター、決定、および受け入れ条件を提供します。

<a id="02-技术路线约束"></a>
### 0.2 技術的なルートの制約

**このシステムは機械学習手法を使用しません。 ** 具体的な意味:

- 波形の検出と境界設定には、ウェーブレット変換、適応しきい値、形態学的演算子などの決定論的アルゴリズムが使用されます。
- ハートビート分類では、分類器を使用せずに、テンプレートの相互相関ルールと時間制限ルールを使用します。
- 診断推論では、明示的なルール ベースと専門家が調整した評価スケールを使用します。重みは手動で設定され、文献に追跡可能です。
- すべてのしきい値は構成テーブルで集中管理され、データから適合するパラメーターはありません。

**この制約の直接的な結果** (プロジェクトが承認される際に受け入れられる必要があります):

|影響 |結果 |
|---|---|
|解釈可能性 |完全に解釈可能で、あらゆる結論を特定の手がかり、特定の測定値、特定の基準にまで遡ることができます。
|規制当局への提出 |大幅に簡略化されました。トレーニング セットの代表性、データ ドリフトのモニタリング、再トレーニングの変更管理、その他の資料を提出する必要はありません。
|開発費 |初期段階では低く (データにラベルを付ける必要がない)、後期では高く (ルール ベースのメンテナンスと境界パッチ適用は長期的なタスクです) |
|感度 |典型的な症状を示す症例に対する感度が良い。非定型形態（デ・ウィンター型、アスランジャー型など）に対する感度は、形態学的パターン認識方法よりも大幅に低い。
|ノイズ耐性 |学習方法より弱い。したがって、第 5 章の品質ゲートは、このシステムに対する **重要な安全障壁** であり、オプションのモジュールではありません。

設計上の対応戦略は次のとおりです。 **誤った判断率を高めるのではなく、棄権率を高める**。システムは、信頼性の低い結論を与えるのではなく、「不十分な信号品質/複雑な形態、手動解釈を推奨」を出力します。

<a id="03-预期用途声明"></a>
### 0.3 使用目的に関する記述

このシステムは**補助解釈ツール**であり、出力は医師が検討するための参考情報であり、独立した診断を構成するものではありません。すべてのレポートにはこの声明を含める必要があります。いかなる状況においても、人間によるレビューを行わない閉ループ診断パスとして設計してはなりません。

<a id="12-设计不变式"></a>
### 1.2 設計の不変条件

次の 4 つはアーキテクチャの厳しい制約であり、最適化によって違反してはなりません。

1. **測定と推論を厳密に分離します。 ** L5 以下は数値のみを生成し、医学的な判断を生成しません。 L7 は検出のみを消費し、元の信号に直接アクセスしません。
2. **一方向のデータ フロー。 ** ダウンストリームはアップストリームの結果を書き戻すことはできません。唯一の例外は、L3 内の欠落ビート ルックバック検索です (6.3 を参照)。
3. **各所見と陳述には、証拠の参照を含める必要があります。 ** 引用形式は `(导联, 测量项, 数值, 阈值, 判据条款号)` です。完全な証拠の引用を生成できない結論は出力されません。
4. **棄権は推測よりも優先されます。 ** いずれかのレイヤーが入力が信頼できないと判断した場合、デフォルト値の代わりに `UNRELIABLE` フラグをダウンストリームに渡します。このフラグを持つ必要な入力に遭遇した場合、ダウンストリームは棄権する必要があります。

<a id="14-三值逻辑约定"></a>
### 1.4 3 値の論理規則

すべての結果の値の範囲は `{TRUE, FALSE, UNKNOWN}` です。ルール エンジンは、次の 3 つの値のロジックに従って評価します。

- `TRUE AND UNKNOWN = UNKNOWN`
- `FALSE AND UNKNOWN = FALSE`
- `TRUE OR UNKNOWN = TRUE`
- `FALSE OR UNKNOWN = UNKNOWN`

診断ルールが `UNKNOWN` と評価されると、否定的な結論ではなく免除エントリが出力されます。 **この項目はシステム全体のセキュリティの中核である**ため、実装時には単体テストでカバーする必要があります。

<a id="2-l0-数据接入与标准化"></a>
## 2. L0 データアクセスと標準化

<a id="21-输入要求"></a>
### 2.1 入力要件

|アイテム |要件 |説明 |
|---|---|---|
|サンプリングレート | ≥ 500 Hz、1000 Hz を推奨 | 500 Hz 未満 QRS タイミング エラー ≥ 2 ms では、ペーシング ネイルが完全に失われる可能性があります。
|解像度 | ≤ 5 μV/LSB | |
|期間 | ≥ 10 秒 | 8秒未満の場合、リズミカルな結論の出力を禁止します。
|リード | 8 つの独立したリード (I、II、V1 ～ V6) | III、aVR、aVL、aVF は I と II から計算され導出されます。2.3 | を参照してください。
|メタデータ |年齢、性別、デバイスのフィルター設定 |年齢と性別が欠落している場合、第 10 章と第 11 章の複数の基準を評価できません。

<a id="22-强制元数据"></a>
### 2.2 必須のメタデータ

**年齢と性別はオプションのフィールドではありません。 **次の基準は性別層別によって異なります: コーネル電圧、コーネル積、ペゲロ-ロ プレスティ、QTc 閾値、V2 ～ V3 ST 上昇閾値。次の基準は年齢層別によって異なります: V2 ～ V3 ST 上昇閾値 (40 歳カットオフ)、正常な心拍数範囲。欠落している場合、対応する検出設定は `UNKNOWN` です。

欠落している状況に対する処理戦略の選択 (**プロジェクト レベルで決定し、構成に書き込む必要があります**):

- 戦略 A (保守的、推奨): `UNKNOWN` を設定し、関連する診断を回避します。
- 戦略 B (積極的): 最も厳格な閾値を採用し (女性の閾値に従ってコーネル大学を判断するなど)、レポート内で「性別不明、保守的な閾値に従って判断する」とマークします。

<a id="23-导出导联计算"></a>
### 2.3 輸出リードの計算

デバイスが 8 チャネルしか提供しない場合は、次のようにエクスポートします。

```
III  = II - I
aVR  = -(I + II) / 2
aVL  = I - II/2
aVF  = II - I/2
```

**注意**: デバイスが 12 チャネル データをすべて提供している場合は、**再計算しないでください**。デバイス値を直接使用し、一貫性チェックを実行してください (エクスポートされた値とデバイス値の差が 50 μV を超え、サンプル ポイントの割合が 5% を超える場合、データは異常としてマークされます)。

<a id="24-单位标准化"></a>
### 2.4 単位の標準化

μV と ms は内部で一律に使用されます。変換は L0 で一度完了し、その後はすべてのモジュールで単位変換が実行されなくなります。 **これは次元のバグを防ぐための重要な規則であり、コードレビュー中に確認する必要があります。 **

<a id="25-设备滤波元数据的用途"></a>
### 2.5 デバイスフィルタリングメタデータの目的

さまざまなデバイスのプレフィルター設定により、ST セグメント レベルと QRS 振幅が体系的に変更されます。 L0 はデバイスのハイパス/ローパス カットオフ周波数を記録し、次のシナリオで使用する必要があります。

- 機器 Qualcomm > 0.05 Hz: ST セグメントの測定結果は「フィルタリングの影響を受ける可能性がある」とマークされ、ST 関連の基準の信頼レベルが 1 レベル低下します。
- 機器ローパス < 100 Hz: QRS 振幅基準 (Sokolow-Lyon、Cornell) 信頼レベルが 1 レベル減少
- デバイスの「筋電フィルタリング」または「スムージング」がオンになっています: ノッチング/断片化 QRS 関連する所見設定 `UNKNOWN`

<a id="3-l1-预处理"></a>
## 3. L1 前処理

<a id="31-滤波链"></a>
### 3.1 フィルターチェーン

処理シーケンス: **ベースライン補正 → 電力周波数抑制 → ローパス**。順序は交換できません。

<a id="311-基线漂移校正"></a>
#### 3.1.1 ベースラインドリフト補正

推奨される解決策: **カスケード メディアン フィルター** (位相歪みはゼロ、ST セグメントにとって最も安全)

```
step1 = medfilt(x, win = 200 ms)    # 消除 QRS
step2 = medfilt(step1, win = 600 ms) # 消除 P、T
baseline = step2
y = x - baseline
```

ウィンドウの長さは奇数のサンプル ポイントである必要があります。 `fs = 500` の場合、win1 = 101 ポイント、win2 = 301 ポイントとなります。

代替案: ゼロ位相ハイパス IIR、カットオフ 0.05 Hz、前後方向フィルタリング (`filtfilt`) を使用してゼロ位相を実現します。

**片方向 IIR クアルコムの使用は禁止されています。 ** QRS 後の単方向 IIR によって導入された位相歪みは、人為的な ST セグメント低下を引き起こします。これは、自社開発システムで最も一般的な系統的エラーの 1 つです。

線形位相 FIR を使用する場合、カットオフ周波数は 0.67 Hz まで緩和できます (同等の診断性能)。

<a id="312-工频抑制"></a>
#### 3.1.2 電源周波数の抑制

優先順位:

1. **適応ノッチ**: 電源周波数を中心とした LMS 適応キャンセル、Q 値 ≤ 30
2. 電源周波数 (50/60 Hz) が特定できない場合は、まず 45 ～ 65 Hz で自動ピーク検出を実行します。
3. 代替案: 移動平均消去法 (ウィンドウ長 = 1 電力周波数サイクルの整数倍)

**高 Q 静的ノッチは禁止されています** (Q > 50)。高 Q ノッチは QRS の後に鳴り、ダウンストリームではノッチまたは J 波と誤って判断されます。

<a id="313-低通"></a>
#### 3.1.3 ローパス

|オブジェクト |カットオフ周波数 |注文 |
|---|---|---|
|大人 | 150Hz |ゼロ位相 FIR、次数は遷移ゾーン < 20 Hz となる fs として計算されます。
| 12 歳未満の子供 | 250Hz |同上 |

`fs = 500 Hz` では、250 Hz のローパスは無意味 (ナイキストに等しい) であり、小児シナリオでは `fs ≥ 1000 Hz` が必要です。

<a id="32-未滤波支路"></a>
### 3.2 フィルタリングされていないブランチ

ペーシング パルス検出専用として、**ローパスではなく** ベースライン補正のみを実行する信号を予約します (8.5 を参照)。ペーシング スパイク幅は 0.1 ミリ秒まで低くすることができ、ローパスによって平滑化されます。

<a id="33-测量专用支路"></a>
### 3.3 測定専用ブランチ

ST セグメントと振幅の測定は **中央ビート** で行う必要があります (第 6 章を参照)。これ自体が強力なノイズ抑制手段です。 「よりクリーンに」するためだけに、測定ブランチに追加のフィルタリングを追加しないでください。

<a id="4-l2-信号质量评估与导联合法性校验"></a>
## 4. L2 信号の品質評価とリードの合法性の検証

この章はシステムのセキュリティ障壁です。ルール システムは、学習方法ほどノイズに対して堅牢ではありません。品質ゲートが適切に行われていない場合、その後のすべての細かい基準は自己欺瞞になります。

<a id="41-逐导联质量指标"></a>
### 4.1 リードごとの品質指標

次の指標はリードごとに個別に計算され、すべて [0,1] で正規化またはブール値になります。

|メトリクス |定義 |失敗しきい値 (デフォルト) |
|---|---|---|
| `flatline` |スライド 1 秒ウィンドウのピークツーピーク値 < 50 μV 的时间占比 | > 10% |
| `saturation` | \|x\| ≥ 0.95 × ADC フルスケール サンプル比 | > 0.5% |
| `baseline_drift` | 0.05 ～ 0.5 Hz 帯域エネルギー / 0.05 ～ 40 Hz 総エネルギー | > 0.30 |
| `powerline` | (f0 ± 1 Hz) 周波数帯域エネルギー / 0.05 ～ 100 Hz の総エネルギー | > 0.15 |
| `emg` | TQ セグメントの 40 ～ 100 Hz エネルギー / TQ セグメントの総エネルギー | > 0.40 |
| `pSQI` | 5 ～ 15 Hz エネルギー / 5 ～ 40 Hz エネルギー | < 0.40 或 > 0.90 |
| `kSQI` |信号の尖度 | < 5 (通常の ECG は尖度が高く、尖度が低いとノイズが優勢であることを示します) |
| `bSQI` | 2 つの独立した QRS 検出器からの結果の一致率 | < 0.85 |

`bSQI` には、異なる原理 (パントンプキンスやウェーブレット モード最大法など) を持つ 2 つの QRS 検出器が必要です。 2 つの検出位置の差は 100 ミリ秒未満であり、一貫していると見なされます。 **これは最も効果的な単一の品質指標であり、最初に実装する必要があります。 **

<a id="42-导联可用性判定"></a>
### 4.2 リードの入手可能性の決定

```
lead_usable[l] = NOT flatline AND NOT saturation
                 AND baseline_drift < T_bd
                 AND emg < T_emg
                 AND bSQI > T_b
```

<a id="43-整体门控决策"></a>
### 4.3 全体ゲート決定

| 条件 | アクション |
|---|---|
| 使用可能な誘導 ≥ 10 かつ II、V1、V5 を含む | 全モジュールを正常に実行 |
| 使用可能な誘導 6–9 | 実行するが、使用不可能な誘導に関する判定基準を `UNKNOWN` に設定 |
| 使用可能な誘導 < 6、または II と V1 の両方が使用不可能 | **終了**、「信号品質が不十分です。再採取をお勧めします」と出力 |
| `bSQI` 全誘導で < 0.7 | **終了**、同上 |

<a id="44-导联反接检测"></a>
### 4.4 誘導逆接検出

逆接検出は、いかなる診断よりも前に完了させる必要があります。逆接を病理と誤認することは、臨床的に最も危険なエラータイプのひとつです。

<a id="441-肢导反接的确定性规则"></a>
#### 4.4.1 四肢誘導逆接の確定ルール

| 逆接タイプ | 特徴的な所見 | 判定式 |
|---|---|---|
| LA ↔ RA | I 誘導の P/QRS/T がすべて逆転；II と III が入れ替わり；aVR と aVL が入れ替わり | `P_I < 0 AND R_I < S_I AND corr(II_obs, III_ref) > 0.9` |
| RA ↔ LL | II 誘導が逆転；I と III が入れ替わりかつ逆転；aVR と aVF が入れ替わり | `net_area(II) < 0 AND P_II < 0` |
| LA ↔ LL | I と II が入れ替わり；III が逆転；aVL と aVF が入れ替わり | `corr(I_obs, II_ref) > 0.9 AND net_area(III) < 0` |
| RA ↔ RL(N) | II 誘導がほぼ平坦（振幅 < 100 μV） | `pp_amplitude(II) < 100 μV` |
| LL ↔ RL(N) | III 誘導がほぼ平坦 | `pp_amplitude(III) < 100 μV` |

<a id="442-胸导反接检测"></a>
#### 4.4.2 胸部誘導逆接検出

誘導間のパターン相互相関に基づく段階的分析：V1→V6 に対して、隣接する誘導の中央拍の相互相関係数系列 `c[k] = corr(Vk, Vk+1)` を計算します。正常状態では、この系列は滑らかであり、各項は 0.5 を超えます。もしどこかで顕著な極小値や段階的な逆転が生じた場合、その位置の誘導が入れ替わっていると特定します。

同時に R 波振幅の段階的変化を検証します：正常な V1→V6 では、R 振幅は V4–V5 まで単調に増加し、その後やや低下し、S 振幅は単調に減少します。段階的に非単調なジャンプが生じた場合は、疑わしいとマークします。

<a id="443-与右位心的鉴别关键"></a>
#### 4.4.3 右位心との鑑別（重要）

LA↔RA 逆接と右位心は、四肢誘導での所見が同じです（I 誘導がすべて逆転）。鑑別は胸部誘導で行います：

| | I 誘導 | 胸部誘導 R 波の段階的変化 |
|---|---|---|
| LA↔RA 逆接 | すべて逆転 | **正常な増加** |
| 右位心 | すべて逆転 | **V1→V6 で振幅が減少** |

判定式：
```
IF I导全倒置:
    IF R振幅(V6) < R振幅(V1) AND R振幅单调递减:
        → finding: DEXTROCARDIA
    ELSE:
        → finding: LEAD_SWAP_LA_RA
```

<a id="444-反接检出后的动作"></a>
#### 4.4.4 逆接続検出後の動作

**自動修正後は読み続けないでください。 ** 正しいアクションは次のとおりです。

1. 明確な逆接続警告ステートメントを出力し、レポートの先頭に配置します。
2. 後続の診断モジュールを終了するか、診断結果を出力せずに測定値のみを出力します。
3. 再取得を求めるプロンプト

理由：自動修正により収集動作の問題が隠蔽されるため、逆接続判定自体が間違っている場合、より大きなエラーが発生する可能性があります。

<a id="45-起搏信号预检"></a>
### 4.5 ペース信号の事前チェック

フィルタリングされていないブランチに対してクイック スキャンが実行されます。ペーシング パルスが検出された場合、L7 の M0 モジュールで使用するために `PACED_CANDIDATE` フラグが設定されます (8.5 および 10.1 を参照)。

<a id="5-l3-波形检测与定界"></a>
## 5. L3波形の検出と区切り

区切り精度はシステム全体の上限を決定します。測定が不正確な場合、その後のすべての基準は間違った値に基づいた正しい推論になります。

<a id="51-算法选型"></a>
### 5.1 アルゴリズムの選択

**二項ウェーブレット変換モジュラー最大値法** (Martínez らの古典的なスキーム) がメイン アルゴリズムとして使用され、Pan-Tompkins が `bSQI` および冗長性チェックの 2 番目の検出器として使用されます。

選択の理由: ウェーブレット法は当然ながらマルチスケールであり、同じフレームワーク内で QRS (高周波)、P/T (低周波) を処理でき、ベースライン ドリフトの影響を受けません。それは純粋に決定論的であり、トレーニングを必要としません。

<a id="52-小波配置"></a>
### 5.2 ウェーブレット構成

- ウェーブレット ベース: 2 次スプライン ウェーブレット。その一次微分特性により、波形の変曲点がモード最大値に対応し、波のピークがゼロクロス点に対応します。
- スケール: `2^1 … 2^5` (`fs = 250 Hz` に対して定義。`fs = 500 Hz` を使用する場合、全体のスケールを 1 スケール分上に移動します。つまり、`2^2 … 2^6` を使用します)
- 各スケールの主な用途:

|スケール (fs=500Hz) |主なエネルギー対応 |目的 |
|---|---|---|
| 2^2 | 40～125Hz |騒音評価、釘のペーシング |
| 2^3 | 20～60Hz | QRS 検出メインスケール |
| 2^4 | 10～30Hz | QRS 境界、QRS 内部構造 |
| 2^5 | 5～15Hz | T波、P波検出 |
| 2^6 | 2～8Hz | T 波境界 |

<a id="53-r-峰检测"></a>
### 5.3 R ピーク検出

```
1. 在尺度 2^3、2^4 上计算小波系数 W3、W4
2. 阈值 T = k × RMS(W3, 全段)，k 初值 = 0.35
3. 在 W3 上寻找超过 T 的模极大值
4. 配对：寻找"正极大 → 负极大"（或反向）且间隔 < 120 ms 的模极大值对
5. 该对之间的过零点 = R 峰位置
6. 在 W4 上验证同一位置存在对应模极大值对（跨尺度一致性）
7. 不应期：两个 R 峰间隔 < 200 ms 时，保留幅值大者
8. 漏搏回溯：若某 RR > 1.5 × 局部中位 RR，在该区间内以 0.5×T 重新搜索
9. 多导联融合：见 5.7
```

**パラメータ `k` の適応**：初回検出後、検出されたR波のピーク振幅の中央値を用いて `T = 0.4 × median(peak_amplitude)` を再設定し、再実行する。2回の結果が一致しない心拍は、低信頼度としてマークする。

<a id="54-qrs-起终点定界"></a>
### 5.4 QRS の開始・終了点の境界設定

各R波ピークについて、スケール 2^4 上で：

```
QRS 起点：从 R 峰对应的第一个模极大值向前搜索，
          至 |W4| 降到该极大值的 ξ_on 倍（ξ_on = 0.05）
          或出现符号相反的模极大值为止
QRS 终点：从最后一个模极大值向后搜索，
          至 |W4| 降到 ξ_off 倍（ξ_off = 0.10）
```

`ξ_off > ξ_on` は意図的に設計されています：QRS の終了点の直後に ST 区間が続き、閾値が低すぎると ST 区間の起始部が QRS に含まれてしまい、QRS の時間幅が系統的に長くなります。

<a id="55-t-波检测与定界"></a>
### 5.5 T 波の検出と境界決定

```
1. 搜索窗：QRS 终点后 [100 ms, min(0.7×RR, 600 ms)]
   （窗口右界随 RR 自适应，心动过速时必须收窄）
2. 在尺度 2^5、2^6 上寻找该窗内最大模极大值对
3. 过零点 = T 峰
4. T 波极性：由模极大值对的符号顺序判定
   正向 T：负极大 → 正极大（对应上升-下降）
   负向 T：正极大 → 负极大
   双向 T：窗内存在两组显著模极大值对
5. T 终点定界：优先用小波阈值法（|W| 降至峰值的 0.125 倍）
   备选用切线法：过 T 波下降支最大斜率点作切线，与等电位线交点
```

**T 終点は全工程中誤差が最大の測定項目**であり、QT および QTc を直接決定します。ウェーブレット法と接線法の両方を同時に実装し、両者の差異が 40 ms を超える場合は QT を低信頼度としてマークすることを推奨します。

<a id="56-p-波检测与定界"></a>
### 5.6 P 波の検出と境界決定

```
1. 搜索窗：QRS 起点前 [50 ms, min(0.35×RR, 250 ms)]
2. 在尺度 2^5、2^6 上寻找模极大值对，阈值取 QRS 阈值的 0.15 倍
3. 形态分类：正向 / 负向 / 双向（存在两组反向模极大值对）
4. 起终点定界方法同 T 波
```

<a id="561-未下传-p-波的补充搜索必需"></a>
#### 5.6.1 未下伝 P 波の補足検索（必須）

閾値法は高度房室ブロック時に、RR 間期中に孤立して出現する P 波を見逃すことがあります。二次検索を実装する必要があります：

```
FOR 每个 RR 间期:
    IF 该区间内已检出 P 波数 == 1 AND RR > 1.5 × median(RR):
        在该区间的非搜索窗区域，用 P 波模板做匹配搜索
        模板 = 该导联已确认 P 波的平均形态
        候选点须同时满足:
            (a) 时限 ≥ 60 ms
            (b) 振幅 > 5% × 相邻 QRS 振幅
            (c) 与模板极性一致（正/负/双向同类）
            (d) 与模板互相关系数 > 0.7
        → 标记为"未下传 P 波"
```

**このステップは、第2度II型および第3度房室ブロックを検出できるかどうかを決定する关键环节です。** このロジックを実装していないシステムは、第3度房室ブロックを交界性脱出リズムと誤判定します。

<a id="57-多导联融合规则"></a>
### 5.7 多導聯融合ルール

単一導聯の境界決定結果は、以下のルールによってグローバル基準点に合成されます：

| ルール | 内容 |
|---|---|
| 存在確認 | ある波が **≥ 4 個の利用可能導聯**で同一時刻（±20 ms）に検出された場合のみ、存在とみなす |
| グローバル開始点 | 全ての支持導聯の中で**最も早い**開始点を取る |
| グローバル終了点 | 全ての支持導聯の中で**最も遅い**終了点を取る |
| 時間幅計算 | グローバル終了点 − グローバル開始点 |

「最も早い開始点 / 最も遅い終了点」を採用することは国際的な標準的な手法であり、その理由は心電ベクトルが特定の導聯軸に対して垂直になり、偏転を生じない場合があるためです。**単一導聯で QRS の時間幅を測定すると、結果は系統的に 10–20 ms 短く見積もられます**、これにより束枝ブロックの見落としを直接引き起こします。

<a id="58-生理约束后处理"></a>
### 5.8 生理的制約による後処理

以下の制約を強制適用し、違反するものは除外します：

1. 1つの RR 間期内に T 波は最大1つ；複数の候補がある場合、`QT_expected = 0.4 × sqrt(RR)` に時間的に最も近いものを選択する
2. P 波は QRS と重ならないこと
3. QRS の時間幅は [40 ms, 250 ms] の範囲内であり、範囲外の場合は `UNRELIABLE` とマークする
4. PR 間隔は [80 ms, 500 ms] の範囲内であること
5. 隣接する心拍の QRS の開始点間の間隔は ≥ 200 ms であること

<a id="59-验收标准"></a>
### 5.9 受入基準

| 指標 | データセット | 目標 |
|---|---|---|
| QRS 検出感度 / 陽性予測値 | MIT-BIH 不整脈、NST | ≥ 99.5% / ≥ 99.5%（ANSI/AAMI EC57 プロトコルに基づく） |
| P 波境界誤差 | QT データベース、LUDB | 開始点/終了点の標準偏差 ≤ 10 ms |
| QRS 境界誤差 | 同上 | 標準偏差 ≤ 8 ms |
| T 終了点誤差 | 同上 | 標準偏差 ≤ 25 ms |

<a id="6-l4-心搏模板聚类与中位搏合成"></a>
## 6. L4 心拍テンプレートクラスタリングと中央値心拍の合成

### 6.1 目的

- 優位な心拍と異所性心拍を区別し、異所性心拍は形態学的測定に参加しない
- 中央値心拍を合成し、全ての振幅および時間幅測定の基準とする

<a id="62-模板聚类算法"></a>
### 6.2 テンプレートクラスタリングアルゴリズム

```
1. 对齐：以 R 峰为基准，截取窗口 [-250 ms, +450 ms]
   （窗口须覆盖 P 波起点到 T 波终点）
2. 参与聚类的导联：选择 R 波振幅最大的 3 个导联，拼接为特征向量
3. 逐拍与已有模板计算 Pearson 相关系数：
       IF max(corr) ≥ 0.90:  归入该模板类，更新模板（滑动平均）
       ELSE:                 新建模板类
4. 类合并：若两模板互相关 ≥ 0.95，合并
5. 主导类 = 成员数最多的类
```

相関係数の閾値0.90は経験値であり、検証セット上で標定する必要があります。閾値が高すぎると、ノイズによる形態の揺らぎが複数のクラスに分割され、低すぎると期外収縮が主要クラスに統合されてしまいます。

<a id="63-心搏类型判定规则"></a>
### 6.3 心拍タイプの判定（ルール）

各テンプレートクラスについて：

| タイプ | 判定条件 |
|---|---|
| 主要型（N） | メンバー数が最も多いクラス |
| 室性期外収縮（V） | QRS 時間幅 > 120 ms **かつ** 主要テンプレートとの相関係数 < 0.80 **かつ** 先行する関連P波がない **かつ** 連律間期 < 0.85 × 中央値RR |
| 室上性期外収縮（S） | QRS 時間幅 ≤ 120 ms **かつ** 主要テンプレートとの相関係数 ≥ 0.80 **かつ** 形態異常を伴う先行P'波がある **かつ** 連律間期 < 0.85 × 中央値RR |
| 融合波（F） | 連律間期が室性と主要型の間にあり、形態も両者の中間（2つのテンプレートとの相関係数がともに0.75–0.90） |
| ペースメーカ拍動（P） | ペースメーカスパイクを検出し、スパイク後40 ms以内にQRSが出現 |
| エスケープ拍動 | 連律間期 > 1.15 × 中央値RR（**早期**ではなく、**遅延**） |

**連律間期と補償間歇の判定**：
- 完全補償間歇：`RR(前) + RR(后) ≈ 2 × 基础 RR`（許容誤差 ±60 ms）→ 室性を支持
- 不完全補償間歇：`RR(前) + RR(后) < 2 × 基础 RR − 60 ms` → 房性を支持

<a id="64-中位搏合成"></a>
### 6.4 中央値拍動の合成

```
1. 取主导类全部成员，按 QRS 起点对齐（不是 R 峰对齐 —— R 峰位置受形态影响）
   实际做法：先按 R 峰粗对齐，再用互相关做 ±10 ms 精对齐
2. 逐导联、逐采样点取中位数（不是均值 —— 中位数对异常点鲁棒）
3. 若主导类成员数 < 3，不合成中位搏，直接使用形态最典型的单拍，
   并设置标志 MEDIAN_BEAT_WEAK
```

<a id="65-等电位线基准"></a>
### 6.5 等電位線基準

**すべての振幅測定におけるゼロ基準は、PRセグメントとして統一して定義しなければならない**（P波終点から QRS 起点までの中間付近の20 msウィンドウの平均値）。

P波が識別できない場合（心房細動など）は、TPセグメントの使用にフォールバックする。TPセグメントも識別できない場合（頻脈）は、QRS 起点の直前20 msウィンドウを使用し、ST測定を低信頼度としてマークする。

**これは実装で非常にエラーが発生しやすいポイントである。** 基準の違いによりSTレベルに数十μVの差が生じ、STEMI判定に直接影響する。設定内で基準戦略を明示的に宣言し、レポートで確認可能にしなければならない。

<a id="66-形态复杂度门控"></a>
### 6.6 形態複雑度ゲート

```
IF 主导类成员占比 < 30%  OR  模板类数 > 5:
    设置标志 MORPH_COMPLEX
    → 所有基于中位搏的形态学判据（肥大、缺血、束支阻滞）置 UNKNOWN
    → 仅输出节律相关结论
```

<a id="7-l5-特征量化-特征字典"></a>
## 7. L5 特徴量量化 —— 特徴量辞書

本章は実装チェックリストです。各項目について、コードに対応する実装と単体テストが必要です。

<a id="71-全局时间参数"></a>
### 7.1 グローバル時間パラメータ

| ID | 名称 | 単位 | 計算方法 | 依存関係 |
|---|---|---|---|---|
| `HR_mean` | 平均心拍数 | bpm | `60000 / mean(RR)`、優勢拍間の RR 間期のみを計測 | L3 |
| `HR_min` / `HR_max` | 最小/最大心拍数 | bpm | 3 拍の移動窓に基づく | L3 |
| `RR[]` | RR 間期系列 | ms | 拍ごとの計算 | L3 |
| `P_dur` | P 波時間 | ms | 多誘導融合（5.7）| L3 |
| `PR_int` | PR 間期 | ms | P 波のグローバル開始点 → QRS のグローバル開始点 | L3 |
| `QRS_dur` | QRS 時間 | ms | 多誘導融合 | L3 |
| `QT_int` | QT 間期 | ms | QRS のグローバル開始点 → T 波のグローバル終了点、中央値拍を使用 | L4 |
| `QTcB` | Bazett 補正 QT | ms | `QT / sqrt(RR/1000)` | `QT_int`, `RR` |
| `QTcFri` | Fridericia 補正 | ms | `QT / (RR/1000)^(1/3)` | 同上 |
| `QTcFra` | Framingham 補正 | ms | `QT + 154 × (1 − RR/1000)` | 同上 |
| `QTcHod` | Hodges 補正 | ms | `QT + 1.75 × (HR − 60)` | 同上 |

**4 種類の QTc をすべて計算し、すべて出力する。** 臨床閾値は Bazett に基づいて設定されるが、Bazett は心拍数（HR）が < 60 或 > 100 の場合、歪みが顕著になる。レポートの主要値には Bazett を使用し、同時に Fridericia を参考値として提示する。HR が [50, 100] の範囲外の場合、レポートに「この心拍数では Bazett 補正の信頼性が低下します」と注記する。

<a id="72-电轴与空间特征"></a>
### 7.2 電気軸と空間特徴量

| ID | 名称 | 単位 | 計算方法 |
|---|---|---|---|
| `P_axis` | P 波の額面電気軸 | ° | I、aVF 誘導の P 波**正味面積**（振幅ではない）に基づく |
| `QRS_axis` | QRS の額面電気軸 | ° | I、aVF 誘導の QRS **正味面積**に基づく |
| `T_axis` | T 波の額面電気軸 | ° | I、aVF 誘導の T 波正味面積に基づく |
| `QRST_angle_f` | 額面 QRS-T 交角 | ° | `\|QRS_axis − T_axis\|`、[0, 180] の範囲に正規化 |
| `transition_zone` | 胸誘導移行領域 | — | R/S = 1 となる誘導位置、小数点を含む場合あり（例：V3.5） |

電気軸の計算式（QRS を例として）：
```
A_I   = 中位搏 I 导 QRS 区间的净面积（正面积 − 负面积）
A_aVF = 中位搏 aVF 导 QRS 区间的净面积
QRS_axis = atan2(A_aVF, A_I) × 180 / π   # 结果落在 [-180, 180]
```

**必ずR−S振幅差ではなく、正味の面積を用いること。** 振幅法は多相性QRS（rSR'、qRs）において最大30°の誤差を生じ、枝ブロックの誤判定を招く。

電気軸の区分：

| 範囲 | 判定 |
|---|---|
| −30° ~ +90° | 正常 |
| −30° ~ −90° | 電気軸左偏 |
| +90° ~ +180° | 電気軸右偏 |
| −90° ~ −180° | 電気軸極度偏移（「無人地帯」） |

<a id="731-qrs-形态编码规则"></a>
#### 7.3.1 QRS 形態コード規則

波の順序と相対的な大きさに基づいてコード化する。大文字は振幅 ≥ 500 μV、小文字は < 500 μVを示す：

```
Q/q : QRS 起始的负向波（其前无正向波）
R/r : 正向波
S/s : R 波之后的负向波
R'/r', S'/s' : 第二组正负向波
QS  : 全负向、无任何正向成分
```
サンプルコード：`qR`、`rS`、`RS`、`rSR'`、`QS`、`Rs`、`qRs`、`rsR's'`

判定順序：まず波の分割を行い（等電位線を超えることを境界とし、かつ個々の波の振幅が 50 μV を超えるもののみをカウント対象とする）、その後上記のルールに従って命名する。

## 8. L6 発見層

発見層は、連続的な測定値を証拠付きのセマンティック項目に離散化します。**L7 のルールは finding のみを消費することを許可し、L5 の数値を直接読み取ることは許可されていません。**

<a id="81-数据结构"></a>
### 8.1 データ構造

```
Finding {
    id:        string          # 如 "PR_PROLONGED"
    value:     TRUE|FALSE|UNKNOWN
    grade:     optional enum   # 如 MILD / MODERATE / SEVERE
    evidence:  [ { lead, metric, measured, threshold, clause } ]
    confidence: HIGH|MEDIUM|LOW
}
```

`confidence` のダウングレードルール：
- 測定値が閾値 ±10% の範囲内にある → MEDIUM にダウングレード
- 依存する誘導の SQI が境界値にある → 1段階ダウングレード
- デバイスのフィルタメタデータが歪みの可能性を示唆している（2.5節参照） → 1段階ダウングレード
- `MEDIAN_BEAT_WEAK` → すべての形態学的所見を LOW にダウングレード

## 9. L7の実行順序とゲート制御DAG

<a id="91-为什么必须有执行顺序"></a>
### 9.1 実行順序が必要な理由

ルールシステムで最も一般的なアーキテクチャ上の誤りは、N個の診断をN個の独立した二値判定として実装することである。実際には診断間に強い依存関係が存在し、特定の診断が成立すると**他の診断の基準となる判据が完全に無効化される**場合がある。例えば、左束枝ブロック（LBBB）が存在する場合、通常のSTセグメント偏移の判据は虚血の判定に使用できず、Sgarbossa判据に切り替える必要がある。

したがって、L7は固定されたトポロジカル順序で実行する必要があり、上流の結果を下流のゲート制御条件として使用する。

<a id="93-m2-先于-m1-的理由"></a>
### 9.3 M2 が M1 より先に実行される理由

M2（心室内伝導）は M1（リズム）よりも先に実行されます。その理由は、広 QRS 頻脈の鑑別には、基礎状態における束枝ブロックの形態を知る必要があるためです。

**ただし、循環依存関係が存在します**：記録全体が広 QRS 頻脈である場合、M2 が解析できる上室性心拍は存在しません。対応方法：

```
IF 主导型心搏均为宽 QRS AND HR > 100:
    跳过 M2 的束支阻滞判定
    直接进入 M1 的宽 QRS 心动过速鉴别流程
    M3、M4 全部关闭
```

凡例：✓ 実行 ｜ ✗ 無効（`FALSE` ではなく `UNKNOWN` を出力）｜ ダウングレード = 実行するが信頼度を1段階低下 ｜ 部分的 = 一部の基準のみ利用可能

### 10.2 M2 —— 心室内伝導

<a id="1021-心室预激wpw-型"></a>
#### 10.2.1 心室前興奮（WPW型）

**すべて**を満たす必要がある：

| # | 条件 |
|---|---|
| 1 | `PR_int < 120 ms` |
| 2 | `QRS_dur ≥ 110 ms` |
| 3 | `DELTA_WAVE`：QRS の開始40–60 ms区間の平均勾配が、後続の QRS 区間の平均勾配の50%未満であり、かつこの鈍頭が ≥ 2 誘導で観察される |
| 4 | 二次的 ST-T 変化が存在（ST-T の方向が QRS の終末ベクトルと反対） |

成立時は「心室前興奮」を出力し、**M3およびM4の全基準を強制無効化**し、報告書に「前興奮パターン、心筋梗塞および心室肥大の評価不可」と記載する。

<a id="1022-完全性左束支阻滞lbbb"></a>
#### 10.2.2 完全性左束枝ブロック（LBBB）

| # | 条件 |
|---|---|
| 1 | `QRS_dur ≥ 120 ms` |
| 2 | `V1_QS_OR_rS`：V1、V2でQSまたはrS（r波振幅 < 200 μV） |
| 3 | I、aVL、V5、V6で広大で単相性のR波を示し、かつ ≥ 2 誘導で中切欠または鈍頭（`LATERAL_NOTCHED_R`）を有する |
| 4 | `NO_Q_LATERAL`：I、V5、V6にq波なし（aVLでは狭いq波の存在を許容） |
| 5 | `VAT_LATERAL_LONG`：V5またはV6のR波ピーク時間 > 60 ms |
| 6 | ST-T と QRS の主波方向が反対 |

条件1–5をすべて満たす → 「完全性左束枝ブロック」（HIGH）
条件1–4を満たし、第5項が `UNKNOWN` の場合 → 出力するがMEDIUMに低下

**厳格基準（Strauss、設定が有効な場合のみ追加記述を出力）**：
- `QRS_dur ≥ 140 ms`（男性）/ `≥ 130 ms`（女性）
- V1、V2でQSまたはrS
- I、aVL、V1、V2、V5、V6のうち ≥ 2 誘導で QRS の中切欠または鈍頭を呈する

この基準は心臓再同期治療の候補者選別用であり、感度は通常基準より低いが特異度が高い。

<a id="1023-完全性右束支阻滞rbbb"></a>
#### 10.2.3 完全性右束枝ブロック（RBBB）

| # | 条件 |
|---|---|
| 1 | `QRS_dur ≥ 120 ms` |
| 2 | `V1_RSR_PATTERN`：V1またはV2でrsr'、rsR'、rSR'を呈し、通常 R' > r |
| 3 | `WIDE_S_LATERAL`：IおよびV6に広いS波が存在（時間 > 40 ms かつ S波時間 > R波時間） |
| 4 | `VAT[V1] > 50 ms` |

条件1、2、3は必須；条件4は支持的要因。

<a id="1024-不完全性束支阻滞"></a>
#### 10.2.4 不完全性束枝ブロック

`QRS_BORDERLINE`（110–119 ms）かつ形態学的条件を満たす → 「不完全性左/右束枝ブロック」を出力。

<a id="1025-左前分支阻滞lafb"></a>
#### 10.2.5 左前枝ブロック（LAFB）

| # | 条件 |
|---|---|
| 1 | `QRS_axis ∈ [−90°, −45°]` |
| 2 | aVLでqRを呈する |
| 3 | `VAT[aVL] ≥ 45 ms` |
| 4 | II、III、aVFでrSを呈する |
| 5 | `QRS_dur < 120 ms`（RBBBを合併しない限り） |

**除外条件**（いずれかが成立すると出力しない）：下壁心筋梗塞、心室前興奮、心室肥大による電気軸左偏。

<a id="1026-左后分支阻滞lpfb"></a>
#### 10.2.6 左後枝ブロック（LPFB）

| # | 条件 |
|---|---|
| 1 | `QRS_axis ∈ [+90°, +180°]` |
| 2 | I、aVLでrSを呈する |
| 3 | II、III、aVFでqRを呈する |
| 4 | `QRS_dur < 120 ms` |

**除外条件**：右心室肥大、側壁心筋梗塞、慢性肺疾患、細長い体型（体型情報は通常入手不可）。

<a id="1027-非特异性室内传导延迟ivcd"></a>
#### 10.2.7 非特異的室内伝導遅延（IVCD）

<a id="103-m3-心房异常与心室肥大"></a>
### 10.3 M3 —— 心房異常および心室肥大

<a id="1031-心房异常"></a>
#### 10.3.1 心房異常

| 記述 | 条件（いずれかを満たす） |
|---|---|
| 左房異常 | `P_dur[II] ≥ 120 ms`；または `PTFV1 ≥ 0.04 mm·s`（V1の負性成分の深さ ≥ 100 μV かつ時間 ≥ 40 ms） |
| 右房異常 | `P_amp[II] ≥ 250 μV`；または V1のP波開始正性成分 ≥ 150 μV |
| 双房異常 | 上記両者が同時に成立 |

ゲート：`P_ABSENT` が TRUE（心房細動など）の場合、すべてを `UNKNOWN` に設定。

<a id="1032-左心室肥大-多判据并行评估"></a>
#### 10.3.2 左心室肥大 —— 複数基準の並列評価

**全基準を並列計算して統合し、単一基準のみを使用してはならない。** AHA/ACCF/HRSは、各基準の感度は一般的に50%未満、特異度は約85%–90%であり、基準間の差異が顕著であることを明確に示している。軽中度高血圧患者の大規模群において、Cornell電圧基準とSokolow-Lyon基準の両方を満たすLVH患者は約11%に過ぎない。

| 基準 | 閾値 |
|---|---|
| Sokolow-Lyon | `S_amp[V1] + max(R_amp[V5], R_amp[V6]) ≥ 3500 μV` |
| Cornell電圧 | `R_amp[aVL] + S_amp[V3] > 2800 μV`（男性）/ `> 2000 μV`（女性） |
| Cornell積 | `(R_amp[aVL] + S_amp[V3] + 女性?600:0) × QRS_dur > 244000 μV·ms` |
| Peguero-Lo Presti | `max(全导联最深 S) + S_amp[V4] ≥ 2300 μV`（男性）/ `≥ 1900 μV`（女性） |
| Romhilt-Estes | 10.3.3参照、≥ 5点 |
| aVL 単導 | `R_amp[aVL] ≥ 1100 μV` |
| 肢導電圧 | いずれかの肢導 `QRS_amp_pp ≥ 2000 μV` |

**融合ルール**：

```
n = 阳性判据数量
strain = 存在继发性 ST-T 改变（见下）

IF Romhilt_Estes ≥ 5 OR n ≥ 2:
    → "左心室肥大"                    confidence = HIGH
ELIF n == 1 AND strain:
    → "左心室肥大"                    confidence = MEDIUM
ELIF n == 1:
    → "左心室高电压"（不下肥大结论）   confidence = MEDIUM
ELIF Romhilt_Estes == 4:
    → "可能左心室肥大"                confidence = LOW
ELSE:
    → FALSE
```

**二次性 ST-T 変化（「負荷」型）の判定式**：R 波が優勢な誘導（V5、V6、I、aVL）において、`ST_J < −50 μV` かつ ST 低下が下傾型（`ST_slope < 0`）かつ T 波が非対称性の逆転（`T_amp < 0` かつ `T_symmetry < 0.8`）を示す。

<a id="1033-romhilt-estes-积分表"></a>
#### 10.3.3 Romhilt-Estes 積分表

| 項目 | 点数 |
|---|---|
| 任意の肢誘導で R または S の振幅 ≥ 2000 μV、または `S_amp[V1或V2] ≥ 3000 μV`、または `R_amp[V5或V6] ≥ 3000 μV` | 3 |
| 二次性 ST-T 変化、ジギタリス系薬物**未**使用 | 3 |
| 二次性 ST-T 変化、ジギタリス系薬物使用 | 1 |
| 左心房異常（`PTFV1 ≥ 0.04 mm·s`） | 3 |
| 電気軸左偏 ≤ −30° | 2 |
| `QRS_dur ≥ 90 ms` | 1 |
| `VAT[V5或V6] ≥ 50 ms` | 1 |

≥ 5 点：左心室肥大 ｜ 4 点：左心室肥大の可能性あり

注：ジギタリス系薬物の使用情報は通常入手できない。実装時はこのフィールドをオプション入力とし、欠落時は「未使用」として採点し、エビデンスチェーンでこの仮定を明記する。

<a id="1034-门控关键"></a>
#### 10.3.4 ゲーティング（重要）

| 上流状態 | 処理 |
|---|---|
| LBBB | LVH 関連の結論を出力する**禁止**。AHA の立場では、LBBB が存在する場合は LVH の診断を試みるべきではない。出力は「左束枝ブロックが存在し、心室肥大の評価は不可能」 |
| RBBB | RBBB 専用判定基準セットに切り替え：`S_amp[V1] > 200 μV`、`R_amp[V5或V6] > 1500 μV`、`QRS_axis < −30°`。この基準セットの感度は約 46%–68%、特異度は約 57%–71% であるため、信頼度を強制的に LOW に下げ、表現は「可能性あり」とする |
| 心室ペーシング | 出力禁止 |
| 前興奮症候群 | 出力禁止 |

#### 10.3.5 右心室肥大

| # | 条件 |
|---|---|
| 1 | `RS_ratio[V1] > 1` かつ `R_amp[V1] ≥ 700 μV` |
| 2 | `R_amp[V1] + max(S_amp[V5], S_amp[V6]) ≥ 1050 μV` |
| 3 | `QRS_axis > +90°`（厳格：`≥ +110°`） |
| 4 | `RS_ratio[V5或V6] ≤ 1` |
| 5 | V1–V3 に二次性 ST-T 変化が存在 |

≥ 2 項目該当 → 「右心室肥大」（MEDIUM）；≥ 3 項目 → HIGH

**除外条件**：後壁心筋梗塞（V1 の高 R 波を惹起しうる）、RBBB、B 型前興奮症候群、右位心、誘導の逆接続。いずれかが成立する場合は `UNKNOWN` を設定する。

<a id="104-m4-缺血与心肌梗死"></a>
### 10.4 M4 —— 虚血と心筋梗塞

<a id="1041-导联解剖分组与相邻关系"></a>
#### 10.4.1 誘導の解剖学的グループ化と隣接関係

```
下壁    : II, III, aVF
前间壁  : V1, V2
前壁    : V3, V4
前侧壁  : V5, V6
高侧壁  : I, aVL
后壁    : 由 V1–V3 镜像推断（或 V7–V9 直接记录）
右室    : V3R, V4R（需额外导联）
```

「隣接する2つの誘導」の定義：
- 胸誘導の隣接チェーン：`V1–V2–V3–V4–V5–V6`
- 肢誘導の隣接チェーン（Cabrera 順序）：`aVL – I – (−aVR) – II – aVF – III`

**実装上の注意**：III と aVF は隣接し、aVF と II は隣接するが、III と II は**隣接しない**。誘導が心電図纸上に並んでいる順序で隣接を判断するのは誤りである。

<a id="1042-st-段抬高阈值表"></a>
#### 10.4.2 ST 上昇閾値表

第4版の心筋梗塞の普遍的定義に基づき、測定点は **J 点**（`ST_J`）であり、**隣接する2つの誘導が同時に**以下の条件を満たす必要がある：

| 誘導 | 性別/年齢 | 閾値 |
|---|---|---|
| V2, V3 | 男性 ≥ 40 歳 | ≥ 200 μV |
| V2, V3 | 男性 < 40 歳 | ≥ 250 μV |
| V2, V3 | 女性（年齢不問） | ≥ 150 μV |
| その他の標準誘導 | 年齢不問 | ≥ 100 μV |
| V3R, V4R | 男性 < 30 歳 | ≥ 100 μV |
| V3R, V4R | その他 | ≥ 50 μV |
| V7–V9 | 年齢不問 | ≥ 50 μV |

年齢または性別が欠損している場合、V2/V3 の判定は `UNKNOWN` とする（2.2 戦略選択を参照）。

<a id="1043-st-段压低与-t-波倒置"></a>
#### 10.4.3 ST 低下と T 波逆転

| 項目 | 閾値 |
|---|---|
| ST 低下 | 隣接する2つの誘導で `ST_J ≤ −50 μV` であり、かつ ST が水平型または下降型（`ST_slope ≤ 0`）であること |
| T 波逆転 | 隣接する2つの誘導で `T_amp ≤ −100 μV` であり、かつ当該誘導で `RS_ratio > 1` であること |

上昇型の ST 低下はカウントしない（生理的に多く見られ、特に頻脈時に顕著）。

<a id="1044-高危形态学模板"></a>
#### 10.4.4 高リスク形態学テンプレート

以下のテンプレートは、典型的な閾値基準では見逃されやすい急性冠動脈閉塞の所見を識別するために使用される。**ルールベースの実装では感度に限界があり、すべてを「示唆」レベルとして出力し、人的な再確認を必須とするフラグを設定する。**

**(a) de Winter 型**
```
count over V1..V6 where:
    ST_J[l] ∈ [−300, −100] μV
    AND ST_slope[l] > 1.0 μV/ms   (上斜型)
    AND T_amp[l] > 500 μV          (高尖)
    AND T_symmetry[l] ∈ [0.8, 1.2] (对称)
≥ 4
AND ST_J[aVR] ≥ 0
→ "提示前降支近段闭塞（de Winter 型改变）"
```

**(b) ウェルレンズ B 型**
```
T_amp[V2..V4] ≤ −200 μV （≥2 个导联）
AND T_symmetry ∈ [0.85, 1.15]
AND R_amp[V3] > 300 μV        (R 波保留)
AND ST_J[V2..V4] < 100 μV     (无显著抬高)
AND NOT PATHOLOGIC_Q[前壁]
→ "提示前降支近段严重狭窄（Wellens 型改变）"
```

**(c) Wellens A 型**：V2–V4 の `T_morph` が双方向（まず正、次に負）であり、その他は上記と同じ。

**(d) 左主幹 / 三枝病変型**
```
ST_J[aVR] ≥ 100 μV
AND count(全导联 ST_J ≤ −100 μV) ≥ 6
AND ST_J[aVR] > ST_J[V1]
→ "提示左主干或三支病变，广泛心内膜下缺血"
```

**(e) 後壁心筋梗塞**
```
count(V1..V3 where ST_J ≤ −50 μV) ≥ 2
AND RS_ratio[V2] > 1
AND R_dur[V2] ≥ 40 ms
AND T_amp[V2] > 0
→ "提示后壁心肌梗死，建议加做 V7–V9"
```

**(f) 終末 QRS 変形**：ST 上昇を示す誘導において、QRS 終末に S 波も J 点のノッチも存在しない → 急性完全閉塞を提示し、優先度を高める。

<a id="1045-lbbb-或心室起搏下的急性心肌梗死判定"></a>
#### 10.4.5 LBBB または心室ペーシング下における急性心筋梗塞の判定

通常の ST 判定基準は、LBBB および心室ペーシング下では完全に機能しなくなる（二次性 ST-T 変化自体が著しい偏移として現れるため）。この場合、Sgarbossa ルートに切り替える。

**原始 Sgarbossa スコア**

| 条件 | 点数 |
|---|---|
| QRS 主波と**同方向**の ST 上昇 ≥ 100 μV（≥ 1 誘導） | 5 |
| V1–V3 において、QRS 主波と**同方向**の ST 低下 ≥ 100 μV | 3 |
| QRS 主波と**異方向**の ST 上昇 ≥ 500 μV | 2 |

合計点 ≥ 3 → 急性心筋梗塞を提示（特異度が高く、感度は低い）

**改良 Smith 基準（併用実装を推奨）**

第3項目を比基準に置き換える：
```
对每个不一致导联 l（ST 抬高方向与 QRS 主波方向相反）:
    ratio = ST_J[l] / S_amp[l]        # 两者符号相反，比值为负
    IF ratio ≤ −0.25:  阳性
```
すなわち、ST 上昇の振幅が、当該誘導の S 波の深さの 25% 以上である。この基準の感度は、元の第3条に比べて著しく優れている。

第1条および第2条は変更なし。いずれか1条が陽性であれば、ヒントを出力する。

<a id="105-病理性-q-波与心肌梗死定位"></a>
### 10.5 病的 Q 波と心筋梗塞の部位診断

<a id="1051-病理性-q-波判定"></a>
#### 10.5.1 病的 Q 波の判定

| 誘導 | 条件 |
|---|---|
| V2, V3 | いかなる `Q_dur ≥ 20 ms` でも可、または QS 型を示す場合 |
| I, II, aVL, aVF, V4, V5, V6 | **隣接する2誘導**で `Q_dur ≥ 30 ms` かつ `Q_amp ≥ 100 μV`、または QS 型を示す場合 |
| V1, V2（後壁相当） | `R_dur ≥ 40 ms` かつ `RS_ratio ≥ 1` かつ T 波が直立している場合 |

**aVR は病的 Q 波の判定には含まれない**（aVR は正常でも QS 型を示し得る）。
**III 誘導単独の Q 波では判定不十分**であり、II または aVF の併存が必要である。

<a id="1052-排除条件"></a>
#### 10.5.2 除外条件

以下のいずれかが成立する場合、すべての病的 Q 波判定を `UNKNOWN` とする：

- 完全左束枝ブロック
- 心室早期興奮症候群
- 心室ペーシング
- 左心室肥大（V1–V3 で QS 型を示し得る）
- 右位心 / 誘導の逆接続
- `MORPH_COMPLEX`

<a id="1053-定位与分期"></a>
#### 10.5.3 部位診断と病期分類

| 領域 | 誘導 |
|---|---|
| 前間壁 | V1, V2 |
| 前壁 | V3, V4 |
| 前側壁 | V5, V6 |
| 高側壁 | I, aVL |
| 広範前壁 | V1–V6（+ I, aVL） |
| 下壁 | II, III, aVF |
| 後壁 | V1–V3 の鏡像変化 |

病期分類のルール（単一の心電図のみに基づくものであり、信頼性は限定的）：

```
IF 病理性Q波 AND 该区域 ST 抬高:
    → "心肌梗死，急性期改变"（优先级：急症）
ELIF 病理性Q波 AND 该区域 T 波倒置 AND 无 ST 抬高:
    → "心肌梗死，演变期改变"
ELIF 病理性Q波 AND ST-T 正常:
    → "陈旧性心肌梗死（或既往梗死）"
```

**必須記載**：「心電図では梗塞の時期を確実に判定できず、病期分類の結論は臨床所見および既往心電図との対照を踏まえて行う必要がある。」

<a id="106-m1-节律与房室传导"></a>
### 10.6 M1 —— 律動と房室伝導

<a id="1061-基础节律决策树"></a>
#### 10.6.1 基礎律動の意思決定ツリー

```
1. 起搏搏动占比 > 80% ?
      → 起搏心律（分型见 10.1），结束

2. 心房活动分类:
   a) P 波均一、P_axis ∈ [0°, 75°]、每 P 后有 QRS、PR 恒定
        → 窦性来源
   b) P 波形态异常但均一、心房率 100–250、规整
        → 房性心动过速
   c) ≥ 3 种 P 形态 + RR 不齐 + HR > 100
        → 多源性房性心动过速
   d) F_WAVE_PRESENT（心房率 240–340、规整锯齿）
        → 心房扑动
   e) P_ABSENT + RR_IRREGULAR_ABSOLUTE + f 波谱宽平
        → 心房颤动
   f) P 波倒置于 II/III/aVF 且 PR < 120 ms，或 P 缺如而 QRS 窄
        → 交界性来源

3. 窦性来源者按心率细分:
      HR < 60  → 窦性心动过缓
      HR > 100 → 窦性心动过速
      RR 变异 > 120 ms 且呈周期性 → 窦性心律不齐
      否则 → 窦性心律

4. 交界性/室性来源者按心率细分:
      交界性: 40–60 逸搏心律 / 60–100 加速性 / >100 交界性心动过速
      室性:   20–40 逸搏心律 / 40–100 加速性室性自主心律 / >100 室性心动过速
```

<a id="1062-心房颤动的三重证据要求"></a>
#### 10.6.2 心房細動の三重証拠要件

**RR不整のみで心房細動を判定すると、頻発心房期外収縮時に多数の偽陽性が生じる。** 以下の3条件を同時に満たす必要がある：

| # | 条件 |
|---|---|
| 1 | `RR_IRREGULAR_ABSOLUTE`：`RR_CV > 0.15` かつ `RR_entropy > T_ent` かつ `SD1/SD2 > 0.4` |
| 2 | `P_ABSENT`：判別可能なP波の割合 < 20%（II誘導、V1誘導で評価） |
| 3 | f波スペクトル形状：3–9 Hz以内に鋭い主ピークがない（`f_wave_regularity < 3`）；TQ間隔が短すぎる場合はこの項目を`UNKNOWN`に設定 |

第3項目が`UNKNOWN`の場合、1および2が成立していれば出力可能だが、信頼度はMEDIUMに低下する。

**頻発心房期外収縮との鑑別**：心房期外収縮の二聯律/三聯律では、Poincaréプロットが多群集を呈する（`SD1/SD2`が低い）のに対し、心房細動では単一の拡散した雲状パターンを示す。この特徴は両者を区別する最も効果的な手段であり、実装が必須である。

<a id="1063-心房扑动"></a>
#### 10.6.3 心房粗動

```
F_WAVE_PRESENT
AND 心房率 ∈ [240, 340] 次/分
AND 锯齿波在 II、III、aVF 或 V1 可辨
→ 心房扑动
   传导比 = 心房率 / 心室率，四舍五入至整数或标注"不等比传导"
```

**強制トリガー規則**：心室率が 140–160 の範囲にある整った狭い QRS 頻脈では、心房細動チェックブランチ（2:1 伝導の心房細動は誤って洞性頻脈と判断されやすい）の実行を強制する必要があります。F 波が検出されない場合でも、報告書には「心室率が 150 に近く、2:1 伝導の心房細動を除外する必要がある」と記載する必要があります。

<a id="1064-异位搏动"></a>
#### 10.6.4 異所性拍動

| 記述 | 条件 |
|---|---|
| 室性期外収縮 | 拍動タイプが V（6.3 参照）、数に応じて出力：偶発（< 1%）/ 頻発（≥ 1%）/ 対発 / 二連律 / 三連律 |
| 房性期外収縮 | 拍動タイプが S |
| 多源性室性期外収縮 | 形態が異なる V 型テンプレートが ≥ 2 種類存在する |
| 非持続性室性頻脈 | 連続する V 型拍動 ≥ 3 かつ < 30 s，率 > 100 |
| 逸脱拍動 | 連律間期 > 1.15 × 中央値 RR |

連律パターンの判定：二連律 = 各優勢型拍動の後に異所性拍動が続き、≥ 3 回繰り返される。

<a id="1065-房室传导阻滞"></a>
#### 10.6.5 房室ブロック

判定前提：識別可能な P 波系列が存在する（`P_presence_ratio > 0.5`）。心房細動時はすべて `UNKNOWN` に設定。

| 度 | 判定式 |
|---|---|
| 一度 | `PR_int > 200 ms` かつすべての P 波が伝導される |
| 二度 I 型（文氏） | 伝導されない P 波が存在；脱落前の PR 間期が漸進的に延長（総増加量 > 40 ms）；脱落後の最初の PR 間期が脱落前の最後の PR 間期より ≥ 30 ms 短い；RR 間期が漸進的に短縮 |
| 二度 II 型 | 伝導されない P 波が存在；脱落前後の PR 間期が一定（SD < 10 ms） |
| 2:1 房室ブロック | ちょうど 2 つの P 波につき 1 つが伝導され、**I 型と II 型を区別できない** |
| 高度房室ブロック | ≥ 2 つの連続する P 波が伝導されないが、伝導される拍動が存在 |
| 三度（完全性） | `AV_DISSOCIATION` かつ心房率 > 心室率 かつ PP および RR がそれぞれ整っている |

**2:1 ブロックは単独のカテゴリとして出力する必要があり**、I 型または II 型に強制的に分類してはなりません。報告の表現：「2:1 房室ブロック、本図ではモリス I 型と II 型を区別できません」。

**三度ブロックの必要条件は房室分離 + 心房率が心室率より速いこと**です。房室分離のみで心室率が心房率より速い場合は、干渉性房室分離（加速性房室結節リズムなど）であり、三度ブロックではありません。これは一般的な誤判断のポイントです。

<a id="1066-宽-qrs-心动过速鉴别"></a>
#### 10.6.6 広い QRS 頻脈の鑑別

進入条件：`QRS_dur ≥ 120 ms` かつ `HR > 100` かつ ≥ 3 拍持続。

Brugada 4 段階法に従って順に判定し、いずれかの段階で「はい」の場合、室性頻脈と判定します：

| 段階 | 判定 |
|---|---|
| 1 | V1–V6 のすべての誘導で RS 形態がないか？ |
| 2 | いずれかの胸誘導の RS 間期（R 波の開始点 → S 波の最低点）> 100 ms か？ |
| 3 | 房室分離（`AV_DISSOCIATION`）、融合波、または心室奪取が存在するか？ |
| 4 | V1/V2 と V6 の形態が室性基準に合致するか？ |

4 段階すべてが「いいえ」→ 室内差別的伝導を伴う室上性頻脈。

**室速を支持する追加証拠**（信頼度を高めるために使用）：胸誘導の同方向性（V1–V6 QRS 主波の方向が一致）、電気軸が `AXIS_EXTREME`（無人地帯）に位置する。

**安全戦略（強制）**：
```
IF 宽QRS心动过速:
    无论四步法结论如何，均设置 CRITICAL 标志与强制人工复核
    IF 四步法结论为 SVT:
        措辞 = "宽 QRS 心动过速，形态学倾向室上性伴差异传导，
                但不能排除室性心动过速，建议立即人工判读"
```

理由：室性頻拍を室上性頻拍と誤判定する臨床的帰結は、その逆の誤判定よりもはるかに重大である。ルールシステムはここで保守的な偏向を持たなければならない。

<a id="107-m5-复极异常电解质与药物"></a>
### 10.7 M5 —— 再分極異常、電解質および薬剤

本セクションのすべての結論には、「心電図所見は示唆的であり、検査室検査または臨床情報による確認が必要」という注記を付すこと。

| 記述 | 判定式 |
|---|---|
| QT 間期延長 | `QTcB > 450 ms`（男性）/ `> 460 ms`（女性） |
| QT 間期著明延長 | `QTcB > 500 ms` → 救急優先度を上げる |
| QT 間期短縮 | `QTcB < 340 ms` |
| Brugada 1 型（示唆） | V1、V2 のうち ≥ 1 誘導で `ST_J ≥ 200 μV` かつ ST 弓状下傾（`ST_slope < 0` かつ `ST_shape = CONVEX`）に続いて逆転 T 波 |
| 早期再分極 | 下壁（II, III, aVF）または側壁（I, aVL, V4–V6）で ≥ 2 個の隣接誘導に J 点ノッチまたはくびれがあり、J 点上昇 ≥ 100 μV |
| 高カリウム血症（示唆） | T 波高尖対称（`T_amp > 1.5 × 正常上限` かつ `T_symmetry ∈ [0.9,1.1]` かつ T 波基底狭小）+ `P_amp[II] < 100 μV` または P 波消失 + `QRS_dur` が予想より広大化 |
| 低カリウム血症（示唆） | `U_amp > 0.5 × T_amp` + ST 低下 + T 波低平（`\|T_amp\| < 100 μV`） |
| 低カルシウム血症（示唆） | `QTcB` の延長に伴い T 波の形態と時間的経過が正常（ST 延長による） |
| 高カルシウム血症（示唆） | `QTcB` の短縮、ST 段ほぼ消失 |
| ジギタリス効果 | ST が「フック」状下傾低下（`ST_slope < 0` かつ `ST_shape = CONCAVE` 上凸）+ QT 短縮 + T 波低平または逆転、V5、V6 で多い |

**QT 測定のためのゲート制御**：`QRS_dur ≥ 120 ms` の場合（束枝ブロック、ペースメーカ）、QT 延長の一部は分極遅延に由来する。この場合、補助として `JT` 間期（`QT − QRS_dur`）を出力し、レポートに「QRS 広大化、QTc 判読制限あり」と注記すること。

**Brugada の重要な制限**：標準的な V1、V2 位置では Brugada 型変化に対する感度が不十分であり、第 2、3 肋間での追加記録が必要である。システムが疑わしい波形を検出した場合、「高位胸電極（V1、V2 を 1–2 肋間上方へ移動）の追加記録を推奨」と出力すること。

### 10.8 M6 —— その他

| 記述 | 判定式 |
|---|---|
| 四肢誘導低電位 | 6 つの四肢誘導すべてで `QRS_amp_pp < 500 μV` |
| 胸部誘導低電位 | 6 つの胸部誘導すべてで `QRS_amp_pp < 1000 μV` |
| 全誘導低電位 | 上記の両方が同時に成立 |
| 電気的交替 | `QRS_alternans > 0.1` かつ ≥ 6 拍持続；低電位と併存する場合は「心嚢液貯留/心臓圧迫の示唆」に昇格 |
| 急性心嚢炎（示唆） | ≥ 6 誘導で広範な ST 上昇かつ上凸（`ST_shape = CONCAVE`）+ PR 低下（`PR_seg < −50 μV`）+ aVR の PR 上昇 + **鏡像 ST 低下なし**（aVR、V1 以外）+ 病的 Q 波なし |
| 肺塞栓症（示唆、低感度） | `S_amp[I] > 150 μV` + `Q_amp[III] > 150 μV` + `T_amp[III] < 0`（S1Q3T3）+ 以下のいずれか：不完全/完全右束枝ブロック、V1–V4 T 波逆転、`AXIS_RIGHT` |

**心嚢炎と STEMI の鑑別は、本モジュールにおいて最も重要かつ最も誤りやすい項目である。** 重要な区別点は「広範な分布 + 鏡像低下なし + PR 変化」である。判定が不確実な場合は、**STEMI を優先して出力し、人的レビューを強制する**（STEMI の見落としは心嚢炎の誤報よりも帰結が重大である）。

<a id="113-序列比对若存在既往心电图"></a>
### 11.3 系列比較（既往心電図が存在する場合）

系列比較は、ルールシステムが提供できる最も臨床価値の高い機能の一つであり、新規診断モジュールの追加コストよりも低い。**v1.0 の範囲に含めることを強く推奨する。**

比較項目と顕著な変化の閾値（再測定生理的変動範囲を超える場合）：

| 測定項目 | 顕著な変化の閾値 |
|---|---|
| `QRS_dur` | ±10 ms |
| `QT_int` | ±25 ms |
| `PR_int` | ±20 ms |
| `ST_J`（任意の誘導） | ±100 μV |
| `QRS_axis` | ±30° |
| `T_amp`（任意の誘導） | 極性反転、または ±200 μV |

トリガールール：

```
IF 新出现 病理性Q波:                → 输出"较前新出现 Q 波"，提升至 P1
IF 新出现 ST 抬高 ≥ 100 μV:        → 提升至 P1
IF T 波极性由正转负（≥2 相邻导联）: → 输出"较前 T 波演变"，提升至 P2
IF 基础节律改变（如窦性 → 房颤）:   → 输出"较前节律改变"，提升至 P1
IF 无显著变化:                      → 输出"与 [日期] 心电图比较大致相同"
```

比較を行う前に、2つの記録の収集条件（誘導位置、フィルタ設定）が一致していることを検証し、一致しない場合は「収集条件が異なるため、比較結果は参考のみ」と注記する。

<a id="122-置信度到措辞的映射必须固定并全系统一致"></a>
### 12.2 信頼度から表現へのマッピング（固定し、システム全体で統一する必要がある）

| 信頼度 | 表現テンプレート | 意味 |
|---|---|---|
| HIGH | "〈診断〉" | 全ての必須基準を満たし、測定が信頼できる |
| MEDIUM | "〈診断〉を考慮" | 必須基準を満たすが測定劣化要因が存在するか、または一部の支持基準が満たされていない |
| LOW | "〈診断〉の可能性あり、臨床との併用を推奨" | 基準が部分的に満たされているか、使用された基準自体の特異度が限られている |
| 棄権 | "〈原因〉のため、〈項目〉の評価が不可能" | ゲートが閉じているか、入力が UNKNOWN である |
| 提示 | "〈所見〉を提示、人工による再確認を推奨" | 高リスクの形態学テンプレートが一致した |

AHA/ACCF/HRS は、「probable」「possible」「consider」といった限定語は多様な解釈が可能であり、基準の部分的な満たしや閾値への接近を示すために使用され得ると指摘している。したがって、**本システムは本表において各限定語の正確な意味を固定し、どのモジュールにおいてもこの定義から逸脱することを禁止する**。

<a id="123-正常心电图的输出条件"></a>
### 12.3 「正常心電図」の出力条件

「正常心電図」を出力するには、以下の条件を**すべて**満たす必要がある：

```
1. L2 质量门控：12 导全部可用，无反接警告
2. 全部异常 finding 均为 FALSE（无一为 TRUE）
3. 全部 finding 均非 UNKNOWN
4. 全部测量值落在正常范围内：
     HR ∈ [60, 100]
     P_dur < 120 ms
     PR_int ∈ [120, 200] ms
     QRS_dur < 110 ms
     QTcB ≤ 450 (男) / 450 (女) ms   ← 采用更严格的下限
     QRS_axis ∈ [−30°, +90°]
5. 无 MORPH_COMPLEX、MEDIAN_BEAT_WEAK 标志
```

**UNKNOWN が存在する場合は「正常」を出力することを禁止し**、代わりに「明確な異常は見られないが、〈項目リスト〉の評価は不可能です。」と出力すること。

これは安全性の鍵となる点です。システムは「異常を検出できなかった」からといって正常と宣言してはなりません。検出できないのは、評価が不可能な場合があるためです。

<a id="124-强制人工复核触发条件"></a>
### 12.4 強制的人工复核触发条件

以下のいずれかが成立する場合、レポートにはレビューフラグを最上部に表示する必要があります：

- P0 または P1 レベルのステートメントが存在する場合
- 「ヒント」レベルのステートメントが存在する場合（高リスク形態学テンプレートに一致）
- 棄権項目が 3 つ以上存在する場合
- `MORPH_COMPLEX` または `MEDIAN_BEAT_WEAK`
- 広域 QRS 頻脈（結論に関わらず）
- 心膜炎と STEMI の区別がつかない疑いがある場合
- 使用可能な誘導が 12 未満の場合

<a id="125-陈述编码"></a>
### 12.5 ステートメントのエンコーディング

出力されるすべてのステートメントは標準化されたコードにマッピングする必要があり、SCP-ECG ステートメントコードまたは MDC_ECG コーディングシステムを採用し、SNOMED CT へのマッピングフィールドを予約することを推奨します。

理由：異なるベンダーのアルゴリズムによるステートメントテキストとデータ構造は互換性がなく、標準化を行わないと、後続のデータ分析、品質管理統計、およびクロスシステム統合が不可能になります。このレイヤーは v1.0 で構築する必要があり、後から追加するコストは非常に高くなります。

## 14. 検証およびテスト計画

<a id="141-分层验证原则"></a>
### 14.1 階層別検証原則

**各レイヤーを独立して検証し、エンドツーエンドのテストのみを行わないこと。** エンドツーエンドの指標は良好に見えますが、問題の特定ができません。また、ルールシステムの誤りは、あるレイヤーの系統的なバイアスが下流で増幅されることによるものです。

<a id="145-关于公开数据集标签的重要警告"></a>
### 14.5 公開データセットのラベルに関する重要な警告

**公開データセットのラベルの相当部分は、デバイス搭載アルゴリズムの出力 + 人工レビューに由来する。** これをゴールドスタンダードとして直接使用してパラメータを調整することは、他のベンダーのアルゴリズムのエラーに適合することになり、実際の性能を隠蔽することになります。

必須の対応策：≥ 2,000 例の独自構築ゴールドスタンダードセットを構築し、≥ 2 名の心電図専門医が独立して判読し、意見の相違は第三者が仲裁し、最終的な受入基準とする。開発プロセス中はこのセットを厳格に封印する。

<a id="146-回归测试"></a>
### 14.6 回帰テスト

ルールシステムの最大のリスクは、**境界サンプルの1つを修正する際に、すでに合格した別のサンプルを破壊してしまうこと**です。以下を確立する必要があります：

- 各診断ルールごとに、正例5件＋負例5件以上のユニットテストサンプル
- 三値論理評価器の完全な真理値表テスト
- ルール変更のたびに全量回帰テストを実行し、既存の合格サンプルが失敗に転じた場合はマージをブロック
- ゲート行列（9.4）の組合せカバレッジテスト

<a id="147-鲁棒性测试"></a>
### 14.7 堅牢性テスト

| テスト | 方法 | 合格条件 |
|---|---|---|
| ノイズ耐性 | 清浄な記録に対してNSTプロトコルに従い、ベースラインドリフト、筋電ノイズ、商用電源周波数ノイズを段階的に強度を上げて重ねる | ノイズの増大に伴い、誤判定率の上昇ではなく**棄権率の上昇**を示すこと |
| フィルタ領域の偏移 | 異なる事前フィルタ設定で同一の生記録を再処理する | 診断結論の一貫性 ≥ 95% |
| 誘導欠損 | 各誘導を1つずつ遮断する | その誘導に依存する診断は正しく棄権し、依存しないものは結論を維持すること |
| サンプリングレート | 500 / 1000 Hz の同系データを比較 | 測定値の差異が受容限界内にあること |

第1項は本システムの設計哲学に対する直接的な検証である：**ノイズ下では推測するよりも棄権せよ。**

### 15.2 データとシナリオの限界

| 限界 | 説明 |

<a id="153-需要项目层面决策的开放问题"></a>
### 15.3 プロジェクトレベルの意思決定が必要な未解決事項

1. 年齢/性別が欠損している場合、戦略A（棄権）を採用するか、戦略B（保守的閾値）を採用するか
2. 許容される棄権率の上限（臨床ワークフローにおける再審査の負担に影響）
3. 系列比較の導入の有無（導入を推奨するが、既往データへのアクセス機能が必要）
4. 安全クリティカルクラスのSe/Sp目標（臨床側との協議が必要であり、両立は不可能）
5. 記述符号体系の選択（SCP-ECG vs MDC_ECG）

<a id="154-监管相关"></a>
### 15.4 規制関連事項

医療機器ソフトウェアとして登録申請を行う場合：

- 関連する規格にはIEC 60601-2-25（診断用心電図装置）およびISO/IEC 80601-2-86が含まれる。後者の重要な変更点は、**アルゴリズムのテスト要件、テスト方法、およびデータセットは、アルゴリズムの意図された用途に応じて適用され、アルゴリズムを収容する装置の種類のみを基準としない**ことである。したがって、「我々はソフトウェアに過ぎない」ことは免責理由にはならない
- 純粋なルールベースのアプローチには、提出において顕著な利点がある：訓練データの代表性の提出が不要、データドリフト監視計画が不要、再訓練に伴う変更管理プロセスが不要。**これが本アプローチを選択する主な利益であり、プロジェクト設立文書に明確に記録されるべきである**
- 設定ファイルの各閾値変更はソフトウェア変更であり、変更管理プロセスを経由し、文献的根拠を保持する必要がある

<a id="162-排序理由"></a>
### 16.2 順序付けの理由

- **P2はP3より先**：品質ゲートはルールシステムの生命線であり、測定よりも先に確立する必要がある。境界決定を先に行い、後にゲートを追加すると、多大な手戻りが発生する
- **P3は長期かつ高リスクな項目**：境界決定の精度がシステムの上限を決定する。このフェーズを圧縮してはならない。CSEの受入に失敗した場合、その後の全ての作業の価値が損なわれる
- **P4とP5の間はスキップ不可**：発見層とルール層の疎結合は保守性の鍵であり、進捗を急ぐために特徴から直接診断へ記述してはならない
- **P6はP8より先**：リズムと伝導のルールは確実性が最も高く、臨床ニーズが最も堅固で、受入が最も容易である。先に実施することで信頼を築き、アーキテクチャの問題を早期に発見できる。虚血・梗塞は最も難しく、アーキテクチャが安定してから実施する
- **P9 系列比較はコストが低く臨床的価値が高い**ため、リソースが逼迫している場合はP7と並行して実施可能

| G1（P3出口） | CSE測定精度が全て基準を満たし、QRS検出がEC57目標を達成 |
| G2（P6出口） | リズムおよび伝導クラスが外部検証セットでSe ≥ 90% |
