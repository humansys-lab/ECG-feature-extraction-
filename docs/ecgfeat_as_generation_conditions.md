# ecgfeat 作为条件生成的特征源 —— 可用性说明

面向的用途：把 ecgfeat 当作特征提取器，为 **conditional ECG generation** 提供条件量，
控制 ST、节律、形态、梗死区域。这与诊断用途的要求不同，本文按生成的标准重新评估。

配套：[EDB ST 幅度验证](edb_st_cross_dataset_validation.md)、
[QTDB 描记验证](qtdb_cross_dataset_validation.md)、[诊断特征缺口登记](诊断特征缺口登记.md)。

---

## 0. 一句话结论

**逐导联的连续测量量可以直接用；类别标签一律不要用 ecgfeat 推断，用数据集自带标注。**

ecgfeat 的价值在于提供数据集标签表达不了的细粒度连续量
（"V3 导联 ST 在 80 ms 处压低 0.15 mV"、"QRS 电轴 +45°"、"P 波时限 110 ms"），
而不是复现标签本身 —— 后者只会引入它自己的误差。

---

## 1. 为什么不能照搬诊断结论

诊断评估问的是"报出来的准不准"，生成条件问的是三件别的事：

| 指标 | 含义 | 为什么对生成关键 |
|---|---|---|
| **覆盖率** | 非空比例 | 要求该特征非空时，还剩多少训练样本 |
| **缺失偏差** | 异常组覆盖率 − 正常组覆盖率 | **非零即警报**，见下 |
| **退化度** | 最常见取值的占比 / 变异系数 | 近似常数的特征，生成器无从"调节" |

**缺失偏差是生成独有的坑。** 一个特征算不出来就弃权，在诊断里是安全的；
但如果它在异常记录上更常弃权，那么"要求该特征非空"就等于系统性地筛掉异常样本，
生成器学到的异常分布被削掉一块。插补同样有害 —— 那是在凭空造结构。

## 2. 推荐的条件集

测量依据：`cond_feature_audit.py`，PTB-XL 250 条
（NORM / MI / ISCHEMIC / AFIB / 传导异常 各 50），2026-08-09。

### 2.1 逐导联 12 维向量 —— 覆盖 1.00、缺失偏差 0.00

```
ST     st_hybrid_j_mv, st_hybrid_60ms_mv, st_hybrid_80ms_mv,
       st_hybrid_slope_mv_per_ms, st_hybrid_baseline_confidence
形态   p_amp_mv, p_dur_ms, t_amp_mv, t_polarity, qrs_ms,
       r_amp_mv, s_amp_mv, q_amp_mv, t_symmetry
```

其中 ST 幅度是**唯一有跨数据集精度验证**的一组：EDB 上
MAE **0.099 mV**、偏倚 −0.021 mV、r **0.878**（215 个专家标注事件峰）。

### 2.2 记录级标量

| 特征 | 覆盖 | 偏差 | 退化度 | 范围 |
|---|---|---|---|---|
| `rr_cv` | 1.00 | 0.00 | **0.00** | 0.002 – 0.464 |
| `qrs_axis_deg` | 1.00 | 0.00 | **0.00** | −114° – 123° |
| `heart_rate_bpm` | 1.00 | 0.00 | 0.72 | 37 – 172 |
| `qrs_ms` | 1.00 | 0.00 | 0.76 | 80 – 206 |
| `qt_ms` | 0.97 | −0.04 | 0.88 | 247 – 497 |

`rr_cv` 是节律控制的最佳单一条件（退化度 0.00，且对房颤 vs 窦性的 AUC 达 0.913）。

### 2.3 类别条件

**用数据集自带标注**（PTB-XL 的 SCP 码）。理由见第 4 节。

## 3. 禁用清单

### 3.1 缺失系统性有偏 —— 最危险的一类

| 特征 | 覆盖率 | 缺失偏差 |
|---|---|---|
| `pr_ms` | 0.59 | **−0.34** |
| `t_axis_deg` | 0.60 | **−0.48** |
| `qrs_t_angle_deg` | 0.49 | **−0.46** |

异常记录上的覆盖率比正常低 34–48 个百分点。成因是生理性的
（房颤没有 PR、异常复极算不出 T 轴），**正因如此才危险** —— 缺失本身携带标签信息。

若必须使用：**加 mask 通道显式建模缺失**，不要丢弃、不要插补。
"房颤没有 PR"是有意义的事实，不是噪声。

`q_duration_ms`（覆盖 0.39、偏差 **+0.16**）是相反的情况：偏差为正，
因为病理性 Q 波本就只在异常上出现，它的 null 意为"没有 Q 波"而非"测不出"。
两种 null 语义不同，不可合并。

### 3.2 分布退化 + 与临床含义反相关

`st_pattern_class`（四类形态）、`st_morphology`（斜率三分类）。

实测（PTB-XL 135 条、1620 个导联，2026-08-09）：

- `horizontal` 占 **49%** 的导联，其 ST80 中位数是 **+0.001 mV** ——
  它实际表示"基线平坦"，而非类名暗示的"水平型压低"
- `downsloping` 仅 3%、`j_point_elevation` 仅 0.4% 的导联，几乎从不触发
- 作为缺血指标 **AUC 0.38–0.47（低于随机）**，而单纯的"压低导联占比"是 **0.857**
- **形态与幅度组合（0.72）反而不如只用幅度（0.86）** —— 形态是负贡献

原因：这些类只由斜率/曲率决定，**不含幅度**。静息心电图里多数 ST 段本就是平的。
临床上有意义的实体是"水平型**压低**"，不是"水平型"。

**推论**：本仓库的形态分类多是连续量的粗粒度化，
**一律取分档之前的连续量** —— `st_hybrid_slope_mv_per_ms` 优于 `st_morphology`，
`qrs_axis_deg` 优于 `qrs_axis_class`。

### 3.3 梗死区域 —— 首次评估，不通过

测量依据：`mi_territory_audit.py`，PTB-XL 各区域 50 条 + 50 条正常。
PTB-XL 的 MI 码自带区域（IMI=下壁、ASMI=前间壁、ALMI=前侧壁），可直接对照。

| 输出 | 非空率 | 命中真值区域 | 非空样本中的命中率 |
|---|---|---|---|
| `q_wave_territories` | 0.85 | 0.55 | 0.64 |
| `mi_statement_candidates.territory` | 0.75 | 0.54 | 0.72 |
| `st_territories_elevated` | **0.05** | 0.02 | — |

混淆情况（一条记录可能被赋多个区域）：

| 真值 | ecgfeat 给出的区域 |
|---|---|
| 下壁 (n=50) | inferior **32** / anterior 17 / anterolateral 12 / lateral 6 |
| 前壁 (n=50) | anterior **24** / anterolateral 16 / inferior 15 |
| **前侧壁** (n=50) | anterolateral **25** / anterior 24 / inferior 24 / lateral 18 |

**前侧壁基本无特异性**（正确 25，误判到其他三区分别 24/24/18，接近随机）。
且 **34% 的正常记录被赋予 MI 陈述**，`st_territories_depressed`
在正常组触发 0.94，**高于**梗死组的 0.64–0.74。

## 4. 为什么类别条件要用数据集标签

在 PTB-XL 上训练时，区域 / 节律 / 诊断标注**本身就是真值**。
让 ecgfeat 去重新推断，只会把它的误差注入条件：

| 条件 | ecgfeat 的误差 |
|---|---|
| 梗死区域 | 命中率 54% |
| 房颤 | 检出 67.3% |
| 房扑 | 检出 79.4% |

**两类条件分开取源，各用其长：**

- 类别 / 诊断 / 区域 → **数据集标签**（零误差）
- 连续形态量 → **ecgfeat**（标签无法表达的部分）

## 5. Q 波与 S 波：可用作几何量，不可用作病理量

测量依据：`qs_wave_probe.py`，PTB-XL NORM / MI / LVH 各 50 条、1800 个导联行。

### 5.1 无真值可对照

LUDB 与 QTDB **只标注 QRS 的起点 / 峰 / 终点，不单独标 Q、R、S**，
因此幅度与时限**没有任何参考标注可以核对**；`test_mi_qwave.py` 全是合成单元测试。

### 5.2 定义是"极值"而非"负向波"

```python
r_amp = max(0, max(seg))        # QRS 内最大正向偏转
q_amp = min(seg[:r_pos + 1])    # R 峰之前的最小值
s_amp = min(seg[r_pos:])        # R 峰之后的最小值
```

一个以 r 波起始、根本没有 Q 波的 QRS，照样得到 `q_amp_mv`，且**可以是正数**：

| | 实测比例 |
|---|---|
| `q_amp` 为正（该导联无 Q 波） | **24.4%**（中位 −0.044 mV，p90 **+0.037**） |
| `s_amp` 为正（无 S 波） | **15.7%** |
| `q_duration_ms` 有值 | 32.1% |

### 5.3 病理判别力等同随机

| 特征 | MI vs 正常 | LVH vs 正常 |
|---|---|---|
| `q_amp` | **0.512** | 0.457 |
| `q_r_ratio` | 0.589 | 0.467 |
| `q_dur` | 0.598 | 0.538 |
| `s_amp` | **0.489** | 0.498 |

`significant_q` 在**正常导联触发 10.7%**，MI 组 18.7%（仅 1.75 倍富集）。

### 5.4 但对生成而言仍然可用

生成器不需要该特征能诊断，只需要它能**忠实且可复现地描述波形**。
"R 峰前的极小值"是确定性的、100% 覆盖的几何量，作为条件维度完全可用。

**风险纯粹是解释层面的**：

- 文档与实验记述中改称 `min_before_R` / `min_after_R`，不要叫 Q 波 / S 波幅度
- 要控制"有无病理性 Q 波"→ 用数据集 MI 标签，不要用 `significant_q`
- 想要忠实的 Q 波维度 → 用 `q_duration_ms` 非空作**指示位**，
  幅度按有 / 无 Q 波**拆成两维**，不要把两个物理量塞进同一个轴

## 6. 使用须知

1. **缺失偏差是数据集相关的。** 第 3.1 节的数字来自 PTB-XL。
   换语料必须用 `cond_feature_audit.py` 重测 —— 这正是那个会悄悄扭曲学到的分布的性质。

2. **AUC 的口径。** 本文中对照 PTB-XL 记录级标注的 AUC 含标签噪声，
   且形态是逐导联而标注是记录级（缺血常只累及部分导联，聚合会稀释信号）。
   **应读相对比较**（如形态 vs 纯幅度），不要把绝对值当作分类器性能。
   EDB 上的 r = 0.878 才是对 ST 幅度更干净的测量。

3. **验证空白一览。** 以下在本仓库中从未用真实标注验证过：
   ST 四类形态、梗死区域（本文首次评估，不通过）、Q/S 波幅度与时限、
   12 导联相邻区域规则（EDB 只有 2–3 个物理通道，结构上无法验证）。
